## 척수와 고유 척추의 전체 정점 검사

원본 계층의 척수29분절과 명시된 목뼈7·등뼈12·허리뼈6·엉치뼈1, 총26개를 대조했습니다. 추간판·신경뿌리·꼬리뼈·기타 조직은 이 검사에 포함하지 않았습니다. 원본 척수147,293개·현재 표시용 척수34,566개 참조 정점을 각 뼈와 검사했으며, 모드별754쌍입니다. 현재 정적 교정 명세에 이55개 ID가 없는 것을 확인했고 런타임 포장 좌표에 피부 이동을 중복 적용하지 않았습니다.

뼈의 정확한 좌표 용접 후 연결 성분·모서리 빈도를 검사했습니다.26개 모두1성분·열린 모서리0·비다양체 모서리0·중복 꼭짓점 퇴화 삼각형0입니다. 꼭짓점 링크·자가교차·방향·실제 조직의 완전한 검증은 아닙니다. 각 참조 정점은 뼈 경계상자 밖이면 외부로, 안이면 세 방향 광선 합의와 가장 가까운 삼각형 거리로 분류했습니다.1µm 경계대는 **수치 분류 설정**이며 임상 허용치가 아닙니다.

‘거리’는 **안쪽으로 분류된 척수 정점에서 해당 뼈의 가장 가까운 삼각형까지**입니다. 전체 고체 침투 깊이·겹침 부피·척추관 협착이나 신경 손상을 뜻하지 않습니다. 원본/표시용은 정점 밀도가 달라 내부 정점 합3,772/846의 차이를 교정·면적·부피 개선으로 세지 않습니다. 같은7쌍의 존재는 조립/단순화만이 원인은 아님을 보이지만 단순화가 겹침의 세부 형상에 영향을 주지 않았다는 뜻은 아닙니다.

원본 T8척수–T7뼈의1정점은 세 광선이 불일치했습니다. 별도의 모든 삼각형 입체각 합은 winding 약0, 최근접 거리1.148073mm로 외부와 일치하지만, 원 감사의 `ambiguous`를 조용히 외부로 덮어쓰지 않았습니다.14개 모드별 최대 내부 증거는 입체각 winding 약1, 전 삼각형 최근접 거리와 차이0으로 재확인했습니다. **이15점의 별도 판독을 모든 정점 분류의 독립 재검사로 확대하지 않습니다.**

## 단면과 다음 교정의 기준

원본의 각 최대 증거 높이에서 동일한 횡단면으로 원본/표시용을 나란히 그렸습니다. 파랑은 뼈, 자홍은 척수의 실제 삼각형–평면 선분이고, 검정은 원본 검사점입니다. 조직을 채운 CT/MRI나 해부 판독 영상이 아닙니다. 표시용 칸의 검정점이 표시용 정점이라는 뜻도 아닙니다.

다음 교정에서는 흉요추 주변의 국소 관계를 다루되,29분절의 연속성·머리 쪽 연결·다른 고정 조직과의 관계를 함께 검사해야 합니다. 전체 뇌/척수를 일괄 이동하거나 골격·척수를 축소해 교차 수만 줄이는 근거로 이 수치를 쓰지 않습니다. 새 원본 영상의 신경 경계와 기하학적 충돌 제약은 서로 다른 근거입니다.

## 실행과 검토 범위

앱 파일·모형·수록·카메라·박리·선택·레이아웃은 변경하지 않았습니다. 앱 브라우저/모바일·빌드·프로덕션·201단계 박리 게이트는 이번 진단으로 반복하지 않았습니다. 기존 역사적 감사 파일은 덮어쓰지 않았습니다. 전체 남녀 위치·기관/신경 연결·실제 박리 목표는 미완료입니다.

새 기록 회귀3개를 포함해 Node310/310(건너뛰기0), 기존 단면 합성 Python4/4와 `git diff --check`가 통과했습니다. 단면 확대 제목의 ‘12mm 창’은 실제 가로/세로 범위를 동일하게 뜻할 수 있어 ‘2mm 눈금의 국소 확대’로 수정하고 재촬영했습니다.

agy 읽기 전용 대화 `2f1e42b5-e1a8-43c8-b488-dd569868907d`에서 원본 대조·기하 판독을 제한 정적 검토했습니다. 첫60초 관찰은 응답 없이 끝났지만 같은 대화를 이어 결과를 수신했고 후속 정정도 SUCCESS로 종료했습니다. 척수 파일 크기·Visible Korean으로 잘못 부른 출처·런타임 이동 중복 해석·완전한 다양체/외부 표면 일반화를 명시적으로 정정했습니다. agy가 원본 전수 계산이나 화면·임상 검증을 실행한 것은 아닙니다. 검토 이후 추가한 단면 생성·선분 재계산을 agy 검토 범위로 소급하지 않습니다.
