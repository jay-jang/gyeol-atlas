# 여성 보완 발뼈의 변환·발목 검사 — 2026-09-21

**진단 기록이며 위치 교정 배포가 아닙니다.** 현재 발뼈56개를 원본과 대조하고 두 축소 가설을 시험했습니다. 피부 이탈 감소만으로 정합을 승인하지 않았으며, 공개 좌표·가시 집합·기관 상세·박리 동작은 변경하지 않았습니다. 전체 목표는 진행 중입니다.

## 원본에서 현재 좌표까지

BodyParts3D 4.0 원본과 여성 합성 파일의 목말뼈 정점 대응으로 변환을 복원한 뒤, 양쪽 각28개 발뼈 전체에서 인덱스 배열·정점 수·변환 잔차를 검사했습니다. 대상은 `BM0124`~`BM0179`입니다. 원본·피부·청크와 검사 코드의 SHA-256은 [복원 보고서](foot-registration-baseline.json.gz)에 있습니다. 출처·라이선스는 기존 여성 manifest의 BodyParts3D 보완 기록을 따릅니다. 새로운 외부 모델 수록은 아닙니다.

| 측정 | 왼발 | 오른발 |
| --- | --- | --- |
| 복원된 세 축 공통 배율 | 약1.0762178 | 약1.0725580 |
| 전체 정점의 최대 복원 잔차 | 0.0000097354mm | 0.0000130138mm |
| 피부 포함 검사에 쓰인 참조 정점 | 8,352 | 8,490 |
| 현재 피부2mm 경계대 초과 정점 | 1,090 | 1,093 |
| 해당 정점이 있는 메쉬 | 12 | 11 |

세 특잇값이 거의 같고 행렬식이 양수여서 현재 변환은 반사나 한 축만의 늘이기가 아닌 **균일 배율을 포함한 유사변환**으로 복원됩니다. 크기를 보존하는 강체 변환이 아닙니다. 앞선 진행 안내에서 `reach`를 ‘발 길이 방향 확대’로 해석한 것은 정정합니다. manifest의 `reach`1.198/1.194와 앞 단계 배율 약0.898의 조합은 최종 균일 확대와 부합하지만, 이것이 올바른 여성 발 크기라는 뜻은 아닙니다.

양쪽 피부를2mm 간격의 수평면60개씩으로도 잘랐습니다. 기증자 피부에는 한 평면에서 복수 윤곽이 나오며 중첩 여부와 조직 안/밖의 의미는 분류하지 않았습니다. 윤곽 면적을 합하거나 정합 목적 함수로 쓰지 않았습니다. 왼쪽 변환 기증자 피부의 높이62.031mm에서 단면 알고리즘이 `Degenerate section segment`를 반환했습니다. 이는 원본 피부 결함이나 조직 누락을 입증하지 않으며 빈 정상 단면으로 취급하지 않습니다.

## 단순 축소 가설의 결과

각 발의 목말뼈 **참조 정점 평균**을 중심으로28개 발뼈를 함께 균일 축소했습니다. 이 중심은 해부학적으로 식별한 발목 회전축이 아닙니다. `source-size`는 복원 배율의 역수, `undo-reach`는 manifest `reach`의 역수를 적용하는 비교 가설입니다. 회전·이동 최적화나 여성 크기의 독립 검증은 수행하지 않았습니다.

| 가설 | 왼발/오른발 피부 밖 정점 | 합계 | 목말뼈→종아리뼈 정점-표면 최솟값, 좌/우 |
| --- | --- | --- | --- |
| 현재 | 1,090 / 1,093 | 2,183 | 0.685 / 0.600mm |
| 원본 크기까지 축소 (`source-size`) | 423 / 344 | 767 | 1.979 / 2.085mm |
| 추가 `reach` 역수 축소 (`undo-reach`) | 30 / 7 | 37 | 4.267 / 4.357mm |

두 가설에서 새 피부 이탈·기존 이탈 거리 악화는0입니다. 그러나 피부 안으로 들어가게 하는 것과 발목 관절 관계를 보존하는 것은 같은 문제가 아닙니다. 현재 목말뼈–정강뼈에는 좌28/우31개의 삼각형 쌍 교차가 있으며, 두 축소안에서는 없어집니다. 큰 축소안에서는 목말뼈→정강뼈 정점-표면 최솟값도 좌2.482/우2.559mm로 벌어집니다.

이 측정은 연골 간격·임상적 탈구·침투 깊이가 아닙니다. 현재의 작은 간격이나 교차를 정상 관절 기준으로 승인하지도 않습니다. **두 축소안 모두 해부 위치 교정으로 채택하기에는 근거가 부족합니다.** 검사한 발목4쌍 외에 전체 골격 쌍의 교차, 인대·근육·신경과의 연결, 각 발가락 위치는 아직 검증하지 않았습니다. 다음 교정에서는 발목 관계와 발 앞부분의 크기·방향을 독립 제약으로 다뤄야 합니다.

[모든 메쉬·세 가설·양방향 거리·교차 수치](foot-scale-audit.json). 기존 전체 피부 감사의56개 대상별 참조 정점 수·이탈 수·최대 거리를 다시 대조해 일치를 확인했습니다. 런타임 팔 교정 목록에 이56개 발뼈가 없다는 조건도 검사합니다.
