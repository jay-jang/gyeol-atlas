# 같은 여성 CT의 저장값 대조와 골격 자동 분할 선별 — 2026-09-28

**같은 Visible Human Female의 원본 DICOM 한 장과 BoneHub 파생 CT를 대조했고, 약 2mm 후보 영상에 골격 자동 분할을 실행했습니다.** 자동 결과는 캐시에만 두었습니다. HRA 여성 피부와의 정합, 관절·근육·기관·신경 관계, 임상적 정확도가 검증되지 않았으므로 앱의 여성 모형이나 박리 레이어는 변경하지 않았습니다.

## 원본 한 장으로 한정한 강도값 확인

[BoneHub 고정 버전](BONEHUB_FEMALE_SOURCE.md)의 `02_Female.nii.gz`는 `uint16`, 673×670×1727, 간격 0.722656×0.722656×1mm, NIfTI slope/intercept 1/0입니다. SHA-256은 `638c569c9a702a6c7b3f50e36fe4be8ef7acc2ab0c53d960ad19418d7f00d979`입니다. [Harvard Dataverse의 같은 여성 원본 CT](https://doi.org/10.7910/DVN/3JDZCT)에서 `VHFCT1mm-Head (100).dcm`([파일 ID 7575838](https://dataverse.harvard.edu/api/access/datafile/7575838))를 받아 배포 MD5 `c429a90d77b413d9b19e2e664cd2b56d`와 로컬 SHA-256 `0eb0922c813c97a3659cd6984be0297e2f64030b445904fc966d2b6902a386bd`를 확인했습니다. 해당 DICOM의 `RescaleSlope=1`, `RescaleIntercept=-1024`입니다.

원본 DICOM과 파생 CT의 머리 부분을 저장값 `>1500` 이진 특징으로 맞췄습니다. 이는 **영상 대응용 특징**이지 임상 뼈 임계값이 아닙니다. DICOM의 픽셀 간격1×1mm·방향 `[1,0,0,0,1,0]`·절편 두께1mm를 강제 확인하고 물리적 픽셀 간격으로 축소 비율을 계산했습니다. 시험한 z=1580–1604의 13개 후보 중 z=1592가 최상으로, 2D 이동 `(y,x)=(130,166)`, 특징 IoU 0.8554였습니다. 양쪽에 양수인 33,665픽셀의 저장값 상관은 0.9971, 파생값/원본값 선형 기울기 0.9872, 절편 7.61, 차이 중앙값 -0.55, 절댓값 차이 95백분위 99.0입니다. 영상 재표본화와 한 장의 대조 오차가 포함됩니다. 2D 이동만 탐색했으므로 미세 회전이 있다면 회귀 잔차에 남습니다.

추가로 [같은 Dataverse 데이터셋](https://doi.org/10.7910/DVN/3JDZCT)의 여성 `Ankle`·`Head`·`Hip`·`Knee`·`Pelvis`·`Shoulder` **6개 촬영 묶음 각각 숫자 순 중앙의 DICOM 한 장**을 받아 배포 MD5와 픽셀 자료를 확인했습니다. 여섯 표본 모두 재척도1/−1024, 픽셀 간격1mm, 같은 방향, 두께1mm, 음수 저장 픽셀0이며 저장값 최대는2,505–3,170입니다. [선택 파일 ID·해시·값](vhf-ct-dicom-series.json)은 `scripts/audit-vhf-ct-dicom-series.py`로 재현합니다. 각 묶음 전체나 BoneHub의 나머지 단면과의 일대일 일치를 검사한 것은 아닙니다.

이 결과는 BoneHub 영상의 저장값에서 **1024를 빼는 해석을 지지**하지만, 전체1727장·모든 조직에서 HU가 정확하다는 증명은 아닙니다. 따라서 아래 분할 입력의 이름도 `HU_candidate`로 제한합니다. [원본-파생 대응 전체 수치와 고정 해시](bonehub-ct-intensity.json)는 `scripts/audit-bonehub-ct-intensity.py`로 재현합니다.

## 오프라인 자동 골격 후보

같은 CT를 영상 가장자리를 유지하는 선형 보간으로 243×242×864(약2mm)로 줄이고, 위의 한 장에서 지지된 `-1024`를 적용했습니다. 후보 입력 SHA-256은 `92996cd3b2e8169d2fcb5456b5a02e06c6269bdeb43b19de8eac1f3421f9edf9`입니다. 원본 voxel centre와 후보 centre의 RAS 행렬 대응을 검사했습니다. 원본 및 앱 파일은 수정하지 않았습니다.

[MOOSE 공식 저장소](https://github.com/ENHANCE-PET/MOOSE)의 `clin_ct_peripheral_bones` 모델을 MPS로 실행했습니다. 설치된 모델 `Dataset666_Peripheral-Bones`는 [공식 릴리스 다운로드](https://github.com/ENHANCE-PET/MOOSE/releases/download/moosez-v.3.1.3/clin_ct_peripheral_bones_ras_07052025.zip)에서 받았고, 로컬 `checkpoint_final.pth` SHA-256은 `d12373c2f13b94abf4ed1102be2eb494020f6d075d8aca93afd9fd405d86cd47`입니다. [모델 가중치 라이선스](https://github.com/ENHANCE-PET/MOOSE/blob/main/MODEL_LICENSE)는 CC BY4.0입니다. 반환된31개 전경 라벨 영상 SHA-256은 `c9e3566b36443600051e1c7067a4cf306375fa836e863348d52a7d6918f6b150`입니다. 입력·출력·가중치는 모두 `.cache/`에만 있으며 앱이 다운로드하지 않습니다.

모델의 `dataset.json` 라벨명↔정수 대응 SHA-256 `f3d8e43a0f9dada1ec77f86fbedd6c06dc0605d2d5018ddb831c81fb382c1a6f`도 검사했습니다. 이 대응에서 두개골은23, 오른 자뼈는31, 왼 넙다리뼈는5입니다.

## 같은 여성 원본 라벨과 겹침

BoneHub가 같은 CT에 제공한 NRRD를 후보의 약2mm 복셀 중심에 최근접 표본화했습니다. NRRD LPS↔NIfTI RAS 방향·원점, 원본/후보 아핀 행렬 및 파일 해시를 검사했습니다. 아래는 **시험한10개 구조만**의 이진 Dice와 두 표본의 중심 거리입니다. 수치는 [전수 계산 JSON](bonehub-moose-bones.json)에 고정했습니다.

| 구조 | Dice | 중심 거리 |
| --- | ---: | ---: |
| 두개골·아래턱 합집합 | 0.7924 | 6.74mm |
| 오른 쇄골 / 어깨뼈 | 0.9017 / 0.8404 | 1.49 / 5.55mm |
| 오른 위팔뼈 / 노뼈 / 자뼈 | 0.9176 / 0.8766 / 0.8073 | 10.16 / 1.71 / 18.37mm |

| 왼 넙다리뼈 / 무릎뼈 | 0.9605 / 0.9306 | 0.56 / 0.83mm |

자동 후보는 특히 오른 자뼈·두개골에서 원본 라벨과 상당히 다르고, BoneHub 원본 자체도 팔꿈치 CT 결손을 명시합니다. Dice가 높은 넙다리뼈도 같은 원본 분할과 **저해상도 일치**한다는 뜻일 뿐, 피부 안 위치·관절 접합·임상 검수나 HRA 자세 정합 승인 결과가 아닙니다. 이 모델에는 골반·척추·갈비뼈·손발의 개별 마디, 근육·장기·신경이 모두 들어 있지 않습니다. 따라서 기존 차용 골격을 바로 대체하거나 여성 전체 기관이 완성됐다고 표시하지 않습니다.

원본 라벨을 약15:1 체적비로 줄일 때 대표점 하나만 택했으므로 얇은 뼈의 Dice·복셀 수가 표본화에 민감합니다. 후보의 더 큰 복셀 수를 **자동 분할 과잉이라는 원인으로 단정할 수 없으며**, 다수결/체적 점유 재표본화와 표면 거리 대조가 필요합니다. 이 초기10개 검사에서는 오른 상지·왼 하지로만 대조했고 손발 4D 다층 NRRD를 제외했습니다.

### 후속: 양쪽 팔·다리·손·발을 포함한 31라벨 선별

위 초기10개 범위의 비대칭을 [31라벨 전체 기록](bonehub-moose-all-bones.json)으로 확장했습니다. 손·발의 4D NRRD를 실제 `(레이어, 라벨값)` 쌍으로 읽고, MOOSE의 손목뼈/손가락/손허리뼈·발목뼈/발가락/발허리뼈 **묶음 라벨**에 대응하는 각각의 원본 뼈를 합쳤습니다. 양쪽 쇄골·어깨뼈·위팔뼈·노뼈·자뼈와 넙다리뼈·정강뼈·종아리뼈·무릎뼈, 두개골까지 모델의 전경31/31개를 검사했습니다. 대응하는 원본 세그먼트는 중복 없는90개이며, BoneHub 전체143개의 검사라는 뜻은 아닙니다. 원본9개 NRRD의 LPS 좌표와 CT RAS 아핀 행렬 최대 성분 차이는0, 원본↔축소 CT 복셀 중심의8개 모서리 최대 세계 좌표 거리는0.0000266mm였습니다. 모델 라벨명↔정수 대응도 확인했습니다. 좌표 그리드 대응은 기관·관절의 해부학적 위치 승인이 아닙니다.

| 지표 | 31개 구조의 범위·대표 사례 |
| --- | --- |
| 원본 중심 복셀 하나를 택한 Dice | 0.7417(오른 손목뼈 묶음)–0.9605(왼 넙다리뼈) |
| 각 후보 복셀의 8개 내부 표본 중 4개 이상을 원본으로 택한 Dice | 0.7671(오른 손목뼈 묶음)–0.9657(왼 넙다리뼈) |
| 두 표본 방식 사이 Dice 변화 | 최소 −0.0094(왼 손가락 묶음), 최대 +0.0267(왼 손목뼈 묶음) |
| 중심 위치가 가장 크게 다른 두 구조 | 오른 자뼈18.37mm, 오른 위팔뼈10.16mm(중심 한 점 표본 기준) |

이는 앞서10개에 한정한 결과를 **대체하는 추가 범위 검사**이지, 31개를 개별 뼈31개나 완성된 여성 전신 골격으로 부르는 근거가 아닙니다. 8점 다수결은 정확한 복셀 체적 적분이 아니며, 두 방식의 차이를 모델 오류의 원인별 크기로 해석하지 않습니다. 오른 팔꿈치 주변의 큰 중심 차이는 원본 CT 결손·자동 분할 형상·저해상도 표본화 등을 분리해 표면·관절 관계로 추가 검사해야 합니다. 후보를 현재 HRA 여성 피부에 정합하거나 화면에 도입하지 않았습니다.
