# 여성 발 전체 자세 후보 — 2026-09-27

기존 정강뼈 기준 배치에서 발 앞부분이 아래로 향하는 문제를 실제 전체 발 회전으로 시험했습니다. **새 후보도 배포하지 않았습니다.** 단순히 원본 발8파일을 한 묶음으로 회전하는 것만으로 모든 피부/발목 조건을 만족한 것은 아닙니다. 후속은 [새 여성 골격 원본](BONEHUB_FEMALE_SOURCE.md)의 개별 발허리뼈·발가락 묶음과 좌표 대응을 확인하는 일입니다.

## 변환과 검사

이전 `surface-shank` 후보에서 시작합니다. 각 발의8파일에 같은 강체변환만 추가하고 형상·삼각형 순서·부위 간 관계를 보존합니다. 중심 후보는 목말뼈 상자의 중심/위쪽4분의1 지점이며, 실제 해부 관절축으로 검증된 점은 아닙니다. 좌우 축 회전(pitch) 후 수직 축 회전(yaw), 세부 탐색은 pitch→roll→yaw 순서입니다. 탐색 각도와12mm 이동 한계도 수치적 범위이지 생리적 가동 범위가 아닙니다.

초기 표본 탐색은 각 파일200정점이며, 선택된 후보는 좌우41,083/41,675정점을 모두 검사했습니다. 첫 회전의 피부 최대 거리는 왼쪽78.107→12.038mm(위쪽 중심), 오른쪽70.585→7.684mm(중심)로 줄었지만 이탈은 남습니다. [회전 기록](donor-foot-pose.json).

## 표본의 실패와 모든 정점의 재검사

| 후속 방법 | 왼쪽 전체 피부 밖 정점 / 최대 거리 | 오른쪽 전체 피부 밖 정점 / 최대 거리 | 발–정강뼈/종아리뼈 엄격 교차 쌍 |
| --- | --- | --- | --- |
| 표본 목적함수 + 약한 충돌 벌점 |2,772 /11.345mm |325 /4.663mm |왼쪽1, 오른쪽0 |
| 모든 정점 목적함수 + 약한 충돌 벌점 |1,738 /9.685mm |44 /2.520mm |좌우 각1 |
| 모든 정점 + 표면 교차 후보 거부 |2,535 /11.658mm |73 /2.641mm |좌우0 |

피부2mm 경계대 밖을 집계했습니다. **표본 목적함수의 오른쪽 이탈0은 전체 검사에서325개로 뒤집혔습니다.** 또한 목적함수에 충돌 벌점을 더하는 것만으로는 작은 충돌을 허용하면서 피부 오차를 낮추는 결과가 생깁니다. 따라서 마지막 후보는 발8파일×정강뼈/종아리뼈2파일의 삼각형 표면 교차를 탐색 중 거부하고, 저장된 Float32 세계 좌표에서 다시 검사했습니다. 그래도 피부 실패는 남아 있습니다. 세부 형상/형상 수가 다른 기존 남성 보완 발과 정점 비율을 조직 부피처럼 비교하지 않습니다.

[표본 후보](donor-foot-pose-sampled.json), [전체 정점 후보](donor-foot-pose-full.json), [교차 거부 후보](donor-foot-pose-hard.json).

검사 범위는 피부와 지정된 발목 뼈입니다. 교차0이 관절 간격, 닫힌 고체 전체의 분리, 근육 부착·혈관·신경 연결을 검증한 것은 아닙니다. 실제 관절축/표면 대응이 없는 국소 탐색의 실패를 전역적으로 정합 불가능하다는 결론으로 바꾸지 않습니다.
