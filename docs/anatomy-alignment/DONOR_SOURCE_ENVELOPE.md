# 원본 외피와 근육의 좌표 관계 — 2026-09-21

새로 받은 Original 표면과 기존 Final 근육76개를 **HRA로 옮기지 않은 동일 원본 좌표**에서 비교했습니다. `All` 표면 기준 전체 근육 정점에서 명확한 외부 판정은0, 경계대2, 판정 불일치1개였습니다. 반면 지방 조직의 껍질에는 대부분의 근육이 포함되지 않습니다. 이 구분 없이 지방 파일을 신체 외피로 사용하면 잘못된 이탈 판정이 생깁니다.
