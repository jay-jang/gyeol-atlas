2026-09-28. **후보 미적용. 공개 앱 모델·선택·박리·레이아웃은 바뀌지 않았습니다.** 이전 [공통 변위 시험](COMMON_CALF_DISPLACEMENT.md)의 뼈 이동 실패를 줄이는 실험입니다. 원본 뼈 보존은 확인했지만 초기 배치의 주변 조직 불일치와 피부 이탈이 남아 전체 정합을 승인하지 않습니다.

## 자료와 방법

사용자가 Downloads에 제공한 Denver Visible Human Female의 Final/Original STL과 Metadata의 기존 수령·해시 기록을 사용했습니다. 원본 근육 packed 데이터와 초기 공통 shank 변환도 기존 기록에 고정했습니다. 새 자료 취득이나 출처 변경은 없습니다. HRA와 같은 Visible Human Female에 기반하더라도 처리 좌표·형상 표현이 같다는 뜻은 아닙니다.

- [생성 기록](calf-bone-fixed.json): 입력 파일 SHA, 매개변수, 양쪽240단계, 원본24근육132,027정점과791,874인덱스 참조.
- [독립 재읽기와 전체 주변 검사](calf-bone-fixed-audit.json): 원본 STL 직접 판독, 지지 영역 검사, 세 가지 배치 대조.
- [화면 기록](calf-bone-fixed-captures.json): 고정 카메라8장과 SHA·표시 ID.

각 측의 초기 변환은 회전·이동·균일 배율을 포함하는 similarity이며 강체만의 변환이 아닙니다. 이후 모든 대상 조직에 같은 국소 변위를 적용합니다. 반경 R 안에서 `u(x)=c(1-r/R)^4(4r/R+1)`, 밖에서는0입니다. 단계별 도함수 노름 상계 `135|c|/(64R)`를0.25 이하로 제한합니다. 연속 함수의 가역성과 양의 행렬식은 이산 Float32 삼각형·다른 측 함수·고정 HRA 조직 사이의 관계를 보장하지 않습니다.

각 지지 구는 초기 배치된 원본 넙다리뼈·무릎뼈·정강뼈·종아리뼈 표면과1µm 이상 떨어지도록 제한했습니다. 보호하는 것은 **원본 뼈 표면**이지, 원본과 정확히 일치하지 않는 HRA 대상 표면이 아닙니다. HRA 뼈 자체는 고정된 비교 대상입니다. 반경3–80mm, 단계 변위 최대5mm, 피부1,000표본/측과 결정론적 후보 중심을 사용합니다. 뼈400표본씩은 가중치0인 진단용이며 피부만 목적함수에 기여합니다. 면적 가중 표본이나 해부학적 표지점 대응은 아닙니다. 근육은 최적화에 사용하지 않고 결과를 검사합니다.

양쪽 모두240회 한도에 도달했으며 수렴 성공이 아닙니다. 피부 표본 RMS는 왼쪽10.363→7.637mm, 오른쪽12.300→8.887mm입니다. 선택한 원본 외피48,803/51,570정점 전체의 p95 거리는18.040→13.887mm /20.574→15.244mm이나, 왼쪽 최대 거리는29.229→29.418mm로 증가했습니다. 원본 외피 전체의 정합 결과로 일반화하지 않습니다.
