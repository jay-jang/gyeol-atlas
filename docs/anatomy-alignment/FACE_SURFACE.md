# 얼굴에서 맞지 않아 보이던 부분 — 2026-10-04

사용자 보고(남성 0%, 얼굴 3/4 시점): 눈의 노란 초승달, 콧구멍의 붉은 조각, 분홍 귀·입술, 목 아래의 붉은 점. 같은 카메라에서 실제 삼각형 광선으로 피부보다 앞에 오는 구조와 그 뒤 피부까지의 거리를 쟀다.

원본 해상도 피부(1,586,498삼각형)로 같은 상자를 다시 재 원인을 나눴다. 얼굴 상자에서 코근 71→0선, 목 상자에서 넓은목근 55→0선(원본 피부에서도 0)이라 단순화 탓이었다. 코연골은 원본 피부에서도 37선, 눈둘레근은 22선이 남아 원본 자료의 접촉이었다.

## 수정

1. **피부 세부 영역 추가**(`scripts/build-models.mjs`): 코·입(코뼈·위턱뼈 경계+20mm) 0.4mm, 목 앞(목뿔뼈·자루 경계+40mm) 0.6mm. 머리 0.6mm, 손·발 0.4mm는 그대로. 피부 102,392→112,478삼각형, 1.80→1.98MB. 기본 모형 6개 합계 51,967,552바이트로 52MB 예산 안이다(0.3mm 코·입은 2.07MB로 예산을 넘어 채택하지 않음). 얼굴 상자에서 코근 0, 목 상자에서 넓은목근 0, 코연골 106→76선.
2. **겹친 눈**(`src/anatomy-rendering.ts`의 `isSupplementEyePart`): BodyParts3D 눈알이 그려지는 동안 Z-Anatomy의 눈알 구성 20개(각막·공막·홍채·수정체·망막·유리체·앞방·섬모체띠·앞/뒤 구획, 좌우)는 선택되지 않으면 숨긴다. 장기를 걷어내면(84% 이후) Z 눈이 보인다. 검색·선택은 그대로다. 맥락얼기·시신경·망막중심동맥은 해당하지 않는다.
3. **겉면 기관의 피부 톤**(`SURFACE_TONES`): 피부가 불투명하게 그려지는 동안 귀·입술은 피부색, 눈알은 흰자색으로 그린다. 몸에서는 피부로 덮인 부분이고 눈은 흰자가 보이기 때문이다. 원본에서 피부와 0.9mm 이하로 맞닿는 눈둘레근 눈확부분과 코연골도 피부가 그려지는 동안 피부색이다. 피부를 걷어내거나(투명도 0.5 미만) 비교의 내부 선택 모드, 선택하면 본래 계통색(장기 분홍·근육 빨강)·선택색으로 돌아간다. 형상과 위치는 바꾸지 않았다.

경혈 표식은 다시 같은 면의 가장 가까운 점으로만 옮겨졌다(이번 최대 1.44mm, 처음 원본 대비 누적 최대 2.68mm, 3mm 초과 0).

## 검사

- 단위(`tests/face-surface.test.mjs`): 피부 톤 대상이 실제 얼굴 메쉬 6개인지, 겹친 눈 규칙이 Z 눈알 구성 20개에만 맞는지(맥락얼기·시신경·망막중심동맥 제외).
- 브라우저(`tests/browser/face-surface.spec.ts`): 0%에서 6개 구조의 실제 재질 색(피부색·흰자색)과 Z 눈 부분 미표시, 30%에서 귀=장기색·눈둘레근=근육색·Z 눈 계속 숨김, 90%에서 Z 눈 표시, 0%에서 귀 선택 시 선택색. [사용자 시점 화면](face-surface-desktop.png).
- [피부 앞 노출 기록](male-show-through.json)은 화면처럼 Z 눈 부분을 빼고 다시 만들었다(머리 보완 구조 814→616선). 피부 톤은 화면 규칙이라 광선 기록의 기하 노출 수에는 남는다.

## 한계

- 피부 톤은 표시 규칙이다. 귀·입술·눈알·눈둘레근·코연골의 형상은 그대로이며, 피부를 걷어내면 본래 위치·색으로 보인다.
- 눈은 피부가 있는 동안 흰자색 하나로 그린다. 홍채·동공은 그리지 않는다(BodyParts3D 눈알은 하나의 메쉬).
- 아래에서 올려다볼 때 목빗근·목갈비근·속목동맥 일부가 원본 피부에서도 보인다(목 상자 124선). 정면·옆·3/4 시점에서는 보이지 않았다.
- 여성(HRA) 얼굴은 이번 범위 밖이다.
