# 골반 실제 표면 정합과 좌우 영향 분리 — 2026-09-21

**골반 기준을 개선해 앞선 국소 뒤집힘은 새 검사에서 없앴지만, 근육 후보는 여전히 피부 검사에 실패해 적용하지 않았습니다.** 앱의 기하·성별 자료·선택·박리는 그대로입니다.

## 공식 원본을 먼저 대조

[공식 HRA united-female v1.5 GLB](https://cdn.humanatlas.io/digital-objects/ref-organ/united-female/v1.5/assets/3d-vh-f-united.glb)를 추가 확보했습니다.211,624,968바이트, SHA-256 `472567a56896b9b7890508da6501fbf858e56aaa30745365f7a71ade782b529c`입니다. 여기서 v1.5는 별도 골반 개체가 아니라 과거 여성 전신 참조 세트입니다. 현재 보완된 두덩뼈·궁둥뼈8개가 이 원본에서 왔습니다. 원본은 캐시에만 보존했습니다.

원본의 실제 노드 계층·세계좌표를 읽어 좌우 엉덩뼈/두덩뼈/궁둥뼈의 compact·spongy 조각12개를 현재 개별 ID와 대응했습니다. 기존 피부 공통 이동만 적용한 원본 경계와 도입 당시 manifest 경계의 최대 차이는2.78×10⁻¹⁴mm입니다. 단순화된 실제 표면도 양방향의 모든 참조 정점으로 대조했고 원본 정점→포장 표면 최대 차이는0.584mm였습니다. 경계 일치와 실제 표면 일치를 구분하며 연속 표면 전체 오차의 상한이라고 부르지 않습니다.

v1.5와v1.10에 공통으로 있는 엉덩뼈4개는 원본 참조 정점의 양방향 표면 거리 모두0이었습니다. 이 결과를 모든 골격이나 내부 조직의 버전 동일성으로 확대하지 않습니다. [원본 노드·좌표·해시·수치](hip-surface-fits.json).

## 기증자 골반을 실제 조각6개에 맞춤

각 측의 기증자 `Pelvis` STL을 같은 쪽의6개 표면 조각에 맞췄습니다. 원본 정의의 엉덩뼈·궁둥뼈·두덩뼈 조합이며, source-labelled compact/spongy 구분은 보존합니다. 기존 경계상자 변환에서 출발하고5,000개 결정적 참조 정점으로 회전·균일 배율·이동을 구했습니다. 양쪽 모두 수렴했고, 모든 참조 정점의 양방향 거리와 조각별 역방향 거리를 따로 기록했습니다.

| 모든 참조 정점의 거리 p95(mm) | 왼쪽 전→후 | 오른쪽 전→후 |

최종 표본 RMS는0.777/0.894mm지만 역방향 최대 차이는 여전히16.466/8.623mm입니다. 평균 감소를 완전한 뼈 일치로 해석하지 않습니다. 해부 표지점·부착점·임상 정합 검증은 아닙니다.

기존과 같은 유사변환 계산을 공용 함수로 옮겼습니다. 이전 허벅지·종아리6개 실행을 실제로 다시 계산하여 저장된 결과와 완전 일치함을 확인했습니다. 일반 회전·배율9조건과 잘못된 입력의 단위 검사도 추가했습니다.

좌우 분리는 반대쪽 변환의 영향을 명시적으로 없애지만 모든 지표를 개선하지는 않습니다. 새 이탈은1개 늘었습니다. 남은 최대 피부 이탈은 오른쪽 바깥쪽 장딴지근의10.675mm이고, 국소 행렬식 범위도0.267~2.510으로 큰 압축/팽창이 남습니다. 검사 정점에 음수가 없다는 것이 전역 단사성·비교차·해부학적 변형 타당성의 증거는 아닙니다. 같은 쪽 거리 가중치도 정확한 근육 부착 관계를 대신하지 않습니다.
