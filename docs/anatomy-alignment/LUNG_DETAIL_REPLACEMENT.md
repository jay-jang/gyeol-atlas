## 구현과 확인 범위

- `scripts/download-lung-source.py`: 공식4.3 관계 전체와 업로드 메타데이터를 대조하고19개 ZIP의 CRC,563개 실제 헤더/해시를 검사합니다. 원본은 `.cache/bp4-official/lung43/`, 공개 출처 기록은 `data/catalog/male-lung-source.json`입니다.
- `scripts/import-lung-details.py`: 원본 OBJ의 모든 정점·삼각형을 보존합니다. 공통 `[x*.001,z*.001+.0781112,-y*.001-.1]` 변환, Float32 위치와 정규화 Int16 법선으로 저장합니다. 쌍별 자동 정합/단순화는 하지 않습니다. 원본 면의 위치/법선 인덱스가 같은 조건을 검사합니다.
- `scripts/verify-lung-packing.py`: 별도 NumPy 판독에서563개·233,880정점·358,592삼각형을 재읽었습니다. 좌표 잔차0, 전체 면 인덱스 일치, 법선 성분은 Int16 양자화 반올림 범위 이내입니다. [재검사 기록](lung-packing-verification.json).
- `src/view-state.ts`: 전환은 기존 `detail` 액션을 거칩니다. 정확히 이전280개인 저장 묶음만278개 이전 자료 보기로 이관하고 카메라·투명도·표식 선호를 보존합니다. 퇴역 조각 선택은 임의의 새 조각으로 연결하지 않고 이전 묶음으로 복원합니다. 저장값에 두 대체 묶음이 혼합되면 거부합니다.
- `src/anatomy.ts`와 선택 카드: 기본 폐/내부/이전 자료를 명시적으로 고릅니다. 해당 보기 안에서 개별 선택·단독/전체 복원을 유지합니다. 여성 보기에는 남성 상세가 표시되지 않습니다.

이 검사는 실제 원본 수록과 변환/조작 확인입니다. 전체 폐 미세구조 수록, 혈관·기관지의 세부 연결, 피부·주변 기관과의 임상적 정합을 승인한 것이 아닙니다. 여성 보완 골격·근육 정렬과 뇌/신경 관계, 실제 근육 층서는 별도 미완료입니다.

### 실패와 후속 교정

첫 모바일 테스트는 숨겨진 데스크톱 전용 주요 기관 메뉴를 눌러 대기했습니다. 원인을 확인한 뒤 실행을 중단하고, 실제 모바일 구조 검색에서 한국어 폐실질 선택→기관 전체 진입 경로로 고쳤습니다. 이후 모바일 검사를 통과했습니다. 첫 모바일 화면에서는 이미 전체 묶음인 상태의 중복 버튼2개가 목록 공간을 줄였습니다. 이 경우에만 버튼을 숨기고 개별 선택 시에는 복원/단독 조작을 유지했습니다. 최종 화면에서 세부 목록 요약이 보이는지 확인했습니다.

`isLegacyLung`를 타입 가드로 선언한 초기 구현은 false 분기에서 이미 string[]인 `s.selection.ids`가 never로 좁혀져 타입 검사를 실패했습니다. boolean 반환으로 고쳤으며 런타임 판정은 같습니다. 이전 원본 감사의 macOS 절대경로 CI 실패는 별도 커밋876e827/실행36322517128에서 수정·배포 통과했습니다. 이들 실패를 통과한 검사로 바꾸어 기록하지 않습니다.

agy 대화 `3475216b-9a03-4233-b79f-1cae48788850`는 지정 코드7파일과 후속 변경3영역의 제한 정적 검토입니다. 첫 검토의 ‘완전 격리/100% 일치’는 실제 실행 증거가 아니며 후속에서 정적 검토의 범위를 다시 명시했습니다. 타입 오류는 주 작업자의 실제 빌드가 발견했습니다. agy가 임상 정확도·브라우저·원본 바이너리 전수를 독립 실행 검증한 것으로 주장하지 않습니다.
