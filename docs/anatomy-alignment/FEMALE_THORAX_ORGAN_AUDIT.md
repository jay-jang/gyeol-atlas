# 여성 장기–골격 표면과 같은 기증자 갈비뼈 후보 — 2026-09-28

**여성 전신에 남성 생식기관 모형이 섞여 있다는 증거는 이번 검사에서 확인되지 않았습니다.** 여성 피부는 별도 HRA 여성 모형이고, 현재 여성 보기의 남성 유래 180개는 머리·갈비뼈·팔/손·발 골격 보완입니다. 다만 이름 검사는 보이는 형상 전체의 해부학적 정합을 증명하지 않습니다. 이번에는 실제 여성 장기–골격 표면을 전수 검사하고, 같은 Visible Human Female CT에서 만든 갈비뼈가 24개 차용 갈비뼈의 대체 후보가 되는지 시험했습니다. **앱의 원본·좌표·가시 집합은 변경하지 않았습니다.**

## 현재 여성 장기–골격 표면

포장 여성 전신 1,220개에서 장기 표시 계통 301개(기본 표시 293개, 임신 참조 기본 숨김 8개)와 골격 표시 계통 321개의 **96,621쌍**을 현재 런타임 변환까지 적용해 검사했습니다. 골격 계통에는 진짜 뼈 외에 연골·연결조직이 포함됩니다. AABB 후보 뒤 BVH 삼각형 교차를 검사하고, 교차하는 모든 삼각형 쌍에서 양쪽 평면을 0.001mm 초과로 가로지르는지 확인했습니다.

| 현재 기본 표시 관계 | 교차 모형 쌍 |
| --- | ---: |
| 전체 | 203쌍 / 장기 계통 표면 65개 |
| 남성 유래 차용 골격 상대 | 177쌍 |
| 여성 HRA 고유 골격·연결조직 상대 | 26쌍 |
| 그중 소화·호흡·비뇨·심장·생식 계통 | 93·92·9·5·4쌍 |

203쌍 모두 검사식의 엄격한 평면 가로지름이 있지만, 이는 **고형 장기 관통 깊이·부피 또는 손상 판정이 아닙니다.** 폐 분절과 갈비뼈처럼 정상적인 인접 관계, 다른 표면 해상도, 원본 분할 경계가 얽혀 있으므로 177쌍을 곧바로 177개의 잘못된 뼈라고 세지 않습니다. 반대로 피부 포함만으로 내부 기관 배치가 맞다고 승인하지 않습니다. [모든 쌍·입력 해시](female-organ-bone-relations.json).

공식 HRA 여성 전신 v1.10 GLB를 포장 파일과 **독립적으로 다시 판독**했습니다. 현재 오른쪽 뒤기저 폐분절–T7은 포장 형상에서 엄격한 삼각형 교차 67개, 원본 고해상도 형상에서 139개입니다. 오른 자궁주인대–오른 엉덩뼈는 현재 51개, 공식 원본에서 70개입니다. 수치가 다른 것은 해상도가 다른 표면의 삼각형 쌍 수이며 임상 악화량이 아닙니다. 두 관계의 교차가 가져오기/성별 전환만으로 새로 생긴 것은 아님을 확인한 **제한된 두 쌍**의 원본 대조입니다. 다른 201쌍 전체의 원인까지 일반화하지 않습니다. [두 쌍 원본 재읽기](female-organ-bone-source-readback.json).

## 실제 여성 갈비뼈 24개 후보

[BoneHub 여성 골격 원본](BONEHUB_FEMALE_SOURCE.md)의 LPS mm를 앱 좌·상·앞 m 축으로 바꾸고, 짝수 흉추 T2·T4·T6·T8·T10·T12의 경계상자 중심 여섯 쌍만으로 한 개의 강체 변환과 한 개의 유사변환을 계산했습니다. 갈비뼈·피부·폐·홀수 흉추는 맞춤에 쓰지 않았습니다. 중심은 해부학적 관절 기준점이 아닙니다.

| 후보/검사 | 직접 결과 | 채택 의미 |
| --- | --- | --- |
| 강체의 홀수 흉추 T1·T3·T5·T7·T9·T11 | 중심 최대 1.724mm, 원본→HRA 표면 p95 최대 2.63mm, 역방향 최대 3.02mm | 같은 여성 흉곽 좌표 후보. 실제 갈비관절 정확도 아님 |
| 강체로 놓은 여성 갈비뼈 24개 | 실제 참조 정점 402,418개 전수에서 여성 폐곡 피부의 2mm 경계대 밖 0·분류 모호 0 | 피부 내부성만 확인. 폐/연골/혈관 관계 승인 아님 |
| 현재 남성 유래 차용 갈비뼈 24개 | 참조 정점 19,489개 전수에서 같은 분류 밖 0 | 서로 다른 해상도·모양이므로 정점 수를 개선율로 비교하지 않음 |
| 폐 분절 표면과의 교차 모형 쌍 | 현재 51, 여성 강체 53, 여성 유사변환 56 | 후보가 교차를 제거하지 않음. 해상도가 달라 쌍수만으로 우열 판단 불가 |
| 기존 갈비연골 14개와의 연결 | 현재 모든 14쌍은 삼각형 교차/접촉. 여성 갈비뼈 후보는 왼쪽 3~7번에서 최근접 참조 정점 간격 15.55–23.29mm, 오른쪽 3~6번 4.82–11.59mm | **갈비뼈만 교체하면 연결 문제가 새로 생김. 이번 후보 미적용** |

같은 카메라로 4·7·9번 양쪽 갈비뼈 6개와 고정 HRA 피부·폐분절·등뼈를 비교한 오프라인 장면을 직접 확인했습니다: [현재 앞](bonehub-thorax-current-front.png) / [여성 후보 앞](bonehub-thorax-rigid-front.png), [현재 뒤](bonehub-thorax-current-back.png) / [여성 후보 뒤](bonehub-thorax-rigid-back.png). 이 그림은 앱 화면이 아니며, 일부 갈비뼈만 표시한 진단입니다. 여성 후보의 실제 피부 포함과 흉추 표면 차이는 [전체 계산](bonehub-thorax-screen.json), 카메라·표시 ID·PNG 해시는 [화면 기록](bonehub-thorax-visual.json)에 있습니다.

## 다음 교정 조건과 재현

BoneHub 원본에는 갈비뼈와 복장뼈가 있지만 갈비연골 분할이 없습니다. 현재 남성 유래 갈비연골을 유지한 채 여성 갈비뼈만 바꾸거나, 갈라진 사이를 임의의 관으로 메워 ‘여성 원본’으로 표시하지 않습니다. 같은 기증자의 갈비연골 근거를 확보하거나 기존 연골의 출처·좌표를 제한적으로 재정합할 때에는 각 늑골–연골–복장뼈 관계, 폐·피부·혈관, 박리 중 형상 불변과 선택·모바일 화면을 함께 검증해야 합니다. 현재 자료만으로 이 연결의 임상적 완료를 주장하지 않습니다.

```sh
npm exec --yes --package=node@24.14.0 -- node scripts/audit-female-organ-bone-relations.mjs
npm exec --yes --package=node@24.14.0 -- node scripts/verify-female-organ-bone-source.mjs
npm exec --yes --package=node@24.14.0 -- node scripts/audit-bonehub-thorax-candidate.mjs
npm exec --yes --package=node@24.14.0 -- node scripts/capture-bonehub-thorax-candidate.mjs
```

처음 갈비뼈 시험은 256정점 표본과 흉추 중심만 검사했습니다. 같은 강체 후보를 모든 402,418개 참조 정점과 홀수 흉추 양방향 표면 거리로 확장하고, 남아 있는 갈비연골 연결까지 대조한 뒤 미적용으로 결론을 갱신했습니다. 폐 접촉의 존재/부재는 검사했지만 53쌍 전체의 임상적 접촉 적절성이나 후보 모든 삼각형 내부의 체표 포함을 검증한 것은 아닙니다. `agy` 도구는 현재 환경에 제공되지 않아 이번 감사의 agy 검토를 수행했다고 보고하지 않습니다. 전체 남녀 위치·기관/신경 연결과 실제 표층→심층 박리는 계속 미완료입니다.

검증: 새 보고서·입력 코드 해시·화면 해시 회귀 3/3, 전체 Node 333/333, `git diff --check` 통과. 앱과 배포 산출물이 바뀌지 않아 브라우저 상호작용·빌드·프로덕션·201단계 좌표 게이트를 이번 오프라인 후보의 성공 근거로 재실행하지 않았습니다. 최초 일회성 흉추 중심 계산은 구문 오타로 실행되지 않았으며 수정한 재실행에서 강체/유사변환 12수준 결과를 확인했습니다. 실행되지 않은 시도를 수치 성공으로 세지 않습니다.
