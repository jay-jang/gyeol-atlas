# 여성 척수–척추 표면 교차의 제한적 표시 교정

2026-09-28. **여성 전신 표시용 척수 15분절만 최대 2.916mm 이동했습니다.** 원본 HRA 뇌·척수·골격 파일, 남성/여성 CT 별도 자료, 수록 구조, 검색 ID, 경혈과 공통 보기 상태는 바꾸지 않았습니다. 이것은 원본에서 확인된 척수–척추 삼각형 교차를 줄이는 **기하학적 부분 교정**이지, CT/MRI에 맞춘 신경 경로·임상 해부학적 정합 완료가 아닙니다.

## 선택한 이동과 앞선 실패의 구분

[기관별 척수 v1.1 원본 대조](NEURAL_COMPONENT_SOURCE.md)에서 척수–척추 7쌍이 원본/표시용 모두 실제로 교차했습니다. [첫 국소 이동 두 후보](CORD_SHEAR_CANDIDATES.md)는 새 교차를 만들거나 6쌍을 남기고 유한 선형 제약도 충족하지 못해 미적용입니다. 이번 후보는 그 선형화의 접선·방향 가정을 재사용하지 않았습니다.

7개 최대 겹침 증거의 높이에서 각각 ±0.137mm 평면을 잘랐습니다. 세 평면은 척수 분절 끝을 벗어나 단면이 없어 **14개 중 11개만 유효**했습니다. 유효 단면의 척수/근처 뼈 선분은 1nm 좌표 반올림으로 공유 끝점을 대조했을 때 모두 차수 2였고, 그 한정된 단면에서 0.5mm 간격의 X/Z 25×25 이동 격자를 검사했습니다. 실제 선분 교차·포함을 함께 배제하는 18개 공통 격자점 중 원점에서 가장 가까운 `X −1.5mm, Z +2.5mm`를 골랐습니다. 이는 **11개 평면의 유한 격자 근거**이지 전 높이·연속 공간의 실행 가능성 증명은 아닙니다. [전 격자·원본 해시](cord-section-clearance.json), [합성 단면 검사](../../scripts/test-cord-section-clearance.py).

같은 높이의 모든 척수 분절에 동일한 compact cubic B-spline 이동을 적용하고, y=1.11–1.31m 밖은 정확히 고정했습니다. 29개 중 15개가 일부 이동했고 C1/S4 등을 포함한 14개는 전체 정점이 고정입니다. 저장 정점 최대 변위는 2.915474mm입니다. 연속 함수는 높이를 보존하고 같은 높이에서 단면을 축소하지 않으며, 이동량을 빼는 역함수·Jacobian 행렬식 1을 갖습니다. 런타임은 원본 Int16 법선을 읽어 변형의 역전치 미분으로 정규화합니다. 이 수학적 성질은 **저장된 삼각형의 자가교차·신경뿌리 연결·해부 정확도 보증이 아닙니다.** [정적 설정](../../data/catalog/female-cord-registration.json), [오프라인 후보](cord-section-grid-shift.json).

## 실제 3D 감사

원본·표시용 각각 척수 29×척추 26=754쌍의 모든 참조 정점과 엄격한 삼각형 내부 교차 증거를 검사했습니다. 기존 기준의 내부 정점 발생 3,772/846과 교차 7/7쌍은 후보에서 모두 0이었습니다. 척수끼리 406쌍 중 기존 교차 28쌍의 **정확한 쌍 집합은 유지**되고 새 쌍은 0입니다. 이동한 분절과 가까운 척추 표면의 최소 삼각형–삼각형 거리는 원본 0.181mm, 표시용 0.155mm입니다. 이는 임상 안전 여유가 아니라 이 삼각형 파일들 사이의 수치 거리입니다. [전수 쌍 기록](cord-section-grid-audit.json).

현재 여성 전신의 **다른 1,191개 고정 메쉬 전부**에 대해 이동한 15분절과 17,865쌍을 확인했습니다. 경계상자가 접근한 91쌍에서 엄격한 표면 교차는 7→0쌍, 새 쌍 0입니다. 이 파일은 피부·근육·장기·혈관·림프·뇌와 보완 골격을 포함하나 별도 CT 상세와 다른 인체 원본은 같은 좌표에 합치지 않습니다. 완전 포함, 조직 간 거리와 보이지 않는 신경뿌리 부착은 검사하지 않습니다. 런타임 적용 후의 15개 Float32 위치가 오프라인 후보와 **전부 일치**하는지도 별도로 대조했습니다. [고정 조직 감사](cord-section-grid-neighbors.json).

피부에 대한 전체 참조 정점 감사에서 여성 신경계 362메쉬·369,522정점의 피부 이탈 0은 유지됐습니다. 같은 감사에서 보완 골격 3,169정점·근육 4,060정점의 이탈은 **여전히 남아** 있습니다. 피부 포함은 척수가 척추관 중심에 정확히 위치한다는 증거가 아닙니다. [현재 전체 피부 감사](cord-grid-body-containment.json). [T11척수/T10뼈와 T12척수/T11뼈의 원본·후보 단면](cord-section-grid-source.png)을 동일 축/눈금으로 직접 확인했습니다. 파랑은 뼈 표면, 자홍은 척수 표면의 평면 교선이고 검정점은 이동 전 원본 증거점입니다. CT 영상이나 조직 채움이 아닙니다.

## 실행·표시 범위와 남은 과제

런타임은 여성 HRA 청크를 로드할 때만 정적 위치·법선을 한 번 교정합니다. 성별·계통·선택·비교·박리·위키 전이는 기존 `view-state.ts`를 그대로 사용합니다. 출처 카드에는 **원본 7쌍과 표시용 0쌍을 분리**해 적고, 신경뿌리 미수록과 영상/임상 검증 미완료를 계속 고지합니다.

Node 전체 317/317, 단면 합성 3/3, TypeScript·빌드, 표적 브라우저 2/2, 프로덕션 스모크·모바일 최소12px/대비4.5:1을 통과했습니다. 남녀 각 201개 0.5% 설정에서 각각 163,944/245,220개의 실제 세계 경계 비교는 변화 0m였습니다. 척수 상세의 데스크톱·모바일·가로 스크린샷과 두 원본 단면을 직접 확인했습니다. 브라우저 전체 시나리오를 단일 실행으로 모두 재검사한 것은 아니고, 실기기·임상 영상 판독도 하지 않았습니다. 첫 Node 실행 316/317의 유일한 실패는 감사 스크립트 변경 뒤 역사적 보고서의 파일 해시가 오래된 것이었고, 같은 구형 후보 감사를 재실행·재읽어 317/317로 수정했습니다.

agy 읽기 전용 대화 `e5eec7f6-dc81-4ead-b474-37c024865c1e`는 첫90초 호출에서 본문 없이 시간 초과됐고, 같은 대화의 후속에서 정적 코드 검토상 P1/P2를 찾지 못했다고 답했습니다. 수학적 변형·법선·버퍼 격리와 보고서 해석을 검토했지만 실제 브라우저·대용량 기하·의학 검증을 별도로 수행한 것은 아닙니다. 답변의 ‘재현성 검증’과 ‘317개 테스트 통과’는 **자체 실행 결과가 아니라 기록된 증거에 대한 검토**로만 취급합니다.

현재 HRA 척수 묶음에는 신경뿌리, S5·미수 분절이 없고 뇌–척수 접합과 개별 분절의 임상적 위치·주행을 판정할 영상 경계가 없습니다. 독립 CT 원본의 보정값/정렬도 [아직 미확인](CT_INTENSITY_PROVENANCE.md)입니다. 이 결손을 그럴듯한 표면 이동만으로 채우지 않습니다. 전체 여성/남성 전신 기관 정합, 보완 근육·골격, 실제 근육 층서와 0.5% 깊이 해부 요구는 미완료입니다.

```sh
.cache/female-ct-venv/bin/python scripts/test-cord-section-clearance.py
.cache/female-ct-venv/bin/python scripts/audit-cord-section-clearance.py
npm exec --yes --package=node@24.14.0 -- node scripts/generate-cord-section-grid-shift.mjs
npm exec --yes --package=node@24.14.0 -- node scripts/audit-cord-shear.mjs --grid-shift
npm exec --yes --package=node@24.14.0 -- node scripts/audit-cord-grid-neighbors.mjs
.cache/female-ct-venv/bin/python scripts/capture-cord-section-grid.py
```

오프라인 대용량 원본/후보 기하는 `.cache/neural-component-source/`와 `.cache/cord-section-grid-shift/`에만 있고, 앱에는 런타임 정적 이동 계수만 들어 있습니다. 회귀 검사는 원본 계층·전체 ID·후보 기록을 확인하지만 이 대용량 감사를 매번 실행하지는 않습니다.
