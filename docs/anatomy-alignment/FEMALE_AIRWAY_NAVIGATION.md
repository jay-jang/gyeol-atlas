# 여성 기관·기관지 나무 상세 탐색 — 2026-09-28

여성 HRA 전신 v1.10의 `HRA:tracheobronchial_tree` 개념에 속하는 **실제 36개 메쉬**를 주요 기관의 별도 상세 화면으로 연결했습니다. 기관·기관분기부·좌우 기관지와 그 원본에서 분리한 연골 7개가 포함됩니다. 기존 `HRA:lungs` 27개 폐 모형과는 서로 다른 수록 집합이며, 기관지를 폐 실질이라고 바꾸어 표시하지 않습니다. 목록에서 전체 묶음 또는 각 원본 메쉬를 선택·확대할 수 있습니다. 여성 보기에는 남성 모형을 추가하지 않았습니다.

`public/models/female/atlas-female.json`의 개념 `elements`와 별도 탐색 오버레이 `data/female-airway-groups.json`의 36개 ID를 순서까지 대조했습니다. 생성 산출물 `female-organ-groups.json`과 원본 여성 카탈로그는 고치지 않아 원본 가져오기를 다시 실행해도 상세 진입점이 유지됩니다. 모두 `respiratory` 원본 계통이며 여성 카탈로그에 존재합니다. 원문 영어 이름·HRAF ID는 그대로 두고, 런타임 탐색 경로에 한국어 묶음명을 덧붙여 `기관지 나무` 검색으로 36개가 나타납니다. 이는 각 가지의 개별 한국어 명칭을 검수했다는 뜻이 아닙니다. 이미 포장된 형상·좌표·가시 규칙·0.5% 박리 공식은 변경하지 않았습니다. 상세 진입과 복귀는 기존 `src/view-state.ts` 경로를 사용하고, 검색으로 단일 기관지를 고르면 같은 원본 묶음으로 돌아갈 수 있습니다.

실제 장면에서 50.5% 여성 박리→상세 36개→오른 앞기저 기관지 `HRAF0808` 단독→모바일→새로고침→전체 36개→전신 복귀를 검사했습니다. 세부 선택에서 장기 레이어로 전환하고, 전신 복귀에서 이전 50.5%·표시 모드·표식 선호가 유지됐습니다. [데스크톱 전체](female-airway-desktop.png), [모바일 단독](female-airway-mobile.png), [모바일 전체](female-airway-mobile-whole.png)를 직접 확인했습니다. 모바일 카드는 장면 아래쪽에 떠 있으며 화면 너비를 넘지 않습니다. 실기기와 다른 브라우저의 사용성은 검증하지 않았습니다.

이것은 **수록된 표면을 찾아보는 기능**입니다. 기관지 36개가 실제 기증자의 미세 기도 전체라는 뜻도, 폐·혈관·신경과의 연결 또는 박리 중 해부 위치가 임상적으로 맞다는 증명도 아닙니다. 여성 위·상체 근육·일부 말초신경 미수록과 차용 골격 정렬 문제는 그대로 남습니다. 로컬 `agy` CLI를 찾았으나 현재 `127.0.0.1` 바인딩이 `EPERM`으로 막혀 읽기 전용 검토를 시작하지 못했습니다. agy가 이 변경을 검증했다고 보고하지 않습니다.

[기존 장기–골격 전수 감사](female-organ-bone-relations.json)에서 이 36개 ID만 다시 집계하면, 기관지 표면5개와 남성 유래 보완 갈비뼈·빗장뼈 사이에 엄격한 표면 교차7쌍이 있습니다(원본 여성 골격 상대0쌍). 왼 셋째 갈비뼈2·왼 빗장뼈2·왼 다섯째 갈비뼈1·오른 빗장뼈1·오른 둘째 갈비뼈1쌍입니다. 이 집계는 표면 교차의 **존재**만 나타내며, 기관지가 뼈를 임상적으로 관통했다는 판정이나 깊이 측정이 아닙니다. 상세 탐색 추가가 이 위치 관계를 고친 것은 아닙니다.

검증 실행과 실패/재검사 결과는 [요구·증거표](VERIFICATION.md)에 기록합니다. 최종 코드의 TypeScript·정적 빌드는 통과했지만 실행 환경 전환 후 브라우저 전체·프로덕션·공개 확인은 완료하지 못했으므로 이번 변경을 배포 완료로 취급하지 않습니다.
