# 여성 신경–골격 원본 대조와 척수 상세 — 2026-09-27

## 위치 문제의 원인 범위

오른쪽 엉덩뼈 복원 후에도 남은 여성 신경 계통–골격 교차를 공식 원본과 현재 앱 기하로 다시 대조했습니다. 여성 신경 계통362개×골격 계통321개, **116,202쌍**을 다음 네 조합으로 검사했습니다.

| 신경 표면 | 골격 표면 | 교차 증거가 있는 모형 쌍 |
| --- | --- | ---: |
| 원본 | 원본/보완 골격 고정 |82 |
| 현재 앱 | 현재 앱 |82 |
| 원본 | 현재 앱 |82 |
| 현재 앱 | 원본/보완 골격 고정 |82 |

개수만 같다는 뜻이 아니라 **같은82쌍 모두에 네 조합의 증거가 있음을 확인**했습니다. 그중 척수–고유 척추7쌍은 동일 HRA v1.10 원본에도 있습니다. 나머지75쌍은 뇌·눈 등과 남성 유래 보완 두개골 사이의 관계입니다. 후자의 ‘원본’ 검사에서도 보완 뼈는 현재 위치·형상 그대로이므로, 이를 여성 고유 두개골 검사라고 부르지 않습니다. [행별 입력·전체 증거](female-neural-source.json).

따라서 **검사한 교차 쌍의 존재는 신경 또는 고유 골격의 단순화 해제로 해소되지 않습니다.** 교차 부위·정도·형상이 동일하다는 결론은 아닙니다. 원본을 그대로 복원한 뒤 전체 정합이 해결됐다고 보고하거나, 교차 수만 줄이려고 척수·뇌를 임의 이동/축소하지 않았습니다. 다음 위치 교정에는 척수–척추의 원본 관계와 보완 두개골–뇌/눈 관계를 분리한 기준이 필요합니다.

## 기하 판독과 한계

- 고유503개는 HRA 원본에서 읽었습니다.495개는 v1.10, 복원 두덩뼈/궁둥뼈8개는 v1.5입니다. 보완180개는 현재 앱 자료입니다.
- 원본 계층 세계좌표 변환과 기존 피부 공통 이동 후 Float32로 비교합니다. 실제 앱 쪽에는 오른쪽 엉덩뼈 복원·팔/발가락 정적 보정을 적용했습니다.
- 별도 `@gltf-transform/core` 판독기로 고유503개·**3,572,307정점**의 변환 결과 해시를 대조했습니다. [독립 판독](female-neural-source-readback.json). 임상 해부 검증이나 교차 알고리즘 전체의 독립 검증은 아닙니다.
- 각 쌍의 첫 삼각형 내부 관통 증거를 저장합니다. 지지 평면 양쪽으로1µm 초과 가로지르는 경우만 받으며, 총 교차 삼각형 개수·침투 깊이·신경 손상을 측정하지 않습니다. 검출0도 고체 포함/분리나 신경공 주행의 타당성을 증명하지 않습니다.
- 신경/골격은 표시 계통입니다. 공간·감각기관·지지 조직·연골 등이 섞여 있으므로 모두 신경세포나 독립된 뼈 개수라고 부르지 않습니다. 이번에는 남성이나 독립 CT 상세를 다시 검사하지 않았습니다.

## 척수 전체/분절 상세

원본 `VH_F_spinal_cord`는 자체 메쉬가 없는 그룹 노드373이며 실제 하위29개 모형이 있습니다. 원본 GLB 계층과 포장 매니페스트의 구성 ID를 일대일 대조했습니다. 화면의 **‘척수 수록 분절 전체 상세 보기’**는 이 모형만 함께 보여줍니다.

- 경수 C1–C8·흉수 T1–T12·요수 L1–L5·천수 S1–S4, 총29개. 이 계층에 없는 S5·미수 분절·신경뿌리를 추가하거나 포함된 것으로 표시하지 않습니다.
- 기존 개별 조각 선택에서 전체 상세로 들어가고, 분절별 선택과 전체 모형 복귀를 제공합니다. 기존 `view-state`의 `detail`/`select`/박리 전이를 사용합니다.
- 한국어 검색용 이름을 추가하고 원문 영어 이름·HRAF ID·원본 개념 ID는 보존했습니다. 척수 조직을 척수 중심관 공간으로 바꾸지 않았습니다. 한국어 표기는 전문가 미검수입니다.
- 원본 파일 순서의 T7·T8·T6을 화면 목록에서 T6·T7·T8로 정렬합니다. 정점이나 원본 식별자를 바꾸지 않습니다.
- 대퇴골 전용이던 ‘관절연골 포함’ 요약을 묶음별 설명으로 분리했습니다. 척수에는 수록 범위와 **원본 척추와 교차7쌍·위치 교정 미완료**를 표시합니다.
