# 기관 상세 직접 진입의 시점 복귀 — 2026-09-28

주요 기관 목록에서 상세를 **바로** 열면 `view-state.ts`의 복귀 기록에 박리 깊이·레이어는 저장됐지만 카메라는 빠져 있었습니다. 이미 일반 구조를 선택한 뒤 상세를 열 때만 `selectionReturn.camera`가 전달되어 같은 버튼이 다른 시점 복귀 규칙을 가졌습니다. 상세 화면이 구조를 확대해 카메라를 바꾼 뒤 ‘전신으로 돌아가기’를 누르면 원래 시점 대신 전신 자동 맞춤으로 이동했고, 상세에서 경혈을 고르는 경로도 자동 맞춤을 사용했습니다.

공통 `returnView`에 진입 직전 카메라를 저장했습니다. 상세 복귀·선택 해제·경혈 전환은 해당 시점으로 돌아가고, 카메라 정보가 없는 과거 저장 상태는 기존의 안전한 자동 맞춤을 유지합니다. 별도 CT/BP4 원본에서 전신으로 돌아올 때에는 전신 모형 로딩 완료 뒤 저장 시점을 적용하도록 하여 출처 전환의 일반 자동 맞춤이 이를 다시 덮지 않게 했습니다. 성별을 바꾸면 대기 중인 시점을 버리고 새 성별 화면을 맞춥니다. 원본 모형·해부 좌표·기관 묶음·0.5% 박리 공식·표식 선호는 변경하지 않았습니다. 같은 카메라 객체를 상세 안에서 갱신하는 것이 아니라 `onPose`가 새 위치 배열을 상태에 전달하므로 복귀 기록의 이전 배열은 유지됩니다.

수정 전 새 단위 검사는 직접 상세 진입의 `detailReturn.camera === undefined`로 실패했습니다. 수정 후 여성 뇌 상세의 50.5%→확대→저장 복원→전신 복귀/경혈 선택에서 원래 카메라·박리 상태를 확인했고, 기존 공통 상태·여성 기하 표적24/24를 통과했습니다. 전체 Node 회귀는337/338이며 HTTP 경계 검사1건만 `127.0.0.1 listen EPERM`으로 실패했습니다. TypeScript와 정적 Vite 빌드는 통과했고, 새 브라우저 시나리오4개는 목록 등록을 확인했습니다. 남성 심장·여성 뇌·별도 여성 CT 위의 직접 진입→새로고침→복귀, 심장 상세→경혈을 검사하도록 했지만, 로컬 포트 제한 때문에 일반 브라우저 검사는 시작하지 못했습니다. 정적 빌드를 브라우저 요청에 직접 제공하는 `node scripts/check-direct-detail-camera-offline.mjs`도 시도했으나 Chromium 시작 직후 macOS Mach 포트 `Permission denied (1100)`으로 종료됐습니다. **최종 앱 브라우저 실행과 새 데스크톱/모바일 화면 검토는 미완료**입니다. 두 환경 오류를 앱 회귀 실패 또는 시각 검사 성공으로 세지 않습니다. 따라서 이 수정은 아직 상호작용 출시 완료 판정이 아닙니다. 기존에 캡처한 화면은 이 새 전이의 검증으로 재사용하지 않습니다.

이 교정은 상세와 직전 보기 사이의 시점을 다룹니다. 남녀 기관·뇌·신경 형상의 위치 정합, 여성 미수록 구조, 실제 조직 깊이 순서와 모든 카메라 경로를 검증한 것은 아닙니다. 브라우저 사용이 가능한 환경에서 추가한 전이 시나리오와 데스크톱·모바일 캡처를 확인한 뒤 출시 여부를 판단해야 합니다.
