2026-09-28. 남성 심장·여성 뇌·여성 CT 위를 포함한 기관 상세에서 전신으로 돌아갈 때, 직전의 **0.5% 단위 연속 박리 깊이·계통 가시 집합·부위**를 다시 보여주도록 공통 보기 상태를 수정했습니다. 기관의 정점·원본·해부 좌표나 실제 조직 절단 방식은 변경하지 않았습니다.

## 재현한 문제와 변경 범위

이전 `view-state.ts`는 50.5% 연속 박리에서 기관 상세를 열면 66% 등 상세 계통 단계로 바꾼 뒤, `detail-close`에서 선택만 지우고 상세 레이어를 그대로 남겼습니다. ‘전신으로 돌아가기’ 뒤에 근육·골격이 있는 50.5% 장면 대신 장기만 켜진 계통 보기가 나타났습니다. 상세 중 새 경혈을 고르거나 전신 부위를 바꿀 때도 상세 레이어/근접 시점이 남을 수 있었습니다. 이는 원본 위치가 이동한 것은 아니지만, 박리 단계에서 기관이 어긋나거나 사라진 것처럼 보이게 하는 별도 상태 오류입니다.

새 `detailReturn`은 상세 진입 직전의 `anatomyRegion`, `stage`, `dissection`, `displayMode`, `layers`, `cutaway`, `selectionTarget`만 저장합니다. 내부 세부 구조 선택과 상세 자료 간 이동에서는 최초 스냅샷을 유지합니다. 전신 복귀·선택 해제·필터 결과 보기·경혈/부위 변경은 이 상태로 돌아가되 선택/비교/단독 보기는 지웁니다. 성별·계통 버튼·슬라이더로 명시적으로 다른 상태를 선택하면 이전 스냅샷을 버립니다. 카메라·표식·투명도·검색 필터는 별도 사용자 선호로 유지하고, 상세에서 경혈을 선택할 때만 전신 카메라 맞춤을 요청합니다. 여성 CT는 여전히 HRA와 다른 장면이며 복귀 시에만 HRA 자료를 다시 로드합니다.

저장된 예전 상세 세션에는 직전 보기 정보가 없으므로 복귀 시 안전한 체표0% 전신 보기로 내려옵니다. 새 스냅샷은 복원 시 필드·범위·레이어 타입을 검사하고 손상된 저장값은 기본 상태로 초기화합니다. 현재 저장 형식은 버전4를 유지하며, 기존 버전4의 스냅샷 누락을 허용합니다.
