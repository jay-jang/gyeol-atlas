# 여성 원본 무릎 기준 초기 배치와 허벅지–종아리 연속성

2026-09-28. **전신 좌표 교정은 미완료이고 이번 후보는 앱에 적용하지 않았습니다.** [뼈 고정 종아리 시험](BONE_FIXED_CALF.md)에서 남은 실패가 초기 배치에 이미 존재함을 확인한 뒤, 같은 측 허벅지·종아리의 공통 배치를 시험했습니다. 전체 교차 수나 무릎 RMS가 작아졌다는 이유로 주변 조직 실패를 승인하지 않습니다.

## 범위와 기준 상태

Downloads로 제공된 Final STL과 기존 해시 고정 원본 근육 packed 자료를 사용했습니다. 양쪽 허벅지·종아리 **50개, 한쪽25개**의 원본402,434정점·2,414,004삼각형 인덱스 참조를 유지합니다. 기본 숨김 넙다리곧은근2개도 포함합니다. 엉덩이 근육26개 및 나머지 여성 개요 모형은 기존 좌표로 고정합니다. 전체1,220모형 중 대상50개가 포함된59,725고유 쌍을 후보마다 검사했습니다. 남성 상세·별도 여성 CT는 같은 좌표계가 아니므로 포함하지 않습니다.

세 가지 원본/표현 기준을 구분합니다.

- `current`: 실제 현재 앱의 저해상도 근육과 주변 모형. 대상 포함 교차152쌍.
- `legacy`: 같은 고해상도 원본50근육에 기존 묶음별 배치를 적용한 상태. 교차133쌍, 피부2mm 경계대 초과16,657정점. 후보와 피부 정점을 일대일로 비교하는 기준입니다.
- `sourceSameSide`: 좌표를 변환하기 전 같은 측 원본 근육끼리의 관계.600고유 쌍 중29쌍에 교차가 있습니다. 원본에도 교차가 있으므로 모든 교차를 새 배치 오류로 분류하지 않습니다.

검사 결과는 [전체 맞춤·피부·쌍 기록](knee-initial.json), [독립 산술·삼각형 증거](knee-initial-audit.json), [화면과 해시](knee-initial-captures.json)에 저장합니다. 입력/도구 파일 해시와 원본 인덱스를 보존합니다. 새 임상 표지점·기관 라벨·압력 경로는 만들지 않았습니다.

## 초기 맞춤 방법

무릎 영역은 기존 전 다리 변환에서 HRA 정강뼈 최고 Y를 중심으로 ±70mm인 고정 수치 구간입니다. 이 구간을 해부학적 관절선이라고 부르지 않습니다. 원본 넙다리뼈·무릎뼈·정강뼈·종아리뼈에서 각각400정점을 결정론적으로 선택하고, 같은 이름의 HRA 표면 최근접 점으로 반복 맞춥니다. HRA 넙다리뼈는 공식 계층16조각(연골/부착부 포함), 다른 뼈는 각1개입니다. 순수 골조직끼리의 완전 대응을 뜻하지 않습니다.

| 모드 | 적용/목적 |
| --- | --- |
| `calf-common` | 이전 종아리12개/측은 공통 shank 변환, 나머지 허벅지13개/측은 기존 묶음 변환. 이전 실험의 초기 상태를 재현하되 허벅지도 원본 해상도로 검사 |
| `whole-leg` | 기존 계층 보완 전 다리 변환을25개/측에 동일 적용 |
| `knee-only` | 무릎 구간4×400표본으로 회전·이동·균일 배율 맞춤 |
| `knee-balanced` | 무릎1,600표본에 넙다리뼈·정강뼈·종아리뼈 전체 각400표본 추가. 무릎57.1%/전체42.9% 가중 |
| `knee-fixed-scale` | 무릎1,600표본. 기존 전 다리 배율을 고정하고 회전·이동만 추가 맞춤 |

새 세 모드는 shank/whole-leg 두 초기값으로 각각 실행하여 같은 목적함수의 최종 RMS가 낮은 쪽을 선택합니다. 고정 배율 모드는 두 초기값 모두 기존 whole-leg 배율로 통일하되 표본 중심 위치를 유지한 뒤 시작합니다. 총12회는 RMS 변화1e−9m 조건으로 종료했습니다. 이는 국소 표본 목적함수의 종료이며 전역 최적이나 해부 정합 성공이 아닙니다. 면적 가중·대칭 표면 목적함수가 아니고 구간 밖 좌표로도 최근접 대응할 수 있습니다. 모든 뼈의 전체 양방향 잔차와 맞춤에 쓰지 않은4인대/측의 전체 정점–표면 잔차를 별도로 기록합니다.

같은 측25근육을 하나의 변환으로 옮긴 네 모드는 원본29교차 쌍을 유지했고 원본에 없던 내부 교차가 없습니다. 반면 혼합 `calf-common`은 넙다리두갈래근 짧은갈래–장딴지근 가쪽갈래/장딴지빗근의 양쪽4쌍을 새로 만듭니다. 따라서 허벅지와 종아리를 서로 다른 변환으로 나누는 것이 이4쌍의 원인임을 이 비교 범위에서 확인했습니다. 교차 쌍 집합의 보존을 미세 접촉·부착의 임상적 검증으로 확대하지 않습니다.

그러나 공통 변환들은 고정 엉덩이 근육과 HRA 골격에 새로운 교차를 만듭니다. 고정 배율 모드조차 새37쌍은 피부9·골격/연결 구조14·고정 근육13·변경 근육끼리1입니다. 마지막1쌍은 오른쪽 장딴지빗근–가쪽 장딴지근으로 원본에도 존재합니다. 나머지는 자동으로 정상 또는 병적 관통으로 단정하지 않고 실패 근거로 유지했습니다. 고정 배율의 전체 교차113이 현재152보다 작다는 사실로 채택하지 않습니다.

무릎 전용 맞춤의 표본 RMS는 왼쪽1.119/오른쪽1.196mm이지만 원본 배율은1.0554/1.0527입니다. 이때 전체 정강뼈 원본→HRA p95가13.672/16.537mm, 넙다리뼈는15.305/15.574mm로 커집니다. 배율을1.0110/1.0029로 고정하면 RMS는1.722/1.889mm이고 피부 이탈은 줄지만 위 실패가 남습니다. 균형 모드도 RMS2.165/2.286mm에서 완료를 승인할 수 없습니다. 인대 잔차는 모든 참조 표면 정점의 거리이지 끝점·부착점 측정이 아닙니다.

## 독립 재구성과 화면

저장된5상태 행렬을 스칼라 식으로 적용해2,012,170정점 발생의 Float32 위치 해시를 재구성했고12,070,020인덱스 참조의 원본 해시가 일치했습니다. 최대 역변환 반올림 잔차3.213e−8m, 선형부의 균일 배율/직교성 지표 잔차1.333e−15입니다. 새로운 packed 배포 모델을 검사한 것이 아니라 원본과 저장 행렬에서 계산한 위치 해시를 대조한 것입니다.

## 해석 제한·다음 실제 검사

공식 united-female v1.10 GLB의 해시와 노드 소속을 대조한 **accessor 개수 조사**에서 정강뼈는 각1,747→385정점, 종아리뼈는607→169/168정점으로 앱에서 줄었습니다. 넙다리뼈 계층은5,529→1,997/1,996, 무릎뼈는209→204입니다. 실제 원본 표면을 다시 판독해 좌표/거리 차이를 계산한 결과가 아니므로, 이 개수만으로 정렬 실패 원인을 단순화 탓으로 결론내리지 않습니다. 다음에는 변환을 고정한 채 **HRA 원본 표면과 앱 표면을 대조**하여 대상 해상도 영향을 분리해야 합니다. 동시에 원본 근육–뼈와 고정 골반/엉덩이의 연결을 유지하는 조건이 필요합니다. 현재 후보의 새로운 확대·변형을 그대로 배포하지 않았습니다.

agy는 맞춤/강체 보조 함수와 이후 감사·캡처 코드를 읽기 전용 정적 검토했습니다. 최초 응답의 ‘한쪽50개’, ‘강체7자유도’, ‘인대 끝점 거리’, 용접을 위상 보존 증거로 부르는 표현을 실제 코드 범위에 맞게 정정했습니다. 후속 응답의 원본 대상 ‘19개’는 한쪽 수이며 전체38개입니다. 응답의 PASS는 실행 결과가 아니라 정적 검토 의견으로만 취급합니다. 참조 정점 수 보고를 일관되게 보강했고, 자체 검토에서 원본에만 있는 교차도 기록에서 빠지지 않게 했습니다. 재실행의 기존 수치·형상은 같습니다. 정적 검토는 독립 수치 실행·의학적 승인이 아닙니다.
