# 여성 상지의 추가 원본 확보 — 2026-09-20

**새 여성 기준 자료를 실제 내려받아 구성·참조 좌표를 검사했습니다. 공개 여성 모델의 위치를 교정하거나 교체한 작업은 아닙니다.** 기존 팔 정합 후보가 관절 표면 교차로 거부된 뒤, 다른 여성 원본과 명시적인 관절 정의가 있는지를 조사한 결과입니다.

## 고정 원본

- 커밋: `cc986b7df66b109c1c73d4d5986553877e28b0dd`. ZIP 주석과 [공식 태그 API](https://openvt.eu/api/v4/projects/171/repository/tags/v2.0.2)의 `commit.id`를 대조했습니다. 태그 객체의 `target`과 커밋은 다릅니다.
- ZIP SHA-256: `94b9415ffdc844c14e6ff79ca5a7a79810bc7f7e8632966dedf20f7faddcf7d1`. 전체 ZIP CRC 검사와 사용한 파일5개의 개별 해시를 기록했습니다.
- 여성 서 있는 자세의 main 파일은 `SEX=0`, `STANDING=1`, `AGE=50`을 지정합니다. 남성·앉은 자세의 노드 파일을 사용하지 않았습니다. 모델 버전 헤더의 날짜는2025-08-07, 태그가 가리키는 커밋 날짜는2026-01-22로 서로 다릅니다.
- 실제 노드 파일의 길이 단위는 mm. [공식 모델 설명](https://vivaplus.readthedocs.io/en/latest/model/)의 축은 앞·왼쪽·위이며, 앱 표시 축으로 바꿀 경우 `(x,y,z)→(y,z,x)/1000`의 공통 변환이 필요합니다. 이번 감사에서는 변환도 적용하지 않았습니다.

VIVA+는 충돌·손상 연구용 유한요소 모델입니다. 여성 기준 형상이라는 점은 유용하지만, 모든 부분이 한 여성의 원형 스캔인 것은 아닙니다. [개발 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC9343945/)과 [상지 설명](https://vivaplus.readthedocs.io/en/latest/model/body-region/upper-extremities/)은 형상 출처·단순화·관절 가정을 구분합니다. 손·손목은 PIPER 여성 참조에서 유래하며, 이 사실이 개별 손뼈의 상세 수록을 보장하지 않습니다.

## 적용 판단

현재 확보한 것은 **여성 상지 교체·비교 후보**입니다. 기존 HRA 체표와 어깨·팔꿈치·손목의 대응을 검증하지 않았으므로 기존 장면에 합치지 않습니다. 92개 면/체적 부품을 기존 골격·근육 수록 개수에 더하지도 않습니다. 상체의 모든 근육, 말초신경, 상세 손가락 구조 누락이 해결된 것은 아닙니다.

후속으로 같은 원본의 표면 추출·좌표 보존·손의 세분화·관절 표면 교차를 검사했습니다(아래). 독립 상세 보기의 유용성과 HRA 대응 가능성은 아직 판단 중입니다. 기존 실패 후보를 통과시키기 위해 허용 오차를 넓히지 않습니다.

원본 main과 LICENSE는 LGPL v3 또는 이후 버전을 명시합니다. [공식 FAQ](https://vivaplus.readthedocs.io/en/latest/about/faq/)는 수정본 공개 시 같은 라이선스와 명칭 제한을 설명합니다. 변환 모델을 배포하기 전 원본·변환 코드 등 대응 소스, 라이선스, 변경 고지와 이름을 갖춰야 합니다. 이번에는 원본 ZIP·변환 형상을 앱이나 저장소에 배포하지 않았습니다. 프로젝트 코드의 라이선스를 원본 모델에 덮어씌우지 않습니다.

### agy 검토와 회귀 검사

agy 세션 `41551c87-0aa3-4944-ba31-4d3ad3900657`에서 검사기와 합성 테스트2개 파일만 읽는 제한 범위 정적 검토를 요청했습니다. 반복 키워드를 사전으로 바꾸면 앞선 PARAMETER가 사라지는 문제를 지적해 모든 PARAMETER 행을 수집하도록 바꿨습니다. PART·관절 행 수의 검사가 없다는 지적도 반영해 고정 원본의 형식과 다르면 명시적으로 중지합니다.

agy의 ‘동일 카드 아래 여러 PART/관절 레코드가 합쳐질 수 있다’는 일반화는 이번 원본에서 발생한 결함으로 확인된 것이 아닙니다. 실제 원본은 PART2행76개·PART_CONTACT3행20개이며, 읽는 두 종류의 관절 카드도 모두2행입니다. 범용 LS-DYNA 파서를 주장하거나 검증하지 않은 형식을 임의 지원하지 않습니다. 단위 테스트10/10은 파서·오류 처리의 합성 검사이며 해부 검수는 아닙니다. 수정 후 실제 원본 감사도 다시 실행했습니다.

기존 Node 단위 검사도50/50 통과했습니다. 런타임·공개 모델·UI·박리 동작을 변경하지 않았으므로 이번 원본 감사에서 브라우저 시각 게이트를 다시 실행하지 않았습니다. 전체 요구는 계속 미완료입니다.

## 후속: 실제 표면 추출과 원본 관절 검사

고정 원본에서24개 진단 그룹·삼각형101,704개를 생성했습니다. 여기에는 양측 뼈 경계면, 원본 피부, 어깨밑근, 대조용 null 표면이 포함됩니다. **24개를 새 기관 수로 세거나 앱에 넣지 않았습니다.** null 표면3개씩은 대조용이므로 실제 진단 화면에는 겹쳐 그리지 않습니다.

### 변환과 직접 검사

- 선택한8절점 solid의 공통 노드 면을 소거해 경계면을 추출했습니다. 같은 뼈의 피질·해면 부분 사이 계산용 경계는 추가 조직으로 그리지 않습니다. 쉘 두께를 임의로 돌출시키지 않습니다.
- 공통 축/단위 변환만 적용했고 원본 노드 왕복 최대 오차는1.14×10⁻¹³mm입니다. 렌더링 Float32 최대 오차는0.000060mm 미만입니다. HRA로 옮긴 결과가 아니라 원본 상대 좌표 보존 검사입니다.
- 뒤집힌 사각면을 나누는 대각선이 달라지는 문제를 수정했습니다. 공유 면은 원본 노드 ID 기준으로 같은 대각선을 사용합니다. 면의 양쪽 삼각형이 모두 바깥 방향인지 검사하며, 중복 volume cell을 거부합니다. 최종 그룹의 중복 사각면은0입니다. 이는 FE 보간 곡면이나 실제 조직 표면과 동일하다는 의미는 아닙니다.
- 앱을 실행하지 않는 별도 WebGL 진단 장면에서 전면·손 피부·손뼈·팔꿈치·어깨5개 화면을 캡처하고 직접 확인했습니다. 새 형상과 화면은 `.cache/vivaplus/`에만 있습니다. HRA나 경혈과 겹치지 않았습니다.
