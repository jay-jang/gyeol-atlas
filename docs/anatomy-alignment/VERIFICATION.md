# 성별 분리·기관 상세·연속 박리 재검증

이전 여성 공통 전신 합성(54996cc)은 이 변경으로 대체됩니다. **남녀 전체 기관을 빠짐없이 수록한 상태는 아닙니다.** 여성 위·상체 근육·일부 말초신경은 미수록이며, 임의의 남성 기관으로 대체하지 않습니다.

## agy 검토

독립 소스 검토 응답: [agy-source-review.json](agy-source-review.json), 대화 ID `7a2db3c5-8b6c-4447-83de-b33f1d28e044`. **agy는 정적 소스 검토만 수행했으며 브라우저·의학 검증은 하지 않았습니다.** 브라우저 검증은 이 저장소의 Playwright 실행입니다. 이전 대화의 재개 응답 `agy-review.json`은 작업 중 안내에 불과해 검증 판정에 사용하지 않았습니다.

- 지적1: 남성 상세 전용 BP4 검색 선택이 전신을 교체하면서 상세 맥락 없이 단독 표시될 수 있음. `detailForStructure`로 검색·3D 클릭·세부 목록 모두 명시적 상세 범위로 진입하게 수정하고 검색→83개 심장 복귀를 회귀에 추가했습니다.
- 지적2: 카탈로그에 없는 packed 파트가 있으면 가시 계수가 누락될 가능성. 현재 여성 원본과 카탈로그 ID 전체 집합이 정확히 일치함을 단위 검사로 강제했습니다. 현 데이터에서 재현된 누락은 아닙니다.

## 실행 기록

- 단위 검사: 35/35 통과. 파일 해시, 실제 정점/인덱스, 원본 기관 구성, 선택·박리·복원, 클리핑 피킹 포함.
- 빌드: 타입 검사·419문서·834앵커·Vite 빌드 통과. 앱 번들 크기 경고는 남습니다.
- 프로덕션 스모크: 남성 GLB9개, 여성 gzip15개, 위키 단독 로딩·복원·출처·브라우저 오류0 통과.
- 가독성: 모바일 표시 텍스트 최소12px 및 대비4.5:1 통과.
- 화면 게이트: 1440×900, 390×844, 360×740, 844×390 캡처·넘침 검사 통과. 후속 화면 조정은 최종 회귀에서 다시 확인합니다.
- 전체 브라우저 회귀: 17/17 통과(3.2분). 마지막 모바일 가로 여백 조정 후 기관 상세·201단계 중 계통별 대표 깊이·성별 전환을 다시 검사했고, 신규 여성 gzip503→오류 안내→재시도를 포함한3/3 추가 실행도 통과했습니다. 고유 시나리오18개를 검사했으며 단일 실행18/18이라고 표현하지 않습니다.
- 공개 Pages 결과는 배포 후 추가합니다.

검사 과정: 신규 검사에서 가시 ID의 CSV를 JSON으로 읽던 테스트 오류, 모바일에서 숨겨진 데스크톱 바로가기 클릭 및 열린 패널 뒤 상세 버튼 클릭을 발견해 실제 모바일 검색→패널 닫기→상세 진입 경로로 고쳤습니다. 중간 회귀 실패를 최종 통과로 기록하지 않았습니다. 로컬 ChatGPT 번들 Node의 네이티브 라이브러리 서명 충돌 때문에 표준 Node24.14.0으로 `npm exec --yes --package=node@24.14.0 -- npm run build`를 실행했습니다. 프로젝트 의존성을 우회 변경한 것은 아닙니다.

## 재현·용량

`npm run models:female-catalog`, `npm run models:male-details`, `node scripts/build-organ-groups.mjs`, `node scripts/audit-male-registration.mjs`로 카탈로그·기관 묶음·정렬 측정을 재현합니다. 여성 geometry는 고정 상류 커밋의15개 gzip 원본을 그대로 보존하며 첫 여성 진입에 약36MB를 로드합니다. 남성 상세는 별도 약2.5MB입니다. 출처·원본 가공·라이선스는 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md), 해시는 `data/catalog/*-source.json`에 기록했습니다.
