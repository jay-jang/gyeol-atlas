# 여성 종아리의 피부·뼈 공통 공간 변형 시험

2026-09-28. **후보 미적용.** 원본 근육24개의 명확한 피부 이탈을0으로 줄였지만, 고정 HRA 골격·인대와 새 교차18쌍이 생기고 뼈 표면 잔차가 악화됐습니다. 피부 포함만으로 정합을 승인하지 않으며 공개 모델·선택·박리는 그대로입니다.

## 기존 후보와 다른 방법

독립 뼈 변환을 거리로 섞던 [기존 후보](BONE_INTERPOLATING_CANDIDATE.md)는 일부 위치에서 음의 야코비 행렬식이 생겼습니다. 이번에는 각 측 원본 종아리 표면 맞춤을 시작점으로, 피부·뼈·근육에 **동일한 작은 공간 변위120개를 합성**했습니다. 전체 인체에 하나의 함수를 적용한 것은 아니며 좌우는 서로 다른 함수입니다.

각 단계는 `F(x)=x+c exp(-|x-a|²/(2σ²))`입니다. 변위 도함수의 전역 노름 상계는 `L=|c|/(σ√e)`이며 코드가 `L≤0.25<1`을 강제합니다. 따라서 정확한 실수의 연속 함수에서는 `|F(x)-F(y)|≥(1-L)|x-y|`이고 역함수 고정점 반복이 수축합니다. 합성도 같은 측 원본 공간의 일대일 대응을 유지합니다. **고정 HRA 조직과의 관계, 좌우 함수 사이 관계, 직선 삼각형 보간·Float32·실제 해부학적 부착 정확도는 이 수학적 성질로 보장하지 않습니다.**

피부 가중치0.5, 뼈4종 각각0.125로 한 방향 최근접 표면 거리 제곱합을 맞췄습니다. 각 측2,600표본은 피부1,000·뼈별400개이며 면적 균일 표본이 아닙니다. 대퇴골은 무릎 쪽 점만 맞춤에 사용하고, 목표 표면은 본체와15후손을 포함했습니다. 나머지는 무릎뼈·정강뼈·종아리뼈입니다. 피부는 원본 `All`에서 같은 측 정강뼈/종아리뼈에 더 가깝고 지정 높이 띠에 드는 점을 골랐습니다. 해부 부위 라벨이나 새 절단면을 만들지 않았습니다.

30/60mm 커널·5mm 최대 단일 이동·120회 한도는 시험 매개변수이며 생체 조직 성질이 아닙니다. 양쪽 모두 반복 한도에서 끝났고 **수렴했다고 기록하지 않습니다.** 근육은 맞춤에 전혀 사용하지 않았습니다.

피부2mm는 수치 경계대이지 피부 두께가 아닙니다. 근육의 ‘전’은 동일한 고밀도 원본을 기존 근육별 묶음 변환에 넣은 값이며, 공개 저밀도 모델의 정점 개수와 직접 비교하지 않습니다. 외피/뼈의 ‘전’은 공통 종아리 표면 맞춤 시작점이므로 근육의 기존 묶음 배치와 다릅니다. 전체 뼈 양방향 잔차를 기록했고, 맞춤에 쓰지 않은 대퇴골 근위부도 검사에서 제외하지 않았습니다.

현재 앱의 **1,220개 전체 모형과 변경24개가 포함되는28,980개 고유 쌍**을 대조했습니다. 팔/발 정합, 원본 장골 복원, 뇌 좌우 연결과 기본 숨김 모형도 반영했습니다. 별도 CT·남성 상세 장면은 이 여성 좌표의 대상이 아닙니다.

- 실제 앱 기준 교차 쌍80→66이지만 **새 교차23쌍**이 발생했습니다.
- 미변경 모형과 새 교차22쌍: 골격 레이어18쌍(인대·연골 포함), 허벅지 근육4쌍입니다. 총 교차 감소가 새 관계 악화를 상쇄하지 않습니다.
- 변경24개 내부의 새 교차1쌍은 오른쪽 장딴지빗근–바깥쪽 장딴지근입니다. 이는 원본에도14삼각형 쌍의 교차가 있었으나 기존 저밀도 앱에서 사라진 관계입니다. 새 변형만의 오류로 분류하지 않습니다.
- 같은 원본 해상도끼리132쌍을 비교하면 교차15→14쌍, 새 표면/새 strict 교차0입니다. 기존8쌍의 평면 가로지름 크기가0.001mm 초과 증가했고 삼각형 수가 바뀐 쌍도 있어, 이산 삼각형 관계가 전부 불변이라고 주장하지 않습니다.

골격 잔차 증가는 피부와 뼈를 단순 가중 평균으로 맞출 때 뼈 위치를 희생할 수 있음을 보여줍니다. 단지 피부를 맞췄다는 이유로 이 변형을 적용하지 않았습니다. 다음 계산은 뼈 보존/비악화를 명시적으로 다뤄야 하며, 원본 뼈 맞춤 자체도 정확한 해부 기준으로 가정하지 않습니다.

## 불일치1정점과 독립 저장 검사

왼쪽 바깥쪽 장딴지근 `VHF0020`의4793번 정점은 피부 표면에서13.693mm 떨어져 있습니다. 세 기본 광선 중 두 번째에서5번 적중 중 약0.0000611mm 간격인 두 적중을0.0001mm 병합 기준이 합쳐4회로 셉니다. 추가32방향은 모두 홀수였고, 전체 피부 삼각형의 부호 입체각 합은 `4π` 대비0.9999999999999988입니다. 이 보조 수치는 내부 판정을 지지하지만 **원래 불일치1개를 덮어쓰지 않았습니다.** 피부 전체의 자기 교차/방향 일관성·임상 내포 증명으로 일반화하지 않습니다.

별도 스칼라 계산이 저장된132,027개 정점을 다시 산출해 Float32 좌표 차이0을 확인했습니다.791,874개 인덱스 참조가 원본과 정확히 같고, BVH는 간접 인덱스를 사용해 순서를 바꾸지 않습니다. 각 근육 최소 행렬식 지점24개에서 유한차분으로 도함수를 확인한 최대 원소 차이는2.98×10⁻¹⁰입니다. 저장·산술 검증이지 독립적인 새 해부 정답은 아닙니다. 후보 바이너리4,751,820바이트(gzip2,544,257바이트)는 캐시에만 있고 공개 모델에 넣지 않았습니다.
