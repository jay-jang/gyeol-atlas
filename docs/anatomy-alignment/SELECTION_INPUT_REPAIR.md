## 실제 검사 범위

`tests/browser/selection-opacity.spec.ts`는 남성 FMA7148·여성 간의 bare area 선택에서 실제 렌더 메쉬 opacity/transparent와 저장된 alpha, 선택 해제 복원을 확인합니다.1440×900·390×844에서 선택 상자와 카드의 분리, 조작 버튼 접근과 가로 넘침을 검사합니다. 검사 대상의 세계 경계상자는 선택/해제·크기 변경 전후 동일합니다. 모든 기관의 위치 정확도나 모든 세부 모형을 검증한 것은 아닙니다.

`tests/browser/dissection-input-scope.spec.ts`는 실제 키보드/휠로 검색창·도구·캔버스 입력 범위, 작은 휠, 가로 입력과 슬라이더 위치 불변, 키를 놓기 전 초점 이탈로 이동 정지를 확인합니다. 같은 이벤트 처리 안에서4개 휠을 보내는 추가 검사는 합성 입력이며 실제 하드웨어 입력으로 표현하지 않습니다. 단위 검사는201회 전진·200회 후진·빠른 이동·경계·비정상 증감 거부와 카메라/표식 선호 보존을 확인합니다.

초기 새 검사에서 여성의 ‘확대’ 버튼을 두 개 찾는 locator 오류와, 이동 중에는 갱신되지 않는 debounced 저장 카메라를 즉시 읽은 오류가 있었습니다. 선택 카드로 locator를 한정하고 초점 이탈 후 저장값을 확인하도록 수정했습니다. 이 두 실패를 앱 결함으로 세지 않습니다. 가로 휠 후 실제 이벤트 대상이 바뀐 실패는 앱 입력 전파 문제로 구분했습니다.
