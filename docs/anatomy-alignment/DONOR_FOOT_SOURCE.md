# 여성 발뼈 원본과 전신 배치 검사 — 2026-09-27

## 결과

사용자가 제공한 Final ZIP에는 여성 발뼈가 좌우 각8파일 있습니다. 기존 하체 기준 변환3종을 적용한 좌우6후보는 모두 피부 검사를 실패해 **앱에 적용하지 않았습니다**. Original ZIP의 발가락 쪽 파일도 각 뼈로 분리된 자료가 아니었습니다. 다운로드 원본은 보존했으며, 공개 앱의 수록·선택·박리·기하는 이번 검사로 바뀌지 않았습니다.

## 출처 설명 정정

종전의 “별도 여성 기증자”, 상위 출처 문서의 “second woman”은 1차 출처로 뒷받침되지 않아 정정합니다.

- [Denver 공식 자료](https://digitalcommons.du.edu/visiblehuman/1/)와 ZIP README는 NLM Visible Human Female 영상을 이용한 별도 분할·후처리 자료임을 밝힙니다. CC BY4.0, Andreassen et al. (2023), DOI10.1038/s41597-022-01905-2.
- HRA가 NIH에 게시한 [여성 무릎](https://3d.nih.gov/entries/20969?version=1)과 [피부](https://3d.nih.gov/entries/3DPX-020986?version=1)의 설명도 NLM Visible Human Female을 지목합니다. 피부 v1.3 설명에는 몸통과 종아리·발목 공간의 수정 이력이 있습니다. 이것을 현재 united v1.10 피부와 동일한 바이트나 정확한 변형 이력으로 단정하지 않습니다.
- 실제 보관 중인 united v1.10 GLB의 `VH_F_skin`, `VH_F_tibia_L`, `VH_F_tibia_R`는 `source_spatial_entity=#VHFemaleOrgans`입니다. GLB SHA-256은 `95f0c3d2f918582608692ca1139e8bdb18c147a16470e9ee9af8b276bd77c422`입니다.

따라서 **별도 제작 자료**와 **다른 사람의 자료**를 구분합니다. 공통 영상 출처가 후처리된 자세·표면·좌표의 동일성이나 전신 조립체의 단일 기증자를 입증하지는 않습니다. Allen 뇌와 남성 보완 뼈 등의 출처 구분은 그대로 유지합니다. `THIRD_PARTY_NOTICES.md`와 `SOURCE_GAPS.md`를 수정하고, 상위 `ATTRIBUTION.md`에는 원문을 남긴 채 정정문을 앞에 붙였습니다.

## 실제 파일 수록·연결 검사

Final128 STL 중 발뼈16개와 정강뼈·종아리뼈4개를 읽었습니다. 발뼈는 총82,758개의 정확히 중복 제거한 참조 정점·165,468삼각형입니다. 원본 `Calcaneous` 철자를 기록에 보존합니다.

| Final 파일 종류 | 좌우 수록 | 연결 성분 검사 |
| --- | --- | --- |
| Talus, Calcaneous, Navicular, Cuboid, 세 Cuneiform | 각7파일 | 대부분1성분. 오른쪽 Talus는 주요1성분+2삼각형 조각2개 |
| Phalanges | 각1파일 | 왼쪽은 주요34,932삼각형+2삼각형 조각4개, 오른쪽은36,202삼각형의1성분 |

`Phalanges`는 개별 발가락뼈 이름·FMA로 자동 분리할 수 없는 묶음입니다. 작은 연결 성분을 독립 뼈로 이름 붙이지 않았습니다. 좌표의 완전 일치만 중복 제거하며 삼각형 순서·방향·형상은 보존했습니다. 경계/비다양체 모서리0이라는 검사도 임상 해부 정확도나 부피가 있는 닫힌 조직을 보증하지 않습니다.

사용자 Original ZIP에서 좌우 `Phalanges` 두 파일만 새 캐시에 추출해 압축 항목의 바이트와 대조했습니다. Original 왼쪽은 주248,072삼각형과 작은5성분, 오른쪽은255,720삼각형의1성분입니다. 전체503,888삼각형의 ASCII 구문을 검사했고, STLLoader의 Float32 판독과 별도 ASCII Float64 판독의 성분별 정점·삼각형 수가 일치합니다. 즉 **Original로 돌아가기만 하면 개별 뼈를 얻는 것은 아닙니다**. 분할 알고리즘은 두 판독에 공통이므로 독립적인 해부 분할 검증으로 주장하지 않습니다. [Original 기록](donor-foot-originals.json).

## 세 정강뼈 기준 변환 시험

새로운 피부 맞춤 최적화가 아니라 기존 가져오기 변환, 원본 계층 전체를 대상으로 구한 정강뼈/종아리뼈 표면 맞춤, 다리 전체 표면 맞춤을 시험했습니다. 발 전체에 한 공통 유사변환을 사용하고 반사·개별 뼈 변형·누락 제거는 하지 않았습니다.

피부2mm 경계대 밖을 집계했습니다. 모든 참조 정점에서 모호한 광선 판정0이지만, 삼각형 내부·정확한 관절 정합을 검사한 것은 아닙니다. 현재 남성 보완 발56개는 같은 검사에서 왼쪽685·오른쪽548정점 이탈이 유지됩니다. 두 자료의 정점 밀도·수록 단위가 다르므로 단순 정점 수의 비율을 같은 조직 부피로 비교하지 않습니다.

목말뼈–HRA 정강뼈 교차는 import-shank 양쪽 및 surface-whole-leg 왼쪽에 남습니다. surface-shank의 이4개 발목 쌍에서 교차가 없어도 발 피부 실패를 통과로 바꾸지 않습니다. 근육·혈관·신경·연골 전체 관계는 이번 검사 범위가 아닙니다.

원본 발8파일 사이 각28쌍도 검사했습니다. 변환 전부터 왼쪽 Calcaneous–Cuboid, 오른쪽 Talus–Calcaneous 및 MedialCuneiform–IntermediateCuneiform에 엄격한 삼각형 교차 증거가 있습니다. 평면 양쪽 걸침량은 최대 약0.202mm이며 실제 침투 깊이나 부피가 아닙니다. Final이라는 배포 단계 이름을 교차0 보증으로 해석하지 않습니다. [전체 감사](donor-feet-audit.json).

## 판독·화면·검토

독립 binary STL 판독과 스칼라 행렬 계산으로 후보48메쉬의 삼각형별 정점 참조1,489,212개를 재읽었습니다. 모든 저장 좌표·삼각형 순서가 Float32 계산과 일치하며 최대 산술 잔차0입니다. 이는 포함·교차 알고리즘 자체의 독립 검증이 아닙니다. [재읽기](donor-feet-readback.json).

surface-shank의 [왼쪽 정면](donor-foot-left-anterior.png)·[왼쪽 측면](donor-foot-left-lateral.png)·[오른쪽 정면](donor-foot-right-anterior.png)·[오른쪽 측면](donor-foot-right-lateral.png)을 직접 확인했습니다. 주황색 원본 발 앞부분이 청록색 HRA 피부와 다른 방향으로 뻗는 불일치가 보입니다. 독립 진단 화면이며 y=0.24m 위를 시각적으로 잘라 발목을 관찰했습니다. 앱 UI·모바일 조작 검사나 임상 자세 판정이 아닙니다. [촬영 조건](donor-feet-visual.json).

agy 제한 읽기 전용 검토 대화: `3688f7bb-5778-4acb-8a19-037d721cad23`. 최초 응답은 최대 거리·이탈 비율을 잘못 일반화하고, 유사변환을 강체변환으로, 왼쪽 Phalanges 성분 수를 양쪽 공통으로 설명했습니다. 그 응답을 검사 근거로 채택하지 않고 실제 파일값으로 후속 정정을 요청해 수치·좌우 성분 수·변환 종류의 정정을 받았습니다. 후속 응답의 작은 조각을 경계 결함으로 단정하는 해부적 해석과 모든 양자화 문제를 배제한다는 일반화는 채택하지 않습니다. 검사한 두 파일에서 성분별 정점/삼각형 수가 같다는 범위만 인정합니다. 검토 응답은 임상/실제 앱 검증을 대신하지 않습니다.

단위128/128(건너뛰기0), 프로덕션 빌드 통과. 앱 조작·레이아웃을 바꾸지 않아 기존 브라우저 상호작용/201단계 박리·모바일 UI 게이트를 이번 진단만을 위해 반복하지 않았습니다. 기존 캡처는 덮어쓰지 않았습니다.
