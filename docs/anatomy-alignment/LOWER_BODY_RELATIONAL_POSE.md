# 큰허리근–요관·총엉덩정맥 관계를 포함한 초기 자세 시험

2026-09-28. **후보 미적용. 공개 모델·수록·선택·박리·레이아웃은 바뀌지 않았습니다.** 초기 관계 일부는 개선했지만 피부·고정 골격에 새 실패가 생겼습니다.

## 시험 이유와 제한된 관계 조건

[고정 조직 보호 흐름](LOWER_BODY_PROTECTED_FLOW.md)은 초기부터 있는 교차를 제거할 수 없었습니다. 이번에는 한쪽 원본38근육과5뼈 전체의 초기 자세를 함께 조정했습니다. 개별 근육을 늘이거나 같은 근육의 윗부분만 이동하지 않았습니다.

모든 신경·혈관–근육 교차를 오류로 간주하지 않습니다. [사체6구의 큰허리근 주변 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC8867435/)는 근육 주변 신경·혈관의 복잡한 관계와 개인차를 기록합니다. [직접 사체 해부를 포함한 골반 해부 아틀라스](https://pmc.ncbi.nlm.nih.gov/articles/PMC13238165/)의 안쪽 큰허리근 공간과 인접 장골 혈관·요관 설명을 참고하되, 특정 기증자의 좌표 정답이나 정상 간격 수치를 얻은 것으로 취급하지 않았습니다.

관계 목적함수는 다음 **4쌍**에 한정했습니다. 근육 안쪽2mm 경계대 초과 표본점의 최근접 표면 거리를 줄이는 수치 가설입니다. 이2mm는 진단 허용차이며 정상 해부 간격이나 임상 관통 깊이가 아닙니다.

| 근육 | 고정 HRA 대상 |
| --- | --- |
| 왼 큰허리근 `VHF0034` | 왼 요관 `HRAF0608`, 왼 총엉덩정맥 `HRAF0653` |
| 오른 큰허리근 `VHF0072` | 오른 요관 `HRAF0592`, 오른 총엉덩정맥 `HRAF0654` |

요관의 전방/안쪽 주행, 혈관 연결, 다른 조직의 정상 통과를 이 목적함수로 확인하지 않습니다. 고정 HRA 대상 자체의 정확성도 별도 문제입니다. 다른 조직은 이 포함 벌점으로 밀어내지 않고 전체 사후 교차 검사에서 확인했습니다.

## 공통 강체 조정과 탐색

기존 측별 whole-leg similarity로 배치한 Float32 좌표를 시작점으로 삼았습니다. 원본76근육 모두 연결 성분1·경계 모서리0·비다양체 모서리0·중복 정점 퇴화 삼각형0을 확인했습니다. 이것만으로 자기 교차 부재나 모든 형상 퇴화·해부 정확도를 증명하지 않습니다.

각 측5뼈의 합성 경계상자 중심을 피벗으로 삼아 회전벡터3개·이동3개를 탐색했습니다. 후속 변환은 proper rigid이며 새 배율을 맞추지 않습니다. 처음부터 있던 similarity 배율은 유지합니다. 이동 벡터 노름20mm·회전벡터 노름5° 이내, 처음 이동 증분2mm/회전0.01rad, 개선이 없으면4번 절반으로 줄였습니다. 최대80회 중 양쪽 모두 최종 증분에서12개 좌표축 이웃에 개선이 없어 종료했습니다. 전역 최적해나 임상 수렴이 아닙니다.

각 측 뼈5개×200점, 근육38개×64점, 관계 대상2개×256점을 결정론적으로 선택했습니다. 뼈 항은 그룹별 평균 거리 제곱, 피부 항은 근육 표본의 피부 밖2mm 초과 거리 제곱, 관계 항은 대상별 평균 근육 안2mm 초과 거리 제곱입니다. 가중치1:4:20은 실험 설정이지 해부학적 중요도 척도가 아닙니다. 근육 역변환 공간에서 고정 대상점을 검사하여 매 후보마다 근육 BVH를 다시 만들지 않았습니다. 광선 판정이 엇갈린 후보는 무한 손실로 거부했으며 왼쪽1회·오른쪽0회였습니다.

실제 평가385/325회. 피벗 이동6.701/2.872mm, 회전1.569/3.527°입니다. **20mm는 이동 매개변수의 제한이지 모든 정점의 이동 제한이 아닙니다.** 회전에 의한 이동까지 포함한 정점 최대 변위는21.609mm였습니다.
