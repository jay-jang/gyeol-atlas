# 뼈 표면과 피부 경계의 공통 변형 시험

2026-09-28. **후보 미적용**. [기준 뼈 보간](HIP_INTERPOLATING_MUSCLES.md) 이후 남은 골격 잔차와 피부 이탈을 함께 줄였습니다. 표본 목적함수는 개선됐지만 새 피부 이탈287정점과 새 고정 조직 교차11쌍이 발생했습니다. 공개 모형·성별 선택·박리는 변경하지 않았습니다.

## 방법과 기준선

입력은 이전의 미승인 inverse-fourth 후보 바이너리입니다. `initial`은 이 후보이고, `current`는 공개 앱, 화면의 `legacy`는 기존 6묶음 배치입니다. 서로 다른 기준선을 혼용하지 않습니다. [전체 결과](hip-joint-flow.json), [별도 재읽기](hip-joint-flow-readback.json).

12기준 뼈마다 면적 표본128점, 76근육마다 피부 검사 표본32점으로 총3,968점을 사용했습니다. 뼈는 원본→고정 HRA 최근접 표면의 한 방향 오차, 피부는3방향 포함 판정이 모두 외부이며 최근접 거리가2mm를 넘는 경우의 초과 거리만 벌점입니다. 내부·경계대·모호 판정은 그 평가에서 벌점0입니다. 2mm는 검사 설정이지 임상 안전 거리나 조직 두께가 아닙니다. 무릎뼈 양쪽·L1·L6는 맞춤에 쓰지 않고 평가만 했습니다.

하나의 공통 공간 변형을76근육·16진단 뼈에 적용했습니다. 고정 HRA는 움직이지 않지만 변형 함수의 고정점으로 보호하지도 않았습니다. 반경30/70/160mm, 단계 이동 최대2mm, 미분 상계0.12로160단계를 수행했습니다. 후보 이동 후 실제 목적함수를 재계산하고 감소하지 않으면 이동을 반으로 줄입니다. 실제 실행은 모든 단계에서 첫 시도가 채택됐고160회 제한으로 종료했습니다. 반감·실패 경로는 합성 검사로만 확인했습니다. 차선의 중심을 재시도하지 않는 탐욕적 선택, 중복 중심 평가, 누적 왜곡의 한계가 있습니다.

가중 목적함수는 0.0000115330→0.00000292465m²입니다. 뼈 전체 가중치1·피부 가중치1의 합이므로 그 제곱근을 전신 RMS라고 부르지 않습니다. 모든16뼈는 전 참조 정점의 양방향 거리를 평가했습니다. 왼 정강뼈 역방향 p95는12.500→12.616mm, 왼 종아리뼈는12.335→12.862mm로 악화했습니다. 모든 부위 RMS가 감소해도 국소 꼬리 오차까지 좋아진 것은 아닙니다. 대상 뼈 계층에 내부/연골 표면이 포함돼 동일한 외곽 경계끼리의 비교라는 보장도 없습니다.

초기 대비 새11쌍은 피부1·골격 계층10쌍입니다. 장기/혈관/신경/림프의 새 쌍0은 기존 실패 해결을 뜻하지 않습니다. 공개 대비 새94는 고정 HRA91(피부10·장기2·혈관7·골격72)과 근육 내부3(원본 관계 재등장2·이전 후보부터 있는 거친 교차1)으로 나뉩니다.

## 재읽기·화면·외부 검토

별도 스칼라 계산으로 근육652,173정점·3,912,126인덱스 차이0, 진단 뼈471,211정점·2,827,170인덱스 해시 일치를 확인했습니다. 88표면의3,968표본과2,109,356입력 삼각형 면적을 재대조했습니다. 초기/최종 목적함수 재계산 잔차는0/4.24×10⁻²²입니다. 모든 최적화나 거부 시도를 독립 재실행한 것은 아닙니다.

추가 흐름의 표본 야코비안9,728개 재계산 차이≤4.45×10⁻¹⁶, 단계 미분 상계≤0.12000000000000002입니다. 각 연속 단계의 가역성 조건은 이전 보간의 전역 단사성·실제 Float32 삼각형 관계·임상 타당성을 보장하지 않습니다. 실제 삼각형 소속과 내부 교차 증거는 새11쌍+이전 원본 내부 교차1의12건을 대조했습니다. 전체94건의 독립 증거 검증이라고 확대하지 않습니다.

[촬영 기록](hip-joint-flow-captures.json)의 정면/사선6장을 직접 확인했습니다. 동일 카메라·133구조(76근육·고정 골격 계층56·피부1)를 사용합니다. [기존](hip-joint-flow-front-legacy.png)·[초기 후보](hip-joint-flow-front-initial.png)·[새 후보](hip-joint-flow-front-flow.png)에서 넓적다리와 큰허리근 배치가 달라지지만 초기→새 후보 차이는 이 배율에서 작습니다. 기관·혈관·신경·림프·발뼈·진단 뼈는 생략했습니다. 불투명 근육이 뼈를 가리고 피부 상부는 잘려 있습니다. 미세 교차나 실제 앱·모바일·박리 검사를 이 화면으로 대신하지 않습니다. 촬영 최초 호출은 원본 폴더 인자 누락으로 실패했고 경로를 전달해 재실행했습니다.

[agy 검토 기록](hip-joint-flow-agy-review.json)은 완료 응답의 요약입니다. 역방향 오차 원인 단정, 모호 판정 누락, 야코비안/증거 검증 범위, 미분 상계 표현을 정정했습니다. 임상/출시 승인이 아닙니다.
