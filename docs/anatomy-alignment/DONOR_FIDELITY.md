# 여성 근육 원본 형상과 압축 데이터 검증 — 2026-09-21

**원본 형상을 보존하는 후속 정합 입력을 만들었습니다. 앱의 좌표·모형은 아직 바꾸지 않았습니다.** 기존 위치 후보에서 발생한 교차를 모두 정합 탓으로 돌리지 않고 원본/단순화 영향부터 분리했습니다.

## 같은 원본 좌표에서 비교

사용자 제공 `Final 3D STL Models-stl.zip`의 근육76개와 현재 배포된 근육76개를 대조합니다. 기존 각 묶음의 회전·배율·이동을 역적용해 현재 모형을 원본 공통 좌표로 되돌린 뒤 검사하므로, 허벅지/종아리 사이의 서로 다른 배치 변환은 이 비교에서 제거됩니다. 원본 파일별·앱 파일별 해시를 확인했습니다.

| 검사 | 원본 STL | 현재 단순화 모형, 원본 좌표로 복원 |
| --- | ---: | ---: |
| 모형 | 76 | 76 |
| 삼각형 | 1,304,042 | 291,390 |
| 검사한 근육 쌍 | 2,850 | 2,850 |
| 표면 교차 쌍 | 33 | 65 |
| 원본에 없던 교차 쌍 | — | 32 |

[전체 수치·교차를 재현하는 삼각형·해시](donor-fidelity-audit.json). 기본 숨김 넙다리곧은근2개도 포함합니다. 이 수치는 신경/골격과의 교차나 앱의 현재 서로 다른 변환 상태가 아니라 **원본 공통 좌표의 근육끼리** 비교한 것입니다.

현재 모형 정점→원본 표면의 최대 거리는0.000119mm인데, 반대 방향인 원본 정점→현재 표면은0.654496mm입니다. 남은 정점은 원본에 거의 일치해도, 삭제한 정점 사이를 잇는 삼각형 면은 곡면에서 벗어날 수 있습니다. 따라서 정점 불변만으로 형상 보존을 승인할 수 없습니다. 이 거리는 모든 참조 정점을 검사한 결과지만, 연속 표면 전체의 Hausdorff 상한은 아닙니다.

## 원본 교차의 독립 재확인

제공 파일의 원본33쌍에도 교차가 있습니다. BVH 삼각형 교차 판정과 별도로, 한 삼각형의 변 내부가 다른 삼각형의 **내부**를 통과하는지 선분–삼각형 계산으로 확인했습니다. 세 barycentric 좌표와 선분 비율을 모두 내부로 제한하고, 양쪽 삼각형이 서로의 지지 평면을0.001mm 초과로 가로지르는 경우의 증거를 저장했습니다. 공면·변/꼭짓점 접촉만으로 증거를 만들지 않습니다. 같은 방법으로 복원된 현재 모형65쌍도 재확인했습니다.

이는 제공된 파일의 기하 교차이며 임상 손상·침투 깊이·분할의 의학적 오류 판정이 아닙니다. [대학 자료 설명](https://digitalcommons.du.edu/visiblehuman/1/)에0.05mm 간격을 목표로 겹침을 정리했다는 설명이 있지만, 그 설명을 이 파일의 모든 삼각형 간격에 대한 검증 대신 사용하지 않습니다. 앞서 측정한 종아리6관계가 원본에서 교차하지 않는다는 결과도76개 전체의 비교차를 뜻하지 않았습니다.

## 새 포장 후보와 원본 그대로의 대안

단순화의 절대 오차 입력을0.01mm로 줄여도, 실제 원본 정점→후보 표면 최대 오차는 첫 계산에서0.141220mm였습니다. 라이브러리의 오차는 근사 지표이므로 설정값을 실제 상한으로 표현하지 않습니다. 실제 양방향 정점 거리가0.02mm를 넘는62개는 원본 삼각형으로 되돌렸습니다. 추가로 원본 교차 쌍 집합이 바뀌거나 지지 평면 가로지름 크기가0.001mm 초과 커지면 해당 모형을 원본으로 복원하는 보호 검사도 넣었습니다. 최종 쌍 검사에서는 추가 복원이 필요하지 않았습니다.

| 저장 방식 | 삼각형 | gzip 바이트 | 확인된 범위 |
| --- | ---: | ---: | --- |
| 실측 제한 단순화 후보 | 1,303,336 | 12,274,790 | 모든 원본 정점→표면 최대0.019766mm, 원본과 같은 교차33쌍 |
| 단순화 없는 원본 보존 | 1,304,042 | 12,282,378 | 원본 삼각형·방향 전체 일치, 원본과 같은 교차33쌍 |

차이는706삼각형·7,588바이트뿐입니다. 따라서 후속 정합의 기준 입력은 단순화 없는 대안으로 두는 것이 타당합니다. [생성 기록](donor-fidelity-packing.json), [별도 바이너리 재읽기 검증](donor-fidelity-readback.json).

재읽기는 gzip 해시·크기·모든 인덱스·유한 좌표·연속 바이트 구간을 확인하고, 원본 보존 대안의 모든 삼각형을 STLLoader가 읽어 미터 단위 Float32로 변환한 삼각형과 정점 순환 순서까지 대조했습니다. 순환 시작점만 정규화하고 방향 반전은 허용하지 않았습니다. **이는 그 Float32 변환 이후의 삼각형 보존이며, 원본 ASCII 숫자를 임의 정밀도로 보존한다는 뜻은 아닙니다.** 두 바이너리를 각각 다시 읽어2,850쌍을 검사했고 교차 쌍 집합이 원본33쌍과 같습니다.

모형을 이동·축소·삭제·숨겨 교차를 없애지 않았습니다. 원본 자체33쌍은 그대로 남습니다. 원본 충실도를 높이는 것과 HRA 피부·골격·관절에 맞추는 것은 별개이며, 새 데이터는 아직 캐시에만 있습니다. 앱 적용에는 정합, 피부/다른 계통과의 관계, 부착 위치, 렌더링·다운로드 비용 검사가 추가로 필요합니다.
