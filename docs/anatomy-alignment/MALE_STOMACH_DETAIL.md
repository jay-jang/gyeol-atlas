# 남성 위·관련 혈관 별도 상세 보기 — 2026-09-28

남성 위를 전신 BodyParts3D 3.0의 단일 메쉬에서 별도 BodyParts3D 4.0 상세 장면으로 열어, 위1개와 좌우 위동맥·위정맥·위그물막동맥·위그물막정맥8개를 개별 선택할 수 있게 했다. **위벽의 해부 층을 새로 만들지 않았고, 4.0 상세를3.0 전신 또는 여성 HRA에 겹쳐 놓지 않았다.** [공식 관계·원본/배포 버퍼·거리 감사](male-stomach-detail-audit.json)는 `node scripts/audit-male-stomach-source.mjs`로 재생성한다.

공통 `view-state.ts`의 상세 전이로 장기·혈관 레이어를 함께 열고 혈관 하나를 선택·새로고침해도 상세 범위를 유지한다. 전신으로 돌아오면 이전50.5% 박리·레이어·카메라를 복원한다. 여성으로 전환하면 `BP4_` 구조를 남기지 않는다. 한국어 이름은 검색용 편집 표기이며 원본 영문명·FMA ID를 보존한다. 여성 CT 위는 기존처럼 다른 사람의 별도 상세로만 제공한다.

브라우저 표적 검사에서 [데스크톱 위+혈관](male-stomach-detail-desktop.png), [모바일 위+혈관](male-stomach-detail-mobile.png), [모바일 개별 혈관](male-stomach-selected-mobile.png)을 직접 열어 확인했다. 모바일의 이동 도구와 카드가 겹치지 않으며 캔버스가 주 관찰 영역으로 남는다. 이 화면 검사는 고정된3D 출처 프레임의 표시·선택을 검증할 뿐3.0/4.0 또는 여성 장기 전체의 위치 정합을 승인하지 않는다.

첫 개별 혈관 모바일 캡처에서는 별도 원본 경고가 긴 구조 설명 아래로 밀려 처음 보이는 카드 영역에 없었다. 카드 제목 바로 아래로 경고를 올리고, 개별 선택·새로고침 후 모바일 뷰포트 포함 assertion과 새 캡처를 재실행해 통과했다. 카드 설명의 나머지는 내부 스크롤로 읽는다.

현행 [BodyParts3D 데이터베이스 라이선스](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html)는 CC BY 4.0과 지정된 DBCLS 표기를 요구한다. 고정 Human-Atlas 커밋과 배포 SHA는 `data/catalog/male-detail-source.json`에 남긴다. 원본 OBJ의 과거 헤더 표기와 현행 데이터베이스 조건의 차이는 기존 [출처 감사](MALE_KIDNEY_DETAIL.md)와 `THIRD_PARTY_NOTICES.md`에서 구분한다.

검증: 처음 표적 Node8/8, 구버전 저장 상세 경계 검사 추가 뒤 전체 Node366/366. 최초 전체 실행은 새 포장 파일을 참조하던 오래된 폐/췌장 감사 해시2건과 옛 상세 총수1건 때문에362/365로 실패했다. 폐 원본563개 전체 버퍼 재읽기·췌장 공식4개 재읽기로 감사를 갱신하고 총수754를 반영한 뒤 재실행해 통과했다. 관련 브라우저18/18, 마지막 경고·가독성 변경 뒤 위 상세 단독1/1, TypeScript, 별도 Node Vite 빌드, 프로덕션 스모크, 모바일12px/4.5:1 가독성 검사 통과. 기본 `npm run build`는 코드 오류가 아닌 로컬 macOS Rolldown 네이티브 서명 오류로 실패했고 같은 의존성의 별도 Node Vite 실행으로 빌드를 확인했다. 새 위 상세의 데스크톱·모바일 화면을 직접 확인했다.

모델 생성기를 한 번 더 실행한 전후의 상세 아틀라스·gzip·두 카탈로그·두 출처 영수증6파일 SHA-256이 각각 동일했다. 이 재현성 검사는 원본 해부학적 정확성이나4.0↔3.0 정합을 증명하지 않는다.

agy의 읽기 전용 지정 범위 검토는 공식 `is_a` 관계와 묶음 설명,3.0/4.0/여성 프레임 분리, 포장 버퍼 보존, 이전 저장 상세 복귀를 확인하고 새 P1/P2를 보고하지 않았다. agy도 표적 Node3개·원본/위치 감사·전체 Node366개를 별도로 실행했다고 보고했다. 그 검토 범위는 여성/남성 전신 위치나 혈관 연결·임상 정확도의 승인이 아니다.

기존 여성 보완 골격/근육의 위치 이탈, Allen 참조 뇌와 두개골의 겹침, 남녀 전신 주요 기관·신경의 연결, 실제 피부→심부 근육 층서와 모든0.5% 단계의 해부학적 의미는 해결되지 않았다. 이 상세 기능을 전체 목표 완료로 확대하지 않는다.
