# 여성 원본 두개골의 목뼈 기준 배치 시험 — 2026-09-27

**여성 원본 두개골을 현재 여성 목뼈에 대응시켰지만, 세 후보 모두 전신 교체에 적용하지 않았습니다.** 원래 크기를 유지한 후보는 피부2mm 경계대 밖 정점이0개였으나, 현재 뇌·신경계와 교차하는 메쉬가49개에서74개로 늘었습니다. 피부 포함이나 목뼈 잔차 감소를 머리 내부 정합 완료로 해석하지 않습니다.

## 원본과 맞춤 범위

[확보한 BoneHub 여성 원본](BONEHUB_FEMALE_SOURCE.md)의 고정 커밋 `ac8de2b38f5ae1a0996053ca0639dd6ae43358f1`에서 목뼈 C1–C7과 `SKULL_CRANIAL_MAXILLA`, `SKULL_MANDIBLE`을 사용했습니다. 두개골은831,288삼각형·415,457고유 정점·56연결 성분, 아래턱은75,944삼각형·37,926정점·9성분입니다. 작은 성분을 삭제하지 않았으며 성분 하나를 뼈 하나로 명명하지 않았습니다. 원본의 두 라벨을 개별 머리뼈/FMA로 임의 분할하지 않았습니다.

실제 앱에 수록된 여성 HRA 목뼈 `HRAF0843`–`HRAF0849`의 압축 해제 위치·인덱스를 읽었습니다. 여성 뇌의 기존 좌우 버퍼 대응도 적용한 뒤 뇌·신경계362메쉬를 고정 대상으로 유지했습니다. 팔·발 정합과 오른 엉덩뼈 복원 대상은 이번 머리 검사에 포함하지 않았습니다.

- 원본 LPS mm를 한 번 Float32 m로 변환하고, `(L,P,S) → (L,S,-P)`의 반사 없는 회전을 초기 축으로 사용했습니다.
- 초기 이동은 C2–C7 경계상자 중심 평균만으로 정했습니다. C1은 초기 이동과 반복 맞춤 모두에서 제외했습니다.
- C2–C7 각각 양방향1,024정점 표본을 사용하고 가까운819개씩 남겨 반복했습니다. 뼈/방향별 개수는 같지만 균일 표면적 표본은 아닙니다. 먼20%를 제외한 목적함수의 한계가 있습니다.
- 초기값, 회전·이동만의 강체변환, 회전·이동·균일 배율의 유사변환을 따로 기록했습니다. 두개골과 아래턱에는 항상 같은 변환을 적용했습니다. 피부·뇌·차용 두개골은 맞춤 목적함수에 사용하지 않았습니다.

[맞춤 기록](bonehub-head-frame.json). 강체62회·유사변환56회 후 표본 이동량0.00001mm 미만 조건에 도달했습니다. 반복 종료는 전역 최적해나 임상 관절 정합의 증거가 아닙니다. 유사변환 배율은1.057851, 즉 약5.8% 확대입니다.

맞춤에서 제외한 C1의 원본→HRA 전체 정점 p95 거리는 초기3.199mm, 강체2.488mm, 유사변환2.555mm였습니다. 역방향은3.302/2.663/2.492mm입니다. 유사변환에서 학습에 사용한 C2–C7의 양방향 p95는0.868–1.771mm로 줄었지만, 아래 두개골 검사에서는 이탈과 교차가 남았습니다. C1 한 구조의 잔차 감소를 머리·관절 전체 일반화로 표현하지 않습니다.
