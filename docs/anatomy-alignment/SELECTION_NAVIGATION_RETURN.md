# 일반 구조 선택에서 경혈·부위 탐색으로 떠날 때 박리 복귀 — 2026-09-28

> **2026-10-03 대체:** 사용자 요청(“기관을 클릭한 뒤 전체 화면으로 돌아가는 문제”)으로 떠날 때 카메라를 되돌리지 않고, 경혈 선택은 기관 선택을 유지하도록 바꿨습니다. [보던 곳을 지키는 화면 흐름](../ui-renewal/VIEW_CONTINUITY.md). 아래는 당시 규칙의 기록입니다.

앞선 [선택 해제 복귀](SELECTION_PEEL_RETURN.md)는 ‘구조 선택 해제’ 버튼을 눌렀을 때만 직전 박리 장면으로 돌아왔습니다. 50.5% 박리에서 일반 장기를 선택한 다음 경혈 또는 전신 부위를 곧바로 바꾸면 선택 카드만 사라지고 선택 장기의 단독 레이어·단계가 남는 상태를 재현했습니다. 수정 전 단위 검사에서 남성 경혈 전환은 원래 `stage=2` 대신 장기 단독 `stage=3`으로 실패했습니다.

## 공통 상태 규칙

`src/view-state.ts`에서 일반 구조 선택의 임시 `selectionReturn`을 떠나는 전이에 적용합니다. 경혈 선택, 전신 부위 변경, 경혈 모델 부위 필터, 필터 결과 표시가 먼저 직전 단계·0.5% 깊이·모드·레이어·앞쪽 숨김·선택 대상·저장 시점으로 돌아간 뒤 해당 경혈/부위/필터만 바꿉니다. 기관 상세는 기존 `detailReturn` 규칙을 그대로 사용합니다. 계통 버튼·박리 슬라이더·성별 전환처럼 새 보기를 명시적으로 선택한 경우에는 원래대로 임시 복귀 대상을 버립니다.

경혈 목록 또는 모델 표식을 누르는 실제 경로는 `src/App.tsx`에서 카메라에도 보존된 시점을 적용합니다. 선택 구조의 확대 카메라에 전신 박리만 표시되는 혼합 상태를 막습니다. 부위/필터 조작은 기존 부위 프레이밍을 따릅니다. 새 독립 레이어·선택 경로를 만들지 않았으며 원본 모형·좌표·투명도 함수는 바꾸지 않았습니다.

## 직접 검증과 제한

- 남녀 각각 50.5%→일반 위/자궁 검색 선택→ST36 경혈 선택: 원래 단계·레이어·가시 구조 ID 집합·카메라 시점 복귀를 검사했습니다.
- 남녀 각각 같은 선택→머리 부위 변경: 박리 모드·단계를 유지한 채 머리 구조가 표시되고 전신으로 돌아오면 원래 가시 ID 집합이 회복됩니다. 모델 부위 필터와 ‘필터 결과를 모델에서 보기’도 선택 단독 레이어를 남기지 않았습니다.
- [남성 데스크톱](selection-navigation-male-desktop.png) · [여성 데스크톱](selection-navigation-female-desktop.png) · [남성 모바일](selection-navigation-male-mobile.png) · [여성 모바일](selection-navigation-female-mobile.png)을 직접 확인했습니다. 네 화면 모두 머리부터 발까지 장면에 있고, 모바일에서 도구가 장면을 대체하거나 가로 넘침을 만들지 않습니다. 이 화면은 50.5% 한 단계이며 전201단계의 시각 검사나 실제 해부 위치 검증이 아닙니다.

새 단위 검사는 수정 전 `stage=3` 잔류를 재현하고 수정 후 통과했습니다. 첫 브라우저 확장 검사는 이전 `ST36` 검색어와 ‘발목·발’ 필터의 교집합이0개여서 비활성 실행 버튼을 기다리다 시간 초과됐습니다. 검색어를 비우고 결과 버튼이 활성인지 확인한 뒤 남녀2/2로 재실행했습니다. 앞서 경혈·부위만 확인한 표적 회귀13/13도 통과했습니다. 최종 단위325/325·빌드·프로덕션 스모크·모바일 가독성·네 화면 시각 게이트 및 단일 전체 브라우저83/83(22.0분)을 통과했습니다. [검증 기록](VERIFICATION.md)에 범위를 구분했습니다.

첫 전체83건 중82건은 통과했지만 과거 폐 상세 세션의 저장 카메라 검사1건이 간헐적으로 실패했습니다. 앱이 저장 시점을 복원한 뒤 선택 카드/자료가 비동기로 다시 배치될 때 자동 ‘구조 맞춤’이 저장 시점을 덮을 수 있었습니다. `src/Atlas.tsx`에서 복원 중인 선택의 카드 높이 변경은 횟수와 무관하게 카메라를 재맞추지 않도록 했습니다. 명시적 카메라 조작이나 선택 없는 전신의 모바일 경계 재맞춤은 유지합니다. 과거 폐 세션 반복12/12, 카드 상세 목록을 펼치는 조건을 추가한 반복3/3을 통과했습니다. 최초82/83을 단일 전체 성공으로 표기하지 않습니다.

이번 조작 복귀는 여성 보완 골격·근육과 뇌–두개골의 정렬, 남녀 기관/신경 연결, 실제 표층→심층 박리 층서를 교정하지 않습니다. agy 도구는 현재 환경에서 제공되지 않아 이 변경을 agy가 검증했다고 주장하지 않습니다.
