# 대퇴골 정합 대상의 누락 수정 — 2026-09-21

**앞선 정합 대상에 오류가 있었습니다.** HRA에서 `Femur (left/right)`라는 이름의 본체 메쉬 하나를 완전한 대퇴골 표면처럼 사용했습니다. 공식 GLB에는 각 본체 아래15개 표면 조각이 더 있습니다. 이전12mm p95·약30mm 최대 거리는 이 불완전한 대상에 대한 거리이므로, 뼈 전체의 위치 차이로 해석하지 않습니다. 이전 실행 기록은 지우지 않고 이 정정을 연결합니다.

## 원본 계층과 기하 증거

공식 HRA united-female v1.10 GLB의 SHA-256 `95f0c3d2f918582608692ca1139e8bdb18c147a16470e9ee9af8b276bd77c422`를 확인하고 실제 node.children을 따라 구성했습니다. 이름 추측이나 ID 범위로 추가하지 않았습니다. 왼쪽 HRAF0937·오른쪽 HRAF0911 각각 본체+15개 표면, 슬개골·경골·비골은 각1개입니다. 총38개 중복 없는 메쉬입니다. [원본 노드·부모·명칭·계통·해시](hra-bone-targets.json).

후손에는 관절융기·도르래고랑·융기사이오목뿐 아니라 **원본에서 연골·부착부로 명명한 표면도 포함**합니다. 순수 뼈조직으로 재분류하지 않으며, 원본 계층의 복합 외곽면을 이용하는 진단 대상입니다. 기증자 STL 뼈와 이 복합면의 조직 경계가 정확히 같다고 주장하지 않습니다. 합친 뒤에도 열린 경계가 남으므로 닫힌 고체로 승인하지 않습니다.1µm 정점 용접은 별도 위상 진단에만 쓰고 정합 좌표에 적용하지 않았습니다.
