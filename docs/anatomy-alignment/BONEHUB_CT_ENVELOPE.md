# 여성 원본 CT 단면과 발 주변 외곽 후보

2026-09-27. **진단용 후보이며 앱 미적용입니다.** 기존 HRA 피부에 새 발뼈를 맞추는 시험은 [이전 기록](BONEHUB_FOOT_AND_CT.md)에서 실패했습니다. 이번에는 다른 좌표계로 옮기지 않고 같은 촬영의 영상과 골격 관계부터 확인했습니다. 이는 기존 여성 전신 위치 오류를 교정했다는 뜻이 아닙니다.

## 자료와 실제 단면

자료: Seyed Hamidreza Alavi·Malte Asseln, University of Twente, [BoneHub Visible Human 3D Models](https://huggingface.co/datasets/BoneHub/visible-human-3d-models/tree/ac8de2b38f5ae1a0996053ca0639dd6ae43358f1), DOI10.57967/HF/10464, CC BY4.0. 고정 버전 `ac8de2b38f5ae1a0996053ca0639dd6ae43358f1`. 아래 그림은 이 자료의 CT 표시·분할선 중첩·새 외곽 계산으로 제작한 파생 진단 이미지입니다. 원저자의 임상 검수를 의미하지 않습니다.

`inspect-bonehub-ct-slices.py`가 압축 CT 해시를 확인하고 전체 영상을 한 번 스트리밍했습니다. 첫200개 Z평면을 ZYX uint16 배열로 저장하고 해시를 기록했습니다. 전체 영상의 값은0–4,050, 발34라벨의764,287복셀 참조 값은885–2,774입니다. 라벨 중복을 합친 고유 씨앗 복셀은764,098개로, 참조 수와 다릅니다. 이 값은 **HU로 확정하지 않았습니다.** 그림의0–2,000은 표시용 밝기 범위일 뿐입니다.

- [발 축상 단면4개](bonehub-ct-feet-axial.png): z20/60/100/140mm, 원본34라벨의 윤곽 중첩. 모든 원본 복셀에 대한 해부 판독이 아닌 선택 단면 확인입니다.
- [몸통·머리 축상 단면4개](bonehub-ct-body-axial.png): z900/1100/1300/1600mm. 추정 장기 라벨을 붙이지 않았습니다.
- [관상 단면2개](bonehub-ct-body-coronal.png): y280/350복셀, 가로축만 최근접 표시 비율 조절. 한 평면에서 안 보이는 부위를 전체 영상 결손으로 판단하지 않습니다.

발 NRRD는 기존 전체 페이로드 검사에서 확인한 각 라벨 경계 안의 모든 복셀을 집계했고 수가 이전 보고서와 일치했습니다. 이번 표시 스크립트의 NRRD 읽기는 z199까지이며, 전체 마스크 페이로드 검사를 새로 수행했다고 주장하지 않습니다. [단면/통계 보고서](bonehub-ct-inspection.json).

## 외곽 추출과 한계

저장값500·650·800 이상을 각각6방향 연결 성분으로 나눈 뒤, 원본 발뼈 마스크의 씨앗을 포함하는 성분을 선택했습니다. 내부의 닫힌 빈 공간만3차원 hole filling으로 채웠습니다. 팽창·닫힘·평활화·개별 뼈 변형은 하지 않았습니다. 임곗값은 민감도 비교용이지 피부 조직의 검증된 정의가 아닙니다.

| 저장값 기준 | 선택 복셀 | 내부 채움 추가 | 최종 외곽 복셀 | 저장 삼각형(인공 끝면 포함) | 인공 끝면 삼각형 | 원본 STL 정점의 외곽 밖 개수 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
|500|3,620,823|80|3,620,903|606,080|29,810|0 /242,730|
|650|3,558,014|52|3,558,066|598,684|29,328|0 /242,730|
|800|3,498,160|15|3,498,175|595,396|28,886|0 /242,730|

세 후보 모두 양발 씨앗이 하나의 연결 성분에 속합니다. 화면에서 양발 사이의 얇은 연결 영역이 보입니다. 실제 조직·접촉·포장재 등의 기여를 구분하지 않았고, 따라서 이를 분리된 정확한 피부로 간주하지 않습니다. 원본 단면의 촬영대처럼 보이는 하부 띠는 후보 그림에 포함되지 않지만, 모든 비조직 물질의 배제를 증명한 것은 아닙니다.

씨앗 복셀 포함은 **선택 방법상 보장되는 결과**입니다. 표의 STL 검사는 별도의 평활화된 원본 메쉬34개·242,730정점을 원본 LPS mm에서 해당 복셀 셀에 대조한 결과이며, 채움 전에도 밖으로 나온 정점은0입니다. 삼각형 내부 전체·관절 적합·임상 피부 경계를 검증한 것은 아닙니다. 이 결과로 HRA 전신에 대한 이전 실패를 뒤집지 않습니다.

원본 셀의 정확한 경계면을 사용해 계단형 모양을 유지했습니다. z199.5mm의 상단 절단면은 별도 **인공 끝면**으로 저장하고 자홍색으로 표시했습니다. 아래 z−0.5mm에는 선택 복셀이 없어 끝면이 없습니다. 끝면을 뺀 열린 표면을 홀짝 포함 검사에 사용하면 안 됩니다. 이번에는 홀짝 검사 자체를 실행하지 않았습니다.

## 별도 판독과 화면 확인

`verify-bonehub-foot-envelope.py`는 저장 Float32/인덱스를 다시 읽어 세 후보의 모든 삼각형이 복셀 셀의 정규 반쪽 면인지, 양쪽이 각각 내부/외부인지, 중복 없이 전체 경계 개수와 일치하는지 확인했습니다. 인공 끝면 분리와 격자 부피도 일치했습니다. 최대 Float32 좌표 반올림 잔차는0.00001514mm입니다. 이 수치는 영상 분해능이나 해부학적 오차가 아닙니다. 다양체 위상은 검증하지 않았습니다.

원본 STL은 별도 scalar `struct` 판독으로34개·1,455,972삼각형 정점 참조를 재구성해 저장 메쉬와 좌표 잔차0을 확인했습니다. 복셀 표면 합성 검사4개(단일 셀, 이동된 셀, 오목/분리된 셀, 속 빈 셀)도 통과했습니다.

- [외곽 투명 화면](bonehub-foot-envelope-transparent.png), [외곽 불투명 화면](bonehub-foot-envelope-opaque.png): 각3기준×2시점, 모든34원본 발 라벨 표시. 직접 열어 확인했습니다. 처음 캡처의 흰 배경에 안내가 안 보이는 문제를 수정하고 재촬영했습니다.
- [후보 보고서](bonehub-foot-envelope.json), [별도 판독](bonehub-foot-envelope-readback.json), [캡처 기록](bonehub-foot-envelope-visual.json).

agy `f53c9e44-60d0-4875-94a1-abb5582df383`는 제한 정적 검토를 했습니다. 잘못 설명한 회전 부호(+90°→−90°), 표시 범위/원본 값 범위 혼동, 실행하지 않은 홀짝 검사의 해석을 후속 정정했습니다. 후속 답변의 “manifold” 표현도 채택하지 않습니다. 이번 검사는 다양체를 보증하지 않습니다. agy는 계산·스크린샷 검사를 실행하지 않았으며, 이후 추가한 STL scalar 재읽기/합성 검사까지 검토했다고 주장하지 않습니다.

```sh

npm exec --yes --package=node@24.14.0 -- node scripts/capture-bonehub-foot-envelope.mjs
```

원본 CT·마스크·큰 후보 배열/바이너리는 캐시에만 두고 보고서와 그림만 저장소에 기록했습니다. 상체 근육·장기·신경이 새로 분할되거나 앱에 추가된 것은 아닙니다. 다음에는 연결 영역의 영상 근거와 더 넓은 범위의 외곽을 대조해야 합니다. 기존 여성 골격33개·근육18개 피부 이탈, 남녀 신경/골격 교차, 전체 기관 연결, 실제 근육 층서는 여전히 미완료입니다.
