# 남성 등세모근–마름근·어깨올림근 박리 순서

2026-09-28. **표시 순서의 제한적 교정**입니다. 근육 형상·좌표·수록 범위는 변경하지 않았으며 여성 상체 근육의 누락이나 전신 해부 정합을 해결한 것은 아닙니다.

## 출처와 적용 범위

[Loyola University Chicago 해부 실습 안내](https://www.meddean.luc.edu/lumen/meded/grossanatomy/2010/dissection%20guide%20509.pdf)는 등세모근을 젖혀 그 아래 층을 드러낸 뒤, 큰·작은마름근과 어깨올림근을 관찰하는 순서를 제시합니다. 이를 남성 BodyParts3D 원본의 실제 양측 등세모근 세 부분과 같은 쪽 큰·작은마름근·어깨올림근에만 적용했습니다. 등세모근의 모든 삼각형이 이 세 근육 전체를 덮는다는 주장, 세 심부 근육 사이의 순서, 수술 박리술이나 조직 두께 측정은 아닙니다.

| 좌우 각각 | 원본 메쉬 | 표시 규칙 |
| --- | --- | --- |
| 앞서 제거 | 등세모근 오름·가로·내림 부분3개 | 세 부분의 페이드 종료 후 아래 근육 페이드 시작 |
| 뒤에 제거 | 큰·작은마름근, 어깨올림근3개 | 서로 간 선후 제약 없음 |

같은 쪽의3×3관계9개씩 총18개입니다. [기존 박리 관계 코드](../../src/muscle-peel-relations.ts)에서 원문 ID를 그대로 사용하고 공통 순위 계산을 거칩니다. 여성 HRA 전신에는 해당 상체 근육 표면이 수록되지 않아 남성 메쉬를 여성이라고 복제하거나 성별 전환 상태를 변경하지 않았습니다.

## 변경 전후의 실제 스케줄

바뀌기 전 [직전 스케줄](https://github.com/jay-jang/gyeol-atlas/blob/83c361d/docs/anatomy-alignment/muscle-peel-audit.json)과 새로 생성한 [현재 스케줄](muscle-peel-audit.json)을 같은 모형에서 비교했습니다. 이18관계에서 이전에는 **2관계의 시작 선후가 역전**, 10관계의4% 페이드 구간이 겹쳤습니다. 이제18관계 모두 위쪽 메쉬 종료와 아래쪽 시작 사이에 간격이 없거나 양의 간격이 있고, 역전·겹침은0입니다. 예를 들어 남성 오른쪽 등세모근 내림부분은32.5–36.5%, 큰마름근은 기존30.5–34.5%에서36.5–40.5%로 바뀝니다. 양쪽 어깨올림근도36.5%부터 사라지기 시작합니다. 이 퍼센트는 물리적 피부 깊이가 아닙니다.

명시적 근육 선후 관계는42→60개, 관련 고유 메쉬는54→66개가 됐습니다. 남성 근육437개 가운데46개, 여성 근육92개 가운데20개에만 명시적 관계가 있으며 나머지463개 근육계 메쉬의 순서는 기하학적 추정입니다. 메쉬 수는 개별 근육 개수가 아닙니다.

## 검증과 남은 문제

원본 이름·성별·좌우·ID의 정확한 목록은 단위 검사에서 검증합니다. 실제 브라우저는 남성12메쉬와18관계의 경계 깊이, 세계 경계·행렬 불변, 모바일 가로 넘침0을 검사합니다. 등 뒤쪽 [32% 데스크톱](upper-back-peel-32-1440.png)·[38% 데스크톱](upper-back-peel-38-1440.png)과 [32% 모바일](upper-back-peel-32-390.png)·[38% 모바일](upper-back-peel-38-390.png)을 직접 확인했습니다. 38% 화면에서는 등세모근 뒤의 마름근·어깨올림근 주변과 골격이 드러나지만, 다른 미제약 근육도 함께 보이므로 실제 신체의 연속 절개면으로 읽을 수 없습니다.

이번 변화는 남성 상부 등 일부의 *순서* 오류를 줄입니다. 여성 상체 근육 부족, 남녀 기관·혈관·신경 위치/연결, 실제 표피·지방·근막을 거치는 연속 박리, 나머지 근육 층서는 미완료입니다. `agy` 도구가 현재 환경에 없어 이번 변경의 agy 검증을 수행했다고 기록하지 않습니다.

최종 검증은 Node 단위328/328, 박리 표적 브라우저5/5, 단일 전체 브라우저85/85(22.7분), 남녀 각201단계 형상 비교163,944/245,220회·최대 이동0m, 프로덕션 스모크, 12px/4.5:1 가독성 및 네 화면 크기 시각 게이트를 통과했습니다. 네 기본 화면과 이 기록의 네 등 화면을 직접 확인했습니다. 작은 모바일 비교 카드는 일부 장면을 가리지만 캔버스를 대체하지 않습니다. 실기기와 다른 브라우저는 별도입니다.

첫 `npm run build`는 현재 앱 내장 Node와 `rolldown` 네이티브 모듈의 macOS Team ID 서명이 달라 중단됐습니다. 저장소 코드·잠금파일은 고치지 않고 별도 Node24 실행기로 같은 빌드를 재실행해 통과했습니다. 첫 전신 형상 감사는 그 빌드의 파일 재생성과 겹쳐 Vite HMR로 R3F 장면 루트가 교체되는 동안 중단됐습니다. 빌드가 끝난 뒤 동일한 남녀201단계 감사를 완전히 다시 실행해 통과했습니다. 중단된 두 실행을 성공 검사로 세지 않습니다.
