# 남성 앞전완근의 표층→중간층→심층 표시 순서 — 2026-09-28

남성 BodyParts3D 근육 GLB의 양쪽 앞전완근22개 실제 메쉬에서 기존 기하 반경 추정 일정이 표층·중간층·심층 순서를 어기는 부분을 보정했다. [TeachMeAnatomy 앞전완근 설명](https://teachmeanatomy.info/upper-limb/muscles/anterior-forearm/)은 원엎침근·노쪽손목굽힘근·긴손바닥근·자쪽손목굽힘근을 표층, 얕은손가락굽힘근을 중간층, 깊은손가락굽힘근·긴엄지굽힘근·네모엎침근을 심층으로 구분한다. [Loyola 의대 해부 실습 지침](https://www.meddean.luc.edu/lumen/meded/grossanatomy/2009/dissection%20guide%20509.pdf)도 표층을 젖혀 아래 근육을 드러내는 순서를 설명한다. 원문 그림·PDF를 앱에 재배포하지 않았다.

원본 카탈로그의 좌우 이름·FMA ID를 실제 `public/models/muscle.glb` 437개 메쉬와 대조했다. 각 쪽은 표층6개(원엎침근/자쪽손목굽힘근의 두 갈래 포함), 중간층2개(얕은손가락굽힘근의 두 갈래), 심층3개다. `src/muscle-peel-relations.ts`에 같은 쪽의 표층→중간층12관계, 중간층→심층6관계를 추가해 양쪽36관계를 고정했다. 4%p 전체 메쉬 페이드가 끝난 뒤 다음 층의 페이드가 시작하며 시작값은0.5% 단위다.

[전수 일정·실제 GLB·입력 해시](muscle-peel-audit.json)의 `forearmPrevious`는 **이번 변경 직전**의 다른66개 관계를 모두 유지하고 앞전완근 관계만 뺀 일정으로 비교한다. 보고서의 일반 `before`는 더 오래된 기준 `6ab02cb`라 이 표의 직접 비교에 사용하지 않았다. 네 역전은 오른쪽 원엎침근 자쪽갈래→얕은손가락굽힘근 위팔자쪽갈래, 오른쪽 얕은손가락굽힘근 노쪽갈래→깊은손가락굽힘근, 왼쪽 대응 두 관계다.

이 관계는 전완 앞칸을 **교육용 전체 메쉬 제거 선후**로 편집한 것이다. 특정 두 표면의 접촉·전 면적 가림·mm 단위 조직 깊이·임상 박리술 단계가 아니다. 남성 GLB 좌표·정점·인덱스, 다른 계통, 카메라·선택 상태는 바꾸지 않았다. 여성 전신에는 이22개에 대응하는 고유 앞전완근이 수록되지 않아 임의 복제하거나 남성 메쉬를 여성 근육으로 표기하지 않는다. 전체 근육계529개 메쉬 가운데 출처로 제약된 것은98개, 나머지431개는 여전히 기하 추정이다. 여성의 위치 불일치·미수록 상체 근육과 뇌/기관/신경 위치는 남는다.

표적 Node6/6, 모든 관계의201개 0.5% 단계 스칼라 투명도 검사 통과. 전체 Node353/354이며 HTTP 경계 검사1개는 `127.0.0.1 listen EPERM`이다. TypeScript·별도 Node 정적 빌드 통과. 기존 전체 근육 브라우저 검사와 새 앞전완근 데스크톱/모바일 검사1개가 이 관계를 다루지만, 기본 개발 서버의 `rolldown` 서명 오류로 실제 실행·새 화면 캡처·육안 검토는 **미완료**다. agy도 로컬 포트 바인드 권한으로 미검증이며 출시 완료로 판정하지 않는다.

후속 실행 환경에서 새 앞전완 브라우저1/1과 기존 남녀 근육 박리2/2가 통과했다. 실제 R3F 메쉬22개·36관계의 순서와 박리 중 경계/행렬 불변을 확인하고 [데스크톱](anterior-forearm-peel-1440.png)·[모바일](anterior-forearm-peel-390.png)을 직접 검토했다. 201개 남녀 전신 깊이의 실제 장면 경계 재감사도 각각201/201, 이동0m다. 이는 위 당시 실패를 소급 통과로 바꾸지 않고, 새 실행 증거를 추가한 것이다. 캡처의 전완 관찰 시점은 진단용이며 모든 앞전완 표면의 실제 접촉/깊이나 여성 미수록 앞전완근을 입증하지 않는다.
