# 여성 다섯째 발가락 줄의 평행이동 후보 감사 — 2026-09-28

이 감사는 [기존 발가락 부분 교정](FOREFOOT_PARTIAL_REGISTRATION.md)이 회전0°인 다섯째 줄의 후속 이동을 건너뛴 공백을 검사한다. **런타임 등록·원본 모형은 수정하지 않았다.** [전체 수치 결과](fifth-ray-translation-audit.json)는 `scripts/audit-fifth-ray-translation.mjs`로 재현한다.

| 조건 | 왼쪽 | 오른쪽 |
| --- | ---: | ---: |
| 현 좌표의 피부2mm 경계대 밖 정점 | 653 | 521 |
| 다섯째 발허리뼈–넷째 발허리뼈 기존 교차 삼각형 쌍 | 37 | 46 |
| 다섯째 발허리뼈–입방뼈 기존 교차 삼각형 쌍 | 34 | 36 |
| 평균 안쪽 방향2mm 후 피부 밖 정점 | 583 | 433 |
| 같은 이동 후 위 두 교차 삼각형 쌍 | 75·70 | 77·86 |
| 피부 개선·새 이탈0·기존 이탈 악화0·새 뼈 교차0·기존 교차 수/평면폭 비악화의0.25~2mm 후보 | 0 | 1 |

각쪽의 다섯째 발허리뼈와 근위·중간·먼쪽 마디뼈를 하나의 강체 묶음으로 둔다. 현재 앱의 여성 팔·발 부분 등록을 먼저 적용한다. 실제 피부의 가장 가까운 점을 향하는 이탈 정점의 가중 평균 방향, 좌표축6방향, 축 대각선20방향의 총27방향을 검사했다. 거리0.25·0.5·1·2·5·10·15mm의189후보를 각쪽에 사용했다. 수치는 탐색 한계이지 생리적 관절 운동 범위가 아니다. 15mm까지 피부 분류는 전체 참조 정점 중 원래 피부에서15mm 이내이거나 이미 이탈한 정점만 재검사했다. 나머지 내부 정점은15mm 이하 이동으로 표면에 도달할 수 없다.

평균 안쪽15mm는 양쪽 피부 이탈을0으로 만들지만 왼쪽8·오른쪽4개 골격 표면 교차를 만들거나 유지한다. 2mm는 피부 이탈을 줄이면서 새 이탈을 만들지 않지만, 양쪽에서 이미 존재하던 넷째 발허리뼈·입방뼈 교차의 삼각형 쌍 수를 모두 늘린다. 해당 입방뼈 접합부의 정점–표면 최소 거리도 왼쪽0.0668→0.0324mm, 오른쪽0.1038→0.0332mm로 바뀐다. 최소 거리 자체는 관절 적합성을 판정하지 않는다.

0.25~2mm에서 정점 이탈·321개 골격/연결/차용 모형 표면 교차·기존 교차의 엄격한 평면 횡단 삼각형 쌍 수와 최대 횡단폭을 함께 제한하면 왼쪽 통과 후보는0개였다. 오른쪽은 `(1,−1,1)` 방향1mm 이동 하나가 이탈521→504개로 줄면서 이 제한을 통과했다. 이 후보의 전체 교차 삼각형 쌍 수도 두 기존 접합부에서46→36·36→13으로 감소했다. 그러나 이 작은 개선은 관절면의 해부학적 대응, 인대·근육·신경 관계, 피부 외 실조직 위치를 검증하지 못해 **적용하지 않았다**. 피부 안쪽으로 옮기는 일만으로 해부 정합이 완료되지 않는다.

표면 교차 검사는 완전한 고체 포함을 잡지 못하며 삼각형 평면 횡단폭은 침투 부피·깊이가 아니다. 피부가 다른 원본의 외피이므로 그 안에 든다는 사실도 정확한 관절 위치 증거가 아니다. 독립 회전·평행이동 결합, 관절별 변형, 같은 촬영 원본 영상의 부위별 기준점은 이번에 탐색하지 않았다. 이 한정된 평행이동 탐색의 실패를 모든 교정의 불가능성으로 일반화하지 않는다.

재현 명령:

```sh
FIFTH_RAY_AUDIT_OUTPUT=docs/anatomy-alignment/fifth-ray-translation-audit.json node scripts/audit-fifth-ray-translation.mjs
```

출력 JSON은 입력 manifest·등록·감사 코드·읽은 청크의 SHA-256을 기록한다. 앱 코드·모형·상호작용·배치를 변경하지 않았으므로 브라우저·모바일 캡처·프로덕션·201단계 박리 게이트를 이번 후보 검사로 재실행하지 않았다. 전체 여성 골격·근육 위치, 주요 기관/신경의 연결, 실제 피부→심부 근육 층서와0.5% 박리 목표는 여전히 미완료다.

`agy` 읽기 전용 검토의 첫 요청은2분 제한으로 결과가 없었다. 코드 한 파일의 피부 정점 생략·새 표면 교차·기존 엄격 횡단 쌍/폭 기준으로 좁힌 두 번째 요청은 새 P1/P2를 보고하지 않았다. 이는 검사 코드의 한정된 정적 검토이며 JSON 수치의 독립 실행, 관절면 적합성 또는 해부학·임상 승인으로 해석하지 않는다.
