# 앞넓적다리 근육의 표시 제거 순서 — 2026-09-28

여성 전신의 양쪽 중간넓은근이 넙다리곧은근보다 **먼저 사라지는 실제 표시 역전**을 교정했습니다. [University of British Columbia 의대 해부 카드](https://www.clinicalanatomy.ca/labs/421cards.pdf)는 중간넓은근을 넙다리곧은근의 깊은쪽으로 제시합니다. [Loyola 의대 앞넓적다리 해부 자료](https://www.meddean.luc.edu/lumen/meded/grossanatomy/dissector/labs/le/ant_th_leg/tha2.html)도 네 갈래 넙다리네갈래근의 실제 표본 맥락을 제공합니다. 사진·PDF는 앱에 재배포하지 않았습니다. 이는 겹치는 앞넓적다리 부위의 **교육용 전체 메쉬 제거 선후**이지 각 삼각형의 실제 조직 깊이나 수술 절개 단계가 아닙니다.

고정된 남성 BodyParts3D 근육 GLB와 여성 HRA packed 원본에서 ID·이름·좌우와 실제 경계 상자를 대조했습니다. 여성 HRA 넙다리곧은근 `HRAF0394`·`HRAF0396`, 여성 보완 기증자 넙다리곧은근 `VHF0009`·`VHF0047`, 중간넓은근 `VHF0013`·`VHF0051`이 실제로 수록됩니다. 보완 넙다리곧은근은 중복 표시를 피하려고 기본 전신에서 숨겨지지만 개별 선택 대상이므로 순서 제약에서 제거하지 않았습니다. 두 종류의 넙다리곧은근과 같은 쪽 중간넓은근은 X·Y 경계가 겹치고, 넙다리곧은근의 경계 중심은 앱 앞축 Z에서 중간넓은근보다 앞에 있습니다. 이 상자 관계는 원본 표면의 국소 접촉이나 정합 정확도 증명이 아닙니다.

| 성별·쪽 | 겉쪽 넙다리곧은근 제거 시작 | 안쪽 중간넓은근 이전 시작 | 안쪽 수정 후 시작 |
| --- | --- | ---: | ---: |
| 여성 왼쪽 | HRA47%, 보완43.5% | 36% | **51%** |
| 여성 오른쪽 | HRA45.5%, 보완42% | 35.5% | **49.5%** |
| 남성 왼쪽 | 55% | 59% | 59% 그대로 |
| 남성 오른쪽 | 54.5% | 58.5% | 58.5% 그대로 |

각 메쉬의 페이드는 시작 뒤4%p 동안 진행합니다. 여성에서 원본별 겉쪽 메쉬가 모두 종료된 뒤 중간넓은근이 시작하도록 고정했습니다. 여섯 관계 중 여성 네 관계가 이전에 시작 순서 역전·페이드 겹침이었고 남성 두 관계는 이미 분리돼 있었습니다. [실제 GLB·packed 정점에서 재계산한 모든 시작값과 입력 해시](muscle-peel-audit.json). 전체 근육계529개 메쉬 중 명시적으로 제약된 고유 메쉬는 기존66→76개, 관계는60→66개입니다. 나머지453개 메쉬의 상대 제거 순서는 여전히 기하학적 추정입니다. 메쉬 개수를 독립 근육 수로 해석하지 않습니다.

실제 원본으로 재생성한 일정의 여섯 관계 모두 역전0·4%p 페이드 겹침0을 확인했습니다. 원본 출처·정확한 명칭/ID·좌우 검사와 각 관계의0.5% 입력201개 스칼라 투명도 검사5/5가 통과했습니다. 전체 Node 회귀는338/339이며 HTTP 경계 검사1개가 `127.0.0.1 listen EPERM`으로 실패했습니다. TypeScript·정적 Vite 빌드는 통과했습니다. 근육 형상·좌표·계통 경계·선택/카메라 전이는 바꾸지 않았습니다. 다만 현 실행 환경은 `127.0.0.1` 포트와 Chromium Mach 포트가 차단돼 실제 GPU 장면·남녀 데스크톱/모바일 화면·전신201단계 형상 감사·프로덕션 검사는 **아직 실행하지 못했습니다**. 따라서 출시 검증 완료라고 기록하지 않습니다. 기존 종아리·엉덩이 화면을 이번 앞넓적다리 결과의 캡처로 대신하지 않습니다.

재현: `node scripts/audit-muscle-peel.mjs`로 실제 원본 일정·해시를 다시 만들고 `node --test tests/muscle-peel.test.mjs`로 수록·관계·0.5% 선후를 검사합니다. 브라우저가 가능한 환경에서는 기존 `tests/browser/muscle-peel.spec.ts`가 새 관계도 포함하도록 구성됐으므로 이를 실행하고 앞/옆·모바일 화면을 직접 확인해야 합니다. 전체 여성 상체 근육 누락, 보완 근육/골격 위치, 기관·혈관·림프·신경의 실제 공간 관계와 임상 박리 층서는 계속 미완료입니다.

후속 실행 환경에서 남녀 공통 근육 박리2/2를 통과했고, 여성 앞넓적다리 전용 브라우저1/1을 추가해 실제6메쉬·4관계의47~55% 일곱 설정에서 겉쪽 종료 전 안쪽 페이드 시작0, 월드 경계/행렬 변화0을 확인했습니다. [48% 데스크톱](anterior-thigh-peel-48-1440.png)·[52% 데스크톱](anterior-thigh-peel-52-1440.png)·[48% 모바일](anterior-thigh-peel-48-390.png)·[52% 모바일](anterior-thigh-peel-52-390.png)을 직접 검토했습니다. 기본 전신에서 중복 숨김 처리된 기증자 넙다리곧은근은 `visible=false`만으로 제거 순서를 입증할 수 없으므로 실제 재질 투명도도 검사합니다. 후속으로 모바일에서 `VHF0009`를 개별 선택해 원본 HRA 넙다리곧은근과 교대 표시되는지 확인하고 [선택 화면](anterior-thigh-donor-selected-mobile.png)을 검토했습니다. 이때 이동 패드가 일반 선택 카드를 가리는 문제를 발견해 모든 선택 카드에 접이식 이동 도구를 적용하고 경계 간격·패드 열기·위로 이동 클릭까지 검사했습니다. 기존 차용 상지 뼈와 하체 정렬 한계가 화면에 남아 있으며, 이 테스트는 앞넓적다리의 실제 공간 접촉·전신 위치를 승인하지 않습니다. 당시 HTTP/브라우저 실패 기록은 소급 변경하지 않습니다.

agy 읽기 전용 정적 검토 `7eaf6b01-41e4-4a52-ac8d-dd71a340c03f`는 표시 순서와 성별 ID 경계 주장에 새 P1을 보고하지 않았고, 위 기본 숨김 메쉬의 `visible` 단언은 단독으로 약하다고 지적했습니다. 이에 개별 선택 경로를 실제 브라우저로 추가 확인했습니다. agy는 직접 화면을 조작하거나 의학적 위치를 판독한 것이 아닙니다.
