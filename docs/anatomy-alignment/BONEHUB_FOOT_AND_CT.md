# 여성 고유 발의 직접 배치와 동일 촬영 CT 확보 — 2026-09-27

새 BoneHub 여성 발을 HRA 정강뼈·종아리뼈에 직접 대응시켰으나 **이번 후보도 피부 조건을 통과하지 못해 앱에 적용하지 않았습니다.** 후속 기준으로 이 골격과 같은 버전의 실제 여성 CT도 확보했습니다. 자료 확보를 전신 교정 완료로 표시하지 않습니다.

## 직접 골격 맞춤과 실패한 방식

[이전 공통 좌표 검사](BONEHUB_DENVER_FRAME.md)의 변환은 초기값으로만 사용했습니다. 이후 원본 BoneHub 정강뼈/종아리뼈와 실제 HRA 동명 구조의 표면을 직접 비교했습니다. 남성 보완 발을 맞춤 목표로 사용하지 않았습니다.

- 양방향512표본·먼20% 제외 방식은240회 제한에 도달하고, 원본→HRA 전체 정점 p95가11.321–15.426mm로 악화됐습니다. [실패 기록](bonehub-foot-shank-symmetric.json).
- 원본 정점2,000개/뼈·한 방향·제외 없는 맞춤은88/76회 후 표본 변화 조건에서 종료했습니다. 종아리뼈 p95는 좌우7.924/7.104→3.703/3.855mm로 줄었지만, 정강뼈 p95는3.878/4.503→4.495/4.629mm로 조금 늘었습니다. 이를 모든 뼈의 개선으로 일반화하지 않습니다. [후속 후보](bonehub-foot-shank.json).

HRA 대상은 정강뼈385정점씩, 종아리뼈169/168정점의 단순한 참조 표면입니다. 원본 정점 분포·대응 정의가 다른 최근접 맞춤이며, 수치 종료는 관절축·임상 위치 검증이 아닙니다.

## 발17구조를 한 묶음으로 유지한 자세 시험

각 발의 원본7개 발목뼈·5개 발허리뼈·5개 발가락 묶음을 같은 강체변환으로 움직였습니다. 개별 마디뼈/FMA를 새로 만들거나 발 일부를 줄이지 않았습니다. 초기 균일 배율은 왼쪽1.010834·오른쪽0.993716이며 이후 발 자세 탐색은 추가 배율 없이 회전·이동만 사용했습니다.

수치적 목말뼈 상자 중심을 기준으로 pitch→roll→yaw를 적용합니다.15mm 이동 한계와 각도 범위는 생리적 가동 범위로 검증된 값이 아닙니다. 탐색은 파일당200정점 표본으로 하고, 최종 저장 좌표에서는 모든 정점과 지정 발목 뼈의 삼각형 교차를 검사했습니다.

| 전체 검사 | 왼쪽 | 오른쪽 |
| --- | ---: | ---: |
| 검사 정점 |121,256 |121,474 |
| 회전 전 피부2mm 경계대 밖 |62,161 |56,849 |
| 자세 후보의 피부2mm 경계대 밖 |5,970 |1,091 |
| 후보의 최대 바깥 거리 |12.482mm |4.284mm |
| 후보 발–정강뼈/종아리뼈 엄격 표면 교차 쌍 |0 |0 |

왼쪽은 주로 발꿈치뼈3,701정점, 오른쪽은 발꿈치뼈1,039정점에 이탈이 남습니다. 발허리뼈/발가락 묶음의 나머지 이탈도 그대로 기록했습니다. 표본 이탈95/11개를 전체 검사 결과로 바꾸어 쓰지 않습니다. 후보 순위는 교차가 없는 결과를 우선하지만, 모든 후보가 교차한다면 교차 없는 결과를 보장하지 않습니다. 교차0 또한 관절 간격·고체 분리·연부조직 연결을 증명하지 않습니다. [전체 검사](bonehub-foot-pose.json).

별도 binary STL 판독과 스칼라 산술로68개 중간/후보 메쉬의 삼각형 정점 참조2,911,944회를 재계산했습니다. mm→m의 Float32 변환, 정강뼈 맞춤, 발 강체변환을 순서대로 대조했고 인덱스·고정 피부/대상 뼈는 보존됐습니다. [독립 재읽기](bonehub-foot-readback.json). 포함·교차 알고리즘의 독립 임상 검증은 아닙니다.

[왼쪽 정면](bonehub-foot-left-anterior.png)·[측면](bonehub-foot-left-lateral.png), [오른쪽 정면](bonehub-foot-right-anterior.png)·[측면](bonehub-foot-right-lateral.png)을 직접 확인했습니다. 발꿈치/발끝 이탈을 숨기지 않았고 각 화면에 원본17개 라벨 모두를 표시했습니다. 상단과 반대 반신의 시각적 자름은 [촬영 기록](bonehub-foot-visual.json)에 명시합니다. 앱 UI·모바일 사용성 검사가 아닙니다.

agy `97def86b-b0f8-460c-a6d9-3d15978b9e9c`는 스크립트의 제한 정적 검토만 수행했습니다. “항상 교차0 강제”, 피부 밖 거리를 “침투 깊이”로 부른 표현, JSON 좌표 대조를 모든 비트 보존으로 확대한 표현은 후속 정정했습니다. 실제 후보 실행과 재읽기는 별도 수행했습니다. `--all-vertices` 목적함수 모드는 이번에 실행하지 않았으며, 이 기록은 **표본 탐색 뒤 전체 정점 검사**입니다.

## 같은 골격의 여성 전신 CT

[BoneHub 원본·저작자·CC BY4.0 고지](BONEHUB_FEMALE_SOURCE.md)의 같은 고정 커밋에서 `CT/Image/02_Female.nii.gz`를 추가 확보했습니다.501,395,759바이트, 공개 LFS SHA-256 `638c569c9a702a6c7b3f50e36fe4be8ef7acc2ab0c53d960ad19418d7f00d979`와 일치합니다. 전체 gzip 스트림의 CRC/길이를 검사했습니다. 기존157파일 영수증과 구분한 [추가 CT 영수증](bonehub-female-ct-receipt.json)이며 대형 영상 자체는 GitHub에 올리지 않습니다.

실제 격자는673×670×1,727, 복셀 간격0.722656×0.722656×1mm입니다. NIfTI RAS 행렬을 LPS로 바꾸면11개 분할 NRRD 헤더의 모든 복셀 중심 좌표와 일치합니다. 독립 nibabel5.2.1 판독으로 qform/sform·자료형·단위를 대조했습니다. 부호 반전에서 생기는 -0과0은 같은 좌표로 처리하며, 이 차이로 첫 엄격 비교가 실패한 뒤 정규화해 재검사했습니다. [격자 검사](bonehub-female-ct-grid.json), [독립 판독](bonehub-female-ct-readback.json).

전체778,721,570복셀의 저장 값 범위는0–4,050이며0값은323,936,364개입니다. 자료형은 unsigned16bit, slope1/intercept0입니다. **이를 HU라고 단정하거나 임의의 HU 임계값으로 조직을 분할하지 않았습니다.** 동일 격자는 해부 라벨·영상 범위·연결의 정확도를 승인하지 않으며 원본 팔꿈치 결손도 남습니다. 아직 이 CT에서 피부·근육·장기 표면을 만들거나 앱에 추가한 것은 아닙니다.
