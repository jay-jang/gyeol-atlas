[번호가 붙은 해부 표본](https://www.lumen.luc.edu/lumen/meded/grossanatomy/dissector/labs/le/glut_post_th/g2_1a.htm)과 연결 사진도 직접 확인했습니다. 원문/사진은 저장소나 앱에 재배포하지 않았습니다.

- 큰볼기근 → 중간볼기근 → 작은볼기근.
- 큰볼기근 → 궁둥구멍근.

궁둥구멍근과 중간/작은볼기근 사이에는 선후 관계를 추가하지 않았습니다. 엉덩이의 모든 근육·근막·힘줄에 대한 순서가 아니며, 표층 근육이 심층 근육 전체를 덮는다는 뜻도 아닙니다. 후방 해부의 제한된 관계를 표시 순서에 반영한 것으로, 신경혈관 주행이나 임상 박리술을 재현하지 않습니다.
