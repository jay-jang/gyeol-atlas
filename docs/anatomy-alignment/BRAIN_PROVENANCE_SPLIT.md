# 여성 뇌 묶음의 출처 분리 — 2026-09-27

기존 283개 전체를 Allen 기반으로 표시한 것은 잘못됐습니다. 현재 고정 HRA 여성 전신 v1.10 GLB의 **개별 노드 메타데이터**를 대조해 Allen 참조 282개와 Visible Human 시신경교차 1개로 구분했습니다. 뇌 묶음의 수록 283개·원문 이름·안정 ID·좌표·삼각형·선택 경로는 변경하지 않았습니다.

| 대상 | 원본 노드의 근거 | 수정 |
| --- | --- | --- |
| `HRAF0070`, `Optic chiasm` | `VH_F_optic_chiasm`; `anatomical_structure_of=#VHFBrain`; `glb_file_of_single_organs=VH_F_Brain&lf;` | Visible Human 여성 시신경교차로 출처 수정. 주변 구조와 위치·연결 미검증 명시 |
| 나머지 282개 | `anatomical_structure_of=#VHFAllenBrain`; `glb_file_of_single_organs=Allen_F_Brain&lf;` | Allen 기반 참조 설명 유지. 여성 기증자 뇌 스캔으로 주장하지 않음 |

이 구분은 `Allen_brain` 부모 노드나 표시 계통 `brain`만으로 원본을 추정하지 않습니다. [원본 SHA-256, 아틀라스 SHA-256 및 283개 메타데이터 기록](../../data/catalog/female-brain-provenance.json)을 남겼습니다. 알 수 없는 출처 조합은 자동으로 Allen에 배정하지 않고 생성 검사를 실패시킵니다. 카탈로그 가져오기는 아틀라스 해시와 이름/개념 ID를 확인합니다.

[NIH / HRA 공식 설명](https://3d.nih.gov/entries/3DPX-020959)은 141개 Allen 참조 구조를 대칭 복제해 Visible Human 신체 크기에 맞췄다고 설명합니다. 이 기관 자료 설명을 전신 GLB의 서로 다른 출처인 시신경교차까지 일반화하지 않습니다.

## 검증 범위

- `scripts/audit-female-brain-provenance.mjs`: 원본 GLB JSON을 읽어 출처 기록 생성. 기하 변경 없음.
- `tests/brain-provenance.test.mjs`: 전체 283개 수록·ID·원문명·출처 구분 및 입력 해시 검사. 별도 `@gltf-transform/core` 판독기로 원본 GLB 283개 노드의 메타데이터도 대조합니다. 이 원본 캐시가 없는 환경에서는 독립 원본 검사를 명시적으로 건너뛰며, 현재 로컬에서는 실제 실행했습니다.
- `tests/browser/brain-provenance.spec.ts`: 전체 묶음과 시신경교차·Allen 구조의 개별 선택 설명, 남성 복귀, 데스크톱·모바일·가로 화면의 모델 여백과 복귀 버튼/출처 접근을 검사합니다. 이전 캡처는 보존하고 `brain-origins-*`, `optic-chiasm-origin-*` 이름으로 새 캡처를 저장합니다.

첫 실제 브라우저 검사에서 시신경교차를 선택하고 긴 출처와 세부 목록을 펼쳤을 때 데스크톱의 복귀 버튼이 카드 스크롤 밖으로 사라졌습니다. 모바일과 같은 설명/조작 영역 분리를 데스크톱에도 적용해 설명만 스크롤하고 조작은 카드 하단에 유지하도록 수정했습니다. 가로 화면의 기존 별도 배치는 유지합니다.

원본 메타데이터의 출처 구분은 임상적 조직 판독이나 정확한 위치의 증명이 아닙니다. 기존 Allen 좌우 표기와 전신 방향 불일치, 신경–골격 교차, 다른 출처의 근육/골격 정합은 해결하지 않았습니다. 이번 수정으로 좌우를 교환하거나 반사하지 않았으며 **전체 목표는 미완료**입니다.
