## 독립 맞춤 결과

기존 종아리(경골·비골), 전 다리(대퇴골·슬개골·경골·비골) 맞춤에 허벅지(대퇴골·슬개골) 맞춤을 추가했습니다. 허벅지는 원본의 기존 허벅지 변환에서 시작합니다. 각 뼈 최대2,000개 결정적 정점 표본으로 동일 이름의 실제 HRA 뼈 표면에 가장 가까운 점을 찾아 회전·이동·균일 배율을 반복 계산합니다. 해부 표지점 대응이나 비선형 변형은 아닙니다. 네 기존 맞춤 결과는 이전 기록과 정확히 같습니다.

| 허벅지 맞춤 | 왼쪽 | 오른쪽 |
| --- | ---: | ---: |
| 표본 RMS, 전→후(mm) |10.225→3.918 |6.815→3.663 |
| 전체 원본 대퇴골 참조 정점→HRA 표면 p95(mm) |12.203 |12.313 |
| 전체 HRA 대퇴골 참조 정점→원본 표면 p95(mm) |4.466 |6.526 |

양쪽 모두 수렴했지만 잔차가 남습니다. 표본 RMS의 감소나 수렴만으로 허벅지 근육에 이 변환을 적용하지 않습니다. 모든 참조 정점의 양방향 거리는 검사했지만 삼각형 내부까지 포함한 연속 표면 거리의 상한은 아닙니다.

## 두 변환이 같은 원본 점을 어디로 보내는가

허벅지 변환과 종아리 변환을 **동일한 원본 뼈 정점** 각각에 적용해 두 결과 사이 거리를 계산했습니다. 이는 뼈 사이 실제 간격이나 근육 부착점 이동량이 아니라, 두 좌표 변환의 불일치 진단입니다. 다음은 각 뼈 전체 참조 정점 중 최대값입니다. 경골·비골 전체를 무릎 주변에 한정한 측정으로 해석하지 않습니다.

| 원본 뼈 | 왼쪽 최대(mm) | 오른쪽 최대(mm) |
| --- | ---: | ---: |
| 대퇴골 |19.089 |16.648 |
| 슬개골 |4.687 |5.244 |
| 경골 |11.026 |14.556 |
| 비골 |12.189 |15.941 |

최대값을 재현하는 원본 좌표·정점 번호를 [전체 기록](joint-bone-surface-fits.json)에 보존했습니다. 이 결과는 서로 다른 변환을 근육 모형별로 배정하는 방식에 한계가 있음을 보여 주지만, 두 변환의 단순 혼합이나 임의 변형을 정당화하지 않습니다. 근육 부착 위치·관절 주변 연결, 피부/다른 조직과의 관계를 함께 검증하는 교정이 아직 필요합니다. 실제 연속 변형장은 만들거나 적용하지 않았습니다.

## 재현·검증

```sh
npm exec --yes --package=node@24.14.0 -- node scripts/fit-donor-bone-surfaces.mjs '추출한/Final 3D STL Models-stl' --joint-analysis
```

출력은 `.cache/calf-registration/joint-bone-surface-fits.json`입니다. 옵션 없는 기존4개 맞춤과 그 출력 경로는 유지합니다. 원본 STL·대상 청크 해시를 먼저 확인합니다. 단위 검사는 기존4개 결과 불변, 신규 허벅지 맞춤의 대상/수렴, 저장된 최대 불일치 좌표의 행렬 재계산을 확인합니다. 원본 전체 기하 실행은 위 명령으로 별도 수행했으며, 저장된 기록을 읽는 단위 검사를 전체 재계산이라고 부르지 않습니다.

앱 변경이 없어 이번에는 브라우저 검사를 반복하지 않았습니다. 여성 전체 정합 및 기존 전체 목표는 미완료입니다.

단위75/75 통과. agy 대화 `561d688c-1f73-4d20-8a35-eef695d37a4e`의 읽기 전용 제한 범위 정적 검토는 구체적 코드 문제를 보고하지 않았습니다. 원본 좌표 증거는 미터 단위이며, agy 응답의 모호한 ‘unscaled/scaled’ 표현과 달리 두 단위를 함께 저장한 것은 아닙니다. 이 검토를 별도의 원본 기하 실행·시각 검사·의학 검증으로 해석하지 않습니다.
