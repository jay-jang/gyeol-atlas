# 여성 자궁 원인대의 좌우 형상 연결 교정 — 2026-09-28

여성 HRA 전신 원본의 자궁 원인대 한 쌍은 이름·개념 ID가 가리키는 쪽과 실제 형상이 놓인 쪽이 반대입니다. 원문 ID와 영문 이름을 보존하면서, **이 두 ID에 한해서** 기존 반대쪽 위치·법선·삼각형 버퍼 전체를 연결했습니다. 새 모형·반사·변형·기관 경로를 만들지 않았습니다. 이는 여성 골반 기관 전체의 위치 교정이 아닙니다.

## 원본에서 확인한 범위

[공식 HRA 여성 전신 v1.10 GLB](https://cdn.humanatlas.io/digital-objects/ref-organ/united-female/v1.10/assets/3d-vh-f-united.glb)의 SHA-256은 `95f0c3d2f918582608692ca1139e8bdb18c147a16470e9ee9af8b276bd77c422`, 현 포장 목록의 해시는 `349ad9085901db2cced179d467542271289ee0b259414a78814402d5ac374d2f`입니다. 두 원본은 [감사 수치](female-pelvic-laterality-audit.json)에 고정했습니다. 원본 GLB의 여섯 노드를 직접 판독하고 포장 형상의 X 경계가 동일한 공통 이동 `+0.006095477878m`만 받는 것을 확인했습니다. 이 검사에서 원본 원인대의 좌우가 가져오기 중 뒤집힌 것이 아닙니다.

뇌(Allen 별도 참조)와 남성 유래 골격·기증자 근육을 제외한 여성 고유 자료에서, 영어 이름의 `left`/`right`만 바꿔 정확히 짝이 되는 **185쌍**을 비교했습니다. 중심 X 선후가 다른 것은 이 한 쌍뿐입니다. 이 방법은 이름이 다르거나 한쪽만 있는 구조·정중선 구조를 누락하므로 전 구조 좌우 검증이 아닙니다. 좌측 난소·자궁주인대의 중심 X가 양수, 우측의 중심 X가 음수인 것을 같은 원본의 내부 기준으로 삼았습니다. 자궁주인대의 왼쪽 표면은 정중선 X=0을 조금 넘으므로 최초 ‘각 왼쪽 기준 구조의 모든 정점이 양수’ 검사는 실패했습니다. 중심 선후로 조건을 바로잡아 다시 실행했고, 원인대 두 형상은 각각 정중면 한쪽에 전부 놓임을 별도로 확인했습니다.

| 원문 ID/이름 | 원본 포장 X 범위(m) | 연결한 형상 출처 |
| --- | ---: | --- |
| `HRAF0417` Right round ligament of uterus | `+0.008164…+0.055067` | `HRAF0418`의 음수 쪽 전체 버퍼 |
| `HRAF0418` Left round ligament of uterus | `−0.085331…−0.024503` | `HRAF0417`의 양수 쪽 전체 버퍼 |

이 판단은 같은 자료 안의 좌우 배치 일관성에 관한 것입니다. 자궁 부착점·인대의 실제 주행·임상적 좌우 확인, 다른 기관·신경의 관계까지 증명하지 않습니다. 공식 원본의 표기가 왜 다른지 원인도 확인하지 못했습니다.

## 앱 연결과 사용자 안내

[`female-pelvic-bindings.json`](../../data/catalog/female-pelvic-bindings.json)은 두 ID·원문 이름·상대 형상 ID와 고정 원본 해시를 기록합니다. `PackedAtlas`는 여성 전신에서만 이 쌍의 버퍼 출처를 바꾸고, 실제 형상 출처 ID/이름을 장면 메타데이터로 남깁니다. 원문 `name`과 `conceptId` 및 기존 여성 카탈로그 파일은 그대로이며, 실행 시 화면용 한국어 표기 `왼쪽/오른쪽 자궁원인대`를 추가합니다. 선택 카드에는 원문과 반대 형상 연결 및 제한을 명시합니다. 남성·독립 여성 CT 상세·다른 여성 형상은 바꾸지 않습니다.

저장된 과거 세션에서 이 중 한쪽만 선택한 확대 시점은 옛 반대쪽을 향할 수 있어 첫 복원 때만 다시 맞춥니다. 양쪽 묶음·다른 구조와 표식/필터 선호는 유지하고, 이후 새로고침은 새 시점을 보존합니다. 레이어·선택·박리 전이 자체는 `view-state.ts` 경로를 그대로 사용합니다.

## 실제 검증과 한계

단위 검사는 매니페스트·원문 개념명·양쪽 버퍼의 SHA-256 다중집합 보존·오래된 단독 선택 시점 이동·짝 전체/다른 선택의 시점 보존을 검사합니다. 브라우저는 실제 두 장면 메쉬의 위치·법선·인덱스 바이트와 출처 태그가 여성 **201개 0.5% 설정** 전체에서 변하지 않는지 검사합니다. 두 ID를 검색해 선택 카드와 확대 시점을 확인하고 과거 저장 상태 복원도 확인했습니다. [오른쪽 데스크톱](pelvic-binding-right-desktop.png)·[왼쪽 데스크톱](pelvic-binding-left-desktop.png)·[오른쪽 모바일](pelvic-binding-right-mobile.png)을 직접 확인했습니다. 모바일에서도 캔버스가 남고 가로 넘침은 없습니다. 전체 게이트 결과는 [검증 기록](VERIFICATION.md)에 남깁니다.

첫 전체 단위 검사에서는 구조 카탈로그 설명 두 줄을 원본 파일에 직접 바꿔 과거 위치 감사16건의 입력 해시 검사가 실패했습니다. 형상·수치가 달라졌다는 실패가 아닙니다. 원래 카탈로그 파일을 정확히 복원하고 표시용 문구를 실행 시 덧씌우도록 변경한 뒤 단위328/328, 관련 뇌·골반·부위 브라우저5/5와 빌드를 통과했습니다. 과거 감사 보고서의 해시를 새 값으로 고쳐 쓰지 않았습니다.

첫 전체 브라우저 실행은83/84였습니다. 팔·발 형상 전수 회귀의 예상 해시 산출기가 뇌 좌우 연결만 알고 이 새 원인대 연결을 모르고 있어, 정확히 `HRAF0417`/`HRAF0418`의 기대 해시가 서로 바뀐 실패였습니다. 예상 산출에 고정 명세를 추가한 뒤 팔·발 검사와 새 원인대 검사를2/2 재실행했습니다. 실패한 전체 실행을 전체 통과로 기록하지 않습니다. 기존 피부 위치 감사기는 향후 재실행 시 두 ID의 실제 렌더링 출처를 사용하도록 갱신했지만, 역사적 감사 JSON의 수치를 소급 변경하지 않았습니다.

수정 후 단일 전체 브라우저84/84(22.9분), Node 단위328/328, 빌드, 남녀 각201단계 형상 감사(각163,944·245,220개 비교, 최대 정점 이동0m), 프로덕션 스모크, 모바일12px/4.5:1 가독성 및 네 화면 크기 시각 게이트를 통과했습니다. 생성된 데스크톱·모바일·작은 모바일·가로 캡처를 직접 확인했습니다. 작은 모바일 비교 카드가 장면 일부를 가리지만 모델 공간 전체를 대체하지는 않습니다. 이 검사는 새 버퍼 연결의 불변성과 화면 작동을 다루며 해부학적 주행을 보증하지 않습니다.
