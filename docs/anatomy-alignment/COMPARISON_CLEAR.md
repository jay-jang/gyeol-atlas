# 비교 선택 해제 후 남는 강조 교정 — 2026-09-28

남성 콩팥 비교를 단독 표시한 뒤 ‘구조 선택 해제’를 누르면 카드만 사라지고 `comparison`이 남는 오류를 실제 브라우저에서 재현했습니다. 비교 메쉬 강조와 비교 안내가 계속 남고 저장 상태에서도 유지되는 경로였습니다. 기존 가로 비교 검사는 카드/목록 복귀만 확인했으므로 이 실패를 검출하지 못했습니다.

## 수정

- 공통 `src/view-state.ts`의 `clear-selection`에서 선택·상세·단독 보기와 함께 비교도 종료합니다. 새 제어 경로는 없습니다.
- 이전 버전에서 생긴 유효한 `selection:null`, `comparison:…` 저장값은 복원 시 비교만 제거합니다. 손상된 ID·다른 경혈 비교 등은 기존 검증대로 초기화하며, 유효성 검사를 건너뛰지 않습니다.
- 비교 중 레이어 인자 없이 개별 구조를 선택하는 기존 동작은 전체 비교 묶음을 유지합니다. 개별 선택과 비교 묶음을 하나로 합치지 않습니다.
- 카메라·레이어·투명도·표식·선택 경혈은 유지합니다. 비교 시작 때 설정된 피부 투명도를 이전 값으로 되돌리는 기능을 추가한 것은 아닙니다.

## 실행과 범위

새 단위 검사에서 남녀·단독/일반 비교·개별 구조 선택·이전 저장값 교정을 확인했습니다. 전체 단위306/306(건너뛰기0), 빌드, 기존 박리 입력4/4, 프로덕션 스모크를 통과했습니다. 큰 JS 청크 경고는 남습니다.

새 브라우저 검사는 남성 콩팥2개·여성 콩팥50개 실제 메쉬의 비교색 제거, 위치/인덱스 SHA-256·세계행렬 불변, 카메라/계통/투명도/표식 보존, 데스크톱1440×900·모바일390×844, 재로딩과 구버전 저장값 복원, 후속66.5% 박리를 검사합니다. 최초 수정 전 남성 비교 상태가 남는 실패를 확인했습니다. 구버전 복원 검사 보강 후 여성 카메라의 약9×10⁻¹⁶m 부동소수점 차이로 엄격 동일 검사가 실패하여, 재로딩 카메라만 소수8자리 비교로 수정했습니다. 이를 해부 좌표 결함으로 세지 않습니다.

최종 새 브라우저2/2(각각 데스크톱·모바일 포함)가 통과했습니다. 기존 박리 입력4개와 합쳐 관련6개 시나리오이며, 반복 실행을 별개 검사 수로 세지 않습니다. 전체 브라우저 스위트와201단계 전신 기하 검사를 새로 전수 실행한 것은 아닙니다.
