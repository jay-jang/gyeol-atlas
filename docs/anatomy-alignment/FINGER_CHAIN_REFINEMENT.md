## agy와 재현

agy CLI의 세 차례 제한 정적 검토는 후보/표면 함수4파일, 결합 검사, 생성기/회귀 검사를 대상으로 했습니다. 내부 관절 재측정은 Float32 합성/저장 회귀에 의미가 있어 ‘완전히 동일하므로 무의미’하다는 최초 평가는 채택하지 않았습니다. 회전만 한 피부 최적값과 기존 공개 좌표 대비 비악화도 별도 기준입니다. 두 번째 답변의 비피부1219개는 실제1200개로 정정했고, 무충돌/해부 유효성 보증이라는 일반화는 채택하지 않습니다. agy는 기하 계산·브라우저·임상 검수를 실행하지 않았습니다.

```sh
npm exec --yes --package=node@24.14.0 -- node scripts/experiment-finger-chains.mjs
# 개발 서버5174 필요; 다른 브라우저와 동시에 실행하지 않음
npm exec --yes --package=node@24.14.0 -- node scripts/capture-finger-chains.mjs
npm exec --yes --package=node@24.14.0 -- node scripts/build-finger-refinement.mjs
```

생성기의 기본 출력은 캐시이며 `--export`에서만 검사 기록·기준v2·v3카탈로그를 씁니다. 여성 고유 자료의 정합·뇌/신경 관계·전체 기관 세부화·실제 근육 층서의 전체 목표는 계속 미완료입니다.
