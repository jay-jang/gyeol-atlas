# 원본 근육에 대한 공통 공간 변형 후보 — 2026-09-21

**두 실험 후보 모두 거부했으며 앱에는 적용하지 않았습니다.** 모형별 변환 때문에 생겼던 간격을 없애기 위해 공통 공간 함수를 계산했지만, 연속적인 함수라는 사실만으로 해부 정합이 되지 않았습니다.

## 입력과 방법

단순화 없는 원본76근육,652,173참조 정점·1,304,042삼각형을 사용했습니다. 입력은 [원본 형상 보존 검사](DONOR_FIDELITY.md)의 압축 파일 해시와 대조했습니다. 동일 원본의 골반·대퇴골/슬개골·경골/비골을 좌우 각각 묶어6개 거리 기준을 만들었습니다. 허벅지·종아리 변환은 [후손 표면을 포함한 정합](FEMUR_TARGET_CORRECTION.md), 골반 변환은 **아직 거친 기존 경계상자 정합**입니다.

원본 좌표의 점 `p`에서 각 기준 뼈 표면까지 거리로 가중치를 구하고,6개 변환 결과를 정규화해 합쳤습니다. 근육 ID·좌우에 따른 함수 분기는 없습니다. 이번 실험의 선택이지 생물학적 부착 규칙이라는 뜻은 아닙니다. 두 방식의 길이 매개변수는20mm이며 수치 실험값이지 조직 두께나 검증된 정합 매개변수가 아닙니다.

- 역제곱: `q = 1 / (거리² + 길이²)`
- 가우스: `q = exp(-거리² / (2 × 길이²))`. 가장 큰 지수값을 공통으로 빼 언더플로를 방지합니다.

골격 자체를 정확히 고정하는 제약은 아닙니다. 원본의 삼각형 연결·방향은 유지하지만 정점은 비선형으로 변형합니다. ‘원본 형상 보존’은 입력에 해당하며 출력 형상이 불변이라는 주장이 아닙니다.

## 같은 정점을 비교한 피부 결과

기준은 **고충실도 원본 근육에 기존 모형별 변환을 적용한 상태**입니다. 배포 중인 단순화 근육과 정점 밀도가 다르므로 이전4,060개 등의 수치와 직접 비교하지 않습니다. 두 후보는 같은652,173개 정점을 기존 변환/후보 변환으로 각각 검사했습니다. 피부2mm 경계대와 세 방향 광선의 불일치 기록을 유지했습니다.

국소 변형률을 해석식으로 계산했고, 가장 작은 행렬식의 정점에서1µm 중심 차분으로 별도 확인했습니다. 행렬 원소의 최대 차이는 역제곱4.63×10⁻¹⁰·가우스3.82×10⁻⁹ 이내입니다. 가우스의 음수 행렬식도 재현됐습니다. 반대로 역제곱의 검사 정점에 음수가 없다는 사실은 전역 단사성·삼각형 유효성·비교차를 증명하지 않습니다. 최근접 표면이 바뀌는 곳은 미분 불가능할 수도 있습니다.

## 후속 방향을 바꾸는 두 관찰

가우스 최소 행렬식은 왼쪽 큰볼기근 VHF0025에서 나왔습니다. 이 점은 왼쪽 골반 변환47.96%와 허벅지 변환52.04%가 지배하며, 두 변환이 같은 원본 점을 보내는 위치는29.174mm 다릅니다. 골반의 거친 변환과 허벅지의 새 표면 변환을 거리 가중치만으로 섞는 방식을 승인할 수 없습니다. 이것만으로 모든 결함의 원인이 골반이라는 뜻은 아닙니다.

가우스 왼쪽 긴발가락굽힘근 VHF0018의 최대 피부 이탈 정점은 왼쪽 종아리 기준 표면까지2.911mm, 오른쪽까지37.301mm였는데도 오른쪽 종아리 변환이15.08% 섞였습니다. 공간적으로 가깝다는 사실은 같은 쪽 근육의 부착 관계가 아닙니다. 따라서 후속 작업에는 골반의 실제 표면 맞춤과 **좌우·부착 관계에 맞는 영향 범위** 검토가 필요합니다. 공통 공간 함수 자체를 목표나 해부학적 정답으로 삼지 않습니다.

[공식 자료 설명](https://digitalcommons.du.edu/visiblehuman/1/)은 Pelvis STL을 각 측의 엉덩뼈·궁둥뼈·두덩뼈 조합으로 정의합니다. 후속 골반 기준은 이 실제 구조를 대조해야 하며 기존 경계상자만의 일치를 충분한 증거로 쓰지 않습니다. 같은 페이지의 원본 STL·메타데이터 다운로드도 확인했지만 자동 요청은403이었습니다. 해당 파일의 내용은 확인했다고 주장하지 않습니다.

## 저장·검증 범위

두 후보의 gzip을 다시 읽어 전체 정점의 유한성, 바이트 범위, 삼각형 인덱스·방향의 원본 대비 일치, 모든 최대 피부 이탈 증거 좌표를 확인했습니다. [역제곱 재읽기](continuous-inverse-square-readback.json), [가우스 재읽기](continuous-gaussian-readback.json). 이는 직렬화 검사이며 정합 승인이 아닙니다. 후보 바이너리는 `.cache/donor-continuous/`에만 있습니다.

두 후보 모두 피부/국소 방향 검사에서 이미 실패했으므로 이번에는 전체 조직 교차나 부착점·시각 검사를 수행하지 않았습니다. 이들을 통과했다고 기록하지 않습니다. 앱의 기하·선택·박리·성별 자료는 변경하지 않았고 전체 목표는 미완료입니다.

```sh
npm exec --yes --package=node@24.14.0 -- node scripts/build-continuous-donor-candidate.mjs '추출한/Final 3D STL Models-stl' 20 inverse-square
npm exec --yes --package=node@24.14.0 -- node scripts/build-continuous-donor-candidate.mjs '추출한/Final 3D STL Models-stl' 20 gaussian
npm exec --yes --package=node@24.14.0 -- node scripts/verify-continuous-donor-candidate.mjs .cache/donor-continuous/surface-weighted-inverse-square-20mm.json .cache/donor-continuous/surface-weighted-gaussian-20mm.json
```

단위 검사는 동일 변환으로의 환원, 두 가중치의 미분/중심 차분 대조, 합성 뒤집힘·유효하지 않은 입력·가우스 언더플로 대응, 기록·재읽기 결과의 일관성을 다룹니다. 원본 전체 계산은 위 명령으로 별도 실행했습니다.

단위85/85 통과. agy 대화 `a070e379-f801-4451-b24b-1a38eda0c453`의 읽기 전용 제한 범위 검토는 구체적인 코드 문제를 보고하지 않았습니다. 응답의 ‘skin expansion’은 정확하지 않은 표현입니다. 피부는 변형하지 않았고 변형된 근육의 피부 밖 정점 수가 늘어난 것입니다. 검토를 해부·시각·전체 교차 검사로 대신하지 않습니다.
