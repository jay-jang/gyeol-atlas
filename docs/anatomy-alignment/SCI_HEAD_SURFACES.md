# SCI 여성 머리 좌표 대조와 공유 경계 표면 — 2026-09-27

후속 [현재 전신과의 배치 시험](SCI_HEAD_PLACEMENT.md)에서 두 공통 변환 모두 뼈의 피부 이탈과 근사 눈 기준점 차이가 남아 거부했습니다. 원본 경계 보존이 전신 정합을 뜻하지 않습니다.

**원본 영상과 맞는 좌표계를 확인하고, 조직별 독립 표면 추출에서 발생한 교차를 공유 복셀 경계 방식으로 피하는 후보를 만들었습니다.** 앱의 머리·기관을 교체한 것은 아닙니다. 명칭 대응·표면 품질·전신 연결과 공개 파생 모델의 사용 조건 검토가 남아 있습니다.

## 실제 원본 좌표와 조직 해석

[SCI 공식 자료](https://sci.utah.edu/sci-head-model/)의 T1.zip(63,732,613바이트)과 Pseudo-CT.zip(6,737,736바이트)을 추가 확보하고 전체 SHA-256·ZIP CRC를 검사했습니다. [입력 해시와 헤더](sci-head-candidate.json)에 선택 파일의 해시도 보존했습니다. 원본 DICOM 파일이나 영상·파생 모델은 GitHub에 넣지 않았습니다.

분할 NRRD와 보정 T1 NRRD는208×256×256 크기·원점·방향 벡터가 정확히 일치합니다. T1이 `left-posterior-superior`를 명시하므로 분할의 같은 격자를 LPS로 해석합니다. 원본 DICOM 방향을 독립 판독한 검사는 아닙니다. NIfTI 합성 CT의 RAS affine·mm 단위와 대조하면 인덱스 대응은 `(i,j,k) → (207-i,255-j,k)`이며 수치 반올림 차이는0.000008복셀 미만입니다. 같은 배열 순서로 CT를 읽지 않고 두 축을 뒤집어 통계를 계산했습니다.

표면에는 `(L,P,S) mm → (L,S,-P)/1000 m`의 공통 회전·단위 변환만 적용했습니다. 이동·확대·좌우 반사·HRA 맞춤은 하지 않았습니다. `scanBoundaryXYZ`는 **원본 격자 X최소/최대, Y최소/최대, Z최소/최대** 순서이며, `scanBoundaryAxisOrder`에도 명시했습니다. 아틀라스 XYZ 순서가 아닙니다.

원본에는 숫자별 공식 이름표가 없어 다음은 영상 위치·대비와 공식 조직 종류를 대조한 **편집상 가설**입니다. 모든 `authoritativeNumericName`은 `false`입니다. 색이나 신호만으로 전문가 검수된 이름이라고 주장하지 않습니다.

## 독립 보간 표면의 실패

각 라벨을 따로 이진화한 Lewiner marching cubes 후보는 재료7개와 진단용 비배경 합집합1개, 총2,268,045참조 정점·4,547,302삼각형입니다. 공기·CSF도 포함하므로7개 모두 신경 조직이 아닙니다. 합집합은 재료를 중복 포함하며 새 기관이 아닙니다.

별도 Node 판독기로 모든 정점을 원본 NRRD 격자로 되돌려, 격자 모서리 정점은0.5경계, 나머지는 혼합 셀 내부에 있는지 검사했습니다. 최대 좌표 왕복 차이는0.000008mm 미만입니다. [재읽기와 교차 증거](sci-head-candidate-readback.json).

그러나 라벨2–3 사이에 삼각형 내부 교차 증거가 있습니다. 저장 증거의 평면 양쪽 거리 기준은0.577349mm이며 임상 관통 깊이가 아닙니다. 라벨2–6과3–6에는 같은 기준의 증거가 없었습니다. **검사한 것은 세 쌍뿐이며 무교차·자가교차 부재·해부 정확도를 증명하지 않습니다.** 원본 격자 소속이 맞는 정점만으로 인접 조직의 삼각형 경계 일치를 보장할 수 없다는 변환 결함을 확인했습니다.

## 공유 복셀 경계 후보와 전수 검사

별도 추출기에서는 라벨이 바뀌는 복셀 면을 한 번 정의합니다. 양쪽 조직은 같은 사각형·같은 대각선을 사용하고 방향만 반대로 가집니다. 원본 셀 경계 ±0.5 위치를 그대로 사용하며 매끈화·축소·재분할·국소 변형을 하지 않았습니다. [후보와 면별 라벨 쌍](sci-head-shared-candidate.json).

[전체 재읽기](sci-head-shared-readback.json). 합집합의4,276,318mm³는 진단용 비배경 복셀 부피이며, 조직 부피 합에 추가하지 않습니다. 인공 절단면을 포함하므로 환자의 완전한 기관 부피 측정도 아닙니다.

이 검사는 **공유 셀 경계의 표현 결함을 해결한 범위**입니다.1mm 계단형 표면이 남고, 모서리/꼭짓점에서 만나는 조직의 다양체 위상까지 보장하지 않습니다. 공유 면이 완전히 겹치므로 함께 불투명하게 렌더링하는 방식의 깊이 충돌 가능성도 별도 검토가 필요합니다. 이 후보를 매끈한 완성 모델로 바꾸어 표현하지 않습니다.

## 화면·agy·재현

두 후보를 각각1440×1000, 정면/왼쪽 시점과 세 가시 조합으로 캡처해 직접 확인했습니다. [독립 보간 캡처 해시](sci-head-candidate-capture.json), [공유 경계 캡처 해시](sci-head-shared-capture.json). 각 페이지 오류0, 원본 좌표·잠정 이름·절단 경계·앱 미적용을 표시했습니다. 실제 앱·모바일 조작 검사는 아닙니다.

agy 읽기 전용 대화 `dd41d305-296b-4686-990c-c6bfa09d6028`에서 변환/판독/캡처와 후속 공유 경계 코드를 제한 정적 검토했습니다. 실행 결과 파일도 읽었지만 agy 자체가 검사를 실행하지는 않았습니다. 최초 응답의 ‘양의 총 부피가 전체 외향 방향·다양체를 보장’, ‘라벨4 고신호 원인 확정’, ‘모든 정점은0.5등가면’은 후속 응답에서 정정했습니다. 좌표·경계 검사를 임상 정합 승인으로 해석하지 않습니다.

그 검토 이후 검증기에 정규 반쪽 면 소속과 원본 전체 경계 개수 대조를 추가해 직접 재실행했습니다. 부피 오차가 상쇄되는 누락을 부피 검사만으로 배제하지 않기 위한 보강이며, 이 추가 부분을 agy가 검토했다고 주장하지 않습니다.

기존 Node 단위116/116을 다시 통과했습니다. 이번 후보 생성·전수 재읽기는 위의 별도 실행이며 이116개 단위 검사 안에 포함됐다고 주장하지 않습니다. 앱 변경이 없어 로컬 앱 브라우저 회귀·프로덕션 검사를 반복하지 않았습니다.

```sh
.cache/female-ct-venv/bin/python scripts/build-sci-head-candidate.py
node scripts/verify-sci-head-candidate.mjs
.cache/female-ct-venv/bin/python scripts/build-sci-shared-surfaces.py
.cache/female-ct-venv/bin/python scripts/verify-sci-shared-surfaces.py
node scripts/capture-sci-head-candidate.mjs
node scripts/capture-sci-head-candidate.mjs --shared
```

Python 의존성은 기존 `scripts/requirements-female-ct.txt` 환경을 사용합니다. 이 환경에서 Node 명령은 `npm exec --yes --package=node@24.14.0 -- node`로 실행했습니다. 원본 ZIP3개와 파생 바이너리·PNG는 `.cache/sci-head/`에만 있습니다. **남녀 전체 기관·신경 위치, 실제 근육 층서, 전신 머리 연결과 최종 상세 모델 목표는 계속 미완료입니다.**
