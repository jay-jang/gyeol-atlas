# SCI 머리–현재 여성 전신 배치 시험 — 2026-09-27

**근사 기준점 배치와 피부 보정 배치 모두 거부했습니다.** [원본 좌표와 공유 경계를 보존한 머리](SCI_HEAD_SURFACES.md)도 다른 출처의 현재 여성 전신에 단순히 맞출 수 있다고 가정하지 않았습니다. 앱 자산·기관 선택·박리 좌표는 변경하지 않았습니다.

## 시험 범위

- SCI 라벨1의 실제 삼각형 연결 성분2개를 분리하고, 각 경계 상자 중심을 눈의 근사 기준으로 사용했습니다. 이름은 여전히 영상 대조에 따른 가설입니다. X부호로 삼각형을 잘라 두 눈을 만든 것이 아닙니다.
- 현재 여성 전신의 오른쪽 공막/각막 `HRAF0026/0041`, 왼쪽 공막/각막 `HRAF0065/0050` 합집합의 경계 상자 중심을 대조했습니다. 눈꺼풀·근육·신경 전체를 안구 중심 계산에 넣지 않았습니다.
- 각 피부의 최고점 아래1mm 패치 정점 평균을 세 번째 근사 기준으로 사용해 공통 회전·이동·균일 배율을 구했습니다. 이 세 점은 전문가 해부 표지점이 아닙니다.
- 후속 후보는 원본 두 눈 평균 높이 아래40mm보다 높은 외피의 결정론적4,000정점 표본을 현재 **전체 피부의 최근접 삼각형 표면**에 반복 맞췄습니다. 눈 기준점은 이 후속 최적화의 제약이 아니며, 이후 오차를 따로 측정했습니다. 아래쪽 원본 절단면을 제외한 높이 자르기는 검수한 해부 영역 분할이 아닙니다.

맞춤에는4,000표본을 쓰지만 외피 거리 통계는 해당 높이 영역137,210정점 전체에서 계산했습니다. 피부 포함 검사는 라벨1·2·3·6의 참조 정점1,210,020개 전부에 수행했습니다. 다른 라벨·외피 전체·삼각형 내부까지 검사한 것은 아닙니다. 현재 피부의2mm 경계대와3방향 레이 분류를 사용하고 모호한 결과를 내부로 바꾸지 않았습니다.

두 출처의 근사 기준 삼각형도 비슷한 모양이 아닙니다. 양쪽 눈 중심 사이 거리는 SCI58.043mm, 현재 모델72.913mm이고, 눈–최고점 패치 거리는 SCI150.234/148.961mm, 현재135.118/135.574mm입니다. 각 변을 정확히 맞추는 배율이1.256/0.899/0.910으로 달라 **이 세 근사 기준을 공통 유사변환 하나로 모두 정확히 맞출 수 없습니다.** 이는 정상 안구 간격 측정이나 어느 원본이 해부학적으로 틀렸다는 판정이 아닙니다. 다른 대응점·정합 방법 전부가 불가능하다는 주장도 아닙니다.

## 저장 계산·화면·agy

별도 행렬 산술로 두 배치×네 라벨의 총2,420,040정점 계산과 경계 상자를 재현했습니다. 세 기준점 잔차·배율·직교성·양의 행렬식을 확인하고, 저장된 최대 피부 이탈 증거도 다시 분류했습니다. [재읽기](sci-head-fit-readback.json). 전체 피부 분류나 최적화 알고리즘을 독립 구현해 재실행한 것은 아니며, 최대 이탈 재분류는 기존 피부 판정 함수를 재사용합니다.

1400×1000 별도 장면에서 두 배치의 정면/왼쪽면, SCI 머리와 현재 피부·공막·각막을 함께 캡처해 직접 확인했습니다. 파란 후보 눈과 초록색 현재 공막/각막의 위치 차이를 볼 수 있습니다. [캡처 해시](sci-head-fit-capture.json), 페이지 오류0. SCI 라벨6은 목뼈와 모형화된 입안 뼈도 포함하므로 현재 이름별 두개골과 동일 범위가 아닙니다. 이 화면은 실제 앱·모바일·박리 검사가 아닙니다.

agy 읽기 전용 대화 `30643d24-c173-4ba5-bf1d-b874b4c14ea0`에서 맞춤/재읽기 코드와 기존 결과를 제한 정적 검토했습니다. 초기 응답의 정점 합1,209,920은 후속 응답에서1,210,020으로 정정됐고, 상태/코드 해시 차이는 검토 도중 알린 재생성이 끝난 후 최종 재읽기로 일치를 확인했습니다. agy가 기하 계산을 직접 실행하거나 캡처를 검수한 것은 아닙니다.

```sh
node scripts/fit-sci-head.mjs
```
