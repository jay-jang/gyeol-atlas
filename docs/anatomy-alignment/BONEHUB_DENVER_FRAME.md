# 새 여성 골격과 기존 근육 기준 골격의 좌표 대조 — 2026-09-27

**같은 Visible Human Female 출처라도 기존 근육 변환을 새 골격에 그대로 적용할 근거는 부족합니다.** BoneHub 골격과 Denver Final/Original의 공통 뼈24쌍을 각각 대조했습니다. 새 원본을 거부하거나 정합이 불가능하다고 판정한 것이 아니라, 이번 공통 변환을 전신 교정으로 채택하지 않은 것입니다. 앱 원본·기관 선택·박리는 변경하지 않았습니다.

## 맞춤 자료와 검사용 자료의 분리

양쪽 대퇴골·정강뼈·종아리뼈·무릎뼈·골반,10쌍의 경계상자 중심으로 양의 균일 배율과 회전/이동을 초기화했습니다. 이후 같은10쌍에서 방향별512개 정점 표본을 사용해 최근접 표면 맞춤을 반복했습니다. 각 뼈·방향 안에서 먼20%를 제외해 반복당8,180개 대응을 계산했습니다. **양쪽 발목뼈14쌍은 초기화와 맞춤 모두에서 제외**했습니다. 경계상자 중심이나 최근접 점은 해부학적으로 검증된 대응점이 아닙니다.

최종 평가는 제외된 표본을 포함해 모든 참조 정점을 양방향으로 검사했습니다. 전체 신체의 조직 관계·관절·HRA 피부를 검사한 것이 아니라 두 원본의 공통 뼈 표면 비교입니다.

| Denver 대상 | 정점 비교 발생 수 | 최종 균일 배율 | 반복 횟수 | 검사용14쌍의 방향별 p95 범위 |
| --- | ---: | ---: | ---: | ---: |
| Final |1,234,381 |1.004887093 |87 |4.663–7.649mm |
| Original |3,251,627 |1.004540439 |138 |4.412–7.636mm |

p95는 각 방향 정점→상대 표면 거리의95백분위수이며, 이 표의 범위는28개 방향 값의 최솟값/최댓값입니다. 침투 깊이·조직 부피·임상 오차 허용치가 아닙니다. 두 실행 모두 중심 변화량0.00001mm 미만에서 종료했습니다. 이는 수치 종료 조건이며 전역 최적해나 임상 수렴의 증명이 아닙니다. 초기60회 제한에서는 Original이 아직 크게 변하고 있어 최대240회로 늘려 다시 검사했습니다.

## Original 오른쪽 골반의 분리 조각

사용자가 제공한 Original ZIP의 해시를 확인한 뒤24개 공통 뼈만 추가 추출했습니다. 기존 추출물을 덮어쓰지 않고 각 파일을 ZIP 구성원과 해시 대조했습니다. 원본 ZIP은 이동·변경하지 않았습니다.

`VHF_Right_Bone_Pelvis.stl`은 정확히 같은 좌표끼리 연결했을 때 본체737,688삼각형/368,844정점과 별도564삼각형/284정점으로 나뉩니다. 본체의 원본 Z범위는818.015–1,031.801mm, 작은 조각은555.278–563.270mm입니다. 작은 조각의 실제 조직 정체나 생긴 원인은 이 검사로 확정하지 않습니다.

전체 상자 중심 차이는129.856mm지만 본체 성분 상자 중심 차이는3.131mm입니다. 반대 방향 최대 표면 거리는268.299mm로 기록됩니다. 작은 조각 때문에 전체 경계상자와 최대 거리의 의미가 달라지는 것이며, 이를 골반 전체의 이동량으로 표현하지 않습니다. **조각은 전체 검사에서 삭제하지 않았습니다.** Final 오른쪽 골반은1성분이며, Final 처리 과정 중 정확히 어떤 연산으로 차이가 생겼는지는 재현하지 않았습니다.

## 독립 판독과 화면

별도 binary/ASCII 정점 판독으로48쌍의 삼각형·고유 정점 수, 변환된1,823,930정점 발생의 유한성, 최대 거리 검사에 사용된96개 쿼리 정점의 좌표를 확인했습니다. 회전 열벡터의 직교/길이와 양의 행렬식도 스칼라 산술로 대조했습니다. 최근접 표면 알고리즘 전체를 독립 구현한 것은 아닙니다. [재읽기](bonehub-denver-frame-readback.json).

검사용 발목뼈만 표시한 [Final 왼쪽](bonehub-denver-final-left.png)·[오른쪽](bonehub-denver-final-right.png), [Original 왼쪽](bonehub-denver-original-left.png)·[오른쪽](bonehub-denver-original-right.png)을 직접 확인했습니다. 주황은 BoneHub, 청록은 Denver이며 두 표면의 차이가 보입니다.
