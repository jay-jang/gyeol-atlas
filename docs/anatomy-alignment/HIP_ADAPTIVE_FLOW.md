# 전체 피부 이탈 지점과 역방향 골격 대응의 추가

2026-09-28. **후보 미적용**. [이전 공통 변형](HIP_JOINT_FLOW.md)에서 놓친 피부 정점과 역방향 골격 잔차를 맞춤에 추가했습니다. 피부 외부 정점은11,178→3,882로 줄었지만 새89정점·악화74정점과 새 골격 교차5쌍이 남습니다. 평균 개선을 정합 완료로 해석하지 않습니다.

## 입력·변형·표본의 의미

[결과](hip-adaptive-flow.json)의 `initial`은 이전 joint-flow 후보이고 `current`는 공개 앱입니다. 이전 후보 역시 미승인이며 공개 앱에 적용된 적이 없습니다. 추가로160개의 공통 공간 변형을76근육·16진단 뼈에 적용했습니다. 고정 HRA 표면은 움직이지 않습니다. 기존 행렬·보고서·공개 모델은 변경하지 않았습니다.

- 12기준 뼈 각각 원본 표면128점→HRA 최근접 표면, HRA 표면128점→**초기** 원본 최근접 삼각형의 대응을 만들었습니다. 후자는 삼각형 위 점을 흐름으로 이동시키면서 최초 HRA 지점을 목표로 유지하는 고정 material 대응입니다. 매 단계 갱신되는 역방향 최근접 거리나 해부 표지점 대응이 아닙니다.
- 근육마다 면적 표본32점에 더해, 전체652,173참조 정점을 검사하여 피부 외부인11,178정점 중508점을 추가했습니다. 각 근육에서12mm 공간 셀별 최대 이탈을 먼저 선택하고 부족하면 큰 이탈 순서로 채우며 최대32점입니다. 한쪽에 몰린 극값을 완전히 균등 분산시키거나 전체 표면의 무편향 표본을 만드는 방법이 아닙니다.
- 표면 표본5,504개+극값508개=총6,012개 제어점입니다. 정방향 뼈/고정 역방향 대응/피부 가중치는0.5/0.5/2입니다. 근육별 극값 수와 면적 표본의 비율은 달라지므로 이전 실행의 목적함수·표본 RMS와 직접 비교하지 않습니다.
- 피부는3방향 광선이 모두 외부이고 표면 거리2mm를 넘을 때만 초과 거리를 벌점으로 줍니다. 내부·경계대·모호 판정은 벌점0입니다. 임상 안전 거리나 실제 피부 두께의 주장 아님.

이전과 같은 반경30/70/160mm, 단계 이동 최대2mm, 단계 미분 상계0.12를 사용했습니다. 모든 실제 표본 손실이 감소한160단계를 채택하고 반복 제한으로 종료했습니다. 이번에도 반감0회이며 각 단계의 연속 가역 조건은 누적 왜곡·이전 보간의 단사성·표시 삼각형 관계를 보장하지 않습니다. 장기·혈관 관계는 전수 추적하지만 이번 목적함수의 직접 제약은 아닙니다.

## 표본 개선과 전수 실패

| 지표 | 초기 → 후보 | 범위 |
| --- | --- | --- |

| 고정 역방향 대응 RMS |2.977→2.261mm| 초기 대응점으로의 거리, 동적 역방향 표면 오차 아님 |

| 주변89,794쌍 교차 |197→196| 새5, 사라진6. 총합만으로 관계 개선 판정 불가 |

가중 손실은0.00001216097→0.00000386299m²이며 가중치 합3의 목적함수입니다. 제곱근을 전신 RMS로 표현하지 않습니다. 새 피부 외부는 VHF0059 `Peroneus longus (right)`73정점, VHF0060 `Soleus (right)`16정점입니다. 같은 두 근육의 기존 외부 정점 중6/68개가1µm 이상 더 멀어졌습니다. 양쪽 종아리 전체를 해결했다고 할 수 없습니다.

모든16진단 뼈의 전 참조 정점 양방향 거리도 다시 검사했습니다. 이전에 악화했던 왼 정강뼈 역방향 p95는12.616→7.823mm, 왼 종아리뼈는12.862→5.423mm로 줄었습니다. 그러나 맞춤에서 제외한 L1의 p95는 정방향3.874419→3.888244mm, 역방향4.956855→4.956940mm로 소폭 악화했습니다. 무릎뼈 양쪽·L1·L6의 제외는 실험 설정이지 임상적 제외 근거가 아닙니다. HRA 계층의 내부/연골 표면과 원본 외곽의 표현 차이는 여전히 구분해야 합니다.

초기 대비 새5쌍은 모두 골격 계층이며 내부 삼각형 교차 증거가 있습니다:

|HRAF0911 Femur (right)|VHF0068 Obturator externus (right)|

이 중4쌍은 공개 앱에도 있고 이전 후보에서 사라졌다가 다시 나타난 관계입니다. HRAF0918/VHF0045만 공개 앱에도 없는 교차입니다. 공개 대비 새 합계90은 고정 HRA87(피부9·장기2·혈관6·골격70)+근육 내부3입니다. 질–오른 바깥폐쇄근, 오른 자궁엉치인대–궁둥구멍근, 자궁정맥·총엉덩정맥·아래곧창자정맥·속음부정맥 관계 등이 남습니다. 이번에 왼 속엉덩정맥–큰허리근 교차가 사라졌어도 올바른 주행·연결이나 전체 장기 정합의 증명은 아닙니다.

## 코드 오류 교정과 재읽기 범위

첫 실행은 역방향 원본 삼각형의 점 재구성 assertion에서 중단됐습니다. 설치된 BVH의 `closestPointToPoint`는 `shapecast`를 통해 **이미 원본 삼각형 번호**를 돌려주는데 `closestPointToGeometry`와 같은 방식으로 다시 번호를 변환한 오류였습니다. 실제 호출 구현을 확인해 이중 변환을 제거했습니다. 삼각형24개가 재배열된 합성 검사에서 원본23번과 barycentric 재구성을 확인하고 전체 후보를 다시 생성했습니다. 이전의 별도 geometry-to-geometry 번호 변환을 바꾸지는 않았습니다.

[재읽기](hip-adaptive-flow-readback.json)는 근육652,173정점·3,912,126인덱스 차이0, 진단 뼈471,211정점·2,827,170인덱스 해시 일치를 확인했습니다. 원본/HRA100표면·5,504면적 표본·2,250,121입력 삼각형, 역방향 material1,536점의 실제 삼각형 소속과 점 재구성(최대2.39×10⁻¹³mm)을 대조했습니다. 피부 전체652,173정점을 다시 분류하고 별도 셀 선택 구현으로508극값 선택을 재현했습니다.

추가 흐름 야코비안9,728표본 재계산 차이≤2.23×10⁻¹⁶, 초기/최종 목적함수 재계산 잔차≤6.78×10⁻²¹m²입니다. 새5교차+이전 원본 내부 교차1의 실제 삼각형 증거6건도 재구성했습니다. 공유 초기 디코더·BVH/피부 분류기를 사용하므로 독립 최적화·전체 교차 재탐색·임상 검증이라고 확대하지 않습니다.

## 외부 검토·화면과 재현

[agy 기록](hip-adaptive-flow-agy-review.json)은 최초90초 관찰 timeout과 같은 대화의 기존 검토 완료 SUCCESS 응답을 모두 보존합니다. 초기 timeout을 작업 종료로 보지 않고 후속으로 확인했습니다. BVH 번호 구분과 고정 material 대응 검토를 받았지만, 부드러운 벌점을 barrier로 읽은 표현, 측정하지 않은 기울기 지배/성능 인과, L1 개선 표현, 원본/공개 기준선 혼동, C4 매끄러움 주장은 정정했습니다. 실제 반경 함수는 C2이며, 각 추가 단계의 가역성과 초기 보간 전체의 단사성은 구분합니다. 정적 검토이지 임상 승인 아닙니다.

[촬영 기록](hip-adaptive-flow-captures.json)의 정면/사선6장을 직접 확인했습니다. 같은 카메라·133구조(76근육·고정 HRA 골격 계층56·피부1)를 유지했습니다. [이전 후보](hip-adaptive-flow-front-initial.png)와 [추가 변형](hip-adaptive-flow-front-flow.png)에서 종아리와 골반 주변 형상 차이가 보이지만 이 배율로 미세 교차를 판정하지 않습니다. 불투명 근육이 뼈를 가리고 피부 상부가 잘려 있습니다. 장기·혈관·신경·림프·발뼈·진단 원본 뼈는 생략한 진단 장면이며 앱/모바일·박리 검증이 아닙니다.

Node24, 이전 보고서/바이너리 캐시, 같은 Denver Final 폴더가 필요합니다. 촬영은 Vite5174를 사용합니다.
