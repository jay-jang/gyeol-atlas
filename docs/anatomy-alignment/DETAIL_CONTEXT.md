# 상세의 세부 선택과 전체 구성 복원 — 2026-09-27

기관 상세에서 세부 모형을 선택한 뒤 ‘전체 구조 보기’를 누르면 원래 상세 묶음의 모든 계통을 복원하도록 수정했습니다. 개별 선택은 유지하며 ‘기관 전체 모형’으로 묶음 자체를 선택하는 동작과 구분합니다. 공개 원본의 정점·인덱스·기관 수록·해부 위치는 변경하지 않았습니다.

## 재현한 실패

- 남성 심장83개에서 관상동맥 세부 선택 후 전체 구조 보기를 실행하면 혈관61개만 돌아왔고, 장기/근육22개가 누락됐습니다. `select`가 해당 혈관 레이어만 켠 뒤 `isolate` 해제는 다른 상세 레이어를 복원하지 않았습니다.
- 여성 CT 주변 기관11개에서 왼쪽 등 근육군을 선택하면, 현재 상세 범위 `abdomen-ct`가 개별 근육의 기본 범위 `back-muscles-ct`로 덮어써졌습니다. 이는 별도 CT 장면 안의 범위 오류이며 HRA 전신에 CT를 합친 것이 아닙니다.
- 첫 수정 후 가시 집합은 맞아도 모바일로 크기를 바꾸면 카메라가 선택한 혈관 하나로 다시 맞춰졌습니다. 간 전체 중심과 카메라 타깃 차이0.052062001m로 별도 브라우저 검사에서 실패했습니다. 모델의 이동을 뜻하는 수치가 아닙니다.

## 변경한 공통 경로

`src/view-state.ts`에서 선택한 세부가 현재 상세에 포함되면 현재 상세를 우선합니다. 다른 상세 밖의 검색은 새 기본 상세로 진입합니다. 상세의 단독 표시를 해제할 때는 원래 `detail.layers`와 전신 부위 필터를 복원하되 선택 ID·투명도 선호·표식·주변 반투명 설정을 유지합니다. 상세 밖의 단독 표시 동작은 그대로입니다.

`src/App.tsx`는 상세 단독 표시 해제 후 가시 묶음 전체를 확대합니다. `src/Atlas.tsx`는 이 문맥에서 크기 변경·정면/후면/측면/초기화 시 가시 상세 전체를 맞춥니다. 개별 단독 보기와 명시적 ‘확대’는 여전히 선택한 한 구조를 대상으로 합니다. 좌표를 바꾸지 않고 카메라만 맞추는 기존 경로입니다.
