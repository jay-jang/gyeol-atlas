# 남성 콩팥·요관·신장혈관 상세 — 2026-09-28

남성 상세 보기에 같은 BodyParts3D 4.0 계열의 **35개 실제 원본 메쉬**를 추가했습니다. 콩팥2·요관2·신장동맥과 가지27·신정맥4개입니다. [BodyParts3D의 공식 API 설명](https://lifesciencedb.jp/bp3d/info/webapi/config/common.html)은 버전과 `partof`/`isa` 관계에 따라 묶음 내용이 달라질 수 있음을 명시합니다. 이번 묶음은 콩팥 하나의 해부학적 `part_of` 자식35개가 아니라 고정된 원본의 콩팥·요관·신장혈관 **서로 다른 `is_a` 개념7개**를 편집상 함께 보는 범위입니다. 개념 ID는 `FMA7203`, `FMA9704`, `FMA14751`, `FMA70494`, `FMA70485`, `FMA70488`, `FMA14334`입니다. [공식 4.0 버전 명시 관계 ZIP](https://lifesciencedb.jp/bp3d/get-info.cgi?version=4.0&cmd=concept-objfiles-list)의7개 원문 `is_a` 구성원과 고정 상류 카탈로그를 [ID까지 정확히 대조](male-kidney-official-v40.json)했습니다. 공식 ZIP은 캐시에만 보관하고 SHA-256을 기록했습니다.

[원본–배포 버퍼 감사](male-kidney-detail-audit.json)는 고정 Human-Atlas 커밋 `5bb5713aab18d7fe9380c3339eb09f173491ea06`의 개념 구성과 실제 `body-7/11/13/14.bin.gz`를 읽어 35개 위치·법선·인덱스 바이트를 배포와 각각 대조합니다. 35개 모두 이름·원본 FMA ID·표시 계통이 일치합니다. 새 원본 두 청크의 압축 SHA-256은 [분지 선별 기록](male-renal-branch-screen.json)에 고정했습니다. 배포 상세는710→745모형, gzip6,681,509→7,002,973바이트입니다. 기존 심장·간·폐·췌장 위치 버퍼를 바꾸지 않았고, 폐·췌장 원본 검사와 저장 해시를 재생성해 재검증했습니다.

양쪽 전체 보기는35개를 함께 표시하며, 왼쪽/오른쪽 확대 보기는 긴 요관을 제외한 해당 측 콩팥·혈관17/16개를 별도 프레이밍합니다. 요관 두 개는 전체 보기의 선택 목록에 남습니다. 개별 목록에서는 한국어 편집명과 원본 영어 이름을 함께 보여주며 FMA ID를 보존합니다. 같은 영어 이름이 반복되는 원본 분지는 `원본 1/2…`로만 구분합니다. 특정 신장동맥 가지나 신정맥을 선택하면 공통 `view-state.ts` 전이를 통해 해당 혈관 레이어·단독 표시로 바뀌고, 같은 좌우 상세 범위·카메라와 복귀 정보를 유지합니다.

## 위치·연결의 확인 범위

같은 원본의 다른 동맥 분지18개를 추가한 이유는 기존9개 혈관만 표시할 때 눈에 띄던 빈 구간을 더 충실히 보여주기 위해서입니다. 다만 [원본 혈관 표면 선별](male-renal-branch-screen.json)의 참조 정점→다른 삼각형 표면 최소 거리는 기존 주동맥과 옛 구역가지에서 왼쪽6.904–29.719mm, 오른쪽18.612–23.173mm였습니다. 새 앞/뒤가지 가운데 일부는 주동맥과0.008–0.305mm에 있지만 다른 것은 최대31.092/29.510mm 떨어집니다. 왼쪽 뒤구역가지 `FJ2053`은 검사한 같은 측 동맥 중 가장 가까운 표면도5.623mm입니다. 이는 표본화된 **최소 거리**이지 관강 연결, 혈류 경로 또는 임상적 결손 진단이 아닙니다. 기존 주동맥과 거의 겹치는 별도 `trunk` 메쉬 두 개는 중복 표시하지 않았습니다.

콩팥 피질·속질·네프론은 이 원본 묶음에 없습니다. 전신 기본 BodyParts3D 3.0 모델과 이4.0 상세의 정확한 위치 대응, 다른 출처 장기와의 정합, 혈관의 완전한 연결·임상적 정확도도 검증하지 않았습니다. 외부 원본에서 새 구조를 추측해 만들거나 여성 장면에 이 남성 상세를 합치지 않았습니다. 여성 콩팥은 별도의 HRA 원본50메쉬 보기를 유지합니다.
