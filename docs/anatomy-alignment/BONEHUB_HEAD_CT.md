# 여성 원본 CT·두개골 분할과 현재 뇌의 단면 대조 — 2026-09-27

**3D 화면과 별개인 원본 분할 복셀에서도 후보 두개골과 현재 참조 뇌의 겹침을 재현했습니다.** 앞선 [목뼈 기준 두개골 후보](BONEHUB_HEAD_FRAME.md)의 강체변환을 거꾸로 적용해 현재 뇌의 위치를 원본 CT 좌표에 표시했습니다. 새 위치 맞춤이나 공개 모델 교체는 하지 않았으며, 이 결과로 신경 손상·관통 부피·임상 위치를 판정하지 않습니다.

## 실제 원본과 검사 범위

CT·두개골 분할은 [BoneHub 여성 자료](BONEHUB_FEMALE_SOURCE.md), Seyed Hamidreza Alavi·Malte Asseln, University of Twente, 2026, CC BY4.0, 고정 커밋 `ac8de2b38f5ae1a0996053ca0639dd6ae43358f1`입니다. 원본 출처와 기반 Denver 자료의 인용은 연결 문서에 보존했습니다. 아래 그림은 원본 단면을 시각화하고 현재 HRA 참조 모델 단면을 겹친 파생 진단 이미지입니다.

현재 [여성 뇌 묶음의 출처](BRAIN_PROVENANCE_SPLIT.md)는 Allen 참조282파트와 Visible Human 시신경교차1파트입니다. 이번 CT에서 분할한 뇌283기관이 아니며, 공간·부속 조직도 포함합니다. 기존 좌우 기하 버퍼 대응을 적용한 실제 수록283메쉬·참조 정점 발생239,303개를 사용했습니다. 다른 메쉬 사이에서 같은 좌표가 반복될 수 있으므로 전역 고유 정점 수로 부르지 않습니다.

`SKULL.seg.nrrd`는 이번에 헤더뿐 아니라 **전체778,721,570복셀**을 읽었습니다. CT도 전체 gzip 스트림을 읽어 길이/CRC와 고정 SHA-256을 확인했습니다. LPS 방향·원점·간격을 NIfTI RAS 행렬과 대조한 기존 격자 기록을 사용하며 축을 임의 교환하지 않았습니다.

## 두개골 라벨을 순수 뼈 조직으로 간주하지 않기

라벨1의 CT **저장값** 범위는36–3,225이며500 미만이87,792복셀입니다. HU로 변환하거나500을 뼈의 임상 임계값으로 사용하지 않았습니다. 단면에서는 밝은 경계뿐 아니라 일부 어두운 내부 영역에도 원본 라벨이 표시됩니다. 그 원인을 공기·골수·부분부피·분할 오류 중 하나로 확정하지 않았으며 조직별 원인 분류를 수행하지 않았습니다.

원본 STL 자체를 같은 분할에 최근접 복셀로 대조해도 두개골415,457정점 중207,060개, 아래턱37,926정점 중18,598개는 배경 값에 대응합니다. 평활화된 표면과 이산 복셀 경계의 차이가 있어, 단순 최근접 값만으로 표면의 정오나 고체 포함을 승인할 수 없습니다. 두개골 STL의2정점은 아래턱 값에 대응했으며 그대로 기록했습니다.

## 현재 뇌의 후보 좌표 대조

기존 세 후보의 역행렬로 고정된 아틀라스 뇌를 LPS mm에 옮겨 검사했습니다. 이는 좌표 표현을 바꾼 진단이며, 공개 뇌를 이동·축소·변형한 것이 아닙니다. 복셀은 `floor(grid+0.5)`로 하나를 선택했고 보간하지 않았습니다.

| 후보의 역변환 | 뇌 참조 정점 발생 | 라벨1에 대응한 정점 발생 | 해당 메쉬 수 | 라벨2 /저장 범위 밖 |
| --- | ---: | ---: | ---: | ---: |
|초기|239,303|32,849|63|0 /0|
|강체|239,303|32,735|58|0 /0|
|유사변환|239,303|20,621|55|0 /0|

이는 복셀 소속 대조이며 앞선 삼각형 교차 검사와 같은 지표가 아닙니다. 예를 들어 유사변환의 뇌 메쉬는 삼각형 교차54개, 최근접 라벨 대응55개로 다릅니다. 수치를 서로 바꾸어 쓰거나 대응 정점 수를 뇌 부피·손상 비율로 표현하지 않습니다.

이 결과는 두개골 후보의 표면 검사만을 독립적인 복셀 표현으로 다시 확인한 범위입니다. 같은 분할에서 나온 STL과 복셀은 독립적인 해부학적 정답 두 개가 아닙니다. 후보 좌표 자체와 라벨의 해부학적 세부 정확도, 참조 뇌와 눈·척수 연결은 여전히 검증되지 않았습니다.

## 직접 확인한 단면과 수치 재읽기

8개 격자 단면에서 CT만 /CT와 원본 두개골 라벨 /현재 뇌 단면선까지 겹친 보기를 나란히 만들고 직접 확인했습니다. 보라색 선은 뇌 삼각형과 평면이 만나는 실제 선분이며 내부를 뇌로 채우지 않았습니다. CT는 저장값0–2,000을 표시용 명암 범위로 썼고, 약0.4mm/픽셀 크기의 최근접 표시 확대와 픽셀 중심 변환을 사용했습니다. 선은1픽셀로 그려지므로 실제 조직 두께를 뜻하지 않습니다.

- 축상: [z=1580](bonehub-head-ct-axial-1580.png), [1610](bonehub-head-ct-axial-1610.png), [1640](bonehub-head-ct-axial-1640.png), [1670](bonehub-head-ct-axial-1670.png)
- 관상: [y=260](bonehub-head-ct-coronal-260.png), [340](bonehub-head-ct-coronal-340.png)
- 시상: [x=300](bonehub-head-ct-sagittal-300.png), [350](bonehub-head-ct-sagittal-350.png)

위 숫자는 격자 인덱스입니다. z 간격만1mm이며 x/y 간격은0.722656mm입니다. 각 그림에 실제 LPS mm와 방향을 따로 표시했습니다. 뒤쪽·위쪽에서 선과 분할 영역이 겹치는 모습을 확인했지만, 선택8단면으로 전신이나 뇌 전체의 위치 정확도를 판독했다고 주장하지 않습니다.

별도 Node 판독기는 원본 gzip을 다시 끝까지 읽어 CT/분할 저장 영역의 모든 바이트, 전체 분할 경계·집계, 전경 밝기 히스토그램을 대조했습니다. NIfTI는 **압축 파일 처음부터** 해제하며,352바이트는 해제 후 헤더 길이입니다. 일반 행렬 역산 대신 균일배율 회전의 스칼라 역변환으로3후보 총717,909정점 발생을 다시 조회했습니다. 선택8평면·283메쉬의 모든 삼각형을 다시 검사해 저장 선분44,471개의 누락/추가를 검사했고, 끝점 최대 차이는9.49×10⁻¹¹mm였습니다. 이8평면의 점 접촉/공면 삼각형은0개이며, 합성 검사에서는 해당 경우를 별도로 다룹니다. [독립 재읽기](bonehub-head-ct-readback.json).

최초 실행은 NumPy 정수의 JSON 저장 오류로 종료했습니다. 정수 변환을 수정하고 전수 생성/재읽기를 재실행했습니다. 표시 확대의 끝점 맞춤 대신 Pillow의 픽셀 중심 변환으로 선 좌표를 맞췄으며, 최종 그림은 수정 후 결과입니다. 소수 인덱스를 정수로 조용히 바꾸지 않도록 입력 검사도 보강했습니다.

agy 대화 `250d0603-8e61-46b0-a8af-3bdab30ca4c8`에서 생성·삼각형 단면·독립 판독 코드를 제한 정적으로 검토했습니다. agy가 원본 전수 판독이나 테스트를 실행한 것은 아닙니다. ‘수학적으로 정확’은 유한 정밀도·평면 허용오차10⁻⁸mm·1픽셀 그리기의 한계를 갖는 코드 대조로 제한합니다. 응답의 낮은 강도 원인 추측은 측정된 사실로 채택하지 않았습니다. 촬영 코드의 Arial 경로는 현재 macOS 전용이며 다른 운영체제에서 실행하려면 같은 글꼴 경로를 제공해야 합니다.
