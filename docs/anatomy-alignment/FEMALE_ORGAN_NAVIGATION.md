# 여성 자궁관·질 원본 상세 탐색 — 2026-09-28

여성 전신에 **이미 수록된** 자궁관 8개 표면과 질 2개 표면을 각각 기관 상세 보기로 찾을 수 있게 했습니다. 새 장기·정점·임상적 연결을 만들거나 다른 신체의 CT를 전신에 합치지 않았습니다. 여성 전신 1,220개, 남성·여성 CT 별도 자료의 파일과 좌표는 그대로입니다.

## 원본 소속과 편집 범위

[`atlas-female.json`](../../public/models/female/atlas-female.json)의 실제 개념 `HRA:fallopian_tube`는 `HRAF0408`–`HRAF0415` 8개, `HRA:vagina`는 `HRAF0406`–`HRAF0407` 2개를 열거합니다. 새 [탐색 묶음](../../data/female-additional-organ-groups.json)은 이 ID와 원본 개념을 그대로 명시하며, 단위 검사에서 원본 개념의 실제 요소와 순서까지 대조합니다. 원본 이름 `Ampulla of uterine tube`, `Isthmus of fallopian tube`, `Vagina` 등은 검색/선택에 남습니다. ‘자궁관’·‘질’은 탐색용 한국어 그룹명으로, 세부 표면의 임상적 경계나 전문 용어 감수를 새로 완료했다는 뜻이 아닙니다. FMA ID가 원본에 없는 항목에 임의의 ID를 만들지 않았습니다.

해시 고정된 `female-atlas-structures.json`은 바꾸지 않았습니다. `src/anatomy.ts`가 기존 두 원본 묶음에 속하지 않던 해당 10개 항목에만 실행 시 `group`·탐색 계층을 붙입니다. 골반 부위 분류는 `src/anatomy-region.ts`의 동일한 원본 그룹 표를 거치고, 검색·상세·개별 선택·복귀·저장 복원은 기존 `src/view-state.ts` 동작을 사용합니다. 여성의 다른 기관, 뇌, 기증자 근육, 차용 골격, 경혈 표식에는 새 묶음이 적용되지 않습니다.
