# 여성 담낭·담낭관·혈관 탐색 묶음

## 범위와 출처

여성 HRA 전신의 기존 포장 매니페스트 `public/models/female/atlas-female.json`에서 `HRA:gallbladder`(`HRAF0527`), `HRA:ducts_of_gallbladder`(`HRAF0505`), `HRA:blood_vasculature_of_gallbladder`(`HRAF0687`, `HRAF0688`)의 실제 메쉬 네 개를 확인했다. `data/female-biliary-groups.json`은 이 세 원본 개념만 하나의 탐색·상세 보기 범위로 묶는다. 각 구조의 영어 원명과 원본 ID는 검색·선택 카드에서 유지하고, 한국어 묶음·개별 명칭은 탐색용 편집 표기다. FMA ID를 새로 부여하지 않았다.

원본 카탈로그 `data/female-atlas-structures.json`, 공식 매니페스트, 압축 기하, 좌표, 박리 일정을 수정하지 않았다. 앱 시작 시 `src/female-biliary-navigation.ts`가 네 구조에만 묶음·표시명·계층을 덧붙인다. `src/anatomy-region.ts`의 출처 기반 범위로 담낭관이 높이 휴리스틱에 따라 가슴으로 분류되던 문제를 이 묶음에서 배 영역으로 바로잡는다. 남성 또는 다른 여성 구조에는 적용하지 않는다.

`HRAF0503` Common bile duct는 기존 췌장관 개념에 포함된 별도 구조이므로 담낭 묶음에 자동 합류시키지 않았다. 모형이 함께 표시된다는 사실을 담도 연결의 임상적 검증이나 압력 전달 경로로 해석하지 않는다.

## 검증과 남은 한계

실제 포장 매니페스트의 출처 개념·4개 ID를 대조하고 각 메쉬의 압축 정점·인덱스를 검사했다. 공통 `view-state.ts` 리듀서에서 여성 50.5% 박리→4개 상세→담낭동맥 단독→전신 복귀 시 원래 박리·시점·표식 설정을 회복하는 단위 검사 3개가 통과했다. 전체 Node 352/353 통과; 실패 1건은 HTTP 경계 서버의 `127.0.0.1 listen EPERM`이다. TypeScript와 별도 Node 실행기의 정적 빌드는 통과했다.

데스크톱/모바일 실제 메쉬 가시성·검색·상세·복귀를 다루는 브라우저 시나리오 2개는 목록 등록만 확인했다. 기본 개발 서버의 macOS `rolldown` 네이티브 모듈 서명 오류로 실행되지 않았으며, 현재 환경에서는 별도 Node 서버도 로컬 포트 `EPERM`을 겪는다. 따라서 새 화면 캡처나 육안 확인은 **없고 상호작용 출시 검증은 미완료**다. 네 구조의 개별 위치·담관/혈관의 실제 연결·여성 전체 장기·골격·신경 정합도 이 탐색 변경으로 입증되지 않는다. agy 검토 역시 로컬 바인드 권한 오류로 완료되지 않았다.
