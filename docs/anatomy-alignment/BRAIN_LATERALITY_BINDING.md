# 여성 뇌 좌우 선택 연결 교정 — 2026-09-27

**Allen 참조 141쌍의 좌우 선택 연결을 전신 기준에 맞췄습니다.** 원본의 좌우 표기가 전신의 눈·대퇴골 기준과 반대인 문제를, 기존 반대쪽 형상의 완전한 버퍼를 연결하는 방식으로 교정합니다. 일반적인 뇌 위치·두개골 정합·신경 연결을 교정한 것은 아닙니다.

## 교정 근거와 실패한 방법

고정 HRA 여성 전신 v1.10 원본의 Allen 282개만 대상으로 했습니다. Visible Human 시신경교차 `HRAF0070`는 다른 출처이므로 제외했습니다. [공식 HRA 설명](https://3d.nih.gov/entries/3DPX-020959)은 141개 참조 구조를 대칭 복제해 신체 크기에 맞췄다고 명시합니다.

## 적용 범위와 출처 보존

- 원문 이름·안정 ID는 유지하고, 각 ID가 사용하는 **기존 반대쪽 형상**의 위치·법선·인덱스 버퍼를 함께 연결합니다. 개별 ID가 가리키는 위치는 바뀌지만 새 정점 변형은 없습니다.
- 전체1,220개 포장 형상의 버퍼 해시 다중집합이 동일합니다. Allen282개 연결만 교환하고 나머지938개는 그대로입니다. 이는 형상 보존이지 내부 교차·틈이 없다는 증명이 아닙니다.
- 개별 설명에 실제 형상 출처의 ID·영문명을 표시합니다. 런타임에는 `sourceGeometryId`, `sourceName`, `femaleBrainBinding`으로 원문 식별자와 형상 출처를 구분합니다. [연결 명세](../../data/catalog/female-brain-bindings.json).
- 남성·남성 별도 상세·여성 CT는 적용 대상이 아닙니다. 여성 전신 매니페스트의 SHA-256이 바뀌면 다운로드를 중단하고 재검증을 요구합니다. 공개 원본 GLB와 포장 자산은 수정하지 않았습니다.
- 박리/선택 전이는 기존 `view-state`를 사용합니다. 교정은 자료를 읽을 때 한 번 결정하며 박리 단계에 따른 변형 경로를 추가하지 않습니다.
- 저장된 선택이 교정 이전의 한쪽 뇌 형상을 확대하고 있었다면 `view-state` 복원에서 처음 한 번 카메라를 다시 맞춥니다. 선택 ID·표식·필터는 유지하고 교정 버전을 기록합니다. 전체 뇌/완전한 좌우쌍·시신경교차·남성·CT 및 이후 새로고침은 해당 이유로 카메라를 초기화하지 않습니다.

## 신경–골격 위치 문제는 별도 유지

교정된 형상 연결을 반영해 여성 신경362×골격321, 총116,202쌍을 다시 검사했습니다. 교차 증거는 기존과 같은82쌍(고유 척추 관련7·보완 골격 관련75)입니다. 실제 형상 출처 ID로 환산하면 기존 보고서의82쌍과 집합이 일치합니다. 양쪽 비교 모두 같은 교정된 형상 연결을 사용하며, 원본 좌우 라벨을 그대로 둔 비교와 혼동하지 않습니다.

[현재 연결 기준 감사](female-neural-bound.json), [503개 고유 원본·3,572,307정점 독립 판독](female-neural-bound-readback.json). 기존 보고서는 역사적 스냅샷으로 보존했습니다. 피부/신경–골격 감사 코드도 현재 형상 연결과 오른쪽 엉덩뼈 복원을 읽도록 갱신했습니다. 전체 목표는 여전히 미완료입니다.

별도 남녀 [신경–골격 재검사](brain-binding-neural-bone.json)도 여성82쌍·남성564쌍(엄격한 면 관통561쌍)을 기록했습니다. [여성 피부 포함 전수 검사](brain-binding-containment.json)는 피부 외1,219개·참조 정점1,394,932개를 검사했습니다. 신경계 정점 이탈은0이지만 이것은 신경 주행·연결 정확도를 뜻하지 않습니다. 기존 골격33개·근육18개의 피부 이탈은 남아 있습니다. 피부 기준은2mm 경계대이며, 삼각형 내부 전체가 아닌 참조 정점 검사입니다.

## agy 및 실제 조작 검증

agy 대화 `297188c4-e009-465b-bf14-b8b7adb8a873`에서 대응 방법·출처 위험과 구현을 제한 정적 검토했습니다. 초기의 전역 X분류·양의 부피로 모든 법선을 판정하는 해석은 후속 응답에서 정정했습니다. 15삼각형을15개 구조로 부른 부분도 실제3개 메쉬로 구분했습니다. agy의 정적 판단을 실제 3D 클릭·박리·임상 검증으로 대신하지 않습니다.

저장 상태 검토에서는 카메라를 `null`로 만들면 자동 재맞춤될 것이라는 정적 추정과 달리 실제 브라우저에서 전신 시점에 머무는 실패(선택 중심과 타깃 차이0.740m)를 확인했습니다. 초기 카메라 동작을 ‘선택 있음·저장 시점 없음’일 때 기존 구조 맞춤 경로로 보내도록 수정했습니다. 이전 세션을 실제로 주입해 교정된 선택으로 맞춰지는지, 표식 선호가 유지되고 다음 새로고침에서는 시점이 보존되는지를 재검사합니다.
