# 척수 단면을 축소하지 않는 국소 이동 후보와 제약 충돌

후속: 이 두 실패 후보가 아닌 [단면 격자 기반 부분 교정](CORD_SECTION_GRID.md)을 별도로 검증해 표시용에 적용했습니다. 이 문서의 '공개 미적용'은 아래 두 후보에 한정됩니다.

2026-09-28. **두 후보 모두 공개 모형에 적용하지 않았습니다.** [원본에서도 확인한 척수–척추7쌍](NEURAL_COMPONENT_SOURCE.md)에 대해, 분절별로 따로 옮기거나 척수 단면을 줄이지 않는 공통 높이별 이동을 시험했습니다. 하나는 악화됐고, 다른 하나는 일부 지표가 개선돼도 제약을 만족하지 못했습니다. 이는 검사한 후보의 실패이지 모든 정합 방법이 불가능하다는 증명이 아닙니다.

## 변형과 고정 범위

29개 척수 분절에 같은 함수 `(x,y,z) → (x+dx(y),y,z+dz(y))`를 적용했습니다. `dx,dz`는10mm 간격의 compact cubic B-spline이며 범위 밖에서 정확히0입니다. 원본의 내부 정점 높이에40mm 수치 여유를 주고 간격에 맞춰 범위를 정해, 실제 지지는 y=1.11~1.31m입니다. 뇌와 골격은 이동하지 않았습니다. 각 후보에서15척수 분절이 일부 움직였고 C1·S4를 포함한14분절은 전부 그대로였습니다.

연속 함수는 높이별 동일 이동으로 단면의 상대좌표를 유지합니다. 높이를 보존하므로 같은 높이에서 이동량을 빼는 명시적 역함수가 있고 Jacobian 행렬식은1입니다. **이는 연속 함수의 성질**이며, 움직인 정점 사이를 직선 삼각형으로 잇는 저장 모형의 자가교차·부피·고정 조직과의 관계를 자동으로 보증하지 않습니다. 접촉하지 않던 두 분절의 실제 연결을 새로 만들었다는 뜻도 아닙니다.

## 두 목표 설정과 실패

원본 척수의 모든 참조 정점을 고정 원본26골격과 대조했습니다. 광선 합의상 내부인 점과0.1mm 안쪽 수치 여유가 필요한 가까운 외부 점에서, 교정 지지 범위 안의4,055개 선형 부등식을 구성했습니다. 모호한 점·1µm 경계대는 방향을 임의 지정하지 않고 맞춤에서 제외했습니다.

1. **최근접 출구:** 내부 점에서 가장 가까운 뼈 삼각형 쪽으로 나가도록 접선 제약을 구성했습니다.
2. **단면 평균 방향 출구:** 원본 척수에서 같은 분절의2mm 높이 띠에 든 정점의 무가중 평균 X/Z를 수치 기준으로 사용했습니다. 해당 뼈의 외부로 판정된 기준점만 사용하고, 그쪽 광선의 첫 표면에서 접선 법선을 구했습니다. 사용 불가 기준점은0개였지만 **척추관의 검수된 중심선이 아닙니다**. 삼각형 밀도의 영향을 받으며 주변 모든 조직의 외부라는 뜻도 아닙니다.

두 경우 모두 계수 제곱+2차 차분의4배를 최소화하고 각 계수±4mm를 요구했습니다. 이 범위·여유·평활 가중치는 수치 시험 설정이며 임상 허용치가 아닙니다. Hildreth 쌍대 좌표 갱신은 첫 선형화에서1,500회 한도에 도달했고, 잔여 위반은 각각3.525/1.175mm였습니다. **계산 종료를 수렴으로 표시하지 않았습니다.** 최근접 후보의 실제 최대 계수는5.22148mm로 목표 범위도 초과했습니다. 단면 평균 후보는 약4mm였습니다. 저장 정점 최대 이동은 각각5.12328/4.15410mm입니다.

### 유한 선형계의 모순을 별도 확인

SciPy1.13.1의 [HiGHS 선형 계획](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html)으로 동일 부등식의 실행 가능성을 검사했으며 두 경우 모두 `status:2`였습니다. 단순히 이 상태 코드만 믿지 않고 비음수 가중치로 부등식을 합친 모순 기록을 구했습니다.

| --- | ---: | ---: | ---: |
|최근접 출구|9|2.046996|2.04×10⁻¹⁹|
|단면 평균 방향 출구|17|0.370870|3.13×10⁻¹⁹|

별도 스칼라 계산으로 모든4,055행과 가중합을 재구성했습니다. 양의 우변이 잔차 상한보다 커서 **이 고정 선형계와 계수 경계는 동시에 만족할 수 없습니다**. 최근접 기록은 T12척수의 가까운 정점2467/2468에서 X/Z 출구 방향이 뒤집히는 것을 포함합니다. 상대편 척수 벽이라고 가정하지 않았으며, 두 정점만이 아니라 경계조건을 포함한 전체9행이 모순 증거입니다. 후속 반복에서 오래된 접선이 쌓인 것이 이번 원인은 아닙니다. 두 실행 모두 첫 선형화에서 종료했습니다.

이 결과는 더 일반적인 비선형 이동·다른 매개변수화·척추 원본 대응이 불가능하다는 뜻이 아닙니다. 표면의 접선 반공간은 실제 굽은 표면 바깥 영역과 같지 않습니다. 일부 지표가 개선된 후보도 수렴한 해처럼 채택하지 않았습니다. [최근접 맞춤](cord-shear-fit.json)·[모순 기록](cord-shear-feasibility.json), [단면 기준 맞춤](cord-shear-seeded-fit.json)·[모순 기록](cord-shear-seeded-feasibility.json).

## 실행의 한계와 다음 판단

첫 실행은 교정 지지 밖의 가까운 외부 점까지 이동 제약에 넣어 시작하지 못했습니다. 이 범위 오류를 고친 뒤 두 설정을 다시 생성했습니다. 별도 재읽기의 첫 실행은 Python의 `-0.0`과 JS의 `0`을 비트 의미로 엄격 비교해 실패했으며, 선형계 계수로서의 동일한 수치 비교로 수정해 재실행했습니다.

agy 읽기 전용 대화 `5afca243-54bd-43b1-b8ce-0800bddd5ab2`에서 변형 함수·유한 제약·보존하지 못한 조건을 정적 검토하고 후속 정정을 받았습니다. 최초 답변의 ‘예전 접선을 여러 반복에서 누적해서 이번 실패’는 실제 한 번의 첫 선형화로 정정했습니다. 같은 후속에서도 `HRAF0841`을 T12뼈라 부르고 정점2467/2468을0.3mm 미만이라고 표현했으나, 실제 원본 ID는 **T11뼈**이고 저장 좌표의 거리는 **0.326455mm**입니다. 두 점만으로 불가능을 증명하지 않으며 각9/17행의 전체 가중합을 사용합니다. agy가 대용량 계산·화면·임상 검증을 직접 수행한 것은 아니고, 별도의 완성된754×2기하 감사와 진단 화면을 최종 재검토한 것으로 표시하지 않습니다.
