# 작은 내부 구조의 주변 반투명 표시 — 2026-09-27

## 재현한 문제와 수정

[이전 공개 검사](ORGAN_REGIONS.md#공개-배포-후-확인)에서 왼 난소 HRAF0432를 선택하면 부위와 카메라 타깃은 맞지만 앞쪽 기관이 시야를 가렸습니다. 단독 보기는 가능했으나 주변 구조와 함께 관찰하기 어려웠습니다. 이번 변경은 이 표시·선택 문제를 다루며 원본 위치 정합을 변경하지 않습니다.

- `view-state.ts`의 `fadeContext` 선호와 `fade-context` 액션을 사용합니다. 기본값은 켜짐이고 구버전 저장값에도 이 기본값을 적용합니다. 명시적으로 끈 설정은 새로고침·위키 왕복·성별 전환에서 유지합니다.
- 단일 구조 선택이고 비교/단독 보기가 아닐 때만 적용합니다. 선택 모형은 기존처럼 불투명하게, 다른 표시 모형은 불투명도 최대12%로 표시합니다. 사용자가 그보다 낮춘 투명도는 올리지 않습니다. 저장된 계통별 alpha·카메라·표식·모델 좌표·부위/계통 가시 집합은 바꾸지 않습니다.
- 선택을 해제하거나 박리·계통을 전환하면 보조 표시가 끝나며 기존 표시 규칙으로 돌아갑니다. 전통 장부 비교와 여러 메쉬 묶음에는 적용하지 않습니다. 상세 장면의 단독 선택도 다른 모형이 숨겨져 있으므로 적용하지 않습니다.
- 같은 화면 위치에서 반투명 문맥과 선택된 표면을 모두 실제로 맞힌 경우, 강조된 선택 표면을 클릭 대상으로 우선합니다. 선택 표면과 겹치지 않은 다른 구조는 기존 앞쪽 교차 순서를 사용합니다. 겹치는 다른 구조를 고르려면 ‘주변 반투명’을 끄거나 검색합니다. 이는 기하학적 앞뒤 관계를 다시 정하는 규칙이 아닙니다.
- 조절 항목과 ‘관찰 보조 · 실제 박리 아님’을 선택 카드의 고정 조작부에 표시합니다. 체크박스는 클릭/키보드로 조작하며 설명을 `aria-describedby`로 연결합니다. 선택·주변 모형을 전면 합성하거나 depth test를 끄는 방식은 사용하지 않습니다.

## 렌더링 범위와 한계

남성 기본 GLB, 전신 신경/혈관 보완, 림프 참조, 여성 HRA 및 별도 상세 PackedAtlas에 공통 투명도 계산을 적용합니다. 보조 표시 중 반투명 주변 모형은 깊이 버퍼를 기록하지 않지만 선택 모형과 깊이 검사는 유지합니다. PackedAtlas는 기존 `opacity > .45` 규칙을 계속 쓰며, 나머지 렌더러는 보조 표시 외의 기존 depthWrite 동작을 유지합니다.

이것은 표면을 실제로 제거하는 박리나 조직 단면이 아닙니다. 여러 반투명 표면이 겹치면 선택 색이 섞이거나 흐려질 수 있고, 모든 시점/모든 구조의 관찰성을 보장하지 않습니다. 실제 층서·기관 연결·피부 이탈·신경–골격 교차 문제를 해결한 것으로 해석하지 않습니다.

## 검증 결과

- 단위155/155 및 타입 검사 통과. 단일/묶음/비교/단독 보기, alpha·카메라·표식 보존, 설정 저장/구버전/잘못된 타입, 실제 교차 목록에서 선택 우선/일반 앞쪽 순서를 검사합니다.
- 초기 재질 검사는 장면의 비해부 메쉬까지 포함해 실패하여, 카탈로그에 등록된 실제 표시 메쉬만 검사하도록 수정했습니다.
- 실제 남성 콩팥·여성 난소의 전후 화면에서 선택 색 픽셀 증가와 버퍼/세계 변환 불변을 확인하는 브라우저 검사를 추가했습니다. 첫 실행은 여성 모바일에서 체크박스가 스크롤 아래 숨는 결함을 검출했습니다. 조절 항목을 고정 조작부로 옮긴 뒤 통과했습니다.
- 관련 브라우저18/18: 새 보조 표시3, 기존 비교2·상세 배치4·박리 입력4·첫 렌더/취소3·선택 불투명도2. 일반 클릭 복원 검사를 보강하고 설명 문구를 추가한 뒤 새3개를 다시3/3 통과했습니다. 이를 별개21개 시나리오라고 세지 않습니다.
- agy 제한 정적 검토와 후속 정정이 정상 종료했습니다. 최초 PackedAtlas depthWrite 누락 주장은 실제 `.45` 임계 규칙과 다르므로 채택하지 않았습니다. 다른 렌더러의 보조 표시 외 depthWrite=true는 기존 동작이며 이번에 새로 도입한 회귀가 아닙니다. 후속은 이를 정정하고 포인터 우선순위·고정 조작부를 검토했습니다. agy가 테스트 파일을 읽은 것을 직접 실행 검증으로 표현하지 않습니다.
