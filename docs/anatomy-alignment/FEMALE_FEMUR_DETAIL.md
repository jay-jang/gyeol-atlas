# 여성 대퇴골 전체·세부 선택 — 2026-09-22

여성 대퇴골 본체를 선택했을 때 원본의 전체16조각을 여는 경로를 추가했습니다. 기존에는 본체 한 조각의 선택/단독 보기만 가능했습니다. **전신 파일에 하위15개가 없었던 것이 아니라, 본체와 복합 구조를 구분하는 상세 진입이 없던 문제**입니다. 기하 파일이나 정점 위치는 바꾸지 않았습니다.

## 원본 범위

공식 HRA v1.10 원본 GLB를 다시 읽는 `scripts/build-hra-bone-targets.mjs`를 실행했고 저장된 [원본 계층 검사](hra-bone-targets.json)와 완전 일치했습니다. 여성 manifest의 `HRA:femur_L`/`HRA:femur_R` 개념에 포함된 ID를 그대로 사용합니다.

| 전체 묶음 | 본체 ID | 표시 범위 |
| --- | --- | --- |
| 왼쪽 대퇴골 |HRAF0937 |본체와15개 하위 표면,총16개 |
| 오른쪽 대퇴골 |HRAF0911 |본체와15개 하위 표면,총16개 |

관절연골과 부착면을 포함한 **원본 계층 묶음**이지, 순수 뼈 조직만의 독립 분할이나 폐쇄된 하나의 고체가 아닙니다. 화면의 접이식 구성 설명에도 이 한계를 표시합니다. 앞선 [대퇴골 정합 대상 정정](FEMUR_TARGET_CORRECTION.md)의 범위와 동일하며, 이 UI 보완이 여성 위치 정합을 승인하지 않습니다.

## 사용 동작

1. 여성 보기에서 `대퇴골` 또는 원본 ID로 검색해 본체/세부 표면을 선택합니다.
2. 선택 카드의 **왼쪽/오른쪽 대퇴골 전체 상세 보기**로 원본16조각을 함께 엽니다. 골격 레이어로 전환됩니다.
3. **세부 구조16개 선택**에서 한 조각을 따로 보고, **대퇴골 전체 모형**으로 돌아갈 수 있습니다.
4. **전신으로 돌아가기**, 박리 변경, 성별 전환은 기존 `view-state` 경로로 상세 범위를 해제합니다. 개별 선택과 상세 범위는 새로고침에도 복원됩니다.

기존 주요 장기 목록과 장부 비교에는 대퇴골을 추가하지 않았습니다. 새 자료 묶음은 별도 `female-composite-groups.json`으로 유지합니다. 여성 카탈로그32항목의 묶음/계층과 본체2개의 한국어 라벨만 변경했고, 나머지 필드는 이전과 대조해 동일함을 확인했습니다. 영문 이름·원본 ID·원본 파일은 보존합니다.

## 직접 검증과 수정 과정

- 신규 브라우저 검사를 먼저 실행해 ‘전체 상세 보기’ 버튼이 없는 실패를 재현했습니다.
- 좌우 실제16개 가시 ID, 본체 단독 ID, 선택 전/상세 내 같은 본체의 세계좌표 경계 일치, 새로고침 복원,50.5% 박리 복귀, 남성 전환을 검사했습니다.
- 초기 긴 설명을 접을 수 있게 바꿨습니다. 이후 모바일에서 세부 선택 줄2.797px가 잘리는 실패(가시 비율0.8446)를 재현해, 이미 전체 묶음인 경우의 중복 ‘전체 모형’·‘단독 보기’ 버튼을 제거했습니다. 개별 선택에는 전체 모형 복귀가 남습니다. 일부만 선택된 묶음을 전체로 오인하지 않도록 ID 집합도 확인합니다.
- 최종1440×900·390×844·844×390에서 세부 선택 줄의 **전체** 노출, 복귀 버튼 접근, 모델/카드 비중첩, 캔버스 포함을 확인했습니다. 표시된 요약·버튼의 최소12px·대비4.5:1도 통과했습니다. 가독성 검사 초기에는 접힌 목록의 비표시 항목까지 읽었으므로 이를 제외하도록 검사 범위를 고쳤습니다.
