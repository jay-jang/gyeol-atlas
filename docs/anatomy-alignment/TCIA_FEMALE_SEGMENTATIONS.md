# TCIA 여성 전신 자동 분할의 실제 수록 범위 — 2026-09-28

여성의 뇌·두개골과 주요 기관을 **같은 사례의 좌표계**에서 대조할 후보를 찾기 위해 [TCIA Healthy-Total-Body-CTs 공식 배포](https://www.cancerimagingarchive.net/collection/healthy-total-body-cts/)의 공개 분할 자료를 검사했습니다. 이번에는 파일을 확인하고 라벨을 집계했을 뿐, 공개 아틀라스의 모형·좌표·선택·박리를 바꾸지 않았습니다. 자동 분할을 해부학적 정답이나 임상 검증으로 취급하지 않습니다.

## 출처와 사용 범위

- 공식 자료: *Healthy-Total-Body-CTs*, TCIA, DOI [10.7937/NC7Z-4F76](https://doi.org/10.7937/NC7Z-4F76). v3은 2026-09-23 배포됐으며 공식 변경 설명은 **NIfTI 분할 파일명을 DICOM 영상과 맞도록 수정**했다는 것입니다. 이름 수정이 새 조직 분할이나 정확도 개선을 뜻하지는 않습니다.
- 사용한 다운로드: [공개 분할 ZIP](https://www.cancerimagingarchive.net/wp-content/uploads/Healthy-Total-Body-Cts_20260923.zip)과 [임상 표](https://www.cancerimagingarchive.net/wp-content/uploads/Healthy-Total-Body-CTs_v02_20240927.xlsx). 공식 페이지는 분할·임상 표를 CC BY 4.0으로 표시합니다. CT 원영상은 NIH Controlled Data Access 대상이라 내려받거나 공개 모형에 사용하지 않았습니다.
- 받은 ZIP SHA-256: `f3daa9c5e9740c8d68688bd800f5d3107236099d3e319bbef04076aa4719b13f`; 임상 표 SHA-256: `a46d50f8549553717a3783884da367f26a728b74795790761378d324a9c10b35`. 이는 로컬 수신 파일 식별값이며 배포자 서명과 대조한 값은 아닙니다. ZIP 전체 CRC 검사 통과.

## 실제 파일 전수 검사

임상 표의 `F` 사례 16개 **003·005·007·010·013·015·018·020·021·023·027·030·031·032·033·034**를 공개 ZIP의 동명 NIfTI와 맞췄습니다. 16개 모두 파일이 있고, 각 512×512×828 복셀 전체를 읽었습니다(총 3,472,883,712복셀). 비유한값·음수·비정수·119 초과 라벨은 0개입니다. 각 파일의 qform/sform 중 유효한 공간 행렬도 기록했습니다. 사례마다 픽셀 간격이 다르므로 같은 격자 번호를 곧바로 공통 좌표로 해석하지 않습니다. [전체 수치·라벨명·해시·사례별 행렬](tcia-v3-female-source.json).

| 항목 | 실제 확인 | 의미 |

사례003은 뇌4가 568,799복셀, 두개골26이 264,082복셀, 심장5가 163,642복셀, 골격근33이 8,646,018복셀입니다. 뇌·두개골은 같은 분할 파일의 좌표계에 있지만, **한 파일에 공존한다는 사실만으로 형태·경계·신경 연결의 정확도가 검증되는 것은 아닙니다.** 003의 압축 NIfTI SHA-256은 `7f94ed7854ec2aabba7f4eaa0db0d5e2fff059480ba392bf1de37d3e1ff6638d`입니다.

## 현재 아틀라스에 대한 판정

이 출처는 같은 여성 사례 안에서 큰 구조의 상대 배치를 따져 볼 독립 후보입니다. 현재 HRA 여성 피부·Allen 참조 뇌·남성 유래 보완 골격과는 **다른 사람 및 다른 자료**이므로, 좌표를 그대로 겹치거나 기존 뇌·골격을 자동 교체하지 않습니다. 2.344mm 축간격의 자동 분할은 얇은 신경·혈관·세부 근육 층서를 증명하지 못합니다. 특히 기존의 두개골–참조 뇌 관통 문제를 `같은 사례`라는 이유만으로 해결한 것으로 표기하지 않습니다. 공개 앱의 전신/상세 모델에 채택하려면 분할 표면·빈틈·해부 연결, 피부 기준 등록, 저작자 표시 및 화면/성능 검사를 별도로 통과해야 합니다.

재현 명령(NumPy·NiBabel이 설치된 기존 여성 CT 검사 환경):

```sh
.cache/female-ct-venv/bin/python scripts/audit-tcia-female-segmentations.py \
  .cache/tcia-v3-2E1ruY/segmentations.zip \
  .cache/tcia-v3-2E1ruY/clinical.xlsx
```

스크립트는 ZIP 안의 16개 압축 NIfTI를 순차 판독하며 공식 CT 원영상을 요청하지 않습니다. 다운로드 원본은 `.cache/`에만 두고 저장소·배포 번들에 포함하지 않았습니다. 이번 검사는 소스 범위 감사라 앱 빌드·화면/박리 게이트를 완료 근거로 주장하지 않습니다. 전체 여성 위치 정합 및 모든 기관 수록 목표는 미완료입니다.

첫 실행은 임상 표의 성별 값이 `Female`이 아닌 `F`인 것을 처리하지 못해 중단됐습니다. 다음 실행은 사례003의 공간 행렬이 sform이 아닌 qform에 있어 중단됐습니다. 원본 형식을 확인하고 두 판독을 수정해 전수 검사를 통과했습니다. 독립 확인으로 NiBabel이 읽은 사례003의 z=730 절편과 스트림에서 직접 읽은 동일 절편이 모든 복셀에서 일치했습니다(해당 절편 뇌16,614·두개골2,851복셀). 최종 스크립트 구문 검사·재실행·`git diff --check` 통과. 별도 전문가 판독 또는 조직 정확도 검증은 수행하지 않았습니다.

후속 [같은 사례003의 뇌–두개골 공간 감사](TCIA_HEAD_SPATIAL.md)에서 두 라벨의 실수록과 복셀 면 접촉55,394개, 비두개골 영역의 외부 연결을 확인했습니다. 라벨의 배타성·이진 등위면의 폐곡면만으로 기존 3D 뇌–두개골 충돌이 해결된다고 해석하지 않습니다. 전신 교체는 보류합니다.
