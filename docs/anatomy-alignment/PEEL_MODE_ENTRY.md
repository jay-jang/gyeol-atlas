# 계통별 보기와 연속 박리 진입 구분 — 2026-09-28

계통별 보기·비교·상세 선택 상태에서도 마지막 박리 수치를 현재 박리인 것처럼 표시하던 문제를 수정했습니다. 비교 상태의0%에서 Alt+↑를 누르면 깊이 숫자가 같다는 이유로 전환 자체가 무시되던 오류도 실제 브라우저에서 재현하고 교정했습니다.

## 동작

- 계통별 보기에서는 현재 모드를 표시하고 **박리 시작 · 기준값%** 버튼을 제공합니다. 슬라이더 접근성 값에도 현재 모드와 시작 기준을 구분합니다. 기준값은 실제 조직 깊이 측정값이 아닙니다.
- 버튼의 클릭·터치·Enter는 기존 `view-state.ts`의 `dissection` 전이를 사용합니다. 같은 숫자에서도 선택·비교·상세를 해제하고 연속 박리로 전환합니다.
- 상대 박리 입력도 계통별 보기의0/100% 경계에서 전환할 수 있습니다. 이미 박리 중이면 경계를 넘는 입력은 기존대로 no-op이고,0·비유한 증감도 무시합니다.0.5% 간격은 유지합니다.
- 카메라·표식·계통별 투명도 선호는 유지합니다. 기존 비교에서 설정한 피부 투명도를 초기화하는 수정이 아니며, 좌표·기관 수록·근육 층서는 바꾸지 않았습니다.
- 계통별 보기의 작은 계통 표시들은 실제 활성 레이어를 따릅니다. 연속 박리에서는 기존 단계 표시를 유지합니다.
