# 표층·심층 근육의 박리 순서 보정

2026-09-20. 가슴·복벽·종아리의 출처가 확인된30개 선후 관계를 실제 모형 ID에 연결했습니다. **전체 근육의 해부 층서를 검증한 것은 아닙니다.** 전신 참조의 근육계529개 중38개(남성26·여성12)에 관계 제약이 적용되며, 나머지491개의 순서는 여전히 기하학적 추정입니다.529개는 기본 숨김 기증자 중복2개를 포함한 메쉬 수로 실제 근육 개수가 아닙니다. 별도 CT 상세는 이 개수에 포함하지 않습니다. 여성 미수록 근육·기관을 추가하거나 기존 보완 골격·근육의 좌표 불일치를 고친 변경은 아닙니다.

## 수정 근거

기준 `6ab02cb`의 남성437개 실제 GLB 및 여성92개 실제 packed 근육 geometry에서 기존 정렬 점수를 재현했습니다. 여성의 몸통 중심 반경만으로 순서를 정하면 양측 안쪽 장딴지근보다 가자미근이 먼저 사라졌습니다. 남성에서도 양측 가자미근보다 긴엄지굽힘근·긴발가락굽힘근이 먼저 사라졌습니다. [모형별 시작값·원본 해시·전후 검사](muscle-peel-audit.json).

## 출처와 해석 범위

- 가슴: [UBC 실제 해부 표본, 큰가슴근을 젖힌 앞가슴](https://www.clinicalanatomy.ca/thorax/thoraxAnteriorPMrefl.html). 수록된 좌우 큰가슴근3부분을 작은가슴근보다 먼저 제거하도록 연결합니다.
- 복벽: [출판사 제공 Gray’s Anatomy for Students 복부 장 샘플](https://booksite.elsevier.com/samplechapters/9780443066122/9780443066122.pdf), 가쪽 복벽의 바깥빗근→속빗근→배가로근. 힘줄막·배곧은근집의 모든 부위에 동일한 층서를 일반화하지 않습니다.
- 종아리: [Loyola University의 posterior leg 해부 자료](https://www.meddean.luc.edu/lumen/meded/grossanatomy/dissector/labs/le/ant_th_leg/tl3.html). 장딴지근→가자미근→깊은 뒤칸의 긴엄지굽힘근·긴발가락굽힘근·뒤정강근 관계입니다. 원본의 좌우·각 갈래를 정확히 구분합니다.

이는 겹치는 부위의 표층/심층 관계를 교육용 ‘모형 전체 제거 순서’로 편집한 것입니다. 각 근육이 다른 근육의 표면 전체를 덮는다는 뜻이 아닙니다. 원문 그림·표·모형 파일을 재배포하지 않았습니다. 여성에는 종아리 관계만 적용하며 존재하지 않는 가슴·복벽 근육을 생성하지 않습니다.

## 구현

`muscle-peel-relations.ts`는 고정 ID·성별·좌우·근육명·출처를 갖습니다. 카탈로그에서 이름에 대응하는 모든 수록 부위가 정확히 포함되는지 단위 검사합니다. `muscle-peel.ts`는 이 관계를 비순환 그래프로 만들고 표층의4% 표시 페이드가 끝나야 심층 페이드가 시작되도록 제약합니다. 긴 선후 사슬도24~60% 시작 구간 안에 들어가게 남은 사슬 길이를 역방향 계산합니다. 시작값은0.5% 단위입니다. 순환·중복 ID·비유한 점수·표시 구간을 넘는 사슬은 오류 처리합니다.

남성·여성 렌더러 모두 이 함수와 같은 `musclePeelOpacity`를 사용합니다. 기존 남성의 별도22~68% 중심값 계산을 제거했습니다. 전체 근육 레이어가54%부터 동시에 흐려지면 관계 제약보다 먼저 심층이 흐려지므로, 전체 레이어 소멸은 개별 제거가 모두 끝난64% 이후로 옮겼습니다. 레이어 상태는68%까지 유지될 수 있지만 실제 근육 메쉬는64%에 모두 제거되며 골격·장기 장면이 남습니다. 기타 계통의 투명도 곡선, 좌표·인덱스, 선택·카메라 상태 전이는 변경하지 않습니다.

## 검사와 한계

- 단위 검사는 정확한38개 ID/명칭/성별/좌우와30개 관계를 확인합니다. 의도적으로 역전된 기하 점수에서도 관계가 우선하며,0.5% 입력마다 실제 공통 투명도와 결합해 심층이 흐려질 때 표층이 이미0인지 확인합니다. 원본 불변, 입력 순서 독립, 최대 허용 사슬 및 초과 오류도 검사합니다.
- 브라우저 검사는 실제 R3F 메쉬의 rank·가시성·material opacity·월드 경계를 읽습니다. 남성19개·여성12개 경계/직후 설정을 거치며 좌표 불변과 선후 관계를 검사하고, 숨겨진 가자미근 검색→레이어 자동 전환→온전한 선택→계통 전환 시 카메라 보존을 확인합니다. 이 검사에서 GPU 렌더링을 중지하지 않습니다.
- [남성 종아리](muscle-peel-male.png), [여성 종아리](muscle-peel-female.png), [여성 모바일](muscle-peel-female-mobile.png)는 후면 관찰 캡처입니다. 최종 캡처는 같은 OrbitControls의 시점을 종아리에 맞춘 진단용 확대이며 메쉬/재질을 별도 교체하지 않습니다.
- 최초 브라우저 실행은 여성 통과·남성 실패였습니다. 동시에 실행한 빌드의 데이터 재생성 중 개발 장면 루트를 읽는 오류가 발생했고, 빌드를 마친 뒤 동일 검사를 다시 실행하여 남녀2개 및 기존 연속 박리1개를3/3 통과했습니다. 최초부터 전부 통과했다고 기록하지 않습니다. 최종 추가 검사 결과는 아래 검증 기록에 이어집니다.

agy 정적 검토 대화 `6e3eea4d-9045-417c-b05b-86cfb40b24c5`는 스케줄 제약·양자화·성별 ID 격리·런타임 연결에서 결함을 지적하지 않았습니다. agy가 출처나 해부 geometry를 직접 검증한 것은 아닙니다. ‘공백 없이 맞물린다’는 답변을 근육이64~68%에도 남아 있다는 의미로 사용하지 않습니다. Packed 렌더러는 선택 재질을 불투명하게 표시하는 경로이며, agy의 설명처럼 모든 경우 `depthAlpha` 변수 자체를1로 고정하는 코드는 아닙니다. 실제 동작은 브라우저로 별도 확인합니다.

검증 범위 밖의 층서와 잘못 정렬된 여성 보완 자료는 계속 남습니다. 초기 확대 전 ‘다리·발’ 영역 캡처에서 손뼈 일부가 함께 보이는 기존 경계 상자 기반 부위 필터 문제도 확인했습니다. 이번 순서 보정이 그 필터나 전체 신체 정합을 해결했다고 주장하지 않습니다.
