## 변경과 범위

저장된 선택의 복귀 시점은 세션 복원에서 좌표·거리·레이어 형식을 검증합니다. 카메라 이동은 저장된 보기 상태의 시점을 사용하며 새 해부 좌표나 모형 변환을 만들지 않습니다. 데스크톱 전체 보기에서 모바일 폭으로 넘어갈 때만 관찰 거리·중심을 다시 맞춥니다. 선택 카드가 사라지거나 스크롤바 크기가 달라지는 것은 모바일 전환으로 취급하지 않아 비교 시점을 건드리지 않습니다.
