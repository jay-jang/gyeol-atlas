# 여성 원본 고관절 연골 중심과 다리 회전 — 2026-09-28

**몸통 기준을 유지한 다리 회전으로 큰 자세 차이가 줄었습니다. 골격의 잔여 오차와 근육·신경 관계는 해결되지 않았고 공개 모델에는 적용하지 않았습니다.** 이전 [전신 공통 프레임](SHARED_LUMBAR_LEG_FRAME.md)과 달리 좌우 다리는 따로 회전하되 몸통/골반은 움직이지 않는 뼈 전용 진단입니다.

## 실제 자료와 추정의 경계

사용자가 받은 Denver Final ZIP에는 좌우 각각 `FemurHead`(넙다리뼈머리)·`PelvisAcetabulum`(절구) 연골 STL이 있습니다. 기존 출처 목록의 네 파일 SHA를 확인했습니다. 새 해부 구조를 생성하거나 앱 수록을 늘린 것은 아닙니다. HRA 대상에는 대응하는 고관절 연골/관절 중심 항목이 없어, 이 네 원본 표면에서 구의 중심을 수치적으로 추정했습니다. **원본이 제공한 해부학적 표지점이나 검증된 회전축이 아닙니다.**

각 표면에서 결정론적 면적 표본2,048개를 사용했습니다. 중심화/정규화한 대수적 구 맞춤으로 시작해, 반지름 잔차의 비선형 최소제곱을 반복했습니다. 네 경우 모두 파라미터 변화 기준으로 종료했습니다. 바깥면·안쪽면·테두리가 모두 기여하며 구면 잔차는 관절 중심 정확도의 오차 범위가 아닙니다.

| 원본 연골 | 정점 | 추정 반지름 mm | 전 정점 반지름 잔차 p95 / 최대 mm |
| --- | ---: | ---: | ---: |
| 왼 FemurHead |8,287 |23.785 |1.443 / 2.087 |
| 왼 PelvisAcetabulum |22,967 |24.892 |1.225 / 1.706 |
| 오른 FemurHead |11,476 |22.478 |1.971 / 4.432 |

같은 쪽 두 추정 중심의 거리는 왼1.080699mm·오른1.178604mm입니다. 두 추정치의 근접성을 독립적인 실제 관절 중심 검증으로 해석하지 않습니다.

## 고정 몸통과 회전 제한

[허리뼈 공통 프레임](LUMBAR_SOURCE_FRAMES.md)의 `rigid` 후보를 몸통 기준으로 사용했습니다. 이것은 근사 BoneHub→Denver 변환의 역변환까지 합성하므로 **Denver→HRA 실제 배율은0.995136675**이며, 그 전체를 배율1 강체라고 부르지 않습니다.

각 다리는 이 공통 기준에 놓인 추정 중심을 고정한 채 하나의 proper 회전만 허용했습니다. 번역 이동이나 추가 배율은 없습니다. 회전 최소제곱 입력에 중심 기준 벡터와 그 음수를 함께 넣어 평균을0으로 만들었습니다. 넙다리뼈·정강뼈·종아리뼈3개를 맞춤에 사용하고, 무릎뼈는 함께 회전시키되 맞춤에서 제외했습니다. 골반은 몸통 기준에 그대로 남겼습니다. 무릎 관절을 따로 굽히는 모델은 아닙니다.

각 뼈 양방향512면적 표본 중 가까운409개씩, 반복마다2,454대응으로 맞췄습니다. 네 경우의 반복 횟수는 왼 FemurHead79·절구60, 오른 FemurHead52·절구55입니다. 모두 표본 최대 이동0.00001mm 미만에서 종료했습니다. 한 초기값의 국소 수치 종료이지 전역 최적해가 아닙니다.

FemurHead 중심을 사용한 회전 각도는 왼8.594776°·오른11.528471°입니다. 절구 중심 사용 시 왼8.574560°·오른11.514921°였습니다. 아래 수치는 **FemurHead 중심 후보**의 전 참조 정점에서 최근접 표면 거리 p95입니다. 각 칸은 원본→HRA / HRA→원본 순서입니다.

## 재읽기와 검증 범위

[연골 계산](hip-cartilage-pivots.json), [다리 계산](hip-pivot-legs.json), [별도 재읽기](hip-cartilage-pivots-readback.json)를 보존합니다. 연골49,188정점·98,364삼각형을 STLLoader가 아닌 바이너리 바이트 판독과 스칼라 산술로 다시 읽어 전 정점/표본 반지름 잔차를 대조했습니다. 네 회전의 직교성·양의 행렬식·고정 중심도 별도 산술로 확인했습니다.

연골4표면과 다리6뼈의 원본/대상12표면, 총16표면·468,024입력 삼각형·14,336표본의 면적 합·정확한 중복·삼각형/무게중심 소속을 대조했습니다. 면적 합 최대 잔차6.94×10⁻¹⁸m², 표본점 재구성 차이0입니다. 별도 검사의 첫 실행은 구문 괄호 오류로 시작하지 못했고 수정 후 전체 검사를 다시 실행했습니다. 이 검사는 독립적인 최근접 표면 재탐색이나 최적화·전체 교차·해부학 검증이 아닙니다.

이 후보는 근육 변형을 아직 만들지 않았습니다. 뼈 회전의 개선만으로 큰허리근의 몸통–넙다리 연결, 피부 포함, 장기·혈관·신경 관계가 개선됐다고 주장할 수 없습니다. 다음 단계는 몸통/다리를 연결하는 근육 변형을 별도 후보로 만들고 원본 관계·피부·주변 조직을 함께 평가하는 것입니다. 근육별 개별 이동이나 피부 안으로 누르기만으로 정합을 대신하지 않습니다.

agy 대화 `c2f13c17-6b22-4f0e-8082-f7163c8c9c59`의 읽기 전용 제한 검토는 구조화 상태 `SUCCESS`로 종료했습니다.
