# 여성 머리의 대체 자료 확보 — 2026-09-27

**SCI 여성 머리 분할 원본은 확보했지만, 해부 이름·좌표계를 확정하거나 앱에 배포하지 않았습니다.** [VIVA 피부 정합 실패](VIVA_HEAD_FIT.md) 후 같은 사람의 피부·두개골·뇌 관계를 함께 검토할 수 있는 대체 자료를 조사했습니다. 새 출처 확보는 기존 여성 전신의 위치 교정 완료가 아닙니다.

## 후보와 사용 조건

[SCI 공식 저장소](https://sci.utah.edu/sci-head-model/)는 여성 머리 MRI,8재료 분할, Cleaver 계산망을 공개하고 출처·지원기관 표기를 요청합니다. [Warner 등의 논문](https://doi.org/10.1101/552190)과 함께 검토했습니다. 뼈는 MRI 기반 합성 CT를 사용한 분할이며, 논문은 치과 장치의 영상 결함 때문에 입안을 고체 뼈로 처리한 한계를 설명합니다. 정상 치아·턱 전체 상세 모델로 간주할 수 없습니다.

공식 페이지의 공개 접근·인용 요청과 논문의 CC BY 표시를 구분합니다. 논문의 라이선스를 데이터에 자동 적용하지 않았으며, 이번에는 원본을 로컬 진단에만 사용합니다. 공개 파생 모델 배포에 필요한 데이터 조건을 더 확인해야 합니다. 공식 지원 표기는 NIH/NIGMS `P41 GM103545`, `R24 GM136986`입니다.

별도로 [MIDA 공식 페이지](https://itis.swiss/virtual-population/regional-human-models/mida-model/)와 [2024 사용 계약](https://itis.swiss/assets/Downloads/VirtualPopulation/License_Agreements/LicenseAgreementMIDA_2024.pdf)을 확인했습니다. 계약2.3.2의 원본·수정/파생 모델 재배포 금지 때문에 공개 Pages 자산 후보에서 제외했습니다. 신청 양식을 제출하거나 모델을 내려받지 않았습니다. 공식 다운로드 설명의115구조와 논문 설명의153구조를 혼용하지 않습니다.

## 실제 확보와 번호 혼동 방지

| 자료 | 확인한 파일 | 검증 범위 |
| --- | --- | --- |
| Segmentation.zip |593,032바이트, `HeadSegmentation.nrrd` | ZIP 전체 SHA-256·CRC, 압축 해제13,631,488복셀 전수 |
| Simulations.zip |17,727바이트, SCIRun 네트워크3개 | ZIP 전체 SHA-256·CRC, 뇌 선택식·전도도 행 기록 |
| Mesh.zip |원격3,463,196,500바이트 중431,583바이트 전송 | 중앙 목록·README·`HeadMesh_poly2.vtk`만 읽음. 전체 ZIP 해시/CRC 미검증 |

[고정 원본 목록](sci-head-inventory.json)에 URL·해시·NRRD 헤더·라벨별 복셀 수와 범위를 보존했습니다. NRRD에는1~8의 값이 있지만 헤더와 README에 숫자별 해부 이름이 없습니다. 공식 네트워크의 뇌 선택식은 계산망 값1·3·7을 사용합니다. **계산망의 전도도 행 번호나 파일 이름의 숫자를 NRRD 이름표로 복사하지 않습니다.**

작은 공식 망 파일 `HeadMesh_poly2.vtk` 전체1,996,985바이트·7,136점을 읽고 CRC를 검사했습니다. 이 점들을 같은 index 좌표라고 가정해 최근접 복셀에 대조하면 오프셋0에서 라벨1이4,938점,6이28점,7이2,145점,8이25점이며 **라벨2는0점**입니다. ±0.5복셀 가정에서도 라벨2는0점입니다. [부분 다운로드·대조 기록](sci-head-mesh-label-probe.json).

이는 번호를 동일시할 근거가 없다는 좌표 진단이지, `poly2`를 눈으로 확정하거나 나머지7조직을 검증한 결과가 아닙니다. 표면 근처의 복셀 차이, 망 생성과 영상 사이의 변환, 파일 접미사와 실제 재료 값의 관계를 더 확인해야 합니다. 계산망 네트워크에는 별도 `AlignMeshBoundingBoxes` 단계도 있습니다.

## 남은 확인과 재현

NRRD 크기는208×256×256, 방향 벡터는 단위 직교축, 공간 표기는 `3D-right-handed`입니다. RAS/LPS나 물리 단위를 명시하지 않으므로 원본 영상과 대조하기 전 축·좌우를 확정하지 않습니다. 현재 JSON의 모든 `anatomicalName`은 `null`입니다. 신경조직과 CSF·공기 공간을 분리해야 하며, 이8재료 자료에는 세부 뇌신경·혈관·전신 기관 전체가 없습니다.

```sh
python3 scripts/audit-sci-head.py
python3 scripts/audit-sci-mesh-labels.py
```

첫 명령은 `.cache/sci-head/`의 고정 ZIP2개가 필요합니다. 두 번째 명령은 공식 ZIP에서 제한된 HTTP Range만 받습니다. 길이·ETag·206응답·Content-Range·읽기 예산을 검사하고 조건이 달라지면 중단합니다. 원본과 파생 표면을 GitHub에 포함하지 않았습니다. **다음 적용 조건은 조직 번호 대응·원본 축/좌우·사용 조건 확인과 실제 뇌–두개골 관계 검증이며, 그 전에는 전신 교체를 하지 않습니다.**
