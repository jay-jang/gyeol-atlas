# 큰허리근의 원본 관계와 고정 참조의 구분 — 2026-09-28

**이전 허리뼈 후보의 새 교차23/25쌍을 모두 같은 종류의 배치 오류로 해석하면 안 됩니다.** 원본 자료와 대조할 수 있는 범위를 나눠 재검사했습니다. 일부 허리뼈 관계는 근사 원본 정합에서도 나타나지만, 골반 주변 다른 근육과의 새 교차는 같은 원본에 없었습니다. 후보를 승인하거나 앱 좌표를 변경하지 않았습니다.

## 어떤 원본끼리 비교했는가

- Denver Final 근육76개와 골반/넙다리뼈4개는 **같은 제공 좌표계**입니다. 두 큰허리근을 포함하는 근육149고유 쌍과 큰허리근2×뼈4=8쌍을 검사했습니다. 근육은 전체 원본 해상도이며 기존 가져오기 변환을 적용하지 않았습니다.
- BoneHub 허리뼈6개와 Denver 큰허리근은 **서로 다른 원본 좌표계**입니다. [기존 Final/Original 근사 맞춤](BONEHUB_DENVER_FRAME.md)을 각각 사용한24쌍-상태를 분리했습니다. 같은 기증자 명칭만으로 정확한 공동 원본 좌표라고 간주하지 않습니다.
- 같은 이름의 HRA 허리뼈는 앱 표면과 공식 v1.10 원본 표면을 모두 검사했습니다. 골반·넙다리뼈는 기존 HRA 계층 묶음과 대응시켜 한 부품이 아닌 전체 뼈 범위에서 비교했습니다.

[전체 계산](psoas-source-relations.json), [점/삼각형 재읽기](psoas-source-relations-readback.json), [촬영 조건](psoas-source-relations-captures.json). 앞선 [허리뼈 후보](LUMBAR_SOURCE_FRAMES.md)의 좌표·교차 기록은 수정하지 않고 고정했습니다.

## 같은 좌표계 원본에서 확인한 관계

근육149쌍 중 광의 교차는 왼 엉덩근–큰허리근1쌍이며 엄격한 삼각형 내부 교차 증거도 있습니다. 최종 가공 원본이라고 모든 교차가0이라고 주장하지 않습니다. 오른 엉덩근–큰허리근은 원본 표면 사이 BVH 최단거리 결과0.04554mm이고, 현재 앱/기존 배치에서는 교차합니다. 이번에는 이 차이의 세부 단순화/변환 원인을 분리하지 않았습니다.

| 큰허리근과 같은 원본의 다른 근육 | 원본 BVH 최단거리 | 허리뼈 후보에서의 새 교차 |
| --- | ---: | --- |
| 왼 바깥폐쇄근 |8.89917mm |두 후보 모두 |
| 왼 두덩근 |2.02696mm |두 후보 모두 |

원본 골반/넙다리뼈8쌍은 모두 교차하지 않습니다. 같은 측 골반과의 최소 간격은 왼0.04101mm·오른0.03233mm이며, 같은 측 넙다리뼈와는 왼9.31854mm·오른11.89438mm입니다. 이 값은 표면간 수치상 최단거리이지 해부학적 부착점·건 길이가 아닙니다. **넙다리뼈까지 거리가0이 되도록 맞추는 것도 이 자료로 정당화할 수 없습니다.** 후보의 같은 측 넙다리뼈 간격은 왼1.28958/2.39612mm, 오른3.20243/3.01572mm(강체 허리뼈 기준/similarity 기준)로 바뀝니다.

큰허리근만 이동하면 같은 원본의 다른 근육과의 관계가 바뀝니다. 골반 단일 모형과 HRA 두덩뼈/엉덩뼈 등의 여러 부품은 일대일 동일 표면이 아니므로, 원본 전체 골반 비교로 특정 부품의 정상 부착을 증명하지 않습니다.

## 허리뼈 교차는 별도 분류

두 후보 모두 HRA 허리뼈와 새로 교차한 관계는9쌍입니다. 앱의 단순화 표면 대신 공식 원본을 사용해도 이9쌍은 그대로입니다. 따라서 이번9쌍을 앱 허리뼈 단순화만으로 설명할 수 없습니다.

| 이전 후보의 새 허리뼈9쌍 | 근사 원본 비교의 결과 |
| --- | --- |
| 오른 L2, 양쪽 L3/L4, 오른 L5:6쌍 |Final/Original 두 원본 정합 방식 모두 교차 |
| 왼 L1:1쌍 |Final 방식은 비교차, Original 방식은 교차 |
| 왼 L5·오른 L6:2쌍 |두 방식 모두 비교차 |

허리뼈 근사 원본 비교24쌍-상태 전체에서는13교차입니다. 이 결과는 이미 근사 정합을 거친 표면이므로 **원본 그대로의 정상 접촉이나 실제 해부학적 부착을 관찰한 증거가 아닙니다.** 여섯 허리뼈195,990정점에서 두 출처 변환의 점별 차이를 별도 계산했으며, 왼 큰허리근의 교차 여부가 달라지는 L1에서 최대0.406220mm입니다. 이전 큰허리근 정점의 역변환 민감도(최대0.394137mm)와는 대상·방향이 다릅니다. 작은 좌표 차이를 전체 관계의 확실성으로 바꾸지 않습니다.

새23/25쌍 중 같은 좌표계 원본에 대응시키는 관계는 각각8/10쌍(전체 골반 부품5/6 + 다른 근육3/4)이며 원본 교차는 없습니다. 허리뼈9쌍은 위의 근사 비교이고, 나머지6쌍(정맥2·추간판4)은 대응 원본이 없어 판단을 보류합니다. 교차 없음·기존 교차·출처 부재를 구분하며 어느 것도 임상 승인을 뜻하지 않습니다.

## 수치 근거의 재검사

BVH 라이브러리의 indirect 모드가 최근접 삼각형 번호를 내부 탐색 순서로 반환함을 코드에서 확인했습니다. 원래 메쉬의 삼각형 번호로 각각 변환한 뒤 좌표를 저장합니다. 두 BVH가 모두 재정렬된 합성 예제, 양의 간격, 가로지르는 교차를 별도 검사했습니다. 최초 실행의 거리/교차 값은 참고로만 읽었고 삼각형 번호 처리를 보완한 뒤 전체 계산을 다시 수행했습니다.

재읽기에서134관계의 최근접점268개가 실제 삼각형에 속하는지, 점간 거리·삼각형 평면/무게중심 조건, 엄격한 교차 증거55건의 양쪽 삼각형과 내부 교차 산술을 확인했습니다. 최대 평면 잔차1.85×10⁻¹³mm·거리 잔차2.85×10⁻¹⁴mm입니다. BVH 전체 최단거리 탐색·비교차 판정을 독립 구현한 것은 아닙니다. 부동소수점 수치이며 임상 오차 허용치·조직 침투 부피/깊이를 나타내지 않습니다.
