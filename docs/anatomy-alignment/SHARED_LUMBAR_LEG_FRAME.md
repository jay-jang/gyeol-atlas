# 좌우 전체 근육의 공통 허리뼈–다리 기준 — 2026-09-28

**같은 원본의 근육 관계를 보존하는 것과 고정 HRA 인체에 맞는 것은 다릅니다.** 양쪽76근육에 하나의 공통 강체/균일 배율 변환을 적용한 두 후보는 원본 내부 교차 집합을 유지했지만 피부·다리뼈·주변 조직 관계가 크게 악화돼 적용하지 않았습니다. 원본 뼈도 같은 변환으로 평가했지만 앱 뼈는 변경하지 않았습니다.

## 공통 기준과 표본

Denver의 양쪽 골반·넙다리뼈·무릎뼈·정강뼈·종아리뼈10개와 BoneHub 허리뼈6개를 함께 사용했습니다. 허리뼈는 [기존 근사 BoneHub→Denver Final 변환](BONEHUB_DENVER_FRAME.md)을 먼저 적용했으므로16개 전부가 정확히 같은 원본 좌표라는 주장은 하지 않습니다. L2~L5와 다리뼈10개, 총14개만 초기 중심 맞춤과 반복 맞춤에 사용했습니다. **L1/L6는 초기화와 맞춤 모두에서 제외**했습니다. HRA 허리뼈는 공식 원본 표면, 다리뼈는 현재 앱 계층 묶음(원본 복원 패치 포함)이 대상입니다.

첫 실행은 무릎뼈 대상 정점이209개여서 ‘각512정점’ 단언에 실패했습니다. 이를 반복 정점으로 채우지 않고 표면 삼각형 면적에 따른 결정론적 표본점으로 변경한 뒤 전체 계산을 다시 수행했습니다. 각 원본/대상 표면마다512점, 총28표면·14,336점입니다. 누적 삼각형 면적을512구간으로 나눠 각 구간의 중간 위치에 해당하는 면을 고르고, 면 내부는 제곱근 무게중심 변환과2/3진 역순 수열로 정했습니다. 해부 대응점이나 무작위 임상 표본은 아닙니다.

방향이 반대여도 좌표가 정확히 같은 삼각형은 표본 면적에서 한 번만 셉니다. 왼/오른 HRA 골반에서3,880/2,768개 중복 면을 제외했고 모형·인덱스·최근접 대상 자체는 변경하지 않았습니다. 부분적으로 겹치거나 서로 다른 내부 표면까지 합집합으로 처리한 것은 아닙니다. 각 방향에서 가까운409점씩 남겨14×2×409=11,452대응으로 맞추므로, 잘라낸 뒤의 분포는 초기 면적 분포와 다릅니다.

강체55회·similarity46회에 표본 최대 이동0.00001mm 미만으로 종료했습니다. 단일 초기값의 수치 종료이며 전역 최적해를 증명하지 않습니다. 강체 배율은1, similarity는1.105447750입니다. 두 경우 모두 좌우·부위·근육별 별도 변환 없이 동일한 행렬을 사용했습니다.

모든 뼈의 전 참조 정점을 양방향으로 검사했습니다. 다리 쪽 오차가 큽니다. 왼/오른 종아리뼈의 원본→HRA p95는 강체97.285/97.198mm, similarity108.685/113.519mm입니다. 제외한 L1/L6의 양방향 p95 범위는 강체9.403~10.660mm, similarity17.322~40.212mm입니다. p95는 정점 분포 통계이며 전체 연속 표면 상계·최대 침투 깊이가 아닙니다.

## 실제로 보존된 범위

전체 원본 근육끼리2,850고유 쌍(반대쪽 포함)을 검사했습니다. 원본의 교차33쌍은 두 후보에서 정확히 같은 쌍으로 유지됐고 새/제거 교차0입니다. **고정된 다른 출처의 근육4쌍**과의 새 교차는 이 내부 보존 범위 밖입니다.

76근육×16원본 뼈=1,216관계에서도 교차23쌍과 비교차 집합이 유지됐습니다. 이 중17쌍은 같은 좌표계의 Denver 뼈,6쌍은 근사 좌표를 사용한 BoneHub 허리뼈와의 관계입니다. 원본 관계 자체의 정상 해부학을 승인한 것은 아닙니다. 강체는 거리를 유지하고 similarity는 모든 거리를 같은 배율로 바꾸므로, ‘관계 보존’을 실제 크기나 간격이 불변이라는 뜻으로 확대하지 않습니다.
