# 실제 피부 표면에 대한 위치 감사 — 2026-09-20

2026-09-21 [발뼈 후속 진단](FOOT_SCALE_DIAGNOSTIC.md): 양쪽 발56개·참조 정점16,842개에서 현재 이탈2,183개를 재현했습니다. 두 단순 축소안의 피부 포함 개선과 발목 거리 변화를 함께 검사했으나 해부 정합 근거가 부족해 미적용입니다. 아래 교정 후 전체 수치는 이번에 변경되지 않았습니다.

후속 [팔·손뼈60개 부분 교정](FEMALE_ARM_PARTIAL_REGISTRATION.md)과 [엄지 추가 교정](THUMB_REFINEMENT.md)에서 보완 골격 이탈은17,260→5,014→4,471정점,90→47→44개 모형으로 감소했습니다. 손가락·다른 골격·보완 근육은 미완료입니다. **아래는 교정 전 원본 좌표의 감사 기록**이며, 최신 표시 좌표는 [부분 교정 후 전체 감사](body-containment-female-registered-all.json)를 참고하세요. 현재 검사 명령은 기본적으로 런타임 교정을 포함하며 `--source-female`로 원본 좌표만 대조할 수 있습니다.

**여성 보완 골격·근육의 위치 문제는 미해결입니다.** 공개 커밋 `aef2329`에서 피부와 골격을 동시에 표시해 오른팔·손뼈가 피부 밖에 놓이는 것을 재현했습니다. [공개 화면 캡처](female-borrowed-arm-containment.png). 기존 전신 직육면체 경계 검사와 박리 중 좌표 불변 검사만으로는 이 문제를 발견하지 못했습니다.

## 검사 범위와 해석

`npm run audit:containment`는 남성 전신2,090개와 여성1,220개 원본 메쉬를 읽고, 피부 자체를 제외한 각 구조에서 최대512개 참조 정점을 검사합니다. 남성 원본 BP3 혈관·신경은 기본 전신에서 숨겨지므로 중복 포함하지 않습니다. 별도 BP4/여성 CT 상세는 다른 좌표계이므로 전신에 섞지 않습니다. [표본 보고서](body-containment.json).

`npm run audit:containment -- --all-female-vertices`는 여성 피부1개를 기준으로 나머지1,219개 모형의 **삼각형 인덱스가 참조하는 정점1,391,061개 전체**를 검사합니다. 기본 숨김인 임신8개·중복 기증자 넙다리곧은근2개도 별도 표시하여 기록합니다. [전체 정점 보고서](body-containment-female-all.json).

- 실제 피부 삼각형까지의 최단거리와 서로 다른3개 비스듬한 광선의 교차 홀짝을 사용합니다. 피부에서2mm 이내는 별도 표면 경계대이며 이탈/내부로 강제 분류하지 않습니다.
- 정점 비율은 부피·조직 면적 비율이 아닙니다. 모든 정점 검사도 삼각형 내부 전체나 해부학적으로 올바른 위치·회전·신경 주행을 증명하지 않습니다.
- 버퍼 인덱스에 쓰이지 않는 정점을 제외하고, BVH 생성은 복제 geometry에서 수행합니다. 원본 파일·정점·런타임 배치는 바꾸지 않습니다. 입력 파일과 렌더러의 SHA-256을 보고서에 기록합니다.
- 피부가 열려 있거나 여러 겹인 경우 홀짝 결과를 신체 안/밖으로 해석할 수 없습니다. 연결 성분·경계선·비다양체 모서리를 함께 기록하며 부적합 피부는 명시적으로 판정 불가로 표시합니다.

## 남성 판정 유보

`FMA7163` 피부에는 연결 성분86개·비다양체 모서리834개가 있습니다. 표본 검사에서 나온 홀짝 `outside` 수치는 **피부로 둘러싸인 신체 밖이라는 판정으로 사용하지 않습니다.** 내부 피부 경계를 두 번 통과하는 경우 신체 내부에서도 짝수가 됩니다. 중첩된 두 상자로 이 실패 조건을 재현하는 단위 검사를 추가했습니다. 남성에 여성용 홀짝 검사를 그대로 적용해 위치를 임의로 고치면 안 됩니다.

남성 피부의 실제 바깥 경계와 내부 경계를 구분하는 검사 및 해부 기준점 대조가 남아 있습니다. 기존 신경4개 중심 맞춤과 혈관 잔차만으로 전신 정합을 완료했다고 판단하지 않습니다.

## 원인과 다음 수정의 기준

고정 [상류 보완 코드](https://github.com/slorksmo/Human-Atlas/blob/5bb5713aab18d7fe9380c3339eb09f173491ea06/scripts/borrow-anatomy.mjs)는 보완 팔을 흉곽 기준 뼈의 경계 상자에 맞춘 뒤, 피부 표면의 주성분 방향과 도달 길이로 회전·축척을 정합니다. 이 과정에 팔꿈치·손목·각 손가락 관절의 실제 여성 위치를 검증하는 조건은 없습니다. 상류 파일의 보정값을 유지해도 현재 여성 자세와 맞지 않는다는 것을 이번 검사와 화면에서 확인했습니다. 이 설명은 원본 알고리즘의 한계 분석이며 특정 새 변환의 타당성을 증명하는 것은 아닙니다.

다음 교정은 어깨·팔꿈치·손목·손가락의 대응 기준과 관절 연결을 함께 확인해야 합니다. 피부 안으로 들어오기만 하도록 모형을 축소·이동하는 것은 올바른 정렬의 근거가 아닙니다. 보완 근육은 같은 기증자의 기준 뼈·부착 위치와 여성 참조 피부를 함께 대조해야 합니다. 현재 원본·가시 집합은 보존했고, 앱에 알려진 정렬 미완료를 표시했습니다. 경고 문구를 위치 수정으로 간주하지 않습니다.

이 감사 당시 근육 박리 순서는 좌표 중심의 반경 추정에 기반했습니다. 기존 `dissection.test.mjs`의 순서 검사는 입력된 rank의 단조 감소만 확인하며 실제 층서의 근거가 아니었습니다. 후속 [근육 순서 보정](MUSCLE_PEEL_ORDER.md)에서38개 모형의30개 선후 관계를 출처와 연결하고 기존6개 역전을 수정했습니다. 나머지 근육 관계·표면 깊이 검사는 별도로 필요합니다. 이 점과 원본 정렬 문제가 남아 전체 목표를 완료로 선언하지 않습니다.
