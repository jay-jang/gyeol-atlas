# 성기 가리기 기본값 — 2026-10-28

사용자 요청: “남자의 성기부분이 다소 부담스럽게 표시되어 있는거 같아. 각 구분 별로 모두 제거할 수 있는 버전을 기본으로 하고 특정한 메뉴나 버튼 클릭시에 보이도록 수정해줘.”

요약
- **기본값**: ‘성기 가리기’가 처음부터 켜져 있습니다. 예전 기본값(꺼짐)으로 저장된 탭도 한 번은 켜진 상태로 엽니다. 그 뒤에 고른 값은 성별 전환·박리·부위·초기화·새로고침에도 유지합니다.
- **모든 계통에서 제거**: 외부 생식기 메시와, 그리로 나가는 혈관·신경 4쌍(8개)을 그리지 않습니다. 기본 7계통, 보완 혈관·신경, 남성 림프 참조 모델, 여성 모델이 같은 규칙(`src/modesty.ts`)을 씁니다.
- **남성 피부**: 짙은 덮개를 버렸습니다. 음경·음낭 부분의 피부 삼각형을 빼고, 그 자리를 매끄러운 면으로 닫습니다. 피부와 함께 옅어지고 잘리므로 박리·투명도·앞쪽 숨기기에서도 윤곽이 드러나지 않습니다.
- **여성 피부**: 원본(HRAF0003)이 이미 매끈해 바꾸지 않았고, 덮개만 없앴습니다. 질(HRAF0406)은 ID로 숨깁니다.
- **보이게 하는 방법**: 상단 방패 버튼(‘성기 가리기’, 누르면 ‘성기 보이기’), 표시 설정의 ‘성기 가리기’ 체크 끄기. 검색·구조 링크로 직접 고른 구조와, 그 구조를 담은 생식기관 상세는 켜져 있어도 보입니다.

과정([검토 원문](review-modesty/)): 감사 워크플로(공간·코드 감사, 각각 독립 반박 확인) → 구현 → 닫는 면 3가지 방식 독립 제작과 심사 → 우승 방식에 심사의 접목 제안을 넣어 다듬기(실제 앱 화면·기하·재현성 독립 검증 3관점, 3라운드) → 마지막 검증에서 차단 문제 0 → Codex·AGY 교차 검토 → 검사·화면 확인.

## 2. 동작

### 보기 상태(Q32)
- `src/view-state.ts`의 `modesty: true`, `modestyVersion: 2`. 버전 표시가 없거나 2가 아닌 저장 상태는 `modesty: true`로 엽니다. 초기화는 이 선호를 바꾸지 않습니다.
- 상단 방패 버튼은 `aria-pressed`로 상태를 알리고, 도움말 말풍선은 다음 동작(‘성기 보이기’/‘성기 가리기’)을 보입니다. 표시 설정의 체크박스는 같은 선호입니다. 도움말 표에 ‘성기 보이기’ 행을 더했습니다.
- 캔버스에 `data-modesty`(`hidden`/`shown`)와 `data-modesty-skin`(닫힌 남성 피부가 그려지는지)을 둡니다.

### 보이는 예외
- 검색·구조 링크(`#atlas/structure/<성별>/<ID>`)로 고른 구조는 그 구조만 보입니다. 링크도 명시적 선택으로 봅니다.
- 기관 상세가 담은 구조(`detailIds`)는 모두 보입니다. 상세 안에서 모델의 한 부위를 눌러도 나머지가 사라지지 않습니다.
- 이때도 남성 피부는 닫힌 채입니다. 고른 구조는 닫힌 피부 밖에 그대로 보입니다.

### 닫힌 남성 피부
- `src/modesty-skin.ts`가 피부 메시를 불러올 때 한 번 준비합니다. 원본 인덱스에서 `hiddenTriangles` 511개를 뺀 기하를 만들고, 닫는 면(1,023정점·2,006삼각형)을 피부의 자식 메시 `modesty-patch`로 붙입니다. 정점 버퍼는 원본과 공유합니다.
- 닫는 면은 피부의 재질을 같이 씁니다. 그래서 색·투명도·박리 절단면·앞쪽 숨기기가 피부와 똑같이 적용되고, 누르면 피부(FMA7163)를 고릅니다.
- 닫는 면의 경계 38개 정점은 원본 피부 정점과 float32 비트까지 같은 위치·법선입니다. 틈이나 겹치는 띠(flange)가 없습니다.
- 데이터는 `data/modesty-male-skin.json`(84,050바이트)이고 `public/models/skin.glb`의 sha256에 묶여 있습니다. 단위 검사가 sha256을, 화면은 불러올 때 삼각형 수를 대조해 다르면 오류를 냅니다.
- 여성 정합의 입력(`scripts/dump-drawn-geometry.mjs`)은 닫힌 피부가 아니라 원본 피부를 씁니다.

### 경혈 표식
- 닫는 면에 걸친 남성 표식 18개는 숨김 모드에서 데이터의 `anchors` 위치를 씁니다(`modestAnchors`). 꺼짐 모드는 `data/anchors.json` 그대로입니다.
- 14개(ST30·SP12·KI11·KI12·LR12 좌우, CV2, CV3, EX-CA1 좌우)는 다시 그린 피부를 따라 표면점이 0.3mm 이하, 표식이 1.1mm 이하로 움직였습니다.
- LR10·LR11 좌우 4개는 원본에서도 음낭과 넓적다리 사이의 막힌 틈에 있었습니다(`tests/data.test.mjs`). 닫는 면이 그 틈을 막으므로, 같은 높이·같은 쪽에서 앞으로 40–44.5mm 옮겨 닫는 면 앞쪽에 둡니다. 만든 면 위의 편집 배치이고 해부학적 위치가 아닙니다.

## 3. 닫는 면 만들기

### 세 방식과 심사
같은 입력·같은 출력 형식으로 세 방식을 따로 만들고, 네 번째 에이전트가 자기 렌더러·광선 검사로 심사했습니다.

| 방식 | 내용 | 결과 |
| --- | --- | --- |
| 수술(surgery) | 구멍 경계를 한 고리로 만들고 bi-Laplacian으로 매끈하게 채움 | 107점. 정면에 가시 모양 줄무늬, 경계 각진 곳 |
| 암시(implicit) | 1mm 복셀·볼 열기로 돌출부를 깎고 다시 메시화 | 91점, 탈락. 정면에 세로 능선과 구슬이 생겨 여성 외음부처럼 읽힘(‘없는 해부를 만들지 않는다’ 위반). 685KB |
| 맞춤(fitted) | 앞아래 45° 방향의 박판 스플라인 면을 맞추고 경계를 원본 정점에 맞춤 | 109점, 우승. 정면이 마네킹처럼 매끈. 옛 음경 뿌리의 어두운 초승달, 회음 아래 4.3mm 처짐, 숨은 띠 |

### 다듬기
맞춤 방식에 심사의 접목 제안을 넣었습니다.
1. 경계 정점을 원본의 float32 좌표 그대로 쓰고 숨은 띠를 지웠습니다(바늘구멍 0).
2. 수술 방식의 bi-Laplacian 고르기(경계와 5mm 접선 띠 고정)를 쓰고, 음경 뿌리 위 치골 위 주름 띠까지 숨겨 치골까지 매끄럽게 이었습니다(초승달 제거).
3. 정중선 바닥을 회음 높이(z −1cm에서 y 0.729m)에서 앞으로 올라가게 두었습니다. 폭 2cm. 넓히면 두덩정강근이 드러났습니다.
4. 흔들리던 구멍 나누기를 장기에 닿는 광선을 씨앗으로 한 최소 절단으로 바꾸고, 안정되지 않으면 멈추게 했습니다.

실제 앱 화면(조명·톤 매핑이 심사 렌더러와 다름)에서 매번 확인했습니다. 독립 검증 1라운드는 회음 처짐과 아래에서 보이는 구덩이를, 2라운드는 틈 위쪽 모서리의 작은 보조개와 주름 줄무늬를 차단 문제로 냈습니다. 마지막 수정은 저장 법선을 20mm에 걸쳐 고르고(경계 법선은 원본 그대로), 법선과 84° 넘게 어긋난 구겨진 곳을 면 안에서 풀었습니다. 3라운드 검증(실제 화면 68장, 기하 재계산, 깨끗한 캐시에서 두 번 재생성)은 차단 문제 0이었습니다.

### 생성기
```
node scripts/modesty/export.mjs                                   # 입력을 .cache/modesty/in에, 약 1.5초
.cache/female-ct-venv/bin/python -I scripts/modesty/gen.py        # data/modesty-male-skin.json, 약 30초
.cache/female-ct-venv/bin/python -I scripts/modesty/check.py      # 검사 보고, 실패 목록이 비어야 함, 약 90초
```
- 피부·장기·주변 GLB, `manifest.json`, `src/modesty.ts`, `export.mjs` 자신, `data/anchors.json`의 sha256을 확인하고, 다르면 멈춥니다.
- numpy 1.26.4·scipy 1.13.1·networkx 3.2.1에서만 돌고(최소 절단 동률 처리와 희소 풀이가 출력 바이트를 정함), `scripts/requirements-female-ct.txt`에 고정했습니다. 레이캐스터 `rt.c`는 `cc`로 `.cache/modesty`에 컴파일합니다.
- 깨끗한 캐시에서 두 번 실행해 바이트가 같았고, 저장소 파일과도 같습니다(sha256 `0704627…089c`).
- 주변 메시는 화면과 같은 자리에서 검사합니다. 처음 내보내기는 보완 모델·림프 참조 모델에 화면이 적용하는 남성 정합(배율 0.968, 사타구니에서 약 24mm 아래로)을 빠뜨렸고, 화면에 그리지 않는 목록 밖 노드도 넣었습니다(Codex 지적). 정합·목록을 적용하고 남성 림프 참조 모델(얕은 샅고랑 림프절 등 15개)을 더해 다시 만든 결과는 바이트까지 같았고, 닫힌 피부 밖으로 나오는 점은 0개였습니다.

## 5. 한계
- 닫는 면은 편집 표시 면이지 해부가 아닙니다. 아무 구조도 재건하지 않습니다.
