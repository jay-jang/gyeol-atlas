## 비교 후 결정한 설계 기준

모델을 항상 주 화면에 두고, 도구는 화면을 밀어내지 않습니다. 선택과 그 대상의 조작을 가까이 둡니다. 전체 계통·복수 장기 묶음·개별 구조의 범위를 구분합니다. 호버 기능에는 터치·키보드 경로를 함께 제공합니다. 경혈의 전통 장부 대응은 실제 구조의 선택과 구분해 표시합니다.

상용 화면과의 시각 비교가 실제 사용성 향상을 입증하는 사용자 실험은 아닙니다. 개선의 직접 근거는 이전 리뷰의 재현 시나리오와 이번 모바일/데스크톱 회귀 검사입니다.

## 2026-09-16 경혈 범위 확장 후 결정

409개 경혈을 동시에 이름표로 채우지 않고 기존 모델 중심 탐색에 부위 선택과 ‘필터 결과를 모델에서 보기’를 추가했습니다. 다중 위치는 표식은 모두 보이되 레이블 반복을 줄였습니다. 전통적 용도와 경맥/오수혈의 서로 다른 오행은 별도 상세 탭에서 읽습니다. 모바일에서도 장면과 패널이 함께 유지됩니다.

이는 기존 agy·Codex 상호 비판의 모델/정보 동시 피드백 원칙을 적용한 설계 판단입니다. 이번에 상용 서비스의 유료 기능을 새로 실측하거나 실제 사용자 성공률을 측정하지 않았습니다. 데스크톱·모바일 과업 검사와 화면 기록은 [확장 검증](../acupoint-expansion/VERIFICATION.md)에 남깁니다.

## 2026-09-17 Explore형 정보 구조 개편

사용자가 지정한 [BioDigital Human Explore](https://human.biodigital.com/explore)의 공개 진입 화면과 위 Anatomy Tree 자료에서, 3D 모델과 함께 계통 카탈로그를 처음부터 노출하고 검색과 주요 구조 진입점을 가까이 두는 정보 구조를 다시 확인했습니다. 제품의 색상·상표·그래픽을 복제하지 않고 다음 패턴만 적용했습니다.

- 데스크톱 왼쪽에 6개 인체 계통과 실제 수록 메쉬 수를 항상 표시하고, 체표→근육→골격→장기→혈관→신경 순서의 깊이 슬라이더·휠 탐색을 제공합니다.
- 검색을 최상단에 두고, 뇌·심장·폐·간·위·콩팥을 한 번에 선택·확대할 수 있는 주요 기관 진입점을 제공합니다.
- `전체 켜기`와 `전체 인체 구조 보기`로 6개 계통 1,179개 검색 메쉬를 한 번에 요청할 수 있습니다. 큰 모델은 기존처럼 계통별 지연 로딩됩니다.
- 모바일에서는 모델을 밀어내지 않도록 계통 선택부만 116px 높이로 축약해 장면 위에 겹치고, 검색·기관 상세는 기존 도구 패널에서 제공합니다.

이 비교는 공개 화면의 정보 구조 참고이며 BioDigital의 계정 기능, 성능 또는 전체 데이터 범위를 직접 검증했다는 뜻이 아닙니다.

후속 해부 범위 보완에서는 골격에 손·발가락 마디뼈 56개를 포함하고, 혈관640·신경525개 구성요소의 좌우 전신 참조 오버레이를 더했습니다. 개별 검색 모델(혈관56·신경340)과 전신 시각 범위 모델을 UI에서 구분합니다.

## 2026-09-20 기관 상세의 관찰 영역

이번 변경은 상용 제품을 새로 비교한 결과가 아니라 GYEOL의 실제 가림 측정에 따른 수정입니다. 1440×900 남성 심장 상세에서 선택 경계가 카드 상단보다 약150px 아래에 위치했습니다. 카드 크기와 펼친 세부 목록을 측정해 모델이 빈 관찰 영역에 들어오게 하고, 정면·후면·측면·초기화는 상세 기관 중심을 유지합니다.

높이550px 이하의 가로 상세 화면은 하단 카드 때문에 모델이 지나치게 작아져, 카드가 왼쪽 탐색 영역을 일시적으로 사용합니다. 전신 복귀 버튼과 확대·선택 조작은 카드 하단에 유지하고, 목록만 스크롤합니다. 전신으로 돌아가면 기존 탐색 목록을 복원합니다. 일반 데스크톱·세로 모바일은 기존 하단 카드 배치를 유지합니다. 기관의 원본 좌표를 움직여 배치를 맞추지 않습니다.

## 2026-09-20 일반 선택·장부 비교의 후속 수정

기관 상세에만 있던 카드 회피 배치를 일반 구조 선택과 전통 장부 비교에도 적용했습니다. 실제844×390 중완→위→단독 보기에서 약112px 가림을 재현한 것이 근거이며, 상용 제품을 새로 조사하거나 사용자 성공률을 측정한 결과는 아닙니다. 위1개·양쪽 콩팥2개·폐5개의 비교 범위를 그대로 유지하고, 짧은 가로 화면에서는 선택 카드가 왼쪽 탐색 영역을 사용합니다. 선택 해제 후 목록이 다시 나타납니다.

여성 전신에 없는 위를 비교하려는 경우에는 실행 버튼 바로 아래에 수록 한계와 ‘위 (여성 CT) 별도 상세 보기’를 안내합니다. 안내를 확인한 사용자가 눌러야 CT를 내려받고 별도 장면으로 이동합니다. 다른 신체에서 얻은 CT를 HRA 전신이나 경혈 좌표에 겹치지 않습니다. 안내가 처음 나타날 때만 스크롤해 후속 수동 탐색을 방해하지 않습니다.
