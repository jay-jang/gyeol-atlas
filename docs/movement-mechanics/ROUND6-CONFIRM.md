반영 내용
- 출처 인용은 주소를 바꾸지 않는 버튼(출처 목록으로 스크롤·초점) — `src/MovementPage.tsx` `Cite`, 브라우저 검사 ‘citations move …’.
- 지면반력: 키프레임마다 압력중심 시작점(`grf.from`: heel·mid·mtp·toe), 키프레임 사이에서 시작점·각도 선형 보간, 오른발 디딤기(0–62%)에만. 반복 동작은 겹쳐 그린 값도 고리를 닫음 — `src/movement-figure.ts` `overlayAt`, `src/MovementFigure.tsx`.
- 지지면: 걷기는 접촉 사건(입각 0–62%, 왼발 반 주기 뒤)으로, 좌면은 데이터의 `seated` 구간에만. 의자는 등받이 없음.
- 걷기 데이터: 엉덩관절을 Perry & Burnfield 2010 넙다리–수직선 기준으로 통일(AAPMR·Kerrigan은 관절 표 비교 행), 장딴지근 안쪽·가쪽갈래 행 분리(Fukunaga는 안쪽갈래만), 지면반력 시작점·각도 재검토. 팔 들어올리기: 도식 경로 전체를 McClure 2001 그림 3(휴식 기준)으로 통일, Ludewig는 비교 행. 서 있기: 0.95 키프레임 삭제. 일어서기: 좌면 이탈 체중심선을 도식에서 빼고 본문·한계에만. 보고: `review/data-fix.md`. 합의안 ‘구현 중 개정’ 표 갱신.
- 칸의 역할·단서(`role`·`note`)와 출처: 현재 단계 설명, 표의 ‘근거’ 펼침(현재 열은 펼침), 휴대폰·가로 카드(FMA id 포함).
- 화면: 휴대폰 첫 화면에 도식·조작·슬라이더·현재 단계 줄, 범례·수행 조건·시간축은 접기. 가로 휴대폰은 제목 줄에 동작 목록, 도식·조작 고정. 넓은 화면 도식 열 고정. 겹쳐 그린 표시 이름은 도식 아래 기호 범례(잘림 없음), 근육 번호는 도식 안으로. 근활성 막대는 걷기만 % 폭.
- 아틀라스: 링크 구조를 못 찾으면 안내. 여성 FT_ 묶음 선택 카드에 ‘남성 원본을 옮긴 보완’ 고지.
- 검사: 인대·힘줄 표시를 끈 상태에서 남성 엉덩넙다리인대·여성 발꿈치힘줄 링크를 실제로 열어 그려진 메시(`data-visible-structure-ids`)와 설정 보존 확인, VHF 제외, 도식 이름표 틀 안 검사(브라우저·촬영), 첫 화면 검사 강화.
