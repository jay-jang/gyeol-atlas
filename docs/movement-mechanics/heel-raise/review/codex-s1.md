# S1 독립 제안 — 뒤꿈치 들기

**두 발로 한 번 올라갔다 내려오는 동작을 제안합니다. 다만 현재 직접 확인한 자료만으로는 전신 키프레임을 확정할 수 없어, 데이터 확보를 구현 착수 조건으로 둡니다.** 기존 합의안·계단 합의안·최신 검증 기록·Q38–Q41·도식 코드와 구조 목록을 읽었습니다. 다른 검토자의 이번 S1 결과는 보지 않았고, 파일은 변경하지 않았습니다.

## 1. 동작 단위

- 이름: **뒤꿈치 들기**, 보조 이름·검색어에 ‘발끝 서기’, ‘발뒤꿈치 들기’를 유지합니다.
- 영문: **Bilateral heel raise**. 주소는 `#movement/heel-raise`, `phaseKind: "구간"`.
- 두 발만 다룹니다. 한 발 동작은 지지 조건과 부하가 달라 별도 후속 항목으로 남깁니다.
- 한 번 올라갔다 내려온 뒤 정지하는 `loop: false`를 권합니다. 반복 실험에서 한 회를 발췌하더라도 ‘독립적으로 시작한 첫 동작’으로 설명하지 않습니다.
- 최고점은 정지해서 살펴볼 **사건**으로 두고, 실험에 없는 유지 시간을 추가하지 않습니다.
- 목록은 기존 일곱 동작 다음 **8번**에 넣고, 서 있기와 상호 연결합니다. 모두 편집 제안입니다.

## 2. 과제 조건

**주 출처 후보는 Abe 외의 무릎 편 조건입니다. 확인된 조건과 미확인 조건을 구분해야 합니다.**

| 항목 | 확인 결과와 제안 |
|---|---|
| 대상 | 건강한 대학생 12명, 모두 21세, 남녀 각 6명 |
| 동작 | 양발 뒤꿈치 들기, 무릎 편 조건만 사용 |
| 속도 | 본문 표현은 초당 한 회. 메트로놈 사용 여부는 확인 필요 |
| 신발 | 맨발 |
| 높이 | 실제 기록된 도달 높이를 사용. 최대 높이를 요구했는지 확인 필요 |
| 최고점 유지 | 별도 유지 지시를 확인하지 못함. 유지 구간을 만들지 않음 |
| 발 너비·방향 | 확인 필요. ‘어깨너비·평행’으로 임의 고정하지 않음 |
| 손끝 지지 | 확인 필요. 무지지 또는 지지 조건을 추정하지 않음 |

위 사실은 **Abe 외 2025, 본문**에서 확인했습니다. 발 배치·손 지지·높이 지시가 확정되기 전에는 수행 조건을 완성된 것으로 취급하지 않습니다. [저자 공개 본문](https://www.researchgate.net/publication/397228052_Intersegmental_Coordination_Patterns_During_Heel_Rise_Effects_of_Knee_Position_and_Movement_Phases)

- Abe의 변위 요약표를 같은 순간의 자세로 묶지 않습니다. 각 변수의 최대 변위가 동시에 일어났는지 확인되지 않았습니다.
- 전체 궤적이 없으면 다른 연구의 각도를 채워 넣지 않습니다. 같은 연구의 정의로 계산 가능한 값만 계산식과 함께 ‘추론’으로 기록합니다.

**공개 데이터 접근 확인**

- SAME-Limb는 데이터 설명·시행 목록과 `heel_raise` 경로를 열었습니다. 그러나 실제 `A1.npz` 파일 열기는 실패했습니다. **메타데이터 열람**, 다운로드·배열 검증은 **확인 필요**입니다. 공개된 각도 출력도 양쪽 무릎·발목 중심이므로 완전한 전신·발가락 자료로 간주하지 않습니다. [데이터 설명](https://huggingface.co/datasets/Tdongxu/A_Synchronized_Lower_Limb_AMG_sEMG_and_Mocap)
- Baxter의 Mendeley 자료는 **설명 페이지 열람**만 했습니다. 단하지 뒤꿈치 들기의 순방향 시뮬레이션 코드이며, 양발 실측 자료의 대체물이 아닙니다. 파일 취득은 확인하지 못했습니다. [자료 설명](https://data.mendeley.com/datasets/933bp2k9mw/1)
- 이번 검토에서 **원파일을 열어 계산한 공개 데이터는 없습니다**. 따라서 어떤 후보도 현재 ‘공개 데이터 검증 완료’로 표시하지 않습니다.

## 4. 국면과 경계

편집 구간은 **시작 자세 → 올라가기 → 내려오기 → 발바닥 지지 복귀**로 제안합니다. 최고점은 올라가기와 내려가기 사이 사건입니다.

| 경계 | 채택할 판정 |
|---|---|
| 동작 시작 | 뒤꿈치 높이·각속도의 기저 변동에서 벗어나는 최초 시점. 필터·역치·지속 조건을 기록 |
| 발꿈치 떼기 | 접촉 센서가 우선. 표식 높이만 있으면 ‘기구학적 이탈 추정’으로 구별 |
| 최고점 | 같은 반복의 뒤꿈치 높이 최대. 발목 최대 발바닥굽힘과 같은 시점이라고 가정하지 않음 |
| 내려오기 시작 | 최고점 이후 하강 속도가 지속되는 시점 |
| 발꿈치 닿기 | 접촉 센서 또는 높이와 속도를 함께 사용한 추정. 센서가 없으면 실측 접촉이라고 쓰지 않음 |

- 역치의 숫자는 S1에서 임의로 정하지 않습니다. 원자료의 해상도·잡음에 맞춰 정하고 독립 재현합니다.
- 진행 표시는 우선 **재생 위치**로 둡니다. 실측 사건 시간이 확보되면 그때 초 또는 ‘해당 자료에서 계산한 회차 %’를 채택합니다.
- 상승·하강을 각각 정규화한 자료를 이어 붙여 전체의 절반씩으로 표시하지 않습니다.
- **예비 자세 조정은 본 동작의 필수 구간에서 제외**합니다. Nardone·Schieppati의 연구에서는 자유롭게 선 조건과 구조물을 잡은 조건이 달랐고, 앞정강근 선행 버스트도 모든 대상에서 나타나지 않았습니다. 손끝 접촉을 허용한 다른 연구에 그대로 이식할 수 없습니다. **초록**: *Exp Brain Res* 69(3), 469–480, 1988; DOI: 10.1007/BF00247301. [초록](https://pubmed.ncbi.nlm.nih.gov/3371431/)

## 5. 도식

- `footFixedPose`에 예외를 덧붙이기보다 **앞발 접촉을 명시하는 새 자세 규칙**을 추가합니다. `stairPose`의 고정점 계산은 재사용할 수 있지만 계단·반주기 보행 규칙은 가져오지 않습니다.
- MTP 부근 고정점은 **도식의 접촉 제약**입니다. 실제 압력중심 또는 항상 일정한 해부학적 회전축이라고 부르지 않습니다.
- 발가락은 바닥에 남도록 그립니다. 현재 `toe`는 도식 발분절과의 상대각이므로, 연구의 엄지–앞발 각을 그대로 대입하기 전에 영점·분절 정의를 변환해야 합니다.
- **강체 발 하나의 한계를 먼저 해결해야 합니다.** Houck 대조군의 최고점 평균은 뒤발–정강이 −22.1°, 제1발허리뼈–뒤발 −18.2°, 엄지–제1발허리뼈 +40.1°입니다. 현재 발목각과 `toe` 두 값만으로 이 다분절 움직임을 모두 재현할 수 없습니다. **본문·표 2**. [각도 정의와 표](https://www.researchgate.net/publication/26711106_Foot_Kinematics_During_a_Bilateral_Heel_Rise_Test_in_Participants_With_Stage_II_Posterior_Tibial_Tendon_Dysfunction/download)
- 권장안은 **뒤발–앞발 굽힘 자유도 추가**입니다. 단순 강체 발을 유지한다면 ‘유효 발기울기’로 명명하고, 연구의 해부학적 발목각과 별도로 표시해야 합니다.
- 몸통·골반을 무조건 수직 또는 서로 같은 각도로 두지 않습니다. 미측정 부분을 단순화하면 화면과 데이터에 ‘편집값’으로 밝힙니다.
- 두 다리는 겹쳐 그리되 양발 대칭 가정을 명시합니다. 시상면에서 겹친다는 이유로 같은 하중이라고 주장하지 않습니다.
- 체중심·압력중심·지면반력은 현재 확보 근거로는 겹쳐 그리지 않습니다. 골반 위치를 체중심으로 대체하지 않습니다.
- 모멘트팔은 별도 확대 도식에 **축척 없는 원리 그림**으로 제안합니다.

- **활동 근거:** Fujisawa 외는 양발 과제에서 가자미근과 장딴지근 두 갈래의 근전도를 기록했습니다. 최고 활동값을 연속 국면 전체의 활동이나 진폭으로 확장하지 않습니다. **본문**: *J Phys Ther Sci* 27(5), 1523–1526, 2015; DOI: 10.1589/jpts.27.1523. [본문 PDF](https://www.jstage.jst.go.jp/article/jpts/27/5/27_jpts-2014-808/_pdf)
- **초음파 근거:** Kudo·Hisada·Sato는 가쪽갈래의 상승기 단축·하강기 신장을 설명하지만, 발판 아래로 더 내려가는 구간에서는 길이 변화가 작았습니다. 이를 가자미근·안쪽갈래 또는 모든 속도에 일반화하지 않습니다. **본문**: *J Phys Ther Sci* 27(12), 3763–3766, 2015; DOI: 10.1589/jpts.27.3763. [본문 PDF](https://www.jstage.jst.go.jp/article/jpts/27/12/27_jpts-2015-624/_pdf)
- **역학 판정:** 내부 발바닥굽힘 모멘트와 각속도에서 계산한 순관절 일률이 상승 때 양수·하강 때 음수인지 확인하면 ‘순생성·순흡수’라고 말할 수 있습니다. 이것만으로 각 근육의 근섬유 수축 방식을 확정하지 않습니다. 두관절근·동시수축·힘줄 변형을 고려해야 합니다.
- Ugbolue 외 2021의 **본문**은 자세를 유지한 측정창의 최대 근전도를 포함합니다. 이를 연속 상승·하강의 `emg` 국면 평균으로 옮기지 않습니다. 논문의 ‘concentric/eccentric’ 명칭도 수축 방식의 독립 검증으로 취급하지 않습니다. *Healthcare* 9(4), 465; DOI: 10.3390/healthcare9040465. [본문 PDF](https://research-portal.uws.ac.uk/files/55251506/2021_04_11_Ugbolue_et_al_Electromyographic_final.pdf)
- 근섬유와 힘줄은 같은 길이 변화를 보장하지 않습니다. Matijevich·Branscombe·Zelik는 뒤꿈치 들기에서 초음파 기반 힘줄 길이 추정이 단순 탄성 모형의 예상과 어긋남을 보고했습니다. **초록만 확인**, 본문은 확인 필요: *J Biomech* 72, 200–206, 2018; DOI: 10.1016/j.jbiomech.2018.03.013. [열람한 초록](https://www.researchgate.net/publication/323845044_Ultrasound_estimates_of_Achilles_tendon_exhibit_unexpected_shortening_during_ankle_plantarflexion)
- 무릎·엉덩관절·몸통 근육은 자세가 거의 일정해 보여도 ‘등척성’으로 채우지 않습니다. 직접 근거가 없는 칸은 `nodata`입니다.

수동 구조는 발꿈치힘줄 `FMA258847`·`FMA264844`, 발바닥널힘줄 `ZA_tendon_plantar_aponeurosis_r`·`ZA_tendon_plantar_aponeurosis_l`을 사용합니다. 발목·발 인대는 국면별 장력 근거가 없으므로 특정 인대가 동작을 만들거나 제동한다고 배정하지 않습니다.

## 7. 골격 메커니즘과 오해

- 중심 설명은 **발목 중심에 대한 모멘트 균형**입니다. 준정적 단순화에서는 `힘줄 힘 × 힘줄 모멘트팔 ≈ 지면반력 × 지면반력 모멘트팔`이며, 동적 구간에는 분절 관성·중량 등의 항이 필요합니다. 이는 **역학 추론**입니다.
- 앞발 지점을 기준으로 발을 그리면 2종 지레 설명이 가능하고, 발목 기준 자유물체도에서는 앞뒤 힘의 모멘트를 비교하게 됩니다. 기준축과 분석 대상을 먼저 밝힙니다. 특히 발목 관절반력을 그대로 체중이라고 놓으면 안 됩니다.
- **힘줄 힘 사례:** Revak 외의 건강한 남성 21명에서 양발 과제의 한쪽 발꿈치힘줄 최대 힘 추정치는 **1,250.51±470.41 N**입니다. 집단 평균 체중 75.81 kg으로 나눈 값은 약 **1.68배 체중**이지만, 이는 평균값끼리 나눈 편집 계산이며 개인별 정규화값의 평균이 아닙니다. 실측 힘줄 센서값이 아니라 근골격 모델 추정입니다. **본문**: Revak·Diers·Kernozek·Gheidi·Olbrantz, *J Athl Train* 52(2), 89–96, 2017; DOI: 10.4085/1062-6050-52.1.04. [본문](https://www.researchgate.net/publication/313239753_Achilles_Tendon_Loading_During_Heel-Raising_and_-Lowering_Exercises)
- 감김틀 기전은 엄지 폄과 널힘줄 장력·아치 움직임의 연결로 설명하되, 동적 아치 상승의 전부로 설명하지 않습니다. Williams 외는 양발 뒤꿈치 들기에서 다른 능동·탄성 기전의 기여를 논의합니다. **본문**: Williams·Ridge·Johnson·Arch·Bruening, *J Foot Ankle Res* 15, 16, 2022; DOI: 10.1186/s13047-022-00520-z. [본문](https://link.springer.com/article/10.1186/s13047-022-00520-z)
- 압력중심은 지면반력의 작용 위치이고 체중심과 다른 양입니다. 뒤꿈치 이탈·압력중심 이동·체중심 이동을 같은 사건으로 묶지 않습니다.
- 피할 표현: ‘발목은 언제나 2종 지레’, ‘두 발이므로 각 힘줄은 체중의 절반’, ‘최고점에서 힘줄 힘 최대’, ‘발가락이 펴지면 발이 완전히 잠김’, ‘내려갈 때 모든 종아리 근섬유가 늘어남’, ‘○회 못 하면 약함’, 운동 효과·치료·예방 주장.

## 8. 페이지·검사 통합

- **서 있기 연결:** 넓은 발바닥 지지에서 앞발 지지로 바뀌는 점을 비교합니다. 기존 서 있기 각도·체중심 값을 새 동작으로 복사하지 않습니다.
- **걷기 연결:** 말기 디딤기의 뒤꿈치 들림과 형태를 비교하되, 양발 지지·전진·반대다리 움직임이 다름을 설명합니다. 서로 다른 연구의 근전도나 힘줄 힘을 직접 비교하는 숫자 표는 만들지 않습니다.
- 근활성 막대는 국면 폭만 사용하고 진폭을 나타내지 않습니다. `nodata`는 빗금과 글자로 구분합니다. 적합한 연속 근전도가 없으면 막대도 생략합니다.
- 휴대폰 세로 도식은 화면 높이 **42% 이하를 시작값**으로 삼고, 뒤꿈치 상승이 보이는지 확대 삽화를 함께 검토합니다. 이는 편집 제안입니다.
- 단위 검사: 새 자세 분기, 앞발 고정·발가락 접촉, 바닥 관통 없음, 전 구간 보간, 최고점·재접촉 연속성, 끝에서 정지, 각도 변환, 원값·편집값 보존, id·출처·금지 표현을 확인합니다.
- 브라우저 검사: 국면 딥링크·새로고침·복귀, GLB·Atlas 요청 0, 터치 조작, 캔버스에 초점이 있을 때만 키보드 이동, 키 해제·초점 상실, 움직임 감소, 여성 대응과 `open-structures` 경로를 검사합니다.
- 기존 여섯 화면 크기에서 시작·중간 상승·최고점·중간 하강·복귀·표를 촬영하고 육안으로 확인합니다. 발 접촉·번호 겹침·첫 화면 조작부·12px 글자·대비를 검사합니다.
- 구현 시 요구–근거 표와 비교 설명·실패 기록을 갱신합니다. 이번 S1에서는 검사나 촬영을 실행하지 않았습니다.

## 9. 주장하지 않을 것과 출시 조건

다음이 해결되지 않으면 출시하지 않습니다.

1. **단일 연구의 동시 자료:** 필수 관절·분절각, 높이와 사건을 확보하거나, 같은 출처에서 계산 가능한 편집값의 정의를 합의할 것.
2. **고정 과제 조건:** 발 배치·손 지지·속도·높이·유지 지시를 확인할 것. ‘기재 없음’을 표준 조건으로 바꾸지 않을 것.
3. **발 도식의 기준계:** 다분절 발을 재현하거나, 강체 근사의 유효각과 해부학적 각을 명확히 구별할 것.
4. **국면 근거:** 접촉 추정과 실측 사건, 편집 시간과 연구 시간을 구별하고 내려오기를 상승의 역재생으로 만들지 않을 것.
5. **수축 판정:** 근전도·순관절 일률·근섬유 길이·힘줄 길이를 서로 대신하지 않을 것. 부족한 칸은 자료 없음으로 남길 것.
6. **품질 검증:** 데이터 재현·단위·브라우저·접근성·화면 검토를 통과하고, 실패와 남은 한계를 기록할 것.

**S1 판단은 범위 설계에 찬성, 키프레임 데이터 확정은 보류입니다.** Abe 원자료 또는 동등한 단일 출처를 확보하기 전에는 빈 값을 다른 연구로 채워 구현하지 않는 것이 적절합니다.
