# 동작별 근육·골격 메커니즘 페이지 — 독립 제안 공통 브리프 (2026-10-18)

## 사용자 요청 (원문)

> 각 근육과 골격의 움직임에 대해 여러가지 동작 하는 과정을 나타내보고 싶어. 일어나는 동작, 앉는 동작 서있는 자세, 걸어가는 자세등 각 동작에 따라 근육과 골격의 매카니즘에 대해 별도의 페이지로 만들어줘. 각 동작 리스트는 codex와 agy와 상의해서 만들어줘.

진행 방식: Claude Code, Codex, AGY가 **서로의 결과를 보지 않고** 각자 제안을 만든 뒤(1차), 서로의 안을 비판·대조해 합의안을 만들고(2차), 합의안을 구현한 다음 구현을 함께 검토합니다. 지금은 **1차 독립 제안**입니다. 핵심 합의 대상은 **동작 목록**이며, 각 동작의 내용(단계·관절·근육·역학)과 표현 방식도 함께 제안하세요.

## 지켜야 할 조건

- AGENTS.md: 없는 해부를 만들지 않습니다. 한국어 구조 이름은 영어 원문명·FMA ID와 함께 유지합니다. 전통적 대응을 해부학적 경로·임상 효과로 표현하지 않습니다(이 페이지에서는 **운동·재활 처방, 치료 효과, 진단 주장**을 하지 않는 것이 같은 원칙입니다). 한계와 근사를 정직하게 기록합니다.
- 관절 각도·근활성 시점 같은 수치는 **출처가 있는 대표값(건강한 성인, 근사)**만 씁니다. 출처(교과서·논문·표준)를 제안에 적어 주세요. 확신이 없으면 “확인 필요”로 표시하세요.
- 의미 있는 글자 ≥ 12px, 대비 4.5:1 이상, 공유 토큰(`src/design-system.css`) 사용, 데스크톱·모바일(390×844, 360×740, 844×390 가로 포함)·키보드·스크린리더 지원, 모든 조작은 클릭·터치로 가능, 움직임 감소(`prefers-reduced-motion`) 존중.
- 위키처럼 이 페이지도 WebGL/GLB 없이 열리는 것이 바람직한지 판단하세요(아틀라스 3D로 넘어가는 연결은 가능).
- ‘AI스러운 UI’ 배제: 장식용 그라데이션·글로우·블러 카드, 의미 없는 영문 대문자 문구, 슬로건형 히어로, 장식용 통계, 반짝이 아이콘·이모지, 모든 것을 둥근 카드로 만드는 습관을 피하고, 교과서·도구형의 절제된 화면을 지향합니다.

## 제안할 것 (한국어, 250줄 이내)

1. **동작 목록**: 1차 출시에 넣을 동작과 후속 후보를 나누어 제안하세요. 사용자가 든 일어서기·앉기·서 있기·걷기 외에 무엇을 넣고 무엇을 뺄지, 선정 기준(일상 빈도, 학습 가치, 근거 수준, 표현 가능성, 이 모델에 있는 구조로 설명 가능한지)과 우선순위를 근거와 함께 쓰세요. 동작마다 짧은 한국어 이름과 영문 학술명을 붙이세요.
2. **동작별 내용 골격**: 각 1차 동작에 대해
   - 단계 구분(예: 보행 주기의 국면 이름과 % 범위, 일어서기 단계 구분)과 그 출처
   - 주로 움직이는 관절과 대표 각도 범위(시상면 위주, 근사)
   - 단계별 주요 근육과 수축 방식(단축성·신장성·등척성), 이 저장소의 해당 구조 id
   - 골격 메커니즘: 지레·모멘트·지지면·무게중심·지면반력, 수동 구조(인대·근막·힘줄)의 역할
   - 흔한 오해와 피해야 할 표현
3. **표현 방식**: 위 모델 한계를 고려해 동작을 어떻게 보여줄지(예: 2D 시상면 도식 애니메이션, 3D 뼈 강체 애니메이션, 단계별 정지 장면, 아틀라스 연결 등) 장단점과 추천안. 재생·일시정지·단계 이동·속도·되감기 등 조작과 모바일/데스크톱 배치.
4. **페이지 구조**: 경로 이름, 목록 → 동작 화면 구성, 근육 표(단계 × 근육), 출처·한계 표시 위치, 아틀라스 3D로 넘어가는 방식.
5. **한계와 검증 방법**: 무엇을 주장하지 않을지, 어떤 검사(수치 출처 대조, 화면 확인, 접근성)를 해야 하는지.
