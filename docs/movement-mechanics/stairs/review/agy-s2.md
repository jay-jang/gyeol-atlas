# 계단 오르기·내리기 합의안 초안 v1 검토 의견서 (S2)

### 쟁점 1. 주 출처를 Darmstadt 데이터셋(DD) 하나로 전환 (§2)
- **결론: 동의**
- **근거**: Grimmer et al. (2020 PLoS ONE, 2023 PLoS ONE)의 공개 데이터셋(TUdatalib)은 동일한 건강한 성인 12명(25.4±4.5세, 180±5 cm), 동일한 17/29 cm 계단(30.4°), 동일한 프로토콜에서 오르기(A5)와 내리기(D6)의 100점 정규화 관절각·모멘트·일률·체중심 속도·6종 근전도 포락선을 모두 제공함 [본문·공개 데이터]. Reznick/Lencioni의 HTTP 403 접근 차단 및 Camargo의 미가공 데이터 처리 한계를 완전히 해소하는 최적의 단일 출처임.

### 쟁점 2. 반대 다리를 실제 왼다리 주기(A4/A6, D5/D7)로 구성 (§3)
- **결론: 반대 (대안: 반 주기 대칭 `t + 0.5` 채택)**
- **근거**: 
  1. `boxfit.mjs` 계산 결과, D6 내리기에서 실제 왼다리를 쓰면 양발 지지 잔여 오차가 대칭 0.83 cm에서 1.91 cm로 2.3배 악화됨 [공개 데이터 직접 계산].
  2. A4/A6 및 D5/D7은 별개 주기이므로 입각기 비율(오른다리 64.1%/65.2% vs 왼다리 62.5~64.5%)과 관절 피크가 달라 49.8% 접합부에서 불연속이 발생함.
  3. 사용자가 학습할 ‘정상 대칭 보행의 대표 도식’을 제공하고 기존 평지 걷기 엔진과의 일관성을 유지하려면 반 주기 대칭(`t + 0.5`)이 역학적·시각적으로 우월함.

### 쟁점 3. 양발 지지 구간 대상 간 ±1 SD 내 WLS 각도 보정 (§0-2, §3)
- **결론: 동의**
- **근거**: 도식 분절(BodyParts3D 남성 골격 1.66 m)과 DD 피험자(평균 1.80 m) 간의 신체 크기 비례 차이로 인해 고정된 (29, ±17) cm 계단에서 기하학적 접촉 오차는 수학적으로 불가피함. 외부 연구의 수치를 임의 합성하는 대신 동일 12명의 피험자 간 표준편차(±1 SD) 내부에서 가중최소제곱으로 닫는 방식은 통계적으로 정당함 [공개 데이터 직접 계산]. 대칭 모델 기준 잔여 오차가 오르기 1.63 cm, 내리기 0.83 cm로 엄격히 억제(2 cm 한도 이내)되며, 원본 `measured`와 SD를 메타데이터에 보존하므로 Codex의 "출처 각도 왜곡 금지" 취지와 양립함.

### 쟁점 4. 유각 후반 처음·끝 불연속 선형 이음 보정 (§3)
- **결론: 동의**
- **근거**: A5 무릎의 0%와 100% 사이 4.9° 불연속을 지면 접촉 구속이 없는 유각 후반(85–100%)에서 선형 분산 제거하여 연속 루프 재생의 튐을 방지하는 실용적 해법임 [공개 데이터]. 각 관절의 이음 보정량 기록 조건부 수용.

### 쟁점 5. 4국면 구성 (M&W 기능명 + 체중심 수직속도 E1) (§4)
- **결론: 동의**
- **근거**: DD의 CoM_Vy 변곡점(오르기 42% 상승 정지, 내리기 23% 하강 감속 극대)을 국면 경계로 객관화함 [공개 데이터]. DD에 물리적 사건 마커가 없는 유각기를 무리하게 둘로 쪼개지 않고 ‘발 들어 넘기기·발 놓기’ 통합 1개 국면으로 둔 처리는 데이터에 충실한 정직한 편집임.

### 쟁점 6. 근활성 막대 DD 포락선 평지 최대 30% 규칙 (§5)
- **결론: 동의**
- **근거**: 타 문헌의 정성적 근전도 합성을 배제하고 DD의 동일 피험자 6종 근전도 포락선으로 한정함 [공개 데이터]. '평지 보행 최대치의 30% 이상' 기준은 기저 긴장과 실제 수축을 가르는 통상적 역치로 적절하며, 미수록 근육은 표의 주석으로만 처리하는 원칙에 찬성함.

### 쟁점 7. 그 밖의 항목 (순서, 시점, 겹쳐 그리기 제외 등)
- **결론: 동의 (이견 없음)**
- **근거**: 5번(오르기)·6번(내리기)·7번(팔 들기) 배치, 계단 고정 추적 시점, 미검증 GRF/COM 1차 제외, 비교 상자, 임상·처방성 금지 표현 강화, 출시 조건 전건에 전적으로 동의함.

### 합의안 초안 내 사실 오류 및 보완 사항
1. **§0-2 및 §3 내리기 오차 서술 오류**: 초안에 "실제 왼다리를 쓰면 내리기는 그대로입니다"라고 적혀 있으나, `boxfit.mjs` 검산 결과 k=1 SD 제한 시 내리기(D6) 잔여 오차는 대칭 모델(0.83 cm) 대비 실제 왼다리(1.91 cm)에서 2배 이상 커집니다 [공개 데이터 직접 계산]. 대칭 모델을 채택해야 하는 핵심 근거로 수정 필요합니다.
2. **§5 용어 보완**: Spanjaard et al. (2007) 초음파에서 내리기 접촉 시 근육-힘줄 단위(MTU)는 늘어나지만 근섬유는 단축/등척성을 유지한다는 지적을 수용하며, 근섬유와 건의 상반 작용을 주석에 명시하는 보완에 동의합니다.
