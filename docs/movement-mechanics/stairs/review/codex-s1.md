**1. 동작 단위**

두 동작으로 분리합니다. 계단 내리기는 오르기의 역재생으로 만들지 않습니다.

| 목록 순서 | 이름 | 영문명 | 주소 |
| --- | --- | --- | --- |
| 평지 걷기 다음 | 계단 오르기 | Stair ascent | `#movement/stair-ascent` |
| 그다음 | 계단 내리기 | Stair descent | `#movement/stair-descent` |

두 화면은 같은 계단 조건을 사용하고 서로 연결합니다. 기존 팔 들어올리기는 그 뒤에 둡니다.

**2. 과제 조건**

**두 동작 모두 Reznick et al. 2021의 같은 계단 조건을 우선 채택**하되, 아직 확인되지 않은 조건을 확정한 것처럼 작성하지 않습니다.

| 항목 | 제안과 확인 수준 |
| --- | --- |
| 대상 | 해당 연구의 건강한 성인 10명, 20–60세. ‘젊은 성인만의 패턴’으로 표현하지 않음 |
| 계단 | 연구의 4단 계단, 명목 경사 30° 조건. 본문이 대응시키는 단 높이는 5.75in, 약 146mm |
| 디딤판 깊이 | **확인 필요.** 명목 경사와 단 높이로 역산한 값을 실험 치수처럼 쓰지 않음 |
| 보행 방식 | 한 발씩 번갈아 딛는 기록만 채택. 원시 기록·영상에서 확인 필요 |
| 난간 | 실험 계단에 난간 없음 |
| 속도 | 스스로 고른 속도의 기록. 평지 접근 속도와 계단 내 속도를 구별 |
| 신발 | **확인 필요.** 다른 연구의 맨발 조건을 가져오지 않음 |
| 분석 위치 | 논문이 가장 주기적이라고 제시한 `s3`를 우선 검토. 첫 단 진입·마지막 단 이탈 기록 제외 |

위 실험 조건은 **본문 열람**으로 확인한 범위입니다. 미확인 항목은 원자료 설명·영상에서 확정한 뒤 데이터 작성을 시작해야 합니다. [Reznick 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8553836/)

**3. 주 출처**

가장 중요한 판단은 **‘한 데이터셋으로 구성할 가능성이 높다’와 ‘실제 키프레임 추출을 검증했다’를 구별하는 것**입니다. 이번에는 후자까지 완료하지 못했습니다.

| 후보 | 직접 확인한 열람 수준 | 판단 |
| --- | --- | --- |
| Reznick 2021 | 논문 본문, 공개 데이터 등록 페이지 | **오르기·내리기 공통 1순위.** 골반 기울임·관절각·전역 마커 좌표가 있어 기준계와 이동을 함께 다룰 수 있음 |
| Lencioni 2019 | 논문 본문 | 각도·골반·근전도·힘 자료가 풍부하지만, 두 단에서 출발·정지하는 과제. 이번 가운데 단 반복 주기의 주출처로는 제외 |
| Camargo 2021 | 논문 초록, 연구실 공개 설명, 데이터 등록 페이지 | 유력한 예비 후보. 양쪽 자세·골반·사건·계단 치수를 실제 파일에서 확인하기 전에는 채택하지 않음 |
| Riener 2002 | 저자 소속기관의 초록 | 역학·첫 접촉 설명의 보조 출처. 이번에 본문 곡선과 기준계를 검증하지 못했으므로 키프레임 주출처로 확정하지 않음 |

[Lencioni 본문](https://www.nature.com/articles/s41597-019-0323-z), [Camargo 연구실 설명](https://www.epic.gatech.edu/opensource-biomechanics-camargo-et-al/), [Camargo 데이터 등록](https://data.mendeley.com/datasets/fcgm3chfff/1), [Riener 초록](https://old.control.ee.ethz.ch/publications/2002/2276.html)

Reznick의 `Streaming.mat`에서 **한 대상자·한 조건·한 연속 기록의 같은 시각**에 해당하는 골반·양쪽 다리·접촉 사건을 추출하는 방식을 권합니다. 대상자는 사전에 정한 완전성·대표성 기준으로 선택하고, 좋은 자세가 나오는 관절끼리 골라 합치지 않습니다.

정규화 자료는 좌우 다리가 합쳐져 있으므로 이를 그대로 두 다리의 동시 기록처럼 사용하지 않습니다. 논문의 사건 설명과 표에는 접촉 사건이 있지만, 필요한 발 떼기 정보의 실제 수록 여부는 **확인 필요**입니다. 계단에서 힘판 측정을 하지 않았다는 제한도 중요합니다.

[공개 Streaming 자료](https://springernature.figshare.com/articles/dataset/Streaming_Dataset/14558181)와 [정규화 자료](https://springernature.figshare.com/articles/dataset/Normalized_Dataset/14558184)의 등록은 확인했습니다. **MAT 배열은 미열람**이며, README 다운로드도 접근 오류로 내용 검증을 마치지 못했습니다. 따라서 구체적인 관절각·사건 %는 지금 확정하지 않습니다.

**4. 국면과 경계**

첫 출시는 **접촉 사건을 기준으로 한 구간**을 사용합니다.

| 구간 | 사건 경계 | 오르기에서 설명할 내용 | 내리기에서 설명할 내용 |
| --- | --- | --- | --- |
| 체중 받아들이기 | 기준발 닿기→반대발 떼기 | 높은 단으로 체중 이동 | 낮은 단에서 하중 받기 |
| 한발 지지 | 반대발 떼기→반대발 닿기 | 몸 끌어올리기·앞으로 진행 | 지지하면서 몸을 조절해 내리기 |
| 지지 넘겨주기 | 반대발 닿기→기준발 떼기 | 다음 지지발로 이동 | 아래쪽 발로 지지 이전 |
| 다리 옮기기 | 기준발 떼기→다음 기준발 닿기 | 단 모서리 넘기·발 놓기 | 다리 끌어오기·발 놓기 |

McFadyen–Winter의 다섯 기능 이름은 설명에 연결하되, 위 네 구간과 일대일로 같은 정의라고 쓰지 않습니다. 일률 봉우리로 정한 경계를 접촉 사건으로 대체하면서 원래 명칭의 정확한 재현이라고 주장해서도 안 됩니다.

주기 시작은 **기준발 접촉**, 끝은 **같은 발의 다음 접촉**입니다. 검증된 기록의 사건 시각으로 주기 %를 계산하며, 평지 걷기의 경계를 복사하지 않습니다. 발 떼기가 확인되지 않으면 해당 국면 % 확정도 보류합니다.

Riener 연구는 오르기·내리기 모두 앞발이 먼저 닿았다고 보고합니다〔**초록**〕. 다만 이를 Reznick의 모든 기록에 자동 적용하지 않고, 채택 기록에서 확인합니다. 데이터의 `heel strike`라는 사건 이름만 보고 뒤꿈치 접촉을 그리지 않습니다. [Riener 2002](https://old.control.ee.ethz.ch/publications/2002/2276.html)

**5. 도식**

계단은 전역 좌표에 고정하고 화면이 몸을 따라가는 방식을 권합니다. 디딤발이 계단 위에서 미끄러지는지 검사하기 쉽습니다.

- 실험의 전체 계단 조건을 기록하고, 화면에는 현재 두 발과 이동 경로에 필요한 단·모서리를 표시합니다. 화면에 보이는 단 수와 실험 단 수를 구별합니다.
- 현재 걷기 엔진의 높이 혼합을 재사용하지 않습니다. **골반 자세, 몸 전체 위치, 좌우 접촉 상태, 접촉한 단 번호**를 갖는 계단 전용 자세 계산이 필요합니다.
- 골반 기준 엉덩관절각을 수직선 기준 각도로 그대로 넣지 않습니다. 같은 기록의 골반·분절 방향을 사용하고, 시상면 투영 과정과 부호를 검증합니다.
- 발 고정점은 항상 발허리발가락관절 하나로 정하지 않습니다. 관측된 앞발·발바닥 접촉에 따라 기준점을 정하고 발의 구름을 허용합니다.
- 디딤판 위 위치는 원자료 마커를 우선 사용합니다. 편집 위치라면 좌면·모서리로부터의 위치를 편집값으로 표시합니다.
- 흔드는 발의 발끝뿐 아니라 **발꿈치·발 외곽 전체와 디딤판·수직면·단 모서리**의 관통을 검사합니다. 발뼈 오프셋과 실제 도식 외곽을 구별합니다.
- 오른발을 기준으로 설명하되 반대발은 같은 연속 기록에서 가져옵니다. 반 주기 이동과 좌우 대칭은 검증 없이 가정하지 않습니다.
- 양발 지지 표시는 서로 다른 높이의 디딤판에 따로 그립니다. 현재의 평면 지지면 띠를 그대로 연결하지 않습니다.
- Reznick을 채택하면 **지면반력 화살표는 기본 제외**합니다. 체중심도 같은 기록에서 타당하게 산출·검증하기 전에는 제외합니다.
- 기존 분절 비율로 출처 자세의 접촉을 재현하지 못하면 도식 방식을 재검토합니다. 발을 맞추려고 출처 각도를 임의 수정하지 않습니다.

**6. 근육과 수축 방식**

구조 ID는 지정된 저장소 카탈로그와 한글 표시명에서 직접 확인했습니다. 아래는 **채택할 설명과 검증 대상**이며, 모든 칸의 수축 방식이 이미 확정됐다는 뜻은 아닙니다.

| 근육·오른쪽 구조 ID | 오르기 | 내리기 | 근거와 표시 |
| --- | --- | --- | --- |
| 넓은근 Vasti: `FMA38930`, `38932`, `38934` | 끌어올릴 때 무릎 폄의 단축성 기여 검토 | 조절하며 내려갈 때 무릎 굽힘을 제어하는 신장성 기여 검토 | 관절 운동·내부 모멘트·일률을 함께 확인한 뒤 **역학+추론**. 개별 갈래 측정으로 표현하지 않음 |
| 큰볼기근 Gluteus maximus: `FMA22328` | 체중 수용·지지 중 엉덩관절 폄 기여 | 국면별 수축 방식 확인 필요 | Lyons의 오르기 활동 근거는 **근전도·초록**. 단축성 판정은 별도 추론 |
| 중간볼기근 Gluteus medius: `FMA22330` | 한발 지지의 골반 제어를 설명 후보로 둠 | 동일 | 계단 국면별 시점·수축 방식 **확인 필요**. 시상면 도식에 이마면 작용을 그린 듯 표현하지 않음 |
| 안쪽장딴지근 Medial gastrocnemius: `FMA45957` | 밀기 구간의 근섬유가 거의 등척성일 수 있음 | 접촉 때 근육–힘줄 단위가 늘어도 근섬유는 짧아질 수 있음 | Spanjaard 2007 **본문·초음파+근전도**. 다른 조건의 비교 근거로 제시 |
| 가쪽장딴지근 `FMA45960`, 가자미근 `FMA22558` | 발바닥굽힘근 기여 검토 | 접촉·하강 제어 기여 검토 | 안쪽갈래 초음파 결과를 확대하지 않음. 근섬유 수축 방식 **확인 필요** |

| 넙다리곧은근 `FMA38928`, 뒤넙다리근 `FMA45888`, `FMA22358`, `FMA22448` | 두관절 작용을 고려 | 동일 | 관절 하나의 운동만으로 수축 방식 결정 금지 |
| 엉덩근 `FMA22322`, 큰허리근 `FMA22342` | 다리 옮기기의 굽힘 기여 후보 | 다리 끌어오기 기여 후보 | 계단별 활동·수축 근거 **확인 필요** |

Lyons는 건강한 11명의 바늘 근전도로 오르기 중 큰볼기근 아래부분의 체중 수용·중간 지지 활동을 보고합니다. 전체 큰볼기근의 균일한 활동이나 내리기의 정확한 %로 확대하지 않습니다. [Lyons 1983, 초록](https://pubmed.ncbi.nlm.nih.gov/6622534/)

Spanjaard의 기본 대조 연구는 **2007년 논문**입니다. 건강한 남성 10명, 170×280mm의 4단 계단, 맨발·자기 선택 속도 조건이므로 주 도식 조건과 차이를 병기합니다. 그 연구의 활동 구간을 주 도식의 %에 그대로 칠하지 않습니다. [Spanjaard 2007, 본문](https://research.vu.nl/files/43522329/spanjaard_jap_2007.pdf)

수동 구조는 발꿈치힘줄 `FMA258847`의 탄성 변형을 중심으로 설명합니다. 발바닥널힘줄 `ZA_tendon_plantar_aponeurosis_r`은 구조 연결을 제공하되 계단 추진의 정량 기여를 주장하지 않습니다. 인대가 몸을 끌어올리는 동력원이라는 설명도 제외합니다.

**7. 골격 메커니즘과 오해**

핵심 대조는 **위치에너지를 높이는 오르기와, 내려가며 얻는 에너지를 제어하는 내리기**입니다. 다만 각 동작 안에는 에너지 생성·흡수 구간이 함께 존재하므로 ‘오르기 전체=양의 일, 내리기 전체=음의 일’로 칠하지 않습니다. [Riener 2002, 초록](https://old.control.ee.ethz.ch/publications/2002/2276.html)

- 내부 폄 모멘트와 관절 운동 방향을 함께 설명하고 외부 모멘트와 부호를 구별합니다.
- 순 관절 일률은 개별 근육의 일률·근섬유 길이 변화가 아닙니다. 특히 장딴지근은 위 초음파 연구를 반례로 제시합니다.
- 지지발·단 높이·몸 전체 이동을 함께 보여 줍니다. 체중심 수직선이 지지 영역 밖이라는 사실만으로 불안정·낙상을 판정하지 않습니다.
- 단 높이·신체 크기·속도가 달라지면 요구되는 운동도 달라집니다. 다른 계단 연구의 최대 각도·관절력 배수를 이번 조건의 숫자로 제시하지 않습니다.
- ‘계단은 무릎에 나쁘다’, ‘무릎이 발끝을 넘으면 안 된다’, ‘내려갈 때 모든 근육이 늘어난다’, ‘엉덩이로 올라야 한다’, 운동 효과·통증 예방 문구는 제외합니다.
- 관절각·모멘트·일률의 대표 숫자는 주자료 추출 후 대상·조건·시점·부호와 함께 제시합니다. 현재는 **확인 필요**입니다.

**8. 페이지·검사 통합**

두 화면에 ‘같은 조건으로 내리기/오르기 보기’ 링크와 짧은 대조 문단을 둡니다. 첫 출시에는 두 애니메이션의 동시 재생보다 각 동작의 설명을 우선합니다.

- 진행 단위는 **주기 %**입니다. 서로 다른 동작의 같은 %가 같은 기능 사건이라는 의미는 아닙니다.

**9. 주장하지 않을 것과 출시 조건**

**S1 결론은 ‘Reznick 단일 데이터셋을 우선하는 조건부 채택’입니다. 아직 수치 데이터 작성·출시 승인 단계는 아닙니다.**

1. 오르기·내리기 각각 한 조건의 완전한 주기를 실제 파일에서 추출할 수 있을 것.
