## 실패와 재실행

- **360×740 첫 화면 넘침**: 국면 범위를 줄이고, 현재 국면 줄을 한 줄 말줄임으로 바꿨습니다. 모든 계단 국면을 확인하는 검사를 추가했습니다.
- **딥링크가 앞 국면을 엶**: `((t % 1) + 1) % 1`의 부동소수점 문제였습니다. `wrap()`으로 고치고 검사를 더했습니다.
- **브라우저 검사의 ‘검출 안 됨’ 0개**: 한계 칸 설명문에 걸렸습니다. 수축 분류 표시를 보도록 고쳤습니다.
- **보정 범위 검사**: 저장값 반올림 때문에 경계에서 실패했습니다. 허용치를 0.15°로 하고, 보정 구간 밖 편집 금지로 바꿨습니다.
- **SD 한도와 보간**: 1% 재표본 키프레임은 표본 시점이 어긋나 1.04 SD가 나왔습니다(Codex). 한도만 0.95로 낮추자 오르기 양발 지지 거리가 2.0 cm에 닿았습니다. 키프레임을 원 표본 시점에 두고 한도를 0.98로 했지만, 확인 라운드에서 Codex가 표본 사이 보간값이 여전히 1.04·1.08 SD라고 지적했습니다. 원 곡선의 표본 사이를 단조 3차로 정의하고, 보정 구간에 0.25% 간격 키프레임을 더하고, 한도를 0.97로 해 0.01% 간격 최종값 0.99 SD로 맞췄습니다(0.5% 간격은 0.998 SD라 여유가 없어 쓰지 않음).
- **휴대폰 근전도 표, 비교 상자, 고정 바, 관절 표**: 각각 열 밀림, 동작 이름 없음, 버튼 글자 접힘, 행 머리 줄바꿈 금지(명시도)가 문제였고 모두 고쳤습니다. 관절 표 문제는 걷기 등 기존 동작에도 있었습니다.
- **검토 실행 실패**: 데이터 검증 1회와 구현 후 검토 3건이 네트워크 장애로 실패해 다시 돌렸습니다.
