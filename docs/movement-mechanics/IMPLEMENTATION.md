# 동작 역학 페이지 — 구현 기록 (2026-10-18)

요청: “각 근육과 골격의 움직임에 대해 여러 가지 동작 하는 과정을 나타내 보고 싶어. 일어나는 동작, 앉는 동작, 서 있는 자세, 걸어가는 자세 등 각 동작에 따라 근육과 골격의 메커니즘에 대해 별도의 페이지로 만들어 줘. 각 동작 리스트는 Codex와 AGY와 상의해서 만들어 줘.”

## 도식

- 하지 분절 길이는 남성 BodyParts3D 뼈(`public/models/bone.glb`)의 범위에서 관절 중심을 근사해 정했습니다(합의 T27). 장면 좌표(m, y 위·z 앞)에서 발목 중심 0.07, 무릎 0.44, 엉덩관절 0.83, 어깨 1.335, 머리끝 1.655(피부 최고점), 발꿈치 뼈 아래 0.011, 엄지 끝 z 0.132(발목 중심 z −0.034에서 0.166 앞). 정강이 0.37·넙다리 0.39 m. 메시 경계 길이가 아니라 관절 중심 사이 근사이며, 이 비율로 체중심을 계산하지 않습니다(Codex 지적). 몸통·머리·팔 모양은 편집 도형입니다.
- 각도 규약: 발목 발등굽힘 +, 무릎·엉덩관절 굽힘 +, 몸통은 수직선 대비 앞기울기(세계 좌표). 출처가 몸통 기울기를 주면 허리가 차이를 받고, 없으면 골반과 몸통이 함께 움직입니다.
- 일어서기·앉기·서 있기는 오른발을 바닥에 고정하고 위로 쌓습니다. 걷기는 엉덩관절을 같은 x에 두는 트레드밀 시점이고, 한 발 지지에서는 디딤발을 바닥에, 두 발 지지에서는 체중 이동 비율(Perry & Burnfield 2010의 12%·50%·62% 경계)로 두 다리 높이를 섞습니다. 왼다리는 반 주기 늦게 그립니다.
- 보간은 단조 3차(Fritsch–Carlson)라 출처 값 사이에서 넘치지 않습니다. 도식 아래에 “키프레임 사이는 보간한 근사이며 측정 궤적이 아닙니다”를 고정 표시합니다.
- 수축 방식은 글자가 먼저이고 선 모양(단축 실선·신장 긴 파선·등척 점선·방식 미확인 가는 실선)과 강조색 하나(`--doc-accent`)가 보조입니다. ‘억제’·‘검출 안 됨’·‘자료 없음’은 그리지 않고 글자로만 적습니다. 도식 안 번호는 실제 화면에서 12.5px가 되도록 SVG 축척에서 계산합니다.
- 체중심은 계산하지 않고, 키프레임에 출처가 있는 앞뒤 위치만 체중심 수직선으로 그립니다. 일어서기 좌면 이탈의 측정값(발목 앞 18 mm)은 이 도식의 분절 질량·각도로 재현되지 않아(그리면 뒤로 넘어지는 자세처럼 보임) 도식에서 빼고 본문과 한계에만 둡니다.
- 지면반력 화살표는 오른발(기준 다리) 디딤기에만, 키프레임에 적힌 압력중심 위치(`from`: 발꿈치·발 가운데·발허리뼈머리·발끝)에서 그립니다. 겹쳐 그린 값은 둘 다 값이 있는 키프레임 사이에서만 선형 보간하고, 빈 구간은 그리지 않습니다.
- 지지면: 걷기는 접촉 사건(오른발 입각 0–62%, 왼발은 반 주기 뒤)으로 디딤발을 정하고, 거리로 판정하지 않습니다. 좌면은 데이터의 `seated` 구간(일어서기 시작–좌면 이탈, 앉기 좌면 접촉–끝)에만 지지면에 더하고, 의자는 등받이 없는 의자로 그립니다.
- 겹쳐 그린 표시(지지면·체중심 수직선·지면반력)의 이름은 도식 안이 아니라 도식 아래 기호 범례에 적습니다(이름표 잘림·근육선 가림 방지). 근육 번호는 겹치면 선을 따라, 그다음 선 옆으로 옮깁니다.

## 조작과 상태

- 진입 시 첫 단계에서 멈춥니다. 단계 이동은 `history.replaceState`로 주소만 바꾸고(히스토리 누적 없음), 재생 중에는 주소를 바꾸지 않습니다. 새로고침은 주소의 단계로 돌아옵니다.
- 단위: 걷기는 주기 %, 팔 들어올리기는 위팔 거상각(올리는 중/내리는 중), 일어서기·앉기는 ‘재생 위치’(국면 이름만), 서 있기는 상태 선택(슬라이더 없음).
- 키보드: 도식에 초점이 있을 때만 Space 재생, ←/→ 단계, Home/End. 단계 이동만 `aria-live`로 알립니다.
- 표의 칸은 수축 방식과 근거 꼬리표를 보이고, 역할·측정 대상 같은 단서(`role`·`note`)와 출처는 ‘근거’ 펼침에 둡니다(현재 단계 열은 펼친 채). 휴대폰·가로 휴대폰은 근육별 카드로 바꾸고 FMA id와 같은 펼침을 둡니다. 현재 단계 설명은 같은 단서를 모두 보입니다.
- 인용은 버튼입니다. 해시가 라우터이므로 주소를 바꾸지 않고 출처 목록의 항목으로 스크롤·초점을 옮깁니다.
- 휴대폰은 도식 → 조작 → 위치 슬라이더 → 현재 단계 한 줄(번호·이름·범위)을 첫 화면에 두고, 근육 번호 범례·수행 조건·재생 시간축은 접습니다. 가로 휴대폰은 제목 줄에 동작 목록을 붙이고, 왼쪽 도식·조작 열을 고정한 채 오른쪽 본문을 스크롤합니다. 넓은 화면도 도식 열을 고정합니다.
- 근활성 막대 폭은 걷기만 주기 %이고, 다른 동작은 단계마다 같은 폭이며 축은 단계 번호입니다.
- `prefers-reduced-motion`에서는 ‘단계 재생’이 2.2초마다 단계를 바꾸고, ‘연속 동작 보기’를 켜야 연속으로 움직입니다.

## 아틀라스 연결

- 행마다 “3D에서 맞춰 보기” 하나. 좌우 대칭 동작은 좌우 쌍, 걷기·팔 들어올리기는 오른쪽. 여성 보기는 `FT_<id>`(남성 원본을 옮긴 보완)나 데이터에 명시한 전체 일치 구조만 열고, 없으면 “남성 모델에서 보기”를 보입니다.
- `App`이 주소를 해석해 `open-structures`를 한 번 dispatch하고 곧바로 주소를 `#atlas/<현재 경혈>`로 바꿉니다. 새로고침은 저장된 보기만 복원합니다. 카메라는 기존 새 선택 맞춤 경로(`camera("structure")`)를 한 번 씁니다.
- 인대·힘줄 표시 설정은 바꾸지 않습니다. 선택한 연결조직 메시는 설정과 무관하게 그려집니다.
- 링크의 구조를 현재 모델에서 찾지 못하면 열지 않고, 아틀라스 오른쪽 열에 이유를 알리는 안내를 둡니다(닫기 가능, 아틀라스를 떠나면 사라짐).
- **강조 규칙(구현 중 결정)**: 아틀라스 전체의 기존 규칙은 ‘단일 선택은 선택색, 묶음(장부 비교·기관 상세·좌우 쌍)은 원래 조직색 + 주변 흐림’입니다. 묶음 전체에 선택색을 칠하면 장부 비교 화면이 바뀌므로 이 규칙을 유지했습니다. 합의안 v2의 ‘묶음 강조 수정’은 남성 Z-Anatomy 보완 모델에서 연결조직만 범주 묶음(`인대·힘줄`)이 아니어도 선택색을 받지 못하던 예외를 고친 것으로 구현했습니다(`Atlas.tsx` `SupplementModel`, `connectiveCategory`). 여성 `PackedAtlas`의 묶음은 기존 규칙(주변 흐림)대로입니다.
