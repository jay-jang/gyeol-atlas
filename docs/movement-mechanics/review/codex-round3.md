1. **§3.4 ‘근육’ — 수동 기여율의 분모·귀속 오류**
‘그 양의 일의 약 58%’는 엉덩근·큰허리근의 일을 뜻하는 것으로 읽힙니다. 원문은 **H3 구간의 순관절 양의 일에 대한 수동 기전의 모델 추정 기여**이며, 두 관절 근육의 수동 성분도 포함합니다. 개별 근육·인대의 기여로 바꾸면 사실 오류입니다.
**수정 문구:** “Whittington 2008은 H3 구간의 엉덩관절 순양의 일 중 평균 약 58%를 수동 기전의 기여로 추정했다. 이는 개별 엉덩근·큰허리근의 일이나 특정 앞쪽 인대의 기여율이 아니다.” [원문 결과·방법 확인](https://uwnmbl.engr.wisc.edu/pubs/gp08_whittington.pdf)

2. **§4 T14·§7 단위 검사 — 진행률 단위의 충돌**
모든 동작에 ‘0–100% 슬라이더·국면 피복’을 요구하면, §3.1의 비주기적 서기 상태와 §3.5의 거상각 구간에 근거 없는 시간 비율을 만들게 됩니다.
**수정 문구:** “서 있기는 상태 선택, 팔 들어올리기는 위팔–가슴 거상각으로 조작한다. 보행은 주기 %를 사용한다. 일어서기·앉기의 편집 재생 진행률은 생리적 국면 비율과 구분한다. 0–100 피복 검사는 정규화된 시간형 데이터에만 적용하고, 상태형·각도형 데이터는 각각 상태 순서·각도 구간을 검사한다.”

3. **§6 연결 규칙·T23 — 연결조직 가시성 판정 누락**
`ZA_` 접두사만으로 `connective`를 켜면 `FT_ZA_tendon_…` 및 기존 FMA 힘줄을 놓칩니다. 연결조직 숨김 상태에서 링크 대상이 보이지 않아 출시 조건을 위반할 수 있습니다. 기존 `selectionReturn`에도 `connective` 복귀값이 없습니다.
**수정 문구:** “먼저 현재 성별의 실제 구조 ID로 해석하고 가용성을 검사한다. 연결조직 여부는 접두사가 아니라 `connectiveKindOf` 등 카탈로그의 종류 정보로 판정한다. 링크가 `connective`를 자동 변경하면 진입 전 값을 복귀 상태에 저장하고 선택 해제 시 복원한다. 남녀 모두 연결조직 숨김 상태에서 해당 링크를 검사한다.” [현재 종류 판정 코드](/Users/nuinuri/workspace/anatomy/src/anatomy.ts:124)
