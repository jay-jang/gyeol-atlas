**조건부 승인** (Claude Code 3차, 독립 에이전트)

차단 항목
- B1. §6 T21 “ZA_ id면 `connective`를 함께 켜고 해제 시 되돌림”: Q27상 인대·힘줄 표시는 보존할 사용자 설정이고, 선택한 인대·힘줄은 설정이 꺼져도 이미 그려짐(Atlas.tsx:406·518, PackedAtlas.tsx:191). `ReturnView`에 없는 필드가 필요하고 ZA_ 아닌 연결조직(발꿈치힘줄 FMA258847)을 놓침. → “선택한 인대·힘줄 메시는 `connective` 설정과 무관하게 그려지므로 `connective`는 바꾸지 않음.”
- B2. §6 T21 주소 처리: App.tsx가 `route.split("/")[1]`을 경혈 id로 넘겨 ‘structure’가 경혈 id로 읽히고, 주소가 남으면 새로고침마다 `open-structures`가 재실행(Q5). → dispatch 직후 `history.replaceState`로 `#atlas/<현재 경혈 id>`.
- B3. 출처 귀속: 서 있기 앞정강근 무활동은 Joseph & Nightingale 1952(0/12). 앉기 89.9·76.2·12.5·38.7°는 Jeon 2025 표 2 REF, Jeon 2024 기준 무릎 73.4°.
