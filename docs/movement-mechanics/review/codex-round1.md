**결 GYEOL 동작 메커니즘 페이지 — 1차 독립 제안**
2026-10-18 · 읽기 전용 검토

**1차 출시는 일어서기·앉기·서 있기·평지 걷기 네 동작을 권합니다.** 주된 표현은 단계별 2D 도식으로 하고, 기존 아틀라스는 관련 구조의 정지 해부를 확인하는 데 연결합니다. 동작 이해와 해부 구조 탐색을 함께 제공하면서 현재 GLB의 변형 한계를 지킬 수 있습니다.

**1. 동작 목록과 우선순위**

선정 기준은 일상 빈도, 서로 다른 역학 개념을 배우는 가치, 단계·근육 역할의 근거 수준, 도식으로 표현할 수 있는 범위, 저장소 구조의 수록 여부입니다.

| 출시 순서 | 한국어 이름 · 영문 학술명 | 선정 이유 |
| --- | --- | --- |
| 1 | 일어서기 · Sit-to-stand transfer | 사용자의 명시적 요청. 지지면 변화, 운동량 전달, 폄근의 일을 함께 설명하기 좋음 |
| 2 | 앉기 · Stand-to-sit transfer | 같은 관절이 반대로 움직여도 근육의 역할은 달라진다는 점을 설명. 일어서기와 함께 출시 |
| 3 | 서 있기 · Quiet standing | 무게중심·압력중심·지지면을 이해하는 기초. 겉으로 움직이지 않아도 조절이 계속됨 |
| 4 | 평지 걷기 · Level walking | 반복 주기, 한발·두발 지지, 충격 흡수와 추진을 통합. 가장 많은 검증이 필요함 |

학습 화면의 권장 읽기 순서는 **서 있기 → 일어서기 → 앉기 → 걷기**입니다.

| 후속 우선순위 | 동작 후보 | 추가 가치와 보류 이유 |
| --- | --- | --- |
| 1 | 뒤꿈치 들기 · Bilateral heel raise | 발목 지레와 근육·힘줄의 차이를 단순하게 설명. 일상 동작 네 편을 완성한 뒤 추가 |
| 1 | 계단 오르기 / 내려가기 · Stair ascent / descent | 위치에너지 증가와 하강 제어 비교. 계단 높이·속도·난간 조건을 따로 정의해야 함 |
| 2 | 한발 서기 · Single-leg stance | 중간볼기근과 골반의 관상면 조절. 시상면 외 도식이 필요 |
| 2 | 몸통 숙이기 · Forward trunk bending | 엉덩관절과 척추 움직임의 분담. ‘허리를 쓰면 잘못’ 같은 오해를 피할 별도 근거 필요 |
| 2 | 팔 올리기 · Arm elevation | 상지까지 학습 범위를 확장. 어깨관절·어깨뼈·빗장뼈의 결합 운동 검증 필요 |

달리기·점프·깊은 스쿼트·무게 들기는 첫 출시에서 제외합니다. 충격, 속도, 외부 하중, 수행 방식에 따른 변이가 커서 단일 대표 도식의 설명력이 떨어집니다. 병적 보행·교정 운동·재활 프로그램은 이번 페이지의 범위에 넣지 않습니다.

**2. 동작별 내용 골격**

모든 편은 ‘조건 → 단계 → 관절 → 근육 → 외력·지지 → 수동 구조 → 오해 → 출처’ 순서를 공유합니다.
각도는 굽힘·폄 방향과 기준을 함께 적고, 몸통의 공간상 기울기와 골반에 대한 엉덩관절 굽힘을 구분합니다.
근육 표의 수축 방식은 문헌과 운동 방향에 따른 **교육적 해석**입니다. 관절 운동, 근육힘줄단위 길이, 근섬유 길이, EMG를 같은 측정값으로 취급하지 않습니다.

**가. 일어서기**

조건은 팔 지지 없이 의자에서 일어나는 사례로 한정하고, 의자 높이·발 위치·속도를 문서 머리에 표시합니다.
단계는 Schenkman 등의 네 단계, 즉 굽힘 운동량 → 운동량 전달 → 폄 → 안정화를 채택합니다. 좌면 이탈과 최대 발목 발등굽힘을 경계로 쓰며 고정된 시간 비율은 부여하지 않습니다. [Schenkman 등, 1990](https://pubmed.ncbi.nlm.nih.gov/2217543/)

| 단계 | 관절·지지 변화 | 주요 근육과 수축 해석 |
| --- | --- | --- |
| 굽힘 운동량 | 몸통이 앞으로 기울고 엉덩관절 굽힘 증가. 좌면과 발이 지지 | 앞정강근의 준비 활동, 몸통 폄근의 자세 조절. 몸통 기울기만 보고 모든 근육을 단축성으로 표시하지 않음 |
| 운동량 전달 | 좌면 이탈 → 최대 발등굽힘. 지지가 두 발로 바뀜 | 넓은근군은 무릎 폄에 단축성으로 기여. 큰볼기근은 엉덩관절의 굽힘·폄 전환에 따라 역할이 달라짐 |
| 폄 | 엉덩관절·무릎이 펴지고 몸이 상승 | 큰볼기근·넓은근군의 단축성 작용을 중심으로 설명. 가자미근·장딴지근은 정강이 진행과 균형을 조절 |
| 안정화 | 상승이 끝나고 잔여 움직임 감소 | 종아리근·몸통근의 자세 유지. ‘전 근육이 동시에 등척성’이라는 표시는 피함 |

근활성 설명의 근거는 발 위치에 따른 차이를 조사한 연구와 함께 대조합니다. 정확한 발현 시점을 일률적인 %로 만들지 않습니다. [Jeon 등, 2019](https://doi.org/10.1016/j.gaitpost.2019.04.030)

각도 예시로는 건강한 고령 여성 대조군의 보고값을 사용할 수 있습니다. 시작 → 좌면 이탈 부근 → 최대 발등굽힘 부근 → 기립 순으로, 엉덩관절 굽힘 약 **72→96→87→0°**, 무릎 굽힘 **88→83→76→8°**, 발목 발등굽힘 **12→17→20→4°**입니다. 논문 표의 평균을 반올림한 사례이며 성인 전체의 정상 범위가 아닙니다. 제품의 대표 궤적으로 채택할지는 측정각 정의와 대상군 적합성 **확인 필요**입니다. [Hayamizu 등, 2025, 표 3](https://www.mdpi.com/2077-0383/14/7/2514)

역학 도식은 무게중심의 전방·상방 이동, 좌면반력의 소실, 지면반력 작용선과 관절 사이의 모멘트팔을 보여줍니다. 동작 중에는 분절의 관성도 작용하므로 정적인 지레 하나로 전체 동작을 설명하지 않습니다. [Riley 등, 1991](https://pubmed.ncbi.nlm.nih.gov/2026635/)

발꿈치힘줄은 종아리근 힘을 전달하고, 엉덩넙다리인대는 폄 방향의 수동 제한에 관여한다고 설명합니다. 단계별 장력 수치는 제시하지 않습니다.
피할 표현은 ‘허벅지 힘만으로 일어난다’, ‘무게중심이 발 위에 오면 반드시 일어설 수 있다’, ‘무릎은 발끝을 넘으면 안 된다’입니다.

**나. 앉기**

‘준비 → 하강 제어 → 좌면 접촉 → 착석 안정’을 교육용 구분으로 제안합니다. 이는 표준화된 네 국면이라는 주장이 아니며, 관찰 가능한 접촉 사건을 기준으로 나눈 편집 구조입니다.

| 단계 | 관절·지지 변화 | 주요 근육과 수축 해석 |
| --- | --- | --- |
| 준비 | 엉덩관절·무릎 굽힘과 몸통 기울기 시작 | 앞정강근·큰볼기근·넓은근군의 협응. 이 구간의 세부 수축 구분은 확인 필요 |
| 하강 제어 | 엉덩관절·무릎 굽힘 증가, 무게중심 하강 | 넓은근군과 큰볼기근의 신장성 작용을 중심으로 하강 제어 설명 |
| 좌면 접촉 | 발에 더해 좌면이 하중을 분담 | 다리 폄근의 역할이 바뀜. 접촉과 동시에 근활성이 모두 사라진다고 표시하지 않음 |
| 착석 안정 | 몸통 정렬 조절, 좌면 지지 유지 | 몸통근의 자세 조절. 등척성 근사 여부는 몸통 움직임과 함께 표시 |

앉기는 일어서기의 역재생으로 제작하지 않습니다. 하강 중 폄근의 에너지 흡수와 속도·수행 조건에 따른 차이를 독립적으로 설명합니다. [Jeon 등, 2024](https://www.frontiersin.org/journals/human-neuroscience/articles/10.3389/fnhum.2024.1399179/full)

각도 사례는 건강한 젊은 성인의 기준 발 위치 조건에서 보고된 최대값인 엉덩관절 굽힘 약 **90°**, 무릎 굽힘 **76°**, 발목 발등굽힘 **13°**를 참고할 수 있습니다. 각 관절의 최대값은 같은 순간이라는 뜻이 아니며, 착석 종료 각도와도 구분합니다. [Jeon 등, 2025, 표 2](https://doi.org/10.1371/journal.pone.0315738)

역학은 중력에 의한 하강, 폄근의 제동 모멘트, 접촉 후 좌면반력의 분담으로 설명합니다. 힘줄은 힘 전달 구조이며 접촉 충격을 전부 흡수하는 장치로 그리지 않습니다.
피할 표현은 ‘굽히는 동작이므로 굽힘근이 주동근’, ‘중력에 몸을 맡기면 된다’, ‘천천히 앉기가 누구에게나 치료가 된다’입니다.

**다. 서 있기**

반복 동작의 국면 대신 ‘정렬 관찰 → 미세 흔들림 → 지지 조절’이라는 관찰 항목을 둡니다. 고정된 순서·주기·%는 부여하지 않습니다.

| 관찰 항목 | 관절·역학 | 주요 근육과 수축 해석 |
| --- | --- | --- |
| 정렬 | 고관절·무릎은 중립 부근, 두 발 사이 영역까지 포함한 지지면 관찰 | 가자미근·장딴지근의 지지 작용. 몸통근의 활동은 자세에 따라 달라짐 |
| 미세 흔들림 | 발목을 중심으로 한 작은 움직임과 무게중심 이동 | 종아리근의 근섬유 길이는 실제로 변할 수 있어 완전한 등척성으로 단정하지 않음 |
| 지지 조절 | 압력중심 이동으로 지면반력 모멘트가 달라짐 | 종아리근의 지속적인 조절. 앞정강근의 동원은 조건에 따라 다르며 발현 시점은 확인 필요 |

조용한 기립에서 종아리근의 길이 변화는 단순한 수동 스프링 모형과 다를 수 있습니다. [Loram 등, 2005](https://pubmed.ncbi.nlm.nih.gov/15661825/)

각도 표시는 중립 자세를 도식의 기준으로 삼되, 발목·고관절·무릎의 보편적인 정상 범위를 임의로 붙이지 않습니다. 대표 정렬과 흔들림의 수치 범위는 대상·측정 조건을 정한 뒤 **확인 필요**입니다.
무게중심과 압력중심을 서로 다른 기호로 표시하고, 정적 균형 설명을 보행 중 안정성의 판정 기준으로 확대하지 않습니다.
엉덩넙다리인대의 폄 제한, 발바닥널힘줄의 발아치 지지, 발꿈치힘줄의 힘 전달을 보조 설명으로 둡니다.
피할 표현은 ‘서 있으면 근육은 쉬고 있다’, ‘완전히 대칭인 자세만 정상’, ‘무게중심과 압력중심은 같은 점’입니다.

**라. 평지 걷기**

한쪽 발의 초기 접촉부터 같은 발의 다음 초기 접촉까지를 한 주기로 정의합니다.
상세 국면은 Perry·Burnfield의 예시 기준으로 통일합니다. 아래의 입각기 약 **62%**, 유각기 약 **38%**와 일반 개요의 약 **60%/40%**를 같은 시간축에 섞지 않습니다. 모두 속도에 따라 달라지는 대표값입니다. [Perry·Burnfield, 2010, 1–2장](https://api.pageplace.de/preview/DT0400.9781040143698_A49203435/preview-9781040143698_A49203435.pdf)

| 국면 · 주기 범위 | 관절·주요 근육과 수축 해석 |
| --- | --- |
| 초기 접촉 · 0–2% | 착지 준비. 앞정강근의 발목 자세 유지, 넙다리뒤근육의 다리 전진 제동 |
| 하중 반응 · 2–12% | 무릎 굽힘을 넓은근군이 신장성으로 제어. 앞정강근은 발바닥이 내려오는 움직임을 신장성으로 제어 |
| 중간 입각 · 12–31% | 정강이가 발 위로 진행. 가자미근·장딴지근의 제어, 중간볼기근의 골반 지지 |
| 말기 입각 · 31–50% | 뒤꿈치 상승과 엉덩관절 폄. 종아리근·힘줄의 작용을 분리해 설명 |
| 전유각 · 50–62% | 반대 발로 하중 이전, 무릎 굽힘 증가. 발목의 양의 일과 다리 전진 준비 |
| 초기 유각 · 62–75% | 엉덩근·큰허리근의 단축성 작용, 앞정강근의 발등굽힘. 무릎 굽힘을 전부 능동 굽힘근 작용으로 설명하지 않음 |
| 중간 유각 · 75–87% | 발의 바닥 통과. 앞정강근의 자세 유지에 가까운 작용, 무릎은 중력·분절 간 상호작용으로도 펴짐 |
| 말기 유각 · 87–100% | 넙다리뒤근육의 신장성 제동, 넓은근군의 무릎 폄·접촉 준비 |

종아리근의 ‘신장성 → 등척성에 가까운 작용 → 단축성’은 기능을 설명하는 근사입니다. 가자미근과 장딴지근의 역할도 동일하지 않으며, 시뮬레이션 결과와 실제 측정을 구별해 인용합니다. [Neptune 등, 2001](https://pubmed.ncbi.nlm.nih.gov/11672713/)
발목이 움직이는 동안 근섬유와 힘줄이 같은 비율로 길어지거나 짧아지는 것은 아닙니다. [Fukunaga 등, 2001](https://pubmed.ncbi.nlm.nih.gov/11217891/)

시상면 각도 후보는 엉덩관절 굽힘 약 **20–30°에서 폄 10°**, 무릎 굽힘 약 **0–60°**, 발목 발등굽힘 약 **10°·발바닥굽힘 15–20°**입니다. 근거 후보는 Perry·Burnfield의 발목·무릎·엉덩관절 장이며, **각 숫자의 원문 곡선·측정 기준 재대조가 필요합니다**. 확인 전에는 제품에 확정값으로 싣지 않습니다.

도식은 뒤꿈치·발목·앞발의 구름 기전, 두발 지지와 한발 지지, 지면반력의 제동·추진 성분, 관절의 모멘트팔을 연결합니다. 중간볼기근 설명에는 작은 정면 도식을 보완합니다.
발꿈치힘줄의 탄성 에너지와 발바닥널힘줄의 발아치·앞발 지지 역할은 보조 도식으로 설명하되 장력·변형량을 계산한 것처럼 표시하지 않습니다.
피할 표현은 ‘걷기는 계속 앞으로 넘어지는 것뿐’, ‘밀어내기는 종아리근의 단축만으로 발생’, ‘유각기에는 모든 근육이 쉰다’입니다.

**3. 표현 방식과 조작**

| 방식 | 장점 | 한계·권고 |
| --- | --- | --- |
| 단계별 2D 정지 도식 | 사건·관절·외력을 비교하기 쉽고 접근성 대안 제공 가능 | **첫 출시의 기준 표현** |
| SVG 도식 보간 애니메이션 | 단계 사이의 연결을 이해하기 좋고 WebGL 불필요 | 보간은 편집한 설명용 움직임. 실측 모션으로 표시하지 않음 |
| 3D 뼈 강체 애니메이션 | 공간 관계를 여러 방향에서 관찰 | 관절 중심·충돌·발 접촉·성별 대응 검증까지 후속 보류 |
| 기존 아틀라스 연결 | 실제 수록 구조의 형태·주변 관계 확인 | 정지 해부임을 링크에 명시 |

추천 화면은 뼈를 단순화한 인체 도식 위에 현재 단계의 근육, 관절 회전, 외력 작용선을 필요한 만큼 겹칩니다. 근육은 역할을 표시하는 영역·선으로 그리고 실제 부착점·변형을 재현했다고 주장하지 않습니다.
힘 화살표는 기본적으로 방향 설명용입니다. 길이가 힘의 크기를 의미하는 경우에만 출처와 축척을 제공합니다.
논문 그림을 그대로 복제하기보다 독자적인 도식을 만들고, 재사용할 그림·데이터는 라이선스를 확인합니다.

- 기본은 정지 상태. `재생/일시정지`, `이전 단계`, `다음 단계`, `처음으로`, 진행 막대, 재생 속도 제공.
- 재생 속도 변경은 관찰 속도만 바꿉니다. 실제 보행 속도 조건이 달라진 결과로 해석하지 않습니다.
- 보행에는 근거가 있는 주기 %를 표시하고, 다른 동작은 단계 이름을 우선합니다.
- `prefers-reduced-motion`에서는 단계별 정지 전환을 기본으로 하고 자동 반복을 하지 않습니다.
- 단계 버튼·진행 막대는 키보드로 조작하고, 단축키는 해당 조작부에 초점이 있을 때만 처리합니다.
- 화면 낭독에는 단계 변경과 핵심 설명만 알립니다. 매 프레임의 각도·진행률을 읽지 않습니다.

데스크톱은 중앙 인체 도식을 가장 크게, 옆에는 현재 단계 설명, 아래에는 근육 표를 둡니다.
모바일은 동작 선택 → 인체 도식 → 재생 조작 → 현재 단계 설명 → 상세 표의 흐름으로 배치합니다. 도식을 표나 패널로 교체하지 않습니다.
가로 휴대폰은 도식과 짧은 설명을 나란히 두고, 긴 표는 아래에서 읽게 합니다. 작은 화면에 모든 정보를 고정하지 않습니다.

**4. 페이지 구조와 아틀라스 연결**

새 경로는 **`#movement`**, 헤더 이름은 **‘동작’**을 권합니다.
목록은 카드 격자 대신 ‘동작명 · 주요 관절 · 학습 주제’가 있는 간결한 행 목록으로 구성합니다.
좁은 화면에서는 네 경로를 헤더의 별도 탐색 줄에 배치해 각 링크의 터치 영역을 확보합니다.

상세 주소 예시는 `#movement/sit-to-stand`, `#movement/walking`입니다. 단계까지 공유할 주소 형식을 정하고 뒤로 가기·새로고침에서 선택 단계가 복원되게 합니다.

상세 화면의 순서는 다음과 같습니다.

1. 동작명·영문명, 대상과 수행 조건, 대표 도식이라는 고지.
2. 인체 도식·재생 조작·단계 선택.
3. 현재 단계의 관절 변화·주요 근육·역학 설명.
4. 단계 × 근육 표와 구조별 아틀라스 링크.
5. 흔한 오해, 전체 출처, 편집·검수 상태와 한계.

근육 표는 행을 근육, 열을 단계로 두고 셀에 ‘단축성·신장성·등척성 근사·혼합·확인 필요’를 글자로 적습니다. 빈칸을 비활성으로 해석하게 만들지 않습니다.
모바일은 현재 단계 열을 우선 표시하고 전체 표를 펼칠 수 있게 합니다. 영어 원문명·좌우·FMA ID는 구조 상세에서 항상 확인할 수 있어야 합니다.
수치 옆에는 출처 표·그림과 대상 조건을 연결하고, 페이지 끝에는 완전한 서지를 둡니다. 중요한 한계는 끝부분에만 숨기지 않습니다.

**이 페이지는 위키처럼 WebGL·GLB 없이 열려야 합니다.** 초기 진입과 단계 재생에 3D 모델 다운로드가 필요하지 않은 구조를 출시 조건으로 삼습니다.
스타일은 `src/design-system.css`의 문서 팔레트·간격·글꼴을 사용합니다. 본문은 16px 중심, 의미 있는 보조 글자는 최소 12px로 두며 장식용 히어로·통계·글로우·카드 반복을 넣지 않습니다.

아틀라스 연결에는 현재 없는 구조 주소, 예를 들어 `#atlas/structure/FMA22558`을 새로 정의해야 합니다.
진입 시 ID·좌우·현재 성별의 가용 구조를 확인하고, 구조 선택과 필요한 레이어 변경은 모두 `src/view-state.ts`를 통과시킵니다.
1차는 구조 한 개씩 연결합니다. 동작에 관련된 근육 목록을 전통 장부 비교 묶음으로 처리하지 않습니다.
카메라 맞춤은 명시적인 확대 행동으로 제공하고 표식 선호를 유지합니다. 동작 화면으로 돌아오면 단계·선택 근육·스크롤을 복원하며, 위키 왕복의 기존 아틀라스 복원도 회귀 검사합니다.
대응 구조가 없는 성별에는 이유를 표시하고 임의의 반대쪽·다른 원본으로 조용히 대체하지 않습니다.

**5. 한계와 검증 방법**

이 기능은 일반적인 동작의 해부·역학 학습 자료입니다. 개인의 근력·관절 부하·정상 여부를 추정하거나 통증 원인, 운동·재활 처방, 치료 효과를 판단하지 않습니다.
근육 강조색은 측정된 활성도나 힘의 크기가 아닙니다. 정지 GLB 수록은 움직임의 정확성을 입증하지 않습니다.
성별·연령·신체 비율·속도·의자 높이·발 위치에 따른 차이를 기록하고, 서로 다른 연구의 값을 하나의 실측 궤적으로 합치지 않습니다.

| 검증 대상 | 필요한 증거 |
| --- | --- |
| 단계와 수치 | 주장별 원문 표·그림, 대상군, 과제 조건, 단위·좌표·반올림 기록. ‘확인 필요’ 항목의 확정값 노출 방지 |
| 근육 역할 | 단계별 관절 운동과 수축 해석 대조. EMG·힘·길이 변화의 구별 및 해부·운동학 전문가 검토 |
| 구조 연결 | JSON ID·좌우·원문명과 실제 GLB 노드 대조. 원본 계층·버전 명시 보완 목록 확인 |
| 도식 | 발 접촉·좌면 접촉·관절 방향·지지면·화살표 모순 점검. 관절별 최대값을 동시 자세로 합성하지 않았는지 확인 |
| 경량 진입 | WebGL 비활성·GLB 요청 실패에서도 목록·상세·재생 사용. 동작·위키 최초 진입의 GLB 요청 0건 |
| 상태 전이 | 링크 진입·복귀·새로고침·뒤로 가기·잘못된 ID·성별 대응·카메라·표식 선호 회귀 검사 |
| 화면 | 1440×900, 390×844, 360×740, 844×390에서 초기·재생·정지·긴 이름·표 펼침 화면 직접 확인 |
| 접근성 | 키보드 순서·초점 표시·키 해제·초점 이탈, 터치, 화면 낭독, 움직임 감소, 확대·줄바꿈 검사 |
| 가독성 | 실제 렌더링 면에서 본문 대비 4.5:1 이상, 의미 있는 글자 12px 이상, 터치 조작부 44px 목표 |
| 출시 기록 | 기존 단위·브라우저·빌드·프로덕션·시각 게이트에 새 경로 포함. 요구사항/증거 표와 전후 비교 기록 갱신 |

현재 캡처 스크립트가 새 동작 화면을 포함하도록 확장한 뒤 `test:visual`을 실행해야 합니다. 기존 화면만 통과한 결과로 새 화면의 사용성을 승인하지 않습니다.
검증 기록에는 실패·재실행·미검수 항목을 남깁니다. 이번 독립 제안에서는 파일 수정, 빌드·브라우저 검사, 실제 GLB 재검증을 수행하지 않았습니다.
