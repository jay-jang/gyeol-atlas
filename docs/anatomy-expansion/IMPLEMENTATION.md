# 구조 누락·이동·가독성 개선 — 2026-09-14

## 누락을 확인한 기준

기존 모델은 근육42·장기19·신경7개만 선택해 넣었습니다. 이 때문에 목빗근, 넓은등근, 볼기근, 위팔두갈래근, 발꿈치힘줄 등 원본에 있는 구조도 보이지 않았습니다.

1. 고정된 BodyParts3D 3.0 원본의 part-of/composite 관계를 따라 모든 가용 근육계·신경계 하위 메쉬를 포함했습니다. 단어에 `muscle`이 들어가는 파일만 고르는 방법은 쓰지 않았습니다. 원본 관계는 `data/catalog/`에 보존했습니다.
2. 소화·호흡·비뇨·생식·내분비·감각·심장 계통의 부속 구조를 추가했습니다. 원본 관계가 중복되는 혈관·치아는 해당 표시 계통으로 분류했습니다.
3. 공식 Anatomography 4.3의 버전 명시 메타데이터와 실제 OBJ 헤더를 대조해 척수 신경조직, 뇌신경, 목·상지의 말초신경, 갑상샘·부갑상샘을 보완했습니다. 여러 버전이 섞인 검색 표의 이름보다 **다운로드된 OBJ 헤더의 FMA·이름**을 사용했습니다.

| 표시 계통 | 이전 | 현재 |
| --- | ---: | ---: |
| 체표 | 1 | 1 |
| 골격·치아 | 101 | 129 |
| 근육·힘줄·근막 | 42 | 437 |
| 장기·부속 구조 | 19 | 67 |
| 혈관 | 50 | 56 |
| 신경계·관련 공간 | 7 | 340 |
| 합계 | 220 | 1,030 |

437은 해부학적으로 구분한 근육의 개수가 아니라 **원본 메쉬 수**입니다. 하나의 근육이 여러 갈래로 나뉘거나 근육계에 속하는 힘줄·근막이 포함됩니다. 신경계에는 뇌실 등 공간 모델도 있습니다. ‘척수 중심관’과 ‘척수 신경조직’을 별도로 명명했습니다. 새로 추가된 말초신경은 원본의 수록 부위에 한정되며 전신·양측 전체는 아닙니다. 좌우가 없는 파일을 임의로 반사해서 실제 원본인 것처럼 표시하지 않았습니다.

## 언급된 구조와 연결

경혈 데이터의 구조 참조와 장부 대응 ID는 전부 실제 메쉬에 연결되는지 검사합니다. 특히 기존 설명에만 있던 다음 항목의 참조를 보완했습니다.

| 경혈 설명 | 실제 구조 참조 |
| --- | --- |
| 풍지 GB20의 목빗근·등세모근 | 양측 목빗근, 양측 등세모근 내림부분 |
| 신문 HT7의 자쪽손목굽힘근 힘줄 기준 | 오른 자쪽손목굽힘근의 위팔·자뼈갈래; 근육 메쉬이며 힘줄만의 분할은 아님 |
| 태계 KI3의 발꿈치힘줄 | 오른 발꿈치힘줄, 실제 반대쪽 원본과 짝 연결 |
| 내관 PC6의 긴손바닥근·노쪽손목굽힘근 힘줄 기준 | 해당 근육 모델 연결; 힘줄만의 분할은 아님 |

원본에 독립 힘줄 메쉬가 없는 경우 같은 이름의 근육을 힘줄이라고 바꾸어 표시하지 않습니다. 한국어 이름은 검색용 편집 표기이고 전문가 미검수입니다. 원문·FMA·FJ 식별자는 유지하며 FMA로도 검색할 수 있습니다.

## 이동과 디자인

- 모델 클릭/키보드 초점 후 WASD 또는 방향키: 전후좌우 이동. Q/E: 아래/위. Shift: 빠른 이동. 카메라와 관찰 타깃을 함께 옮겨 관찰 방향을 보존합니다.
- 검색 입력과 다른 컨트롤에 초점이 있으면 키 입력을 가로채지 않습니다. 키 해제·초점 이탈·창 전환에서 연속 이동을 멈춥니다.
- 휠·핀치 확대/축소, 우클릭·두 손가락 이동, 화면의 6방향 이동 버튼, 확대/축소·전체 보기·초기화를 함께 제공합니다.
- `src/design-system.css`: 진한 본문/보조 글자 토큰, 불투명한 패널, 명확한 경계와 초점, 최소12px 글자, 커진 조작 버튼. 기존 CSS의 작은 글자와 흰 배경에서 대비가 낮은 전경 색상도 정리했습니다.
- 3D 조명을 낮춰 색이 하얗게 날아가는 현상을 줄였습니다. 장부 비교는 선택 묶음 주위로 화면을 잡아, 장기가 늘어나도 비교 대상이 작아지지 않도록 했습니다.

- [3.0 STL 변환 원본](https://github.com/Kevin-Mattheus-Moerman/BodyParts3D/tree/f0eeb6e843380cfe6b83797cf8c3e1af74de5e61)
- `scripts/download-supplement.py`: 공식 내보내기 경로에서 선택한 요소 다운로드, ZIP 무결성 및 요소 이름 검사.
- `scripts/build-models.mjs`: STL/OBJ를 동일한 mm→m 좌표 변환으로 GLB 생성. 원본 해시·삼각형 수·변환 오차는 `public/models/manifest.json`에 기록.
- `catalog-audit.json`: 3.0의 필수 원본 구조 집합, `supplement-audit.json`: 실제로 추가한 4.3 요소249개.

모든 GLB 합계는 약46.3MB로 늘었습니다. 계통별 지연 로딩을 유지하여 초기에는 약1MB 체표만 받습니다. 화면에서 필요할 때 근육23MB·신경12MB가 추가되므로 느린 연결에서의 로딩 시간은 늘어날 수 있습니다. 모든 구조를 다시 뭉개거나 생략하는 방식으로 용량을 맞추지는 않았습니다.

검증 결과와 최종 화면은 `VERIFICATION.md`에 별도로 기록합니다.

좌표의 한계: [공식 버전 설명](https://lifesciencedb.jp/bp3d/info_en/index.html)은 주 버전 사이의 신체 좌표 차이를 명시합니다. 이 작업은 같은 단위·축 변환, 전체 신체 범위 검사와 화면 대조를 수행했으며 3.0과 4.3 사이의 해부학적 정합을 검증한 것은 아닙니다. 원본 간 국소 위치·형태 차이가 남을 수 있습니다.
