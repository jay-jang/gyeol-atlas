## 수정 과정에서 확인한 문제와 한계

초기 검증에서 복원 좌표의 약3.6×10⁻¹⁶m 부동소수점 차이가 엄격한 동등 비교를 실패시켰습니다. 카메라 검사를 소수8자리 허용오차로 바꾸고 실제 복원 과업을 다시 통과했습니다. 초기 캡처에서 모바일 카드 잘림·하단 설명 겹침, 가로 화면 버튼 줄바꿈, 검색창 대비4.24:1도 발견해 수정하고 다시 검사했습니다. 공개 위키 검사에서 React 화면 전환 직전의 DOM을 즉시 읽던 경합도 확인했습니다. 캔버스 해제를 기다린 뒤 검사하도록 수정하고 공개 배포 스모크를 다시 통과했습니다.

메쉬 개수는 실제 근육/신경의 해부학적 개수와 다릅니다. 근육계에는 힘줄·근막, 신경계에는 공간 모델이 포함됩니다. 신경은 뇌·척수 및 원본에 있는 말초 부위만 수록했으며 전신·좌우 전체가 아닙니다. 원본에 독립 힘줄 파일이 없는 위치 설명은 근육 메쉬와 구분해 안내합니다. 한국어 명칭과 위치는 전문가 미검수입니다. 3.0·4.3 모델에는 원본 간 국소 위치 차이가 있을 수 있으며, 같은 축·단위 변환과 신체 범위 검사가 해부학적 정합 검증을 대신하지 않습니다.

모델 총46.3MB와 큰 JS 청크 경고가 남습니다. 초기 체표·위키 지연 로딩은 유지합니다. 검증 환경은 Chromium과 소프트웨어 WebGL이며 물리적 휴대폰·모든 브라우저·사용자 연구를 검증한 것은 아닙니다. Cloudflare는 기존 임시 터널이며 상시 운영 체계로 바꾼 배포는 아닙니다.

수록 기준·출처·재현 방법은 [구현 기록](IMPLEMENTATION.md), 이후 작업 기준은 [품질 기준](../QUALITY_STANDARD.md)과 [AGENTS.md](../../AGENTS.md)를 따릅니다.
