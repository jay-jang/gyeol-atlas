# 결 GYEOL UX 상호 리뷰 및 개선안

2026-09-10 · Codex + agy · 리뷰와 개선안 도출 완료. 제품 수정·재배포는 하지 않았습니다.

가장 먼저 고칠 것은 **단독 보기 중 레이어를 바꾸면 모델이 비어 보이는 상태 오류**입니다. 이어서 **조작부와 결과를 함께 보도록 모바일 배치를 정리하고, 단계·위키 이동에서 관찰 맥락을 보존**해야 합니다. 색상이나 장식보다 이 흐름을 우선합니다.

## 검토 방법

- agy CLI에 독립 UX 리뷰를 의뢰했습니다. 대화 ID: `47380252-57d5-4547-9c21-2c456a39376f`.
- Codex는 agy 결과를 읽기 전에 별도로 현재 배포 빌드 `http://127.0.0.1:3002`를 조작하고 수치를 기록했습니다.
- agy 1차 결과에 Codex가 반론과 재현 증거를 전달했고, agy가 이를 다시 비판·수정한 2차 응답을 받았습니다.
- Chromium 1440×900 및 390×844. 터치 제스처는 별도의 CDP touchStart/move/end로 검증했습니다.
- 실제 사용자 인터뷰·과업 성공률·이탈률 조사는 아닙니다. ‘혼란을 줄 수 있다’는 해석과 화면·상태에서 직접 확인한 사실을 구분했습니다. 임상 정확도나 치료 효과 평가는 하지 않았습니다.
- 최초 agy CLI 출력 프로세스 종료 후 동일 대화를 재개해 기존 조사 결과를 받았습니다. 두 번째 독립 리뷰를 새로 만든 것이 아닙니다.

## 실행할 개선 사항

P1은 핵심 과업을 방해하는 문제, P2는 이해·탐색 효율 개선입니다. P0에 해당하는 장애는 이번 리뷰에서 확인하지 못했습니다. 아래 순서는 Codex의 최종 실행 우선순위이며, 의견 차이가 있는 항목은 명시했습니다.

| 순서 | 우선도 | 확인한 문제와 영향 | 개선안 | 완료 판단 기준 |
| --- | --- | --- | --- | --- |
| 1 | P1 | 위 단독 보기 → 뷰어에서 장기 OFF·근육 ON: 근육 버튼은 켜졌지만 빈 모델. 목록 선택값은 비고 단독 보기 상태가 남음 | 모든 레이어 조작에 공통 상태 전이 적용. 선택 대상이 사라질 때 단독 보기와 선택 상태를 일관되게 해제. 중복 UI 정리는 이후 수행 | 상단·뷰어 어느 조작부에서도 동일 재현 후 근육이 실제로 보이고 선택 상태가 유효함. 빈 화면 회귀 검사 포함 |

## 확정하지 않은 세부 사항

- **모바일 35~40vh 고정, top≤200px 등의 수치**: agy의 설계 제안이지 사용자 검증을 거친 기준이 아닙니다. 모델·조작 동시 가시성과 긴 문서 접근을 만족하는지 프로토타입으로 먼저 확인합니다. 390×844 외 작은 화면·가로 화면도 검토해야 합니다.
- **불투명도 0.3 임계값**: agy 2차 수용 기준에 다시 등장했지만 채택하지 않습니다. 보이는 정도를 바꿨다고 클릭 대상의 의미가 암묵적으로 달라지게 하지 않습니다. 비교 모드의 자동 내부 선택과 명시적 대상 표시를 우선합니다.
- **메모리·성능 영향**: 상시 3D 마운트의 비용은 가능한 트레이드오프입니다. 실제 성능 저하를 측정한 것은 아닙니다.
- **터치**: 캔버스에서 스와이프하면 회전 조작이 우선하고 페이지 스크롤은 유지됐습니다. 바깥 여백에서는 스크롤됐으므로 ‘모바일 스크롤 불능’으로 판정하지 않습니다. 레이아웃을 바꾼다고 자동 해결된다고도 단정하지 않습니다.
- **안내 문구**: 이미 있는 근사 위치·전통 분류 설명은 보존합니다. 더 긴 경고문을 늘리는 것보다 비교 결과와 가까운 위치에 짧고 정확하게 표시합니다.

## 권장 작업 순서

1. 레이어/단독 보기 상태 오류를 먼저 수정하고 재현 경로로 회귀 검증합니다.
2. 비교 대상 묶음·직접 선택 규칙·시점 보존을 함께 설계합니다. 화면 배치 이전에 상태 규칙을 정리합니다.
3. 모바일 모델·조작 동시 표시를 프로토타입으로 비교합니다. 데스크톱 컨트롤 중복도 함께 정리합니다.
4. 위키 왕복 복원, 목록 분류, 구조 검색·범례와 문구를 정리합니다.

실사용 검증 과업은 ‘중완을 찾아 위 비교 → 위 단독 확대 → 가이드 읽고 복귀’, ‘태계에서 양쪽 콩팥 비교’, ‘족삼리 확대 상태로 근육·골격 교대’로 잡는 것이 좋습니다. 과업 완료 여부, 되돌아가기·재검색 횟수, 사용자가 해석한 강조 의미를 관찰합니다. 이번에 이 지표를 측정한 것은 아닙니다.
