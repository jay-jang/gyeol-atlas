# Codex 독립 1차 리뷰

2026-09-10. http://127.0.0.1:3002 현재 빌드, Chromium 실제 조작. agy 응답을 읽기 전에 기록.

## 관찰

1. **P1: 단독 보기와 중복 레이어 조작의 상태 불일치.** 장기 단계 → 위 FMA7148 선택 → 선택 구조만 보기 → 뷰어 안의 장기 끄기 → 근육 켜기. 근육 버튼은 켜졌지만 모델은 비어 있음. 구조 select는 빈 값인데 ‘전체 구조 보기’ 버튼은 남음. App의 상단 setLayers는 isolated와 selectedStructure를 초기화하지만 뷰어 버튼(App.tsx:768)은 layers만 변경. Atlas.tsx:87의 고립 조건 때문에 근육이 전부 숨겨짐. desktop/mobile-isolation-layer-switch.png로 실제 확인.
2. **P1: 모바일 장부 비교 후 결과가 시야 밖.** CV12 상세에서 비교 클릭 후 scrollY=1623, canvas top=-502.6px, 높이610px 중 바닥107.4px만 보임. 정작 상복부 비교는 안 보임. 결과로 이동하거나 ‘비교 결과 보기’ 접근 경로 필요. 무조건 자동 스크롤은 데스크톱에서 맥락을 잃게 할 수 있으므로 모바일 또는 결과가 시야 밖일 때만 적용.
3. **P1: 첫 화면의 핵심 작업 가시성.** 390x844에서 canvas 시작 y=1013px, 가시 높이0. 1440x900에서도 y549px로 718px 중351px만 보임. 단계 패널 → 검색 패널 → 모델의 수직 배치가 탐색 전 스크롤을 강제. 모바일 모델 우선 배치와 검색/상세 패널 전환, 데스크톱 단계 바 압축을 제안. 단, 모든 기능을 숨기는 과잉 단순화는 피해야 함.
4. **P2: 전통 장부 대응과 실제 해부 위치를 비교하는 과업에 비해 상태 설명 부족.** 금색은 선택 구조/경혈 관련 구조/전통 대응에 공용. 해당 의미를 문맥별 범례로 구분하는 편이 안전. 현재 설명 문구는 보존하고 더 긴 면책 문구 추가보다 비교 결과 가까이에 배치.
5. **P2: 구조 목록의 발견 가능성과 이해 비용.** FMA/영어 중심의 큰 목록, 레이어 혼합시 탐색량 증가. 한국어 명칭+원문 검색과 계통별 그룹을 제안. FMA를 없애기보다 상세 정보로 유지. 직접 DOM/소스 관찰이며 사용자의 실제 혼동 여부는 사용자 테스트가 필요.

6. **P1 후보: 단계 전환이 관찰 부위/시점을 리셋.** App.tsx:390-410에서 매 단계마다 카메라를 정면 전신으로 재설정(신경은 머리). 같은 부위를 확대하고 계통을 비교하려는 과업과 충돌. 기본은 현재 시점을 유지하고, 별도 전체 보기/계통 맞춤 시점 제공. 뇌 모델을 전신 프레임에 너무 작게 두는 문제가 있으므로 신경 선택 시 맞춤 보기 안내가 필요. 현재 소스와 실제 ST36 확대 → 골격 전환을 모두 확인. focused-point.png와 after-stage-switch.png에서 무릎 확대가 전신으로 바뀜. 이로 인한 실제 사용자 과업 영향은 사용자 검증 필요.

observations.json, capture.mjs, 현재 화면 PNG. 실제 사용자 연구가 아닌 전문가 검토이며 이탈률·과업 성공률은 측정하지 않음. 첫 화면에 모델이 없다는 사실만으로 P0로 판정하지 않음. 위키에 가이드를 남기는 것은 유용하며, 모든 안내를 제거할 이유는 없음. 제품 코드를 수정하지 않음.
