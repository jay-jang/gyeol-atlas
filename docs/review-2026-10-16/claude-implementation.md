   합의 v2 구조는 대부분 제대로 구현됐습니다. 제가 2·3차에 낸 차단 항목도 모두 반영됐습니다.
   - G-07: 목록에서 고르면 패널이 닫힙니다(AtlasPage.tsx `select()`의 `setPanel(null)`).
   - 모바일 상태 줄에 '해부 모델 로드 완료'가 남습니다.
   - `.ax-depth`·`.ax-point-bar` 계약과 헬퍼(`viewButton`·`openFilters`·`chooseMeridian`)가 같은 변경에서 갱신됐습니다.
   - 비교 축약 고지는 별도 클래스 `.panel-comparison-note`를 씁니다.
   - `restoreView` 보존 조건은 비교가 있고 `skinAlpha`가 있을 때로 한정됐습니다.
   - 부위 select는 휠 박리 처리에서 빠졌습니다.
   - Atlas.tsx 해시는 audit JSON과 일치합니다(`12b5fa70…`, 한 줄만 변경).

   다만 아래 1·2번은 완료 처리 전에 고쳐야 합니다.

2. **합의 위반·결함**

   1. **(조건) G-20 검증이 최종 코드보다 오래됐습니다.**
      - 근거: `src/AtlasPage.tsx`·`src/atlas.css`는 19:07에 수정됐습니다. 마지막 브라우저 재실행은 18:27(2개 실패)과 18:29(실패분 14개만 통과)이고, 겹침 감사·가독성 검사는 18:55입니다. `checks/`에는 `npm test`(view-state·search-rank·muscle-peel 해시) 로그가 없고, REVIEW.md 검증 절은 "(결과 기록 중)"입니다. run2의 8개 실패는 부분 재실행으로만 해소됐습니다.
      - 영향: 최종 트리에서 전체 검사가 한 번도 통과하지 않았습니다(AGENTS 위반).
      - 수정: 최종 트리에서 `npm test`, 전체 e2e, `npm run build`, `test:production`, `test:visual`, `audit:overlays`, `check-readability`를 다시 돌리고 결과를 REVIEW.md에 기록합니다.

   2. **(조건) G-03·G-11 모바일 상태 줄에서 '학습용 근사'가 잘립니다.**
      - 근거: `after/small-mobile-10-female.png`는 "…선택 대상: 내부 구조· 여성 HRA·남성 보…", `mobile-10-female.png`는 "…· 학…"으로 끝납니다. `.ax-status`가 `nowrap`이고 `.ax-source`가 말줄임 처리됩니다(atlas.css 모바일 `.ax-status` 규칙).
      - 영향: 여성 보기나 '선택 대상' 표시 상태에서 근사 고지와 남성 보완 고지가 화면에서 보이지 않습니다.
      - 수정: 휴대폰에서는 `.ax-source`를 둘째 줄로 줄바꿈하거나, 순서를 `{로드 상태} · 학습용 근사 ↗ · {출처 요약}`으로 바꿔 말줄임은 출처 요약에만 적용합니다. 360 여성 상태에서 보이는지 단언을 추가합니다.

   3. **G-06 경혈 결과 수가 서로 맞지 않습니다.**
      - 근거: `after/desktop-04`는 '경혈 75'라고 하는데 섹션 머리는 '경혈 40', 버튼은 '경혈 40개 모두 보기'입니다. 수는 `rankedPoints.length`로 세는데 목록은 `rankedPoints.slice(0, 40)`에서 만듭니다.

   4. **G-10 인접: 성별 전환 뒤 비교의 선택 대상이 남습니다.**
      - 근거: view-state.ts:182–183의 `sex` 액션이 `selectionTarget`을 되돌리지 않습니다. `after/mobile-10`에 '선택 대상: 내부 구조'가 남아 있습니다.
