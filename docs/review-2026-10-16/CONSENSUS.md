## 원칙 (5)

1. **인체가 작업 공간.** 큰 패널은 한 번에 하나. 패널이 덮는 장면 도구는 `visibility:hidden`으로 잠시 숨기고(측정·카메라 불변), 모바일 패널은 제목·조작·고지를 포함해 장면 높이의 45% 이하.
2. **자주 쓰는 조작은 손 가까이.** 모바일은 위에 입력(검색·성별·가리기·설정·도움말), 아래 엄지 영역에 경혈 칩·박리·경혈 도구, 오른쪽 가장자리에 카메라. 가끔 쓰는 것은 한 단계 안(시트·팝오버)에.
3. **찾는 대상을 먼저.** 검색은 정확 일치가 맨 위, 상세는 위치가 첫 화면, 목록은 결과가 첫 화면.
4. **장식 없는 도구.** 불투명 중립 면, 강조색 하나(청록), 시스템 글꼴, 모서리 4px(조작)·8px(패널), 그림자는 떠 있는 면에만. 색 점은 장면 색에 대응하는 견본에만. 이모지·기호만 있는 새 버튼·× 토큰·알약·영문 eyebrow·슬로건·장식 통계·Sparkles·첫 방문 코치마크 없음.
5. **정직성 고지는 문구 그대로, 판단하는 자리에.** 반복만 줄이고 의미를 지우지 않습니다.

## 쟁점과 결정 (3차에서 세 쪽 모두 1–5 동의)

1. **모바일 박리 위치(G-03·G-19).** Codex·AGY는 2차에서 하단 엄지 영역(깊이 줄)을 택했고, Claude는 Atlas.tsx 해시 고정·관찰 상수 때문에 상단 유지로 물러났습니다. **결정: 하단 깊이 줄 + Atlas.tsx 최소 수정(G-19).** 이유: 브리프의 U9(한 손 엄지 조작)가 핵심 요구이고, Atlas 변경은 상수를 CSS 변수로 바꾸는 범위로 한정되며 감사 스크립트로 해시를 다시 고정하는 절차가 이미 있습니다. Claude가 지적한 위험(재맞춤, 해시, 기존 결정 :81)은 수용 기준과 기록으로 처리합니다. 실기기 엄지 검증은 한계로 기록합니다.
2. **검색 범위 탭(G-06).** Codex·AGY는 탭 포함, Claude는 정렬 수정 후 재평가. **결정: 이번에는 탭 없이 유형별 묶음 + 정확 일치 맨 위 + ‘모두 보기’.** 이유: 사용자가 단순함을 요구했고, 정렬만으로 ‘위’ 오선택(진단 공통 P0/P1)이 해결됩니다. AGY 2차의 ‘받아들일 수 있는 대안’과 같습니다. 구현 후 화면 검토에서 유형 혼동이 남으면 탭을 추가합니다.
3. **비교 해제 복원(G-10).** Claude·AGY는 이번 포함, Codex는 명세·검증 합의를 조건으로 허용. **결정: 위 G-10의 좁은 규칙만 이번에 구현**하고, 인대·힘줄 묶음 복귀와 일반적인 ‘사용자 편집 추적’은 후속으로 둡니다.
4. **모바일 카메라(G-18).** 5칸(Claude·AGY) 채택. 1탭 후면(U3)과 한 손 확대(U9) 유지.
5. **가로 모바일 패널.** 셋 다 높이 ≤45% 유지에 동의. ‘가로에서는 폭 ≤45%’ 재해석은 사용자 결정이 필요한 안건으로 기록만 하고 구현하지 않습니다.

## 구현 중 지킬 위험 (세 2차 목록의 공통 부분)

- `select()`·`pickStructure()`는 캔버스에서도 호출됨 → 초점 이동은 닫히는 패널 안에서 실행했을 때만. 이전/다음은 전용 경로.
- `point` 액션은 비교·상세를 끝냄 → 넘기기 비활성 규칙. 넘기기는 히스토리 replace, `route-point` 동일 ID 무시(Q5) 유지.
- 테스트 계약: ‘해부 모델 로드 완료’ 보임(모바일 포함), `.ax-depth`(하단 깊이 줄에도 같은 클래스; `detail-context.spec`의 ‘깊이 막대는 위’ 가정 갱신), `.ax-point-bar`, ‘도움말’·‘표시 설정’ 버튼 이름, 경맥 옵션 이름(팝오버를 여는 헬퍼와 함께), `.source-cards article` 14개(site.spec:15), ‘경혈·구조 검색’·‘검색 결과’ region, `.featured-anatomy > button`, `.point-item`, `.structure-item`(개수·`.first()`), ‘경혈 찾기’/‘경혈 목록’, ‘경혈 검색’, ‘전신 부위 선택’, ‘연속 해부 박리 깊이’, ‘○○ 빠른 보기’, ‘○○까지 박리’, `.ax-top` 안 남/여·성기 가리기, `.point-summary`, ‘대응 장부의 해부 구조 비교’, ‘구조 선택 해제’, `.selection-card strong`, `.comparison-note`, `.movement-pad`·`.view-presets`·‘측면’·‘계통 전체 보기’·‘시점 초기화’, ‘위키 질문’·‘질문 보내기’, `--ax-ligament`·`--ax-tendon`. 바꿔야 하면 헬퍼·검사를 같은 변경에서 갱신하고, 숨은 중복 버튼으로 호환성을 만들지 않음.
- 카드·인스펙터를 숨길 때 `visibility:hidden`(선택 카드 측정 → 재맞춤 방지).
- Atlas는 `memo` → 새 UI 상태가 Atlas에 새 객체·배열을 넘기지 않음.
- 접힌 `<details>` 안의 select는 Playwright에서 조작 불가 → 펼치기 헬퍼 먼저.
- 미커밋 R1–R8 보정은 기준이며 되돌리지 않음.
- 범례: 카드 없이 경혈만 고른 상태의 참조색 설명 공백은 현행 한계로 기록(QUALITY:12).
- 하이브리드 기기(`pointer:coarse`로 잡히지 않는 터치)는 검증 한계로 기록.
