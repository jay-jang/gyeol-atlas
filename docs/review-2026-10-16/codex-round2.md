## 2. 자기 1차 안에서 철회·수정하는 항목

- **C-02: 하단 검색과 5칸 도구를 철회합니다.** 상단 검색을 입력 중 전폭으로 확장하고, 하단은 깊이 줄과 경혈 도구로 정리합니다. 가상 키보드와 검색 결과의 배치를 단순하게 만듭니다.
- **C-06: 박리를 상단 선택 뒤에 접는 기본안을 수정합니다.** 세로 모바일에서는 연속 슬라이더를 하단에 남깁니다. 계통 선택·단독 보기는 펼친 면에서 제공합니다.
- **C-01: 모든 도구를 하나의 `panel` 상태로만 처리하는 해석을 수정합니다.** 큰 작업 패널은 하나지만 짧은 선택기의 논리 상태는 분리합니다. 선택기를 열었다고 상세 탭·스크롤이 초기화되면 안 됩니다.
- **C-04: 비교를 전통 분류 탭 안에서만 찾도록 하는 부분을 완화합니다.** 위치를 먼저 보여 주되 대응이 있는 경혈에는 짧은 `위 비교` 진입을 남깁니다.
- **C-07: reducer 복원을 UI 구현의 선행 조건으로 강제한 순서를 철회합니다.** 저장 스키마와 중간 편집 정책까지 바꾸는 작업이므로 독립 후속으로 분리합니다. 잔류를 해결했다고 표시하지 않습니다.
- **C-12·C-16: 가독성·접근성 기준을 강화합니다.** 1차에서 놓친 문서 대비 문제를 추가하고, 44px 터치 영역을 단순 목표가 아닌 이번 수용 기준으로 올립니다.
- **C-14: 전체 보기 링크는 이번 범위에서 제외합니다.** 경혈 링크를 쉽게 공유하는 기능은 포함합니다.

## 5. 이번 구현에서 뺄 항목과 이유

- **비교·인대 묶음의 선호 복원 재설계:** `ReturnView`에 `alpha`·`connective`가 없고 복원 검사도 함께 바뀝니다. UI 개편과 분리합니다. **비교 종료 뒤 피부·선택 대상 잔류는 알려진 미해결로 기록**하며 U6 복원이 완료됐다고 하지 않습니다.

- **줄 수를 목표로 한 CSS 대량 삭제:** 사용 여부와 테스트 의존을 확인한 부분만 정리합니다.
- **가로 패널의 높이 제한 재해석:** 현재 브리프의 고정 조건을 그대로 적용합니다.
