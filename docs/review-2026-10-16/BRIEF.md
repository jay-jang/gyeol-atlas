# UI/UX 전면 개선 — 독립 제안 공통 브리프 (2026-10-16)

## 사용자 요청 (원문)

> 현재 UI/UX를 모바일과 Desktop 친화적으로 전반적으로 새롭게 개선하고 싶어. AI 스러운 UI/UX는 배제하고 단순하지만, 여러 사용 예를 커버할 수 있도록 해줘. Codex와 AGY도 독립적으로 UI/UX 개선을 진행해서, 합의를 거친 다음에 개선책을 만들어줘.

진행 방식: Claude Code, Codex, AGY가 **서로의 결과를 보지 않고** 각자 개선안을 만든 뒤(1차), 서로의 안을 비판·대조해 합의안을 만들고(2차), 합의안을 구현한 다음 구현을 함께 검토합니다. 지금은 **1차 독립 제안**입니다.

## ‘AI스러운 UI’로 보고 배제할 것 (사용자 요청 해석)

- 장식용 그라데이션·네온·글로우, 겹겹의 반투명 블러 카드, 카드 안의 카드.
- 의미 없는 영문 대문자 eyebrow(“A LIVING, SOURCE-GROUNDED WIKI”, “TRACEABLE BY DESIGN”), 마케팅 슬로건형 히어로 문구, 장식용 숫자 통계 묶음.
- 반짝이(Sparkles) 아이콘·“AI에게 물어보기”식 연출, 이모지, 모든 요소를 둥근 pill/chip/card로 만드는 습관.
- 같은 면책·설명 문단의 반복과 과다한 보조 문구(필수 고지는 유지하되 위치와 밀도를 정리).
- 지향: 지도 앱·해부학 앱·디자인 도구 같은 **도구형 앱의 절제** — 중립 표면, 강조색 하나, 분명한 글자 위계, 일관된 간격 체계, 플랫폼 관습(상단 바, 하단 시트, 사이드 패널, 툴바), 실제 의미가 있는 이름.
- 이 정의에 동의하지 않는 부분이 있으면 근거와 함께 반박해도 됩니다.

## 바꿀 수 없는 조건

AGENTS.md와 QUALITY_STANDARD를 따릅니다. 특히:

- 인체 모델이 주 작업 공간입니다. 도구는 모델 위에 떠 있고, 모바일 패널은 장면을 대체하지 않습니다(패널 높이 ≤ 장면 45%, Q10/Q25 겹침 금지).
- 모든 레이어·단독·비교·표식 전이는 `src/view-state.ts`를 거칩니다. 카메라·표식 선호 보존, 단일 선택과 장부 비교 묶음 구분, 위키 왕복 시 보기 복원, 위키는 WebGL/GLB 없이 열림(Q9).
- 한국어 구조 검색은 영어 원문명·FMA ID를 유지합니다. 없는 해부를 만들지 않고, 전통적 대응을 압력 경로나 임상 효과로 표현하지 않습니다.
- 호버 설명은 키보드 초점에서도 동작하고 모든 동작은 클릭·터치로 가능합니다. 의미 있는 글자 ≥ 12px, 대비 4.5:1 이상, 공유 토큰은 `src/design-system.css`.
- 출처·근사·검수 전 상태 등 정직성 고지는 없애지 말고 위치·밀도를 개선하세요.
