## 1. 위중(BL40) 해제 방법

스크린샷 상태(비경 필터·이름표 켬·후면, BL40 선택·상세 열림)를 재현해 보니, 해제할 수 있는 곳은 경혈 칩의 확대 버튼 오른쪽 **X(경혈 선택 해제)** 하나뿐이었습니다. 상세 패널의 X는 패널만 닫고, 금색 이름표를 다시 누르거나 Escape를 눌러도 선택은 그대로였습니다. 그래서 다음을 더했습니다(Q47).

- 경혈 상세의 동작 줄에 **‘선택 해제’** 버튼(가까이 보기 · 위키 옆).
- 1001px 이상에서는 칩의 X에 **‘해제’** 글자를 함께 표시. 휴대폰은 칩 폭 때문에 아이콘을 유지합니다(접근 이름 ‘경혈 선택 해제’).
- 해제 뒤 초점은 미선택 칩으로 가고, 필터·카메라·표식 선호는 그대로입니다(Q45).
