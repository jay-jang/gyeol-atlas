# Codex 재현 및 합의 후보

기준: HEAD `0e9ce19`, 2026-10-05. 기존 단위 418/418 통과. Chromium/macOS Metal, 실제 로컬 http://127.0.0.1:5174. 데스크톱 1440×900 및 모바일 390×844에서 재현했습니다. [실측](reproduction.json), [초기 데스크톱](before-desktop.png), [초기 모바일](before-mobile.png).

1. `/` 검색 후 Escape가 원래 버튼에 초점을 돌리지 않음(Q10/Q13과 화면 원칙). 도움말 버튼에 초점 → `/` → 검색 → Escape를 누르면 도움말 대신 검색 입력에 초점이 남습니다. `AtlasPage.tsx` 키 처리에서는 원래 activeElement를 기록하지만 input의 onFocus가 같은 동기 호출에서 triggerRef를 덮어씁니다. 제안: 프로그램으로 검색 초점을 옮기는 동안 onFocus의 패널 열기/트리거 갱신을 억제하고, 원래 실행 요소를 보존.
2. 패널이 없는데 Escape가 검색을 열고 캔버스 초점을 빼앗음(Q13). 검색 사용·닫기 → canvas.focus → Escape에서 검색 패널 1개, 검색 입력 초점이 됨(남녀 성별과 무관). 키 처리에 현재 panel 검사 없이 이전 트리거에 focus하는 것이 원인입니다. 제안: 닫을 패널이 없으면 Escape는 아무 동작도 하지 않음. 패널 닫기의 초점 복귀 중 검색 onFocus는 새 패널을 열지 않도록 억제. 일반 검색 Escape 닫기는 기존에도 정상이라 이 경로를 새 실패라고 기록하지 않음.
3. 경혈 상세 tablist가 방향키를 지원하지 않고 탭/패널 이름 연결이 없음(키보드·보조기술 접근). `개요`에 초점 → ArrowRight 후 선택·초점 모두 개요에 남고, tabpanel의 aria-labelledby는 null. 제안: Left/Right 순환, Home/End, 선택 탭만 tabIndex=0, aria-controls/aria-labelledby 연결과 키보드로 들어갈 수 있는 tabpanel. click/touch 경로 유지.

계획된 검증: 수정 전 회귀 실패 → 수정 후 데스크톱/모바일 회귀 및 기존 입력 초점/해제·위키 복귀·경혈/비교 과업; 단위·타입/빌드·프로덕션 스모크·가독성·네 화면 시각 검사와 이미지 직접 확인. 해부 원본/메쉬/표시 순서/공통 view-state 모델은 바꿀 필요가 없는 작은 UI 보정입니다.

별도 후속 추천: 여성 뇌–머리뼈 30쌍 교차·신경 54개 뒤집힘의 재측정과 출처 경계에 따른 교정, 전송량/캐시·느린 연결 실측, 한국어 편집명/근사 표식 전문가 검수, 실제 사용자 과업 테스트. 이번 코드 합의에 자동 포함하지 않습니다.

## 두 독립 리뷰 수신 후 추가 후보

- agy P1: 여성 중완→위 비교 카드의 ‘위 (여성 CT) 상세’가 새로고침·위키 왕복 후 사라집니다. Codex 실제 모바일에서 진입 전 버튼 1개 → 새로고침 0개 → 위키 복귀 0개를 확인했고 비교 자체는 FT_FMA7148로 유지됩니다([실측](comparison-reproduction.json)). `separateDetailIds`는 실패 안내용 상태로만 남기고, 성공한 현재 비교의 CT 후보는 `state.comparison.pointId`/sex/기관 대응으로 매번 도출합니다. 새 복원 상태나 독립 전이 경로는 만들지 않습니다.
- agy P2: 인대·힘줄 묶음의 단독 보기 해제 후 ‘비교 대상만 보기’ 문구는 전통 장부 비교와 혼동됩니다. `state.comparison`이 있을 때만 비교 문구를 쓰고, 인대 묶음은 ‘인대·힘줄만 보기’, 기타 묶음은 ‘묶음만 보기’로 구분합니다.
- Claude P1: 저장된 KI3 비교에서 로고의 #atlas를 누르면 비교는 KI3인데 `selected`는 fallback ST36가 되어 ‘족삼리 · 신 비교’ 안내가 나옵니다. Codex가 다음 실제 회귀에서 확인합니다. 유효 route id를 우선하며 id 없는 #atlas 진입에서는 현재 공통 상태 pointId를 사용하고, 잘못된 명시적 주소는 기존 오류 경로를 유지합니다.
- Claude P2: 최초 경혈 미선택 fallback의 ST36 `structures` 때문에 관련 근육/뼈가 경혈 참조색입니다. fallback의 id뿐 아니라 structures/landmarks도 비워 가짜 경혈 강조를 제거합니다. Atlas.tsx/기하/박리 변경 없이 해결합니다.
- Claude P2: 검색 닫기·도구 패널 닫기·구조 선택 해제에 기존 data-tip을 추가해 호버/키보드 초점 설명을 제공합니다.

합의 요청 범위: 위 추가 5개와 앞의 키보드 3개(총8개)를 현재 UI 결함 보정으로 묶습니다. 새 회귀로 확정한 문제만 반영합니다.

후속으로 분리할 사항: 두 리뷰가 공통 지적한 비교 후 alpha.skin 0.12 잔류는 실제 모바일에서도 확인됐습니다. `ReturnView` 확장/기존 세션/비교 안에서 alpha 편집/계통 전환 시 복원 규칙을 설계하고 상태 전이 전체를 검증해야 하므로 이번 UI 보정에서 섣불리 교체하지 않고 높은 우선순위로 기록합니다. agy reset은 현재 UI가 해당 reducer reset을 호출하지 않고 reset은 다른 선호도 기본화하는 명시 초기화라 지금의 사용자 버그로 단정하지 않습니다. connective-only의 layers 모드 복귀는 실제 장면 복귀 정책과 함께 후속으로 검증합니다.
