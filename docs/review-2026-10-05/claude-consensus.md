# 합의 라운드 판단: 8개 보정 범위

Codex 재현 결과와 두 리뷰를 코드와 다시 대조했습니다. 이번에도 읽기만 했습니다.

## 제안별 판단

1. **검색 단축키 초점 복귀 — 수용.** `/` 처리(`AtlasPage.tsx:226-230`)가 원래 버튼을 기록한 직후 검색 입력에 초점을 줍니다. 그러면 같은 호출 안에서 입력의 onFocus(`:533`)가 기록을 덮어씁니다. Codex 재현과 일치합니다.
2. **패널 없는 Escape — 조건부 수용.**
   - `closePanel`은 초점 복귀를 `requestAnimationFrame` 안에서 합니다(`:208`). 동기 억제 ref는 그 지연된 초점 호출까지 감싸야 합니다.
   - 키 처리에서 현재 panel을 읽는 방식은 의존성 배열이든 ref든 괜찮습니다.
3. **상세 탭 — 수용.** `:90-94`에 방향키 처리와 aria 연결이 없습니다. 클릭·터치와 탭 이름은 그대로 두고, 패널 안 링크·버튼의 Tab 순서도 함께 확인해야 합니다.
4. **여성 CT 버튼 — 수용.** 성공한 비교의 CT 후보를 `state.comparison.pointId`와 성별로 매번 도출합니다. 실패 안내만 로컬 상태로 남깁니다. 새 상태 전이는 생기지 않습니다.
5. **묶음 버튼 문구 — 수용.**
   - 기관 상세 선택도 묶음(bundle)이라, 지금은 거기서도 "비교 대상만 보기"가 나옵니다. 이번 수정으로 함께 고쳐집니다.
   - 테스트·스크립트에서 이 문구를 쓰는 곳은 모두 비교 상태(`state.comparison`)가 있는 경로입니다. `lung-source.spec.ts:28`의 "0개" 확인도 그대로 통과합니다.
6. **주소 없는 `#atlas` — 조건부 수용.**
   - 제안은 잘못된 명시 주소(예: `#atlas/FAKE`)를 기존 경로대로 둡니다. 그런데 이 경우에도 `App.tsx:478`이 상태를 갱신하지 않습니다. 저장된 KI3 비교와 대체 경혈이 겹쳐 같은 "족삼리 · 신 비교"가 나옵니다(코드로 확정, 화면 미확인).
   - **조건:** 비교 카드 문구(`:751`)의 경혈 이름을 `state.comparison.pointId`에서 가져옵니다. 한 줄 수정이고 세 진입 경로(로고, 뒤로 가기, 잘못된 주소)를 모두 막습니다.
7. **대체 경혈의 구조 목록 비우기 — 수용.** `Atlas.tsx`를 바꾸지 않고 해결됩니다.
8. **닫기 버튼 3개 설명(data-tip) — 수용.**
   - 표현은 기존 "닫기" 툴팁과 맞춥니다.
   - 선택 카드의 X는 "구조 선택 해제"처럼 실제 동작을 설명합니다.

## 나중으로 넘길 것

- **`alpha.skin` 잔류 (높은 우선순위):** 비교 진입 전 장면과 피부 불투명도를 `selectionReturn`에 저장해 해제 때 되돌리는 설계가 필요합니다. 비교 안에서 장기를 누르는 `pick`은 같은 장면이라 예외로 두어야 하고, 기존 저장 세션 처리도 정해야 합니다. 상태 규칙을 따로 설계하자는 의견에 동의합니다.
- **인대·힘줄만 보기:** layers 모드에서 진입했을 때 원래 계통 구성이 복귀되지 않는 문제, 그리고 표시 선호(`connective`)를 강제로 켠 채 남기는 문제.
- **agy 후속:** 여성 근사 표식을 켠 뒤에도 이전 안내가 남는 문제(`AtlasPage.tsx:168`의 의존성).
- **`reset`:** 현재 UI에서 호출하는 곳이 없어(view-state 안에서만 참조) 사용자 결함으로 보지 않는다는 데 동의합니다. 쓰지 않는 액션을 정리할지만 후속에서 판단하면 됩니다.

원래 제안 중 이번 8개보다 우선할 확정 버그는 없습니다. P1(엉뚱한 경혈 이름)은 이미 범위에 들어 있습니다.
