# 두 보완 재검토: 최종 승인

1. **검색 클릭의 원래 버튼 보존:** 8개 요구와 일치합니다.
   - 검색이 이미 열려 있으면 클릭이 원래 버튼(`/`로 열기 전 초점)을 덮어쓰지 않습니다.
   - 검색이 닫혀 있을 때의 클릭·터치는 지금처럼 검색 입력을 원래 버튼으로 기록하고 검색을 다시 엽니다.
   - 터치에서 onFocus와 onClick이 차례로 실행돼도 결과가 같습니다.
2. **선택 카드 X 툴팁 위치(`data-tip-side="top"`):** 일치합니다. 기존 위쪽 툴팁 규칙을 그대로 씁니다.
   - **확인할 점(확정 문제 아님):** 위쪽 툴팁은 버튼 가운데에 맞춰 놓입니다. X는 카드 오른쪽 끝 버튼이라 "구조 선택 해제" 문구가 카드 오른쪽 경계에서 잘릴 수 있습니다. 캡처에서 오른쪽 끝을 봐 주세요.
   - 잘린다면 `.view-tools`의 마지막 버튼처럼 오른쪽 정렬 규칙을 추가하면 됩니다.

추가 확정 P1/P2는 없습니다. **최종 승인합니다.**

**검토 범위:** 위 두 패치의 내용만 정적으로 읽었습니다. 테스트·빌드·브라우저는 직접 실행하지 않았고, 통과 결과는 주 에이전트의 보고에 따릅니다.
