# 최종 패치 정적 재검토: 승인 (확정 P1/P2 없음)

`implementation.diff`와 새 `panel-keyboard.spec.ts`만 읽었습니다. 실행 결과는 주 에이전트의 보고를 그대로 따릅니다.

## 합의한 8개 요구 충족 여부 (코드 기준)

1. **검색 단축키 초점 복귀:** 충족.
   - `/` 처리는 원래 버튼을 기록한 뒤 검색 입력에 초점을 줍니다.
   - 이때 `focusWithoutOpeningSearch`가 동기 ref로 onFocus를 막아, 기록이 덮어써지지 않습니다.
2. **패널 없는 Escape:** 충족.
   - `if (!panel || e.defaultPrevented) return`으로 아무 동작도 하지 않습니다.
   - 키 처리는 `[panel]` 의존성으로 다시 등록됩니다.
   - 초점 복귀는 `requestAnimationFrame` 안에서 같은 억제를 거칩니다. 모바일에서 숨겨졌던 경혈 칩이 다시 보인 뒤 초점이 갑니다.
3. **상세 탭:** 충족.
   - 좌우 순환, Home/End, 선택 탭만 `tabIndex=0`을 구현했습니다.
   - `aria-controls`/`aria-labelledby`를 `useId`로 연결했습니다.
   - 패널은 `tabIndex=0`이고, 초점 표시 CSS를 공유합니다.
   - 클릭으로 탭을 바꾸는 경로는 그대로입니다.
4. **여성 CT 버튼:** 충족.
   - 성공한 비교의 후보는 `state.comparison.pointId`와 성별에서 `useMemo`로 도출합니다.
   - 성공 시 로컬 상태는 `[]`로 두고, 실패 안내만 로컬 상태로 유지합니다.
   - 새 상태 전이는 없습니다.
5. **주소 없는 `#atlas`:** 충족.
   - `App.tsx`의 `|| viewState.pointId`로 저장된 경혈을 씁니다.
   - 비교 문구는 `comparisonPoint?.name`에서 가져오므로, 합의 조건대로 `#atlas/FAKE`도 막힙니다.
6. **대체 경혈:** 충족. `structures`/`landmarks`를 비웠습니다.
7. **단독 보기 문구:** 충족.
   - "비교 대상만 보기"는 `state.comparison`이 있을 때만 씁니다.
   - 인대·힘줄 묶음과 그 밖의 묶음은 다른 문구로 구분합니다.
   - 기존 테스트·스크립트의 이 문구는 모두 비교 경로에서만 쓰여 영향이 없습니다.
8. **아이콘 설명:** 충족. 버튼 3개에 `data-tip`을 추가했습니다. 닫기 버튼에 `position`을 덮어쓰는 규칙이 없어 위치가 바뀌는 문제는 없습니다.

모델, 좌표, 박리 규칙, `view-state.ts`는 바뀌지 않았습니다.

## 남은 사소한 점 (P3, 이번 승인에 영향 없음)

- `/`로 연 검색 안에서 커서를 옮기려 입력을 클릭하면, 새 onClick이 기록된 원래 버튼을 검색 입력으로 바꿉니다. 그 뒤 Escape를 누르면 원래 버튼이 아니라 검색 입력에 초점이 남습니다.
- 데스크톱에서 표시 설정 패널과 선택 카드가 함께 열려 있으면 "인대·힘줄만 보기" 버튼이 두 개 보입니다. 하나는 묶음을 여는 버튼, 하나는 단독 보기 토글이라 기능이 다릅니다. 새 테스트는 카드 범위로 한정해 찾으므로 영향이 없습니다.
- 선택 카드 X의 툴팁이 카드 영역 밖으로 나갈 때 잘리는지는 시각 검사에서 확인해야 합니다.

## 후속으로 둘 것 (이번 패치 실패로 보지 않음)

- 비교 후 `alpha.skin` 12% 잔류. `comparison-clear.spec.ts:47`이 이 동작을 고정하고 있으므로 후속에서 기대값을 함께 고칩니다.
- "인대·힘줄만 보기"의 layers 모드 복귀와 `connective` 선호 강제 켬.
- 여성 근사 표식을 켠 뒤에도 남는 이전 안내.
- 사용하지 않는 `reset` 액션 정리 여부.

AGENTS 규칙에 따라 요구사항/증거 표와 VERIFICATION 기록은 따로 갱신해야 합니다. 이 diff에는 들어 있지 않습니다.

## 검토 한계

정적 검토만 했습니다. 브라우저, 빌드, 테스트는 실행하지 않았습니다. 최종 브라우저 검사 19개의 결과와 시각·가독성·프로덕션 검사는 확인하지 못했습니다. 전체 소스는 다시 탐색하지 않았습니다.

**결론: 이 패치 범위를 승인합니다.** 단, 실행 중인 최종 19개 검사와 주 에이전트의 시각 검사가 통과하는 것이 전제입니다.
