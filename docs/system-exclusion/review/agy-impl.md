# AGY 구현 교차 검증 (2026-10-25, Gemini 3.8 Flash high, 사양 검토와 같은 대화)

### 결론: 승인

‘계통 빼기’를 별도 버튼·모드에서 박리 레일 각 행의 ‘포함’ 체크박스로 통합하는 구현이 결함 없이 완벽히 완료되었습니다. 사양 검토 단계에서 지적된 5개 사항이 코드와 검사 모두에 빠짐없이 반영되었으며, 12개 화면 크기 전반에서 레이아웃 안전(45% 상한, 44px 터치, 12px·대비 기준)과 접근성·상태 불변식이 철저히 검증되었습니다.

---

### 검토 항목별 상세 평가

1. **요청 충족 (완료)**
   - 별도 ‘계통 빼기’ 버튼(`.exclude-toggle`), 팝오버 선택기(`.exclude-picker`), ‘완료’ 버튼(`.exclude-done`)이 DOM과 CSS에서 완전히 제거되었습니다.
   - 각 계통 행에 `[포함 체크][이름 버튼][만 보기 눈]`이 배치되어 박리 화면 자체에서 직접 제어됩니다. 비박리 모드(단독 보기·비교 등)에서는 체크가 비활성 정적 견본(`.ax-keep.is-static`)으로 자동 전환되어 조작 혼선을 방지합니다.

2. **사양 검토 지적 해결 현황 (5/5 해결)**
   - **`toggleKept` 스코프 오류**: `AtlasPage.tsx:689`에서 `layerNames[layer]`를 직접 참조하도록 수정되어 런타임 오류 없음 (**해결**).
   - **터치 태블릿 시각 피드백 부재**: `AtlasPage.tsx:745` 및 `atlas.css:362`에 `.ax-depth .ax-row-note`를 신설하여, 툴팁이 없는 1024×680 터치 레일에서도 거부/안내 사유가 해당 행 옆에 시각 말풍선으로 노출됨 (**해결**).
   - **가로 701–760px 자동 검증 누락**: `tests/browser/system-exclusion.spec.ts:885`에 `710×360` 뷰포트 기하·가독성 검증이 추가되어 통과함 (**해결**).
   - **가로 띠 `left` 및 `--lw` 계산 오차**: `atlas.css:820`에서 `left: calc(100% + 9px)`로 조정하여 `x = 142px`를 정확히 맞추고, 701px 폭에서도 우측 10px 여백(`--ax-gap`)을 온전히 보장함 (**해결**).
   - **사양서 오타**: `system-exclusion.spec.ts:421`에서 `"장기 포함"`으로 정상 수정됨 (**해결**).

3. **새로 생긴 문제 및 회귀 검증 (통과)**
   - **레이아웃 & 수치**: 12개 크기에서 도구 비중첩 확인. 45% 패널 규칙 준수(휴대폰 33~38%, 가로 28.9~31.6%, 비교 모드 40.7~44.7%). 터치 44px 대상 확보(701–715px 가로 40–44px 한계 기록).
   - **가독성 & 대비**: `check-readability.mjs` 검사 결과 12개 표면 155개 텍스트 표본 전수 12px 이상 및 대비 4.5:1 이상 통과. 견본 대비 ≥3.67:1, 잉크 대비 ≥3.60:1 합격.
   - **접근성 & 초점**: 21개 탭 스톱 유지, `aria-disabled` 요소 초점 보존, 띠 내 조작 후 띠 닫힘 및 토글 버튼으로 초점 복귀(`leaveBand`), 화면 낭독기 상태 알림(`.ax-vh[role=status]`), Escape 계층 닫기 모두 정상 동작.
   - **상태 규칙**: `view-state.ts` 우회 없음, 7개 전체 제외 방지 및 팔·손 장기 멈춤 불변식 유지.
   - **타 기능 회귀 없음**: 눈 버튼 명칭 변경('○○ 빠른 보기' → '○○만 보기')에 맞추어 연관된 9개 브라우저 스펙 일괄 갱신 완료. 단위 검사 474/474, 계통 빼기 브라우저 검사 21/21, 오버레이 감사 8화면 94상태, 시각 게이트 4화면 모두 통과.

4. **사용성 (우수)**
   - 데스크톱/태블릿 레일 상단에 열 이름(`.depth-cols`: `포함 · 박리 · 만 보기`), 모바일 띠에 범례(`포함: 넣고 빼기 · 이름: 여기까지 박리 · 눈: 이것만 보기`), 미제외 시 안내 문구(`체크를 끄면 박리에서 뺍니다`)가 배치되어 초보 사용자도 행 안의 세 조작 역할을 명확히 인지할 수 있습니다.
