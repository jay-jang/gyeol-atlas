## 통과한 검사

- `npm run build`: 앵커·위키 생성, TypeScript, Vite 빌드 통과. 큰 3D 청크 경고는 남지만 위키에서 미리 로드하지 않습니다.
- `npm test`: 11개 통과. 220개 실제 메쉬와 65개 표면 투영, 분류 집합, 참조 무결성, 검색·HTTP·선택적 LLM 계약 검사.
- `npx playwright test tests/browser/anatomy.spec.ts`: 2개 통과. 여섯 단계, 실제 메쉬 클릭, 단독 보기·확대·절개, 분류·장기 비교, 390px 모바일 조작 및 가로 넘침 없음.
- `npx playwright test tests/browser/site.spec.ts`: 3개 통과. 기존 경혈 클릭·검색·저장·카메라·위키·출처, 모바일, 잘못된 링크, GLB 실패 시 문서 사용.
- `npm run test:production`: 로컬 배포 빌드에서 6개 모델과 API 확인.
- `SMOKE_ORIGIN=https://veterans-curtis-inquiries-configurations.trycloudflare.com npm run test:production`: 실제 공개 HTTPS에서 6개 모델, 문서 45편, 원혈·모혈/마사지 질문 응답, 새 위키 탐색 링크, 브라우저 오류 0건 확인.

## 적용 한계

- 신경은 뇌 구조·양측 시신경 범위이며 척수·전신 말초신경을 포함하지 않습니다. 혈관도 전신 미세혈관 전체가 아닙니다.
- 한 모델의 근사 위치입니다. 65개 앵커의 표면 일치는 임상 경혈 위치 정확도를 입증하지 않습니다. WHO 위치 요약은 원문 재현본과 대조했고 전문가 미검수 상태입니다.
- 전통적 장부 대응과 실제 장기의 기능·치료 효과는 같지 않습니다. 체표를 눌러 내부 장기를 직접 마사지할 수 있다는 근거로 사용하지 않습니다.
- 36개 경혈은 WHO 361개 전집이 아닙니다. 오수혈과 낙혈은 부분 수록입니다.
- Ollama는 선택적 연결이며 실제 모델 생성 품질 평가는 하지 않았습니다. 현재 공개 서비스는 출처 기반 위키 검색으로 응답합니다.
- Cloudflare 주소는 임시 터널이며 현재 서버·터널 프로세스에 의존합니다. 고정 도메인과 자동 재시작은 설정하지 않았습니다.
