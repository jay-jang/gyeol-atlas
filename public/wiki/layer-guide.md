# 인체 구조도 위에서 탐색하기

체표·근육·골격·장기·혈관·신경의 여섯 계통을 같은 화면에서 살펴봅니다. 계통은 관찰 주제이며 전신에 동일하게 적용되는 조직의 깊이 순서가 아닙니다.

## 도구와 화면

왼쪽 떠 있는 도구에 마우스를 올리거나 키보드 초점을 두면 이름이 나타납니다. 클릭·터치로 경혈 찾기, 레이어 조절, 구조 찾기, 도움말을 엽니다. 모바일은 모델을 남겨 두고 아래쪽에 패널을 표시합니다. 닫기 버튼이나 Escape로 패널을 닫습니다. 오른쪽 경혈 이름을 누르면 위치·분류·출처를 읽을 수 있습니다.

모델을 클릭하거나 탭으로 초점을 둔 뒤 WASD 또는 방향키로 앞뒤좌우 이동, Q/E로 아래위 이동, Shift로 빠르게 이동합니다. 화면의 이동 버튼은 터치로도 사용합니다. 검색 입력 중에는 이동하지 않습니다. 드래그는 회전, 스크롤·핀치는 확대, 두 손가락 또는 우클릭 드래그는 이동입니다. 정면·후면·측면·확대·축소 버튼과 구조 검색은 키보드로도 이용할 수 있습니다.

## 같은 부위를 계속 비교하기

상단 계통 버튼으로 모델을 바꾸어도 관찰 시점과 경혈 표식 선호는 유지됩니다. 새 계통이 현재 시야에 없다면 ‘계통 전체 보기’를 누릅니다. 레이어 조절에서는 여러 계통을 함께 켜고 각각의 불투명도를 바꿉니다. 레이어 구성을 바꾸면 단독 보기는 해제됩니다.

경혈 표식은 숨김·선택 경혈만·필터 결과 전체 중에서 정합니다. 표식은 체표 위치이며 뒤쪽도 찾을 수 있도록 투과 표시됩니다. 실제 내부 장기 표면의 점을 뜻하지 않습니다.

## 구조와 장부 비교

구조 찾기에서 한국어명, 영어 원문 또는 FMA 코드를 검색합니다. 검색 목록은 계통별이며, 꺼진 계통의 구조를 선택하면 해당 레이어가 켜집니다. 한국어 명칭은 탐색을 위한 편집 표기이며 영어 원문과 FMA 식별자를 함께 제공합니다.

선택 구조 카드에서 확대·단독 보기·선택 해제를 조작합니다. 경혈 상세의 장부 비교를 누르면 위는 1개, 콩팥은 2개, 폐는 5개 메쉬 전체를 묶어 비교합니다. ‘비교 대상만 보기’는 묶음 전체를 표시합니다. 전통적인 심포·삼초에 단일 장기 메쉬를 임의로 지정하지 않습니다.

청록색은 직접 선택한 구조, 금색은 전통 장부 대응, 옅은 황갈색은 경혈의 해부학적 참조입니다. 장부 대응은 실제 압력 전달이나 치료 효과를 뜻하지 않습니다.

장부 비교에서는 체표를 통과해 내부 구조를 클릭합니다. ‘클릭 선택 대상’에서 보이는 구조·내부 구조·체표를 직접 바꿀 수 있습니다. 불투명도만으로 클릭 대상이 자동 변경되지는 않습니다.

## 시야 확보와 돌아오기

‘앞쪽 구조 일부 숨기기’는 인체의 앞에서 뒤 방향으로 메쉬 일부를 숨깁니다. 잘린 면을 채우지 않으며 실제 조직 단면·압박 깊이를 재현하지 않습니다. 초기화 버튼으로 되돌립니다.

위키를 읽고 ‘이전 경혈 3D 보기로 돌아가기’를 누르면 경혈·레이어·비교·카메라를 복원합니다. 같은 탭의 세션에 저장하며 새 탭이나 저장소 초기화 후까지 보존하는 계정 기능은 아닙니다.

## 수록 범위

체표 1개, 골격·치아 129개, 근육·힘줄·근막 437개, 장기·부속 67개, 혈관 56개, 신경계·관련 공간 340개, 총 1,030개 메쉬를 수록합니다. 기존 3.0 모델의 근육계·신경계 누락 구조를 포함하고 공식 4.3 자료의 척수 신경조직·뇌신경·목과 상지의 신경을 보완했습니다. 척수 중심관은 공간 모델이며 척수 신경조직과 구분합니다. 말초신경은 원본의 일부 부위만 있으며 좌우가 모두 수록된 것은 아닙니다. 혈관도 모든 미세혈관을 포함하지 않습니다.

각 구조는 한 원본 모델에서 변환·경량화한 메쉬입니다. 개인별 위치 차이를 표현하지 않습니다. 화면에 없는 혈관이나 신경이 실제로도 없다는 뜻은 아닙니다.
