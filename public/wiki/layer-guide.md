# 인체 구조도 위에서 탐색하기

체표·근육·골격·장기·혈관·림프·신경을 어두운 관찰 화면에서 함께 살펴봅니다. 연속 박리 슬라이더는 0~100%, 0.5% 간격의 201개 설정값을 사용합니다. 체표의 앞쪽이 점진적으로 잘리고 투명해진 뒤, 근육 메쉬가 계산된 표면 근접도에 따라 서로 다른 시점에 사라집니다. 골격·장기·혈관·림프·신경이 겹쳐 나타나며, 박리 중 구조의 원래 좌표를 이동시키지 않습니다. 퍼센트는 실제 조직 깊이의 측정값이 아니라 보기 순서입니다.

슬라이더 카드 위 휠은 0.5%씩 이동합니다. 3D 모델 위에서는 `Alt`(macOS는 `Option`)+휠 또는 `Alt/Option + ↑/↓`로 0.5%씩 바꿉니다. `Shift`까지 누르면 5%씩 이동합니다. 보조키 없는 모델 위 휠은 카메라 확대·축소입니다. 계통 빠른 보기와 개별 기관 선택은 박리 불투명도와 독립된 보기 모드입니다.

근육 박리 순서는 모델의 공간 배치와 크기로 계산한 시각적 근사이며 전문가가 부여한 근막층·수술층 분류가 아닙니다. 개별 부위의 정확한 층 관계는 구조를 선택·단독 확대하고 해부학 자료와 함께 확인해야 합니다.

## 도구와 화면

왼쪽 떠 있는 도구에 마우스를 올리거나 키보드 초점을 두면 이름이 나타납니다. 클릭·터치로 경혈 찾기, 레이어 조절, 구조 찾기, 도움말을 엽니다. 모바일은 모델을 남겨 두고 아래쪽에 패널을 표시합니다. 닫기 버튼이나 Escape로 패널을 닫습니다. 오른쪽 경혈 이름을 누르면 위치·분류·출처를 읽을 수 있습니다.

모델을 클릭하거나 탭으로 초점을 둔 뒤 WASD 또는 방향키로 앞뒤좌우 이동, Q/E로 아래위 이동, Shift로 빠르게 이동합니다. 화면의 이동 버튼은 터치로도 사용합니다. 검색 입력 중에는 이동하지 않습니다. 드래그는 회전, 스크롤·핀치는 확대, 두 손가락 또는 우클릭 드래그는 이동입니다. 정면·후면·측면·확대·축소 버튼과 구조 검색은 키보드로도 이용할 수 있습니다.

## 같은 부위를 계속 비교하기

계통 빠른 보기 버튼으로 모델을 바꾸어도 관찰 시점과 경혈 표식 선호는 유지됩니다. 새 계통이 현재 시야에 없다면 ‘계통 전체 보기’를 누릅니다. 레이어 조절에서는 여러 계통을 함께 켜고 각각의 불투명도를 바꿉니다. 레이어 구성을 바꾸면 단독 보기는 해제됩니다.

표현색은 의학 아틀라스의 일반 관례를 따라 피부색, 근육 적색, 골격 상아색, 동맥 적색·정맥 청색, 신경 황색으로 구분합니다. 데이터 출처 자체의 원색을 재현하거나 하나의 국제 강제 표준을 의미하지는 않습니다.

경혈 표식은 숨김·선택 경혈만·필터 결과 전체 중에서 정합니다. 표식은 체표 위치이며 뒤쪽도 찾을 수 있도록 투과 표시됩니다. 실제 내부 장기 표면의 점을 뜻하지 않습니다.

## 구조와 장부 비교

구조 찾기에서 한국어명, 영어 원문 또는 FMA 코드를 검색합니다. 검색 목록은 계통별이며, 꺼진 계통의 구조를 선택하면 해당 레이어가 켜집니다. 한국어 명칭은 탐색을 위한 편집 표기이며 영어 원문과 FMA 식별자를 함께 제공합니다.

선택 구조 카드에서 확대·단독 보기·선택 해제를 조작합니다. 주요 기관 또는 ‘기관 상세 보기’를 누르면 원본의 기관 하위 관계에 포함된 세부 모형만 표시합니다. ‘세부 구조 선택’에서 개별 구조를 고르고, ‘기관 전체 모형’과 ‘전신으로 돌아가기’로 범위를 바꿉니다. 남성 심장83·간60·폐280개 상세 모형은 전신 모형과 출처 좌표가 달라 별도로 표시합니다. 원본이 단일 메쉬인 기관에는 존재하지 않는 세분 모형을 만들지 않습니다.

경혈 상세의 장부 비교는 기관 상세 모드와 다릅니다. 남성 전신의 위1개·콩팥2개·폐5개를 묶어 비교합니다. 여성은 같은 기관의 여성 원본 묶음으로 비교하며, 여성 원본에 없는 위는 미수록 알림을 표시합니다. 전통적인 심포·삼초에 단일 장기 메쉬를 임의로 지정하지 않습니다.

청록색은 직접 선택한 구조, 금색은 전통 장부 대응, 옅은 황갈색은 경혈의 해부학적 참조입니다. 장부 대응은 실제 압력 전달이나 치료 효과를 뜻하지 않습니다.

장부 비교에서는 체표를 통과해 내부 구조를 클릭합니다. ‘클릭 선택 대상’에서 보이는 구조·내부 구조·체표를 직접 바꿀 수 있습니다. 불투명도만으로 클릭 대상이 자동 변경되지는 않습니다.

## 시야 확보와 돌아오기

‘앞쪽 구조 일부 숨기기’는 인체의 앞에서 뒤 방향으로 메쉬 일부를 숨깁니다. 잘린 면을 채우지 않으며 실제 조직 단면·압박 깊이를 재현하지 않습니다. 초기화 버튼으로 되돌립니다.

위키를 읽고 ‘이전 경혈 3D 보기로 돌아가기’를 누르면 경혈·레이어·비교·카메라를 복원합니다. 같은 탭의 세션에 저장하며 새 탭이나 저장소 초기화 후까지 보존하는 계정 기능은 아닙니다.

## 수록 범위

BodyParts3D 계열의 검색 모델은 체표 1개, 골격·치아·연골 278개, 근육·힘줄·근막 437개, 장기·부속 67개, 혈관 56개, 신경계·관련 공간 340개, 총 1,179개 메쉬입니다. 골격에는 좌우 손가락·발가락 마디뼈 56개와 손목·발목뼈가 포함됩니다. 여기에 혈관640개·신경525개의 좌우 전신 Z-Anatomy 구성요소를 모두 개별 검색·클릭 대상으로 연결해 총 2,344개 카탈로그 항목을 제공합니다.

전신 혈관·신경 항목은 편집 한국어명, 원문 영어명, TA2 라틴명, 해부학 계층 경로로 찾을 수 있습니다. 선택 카드에는 동맥·정맥·신경·신경얼기·신경절 등 확인 가능한 범주 설명과 출처를 표시하며, 확대와 단독 보기를 지원합니다. 이 설명은 계층 메타데이터에 근거한 학습용 분류이고 개별 구조의 모든 기능·지배 영역을 임상적으로 검증한 설명은 아닙니다. 미세혈관과 말초 신경 말단까지 실제 인체의 모든 구조를 빠짐없이 재현한다는 뜻도 아닙니다.

BodyParts3D와 Z-Anatomy 보완 모델은 같은 계보와 유사한 전신 좌표 범위를 사용하지만 임상적으로 정합한 것은 아닙니다. 개인별 위치 차이를 표현하지 않으며, 화면에 없는 미세 구조가 실제로도 없다는 뜻은 아닙니다.

여성 보기는 남성 전신과 분리한 HRA 여성 표면·기관을 사용합니다. 여성 원본964개, 다른 여성 기증자 하체 근육76개, 남성 유래 보완 골격180개로 총1,220개 구조입니다. 보완 골격은 회청색으로 출처를 구분합니다. 임신 참조8개는 개별 선택 시에만 보이며, 같은 넙다리곧은근의 기증자 중복은 기본으로 숨깁니다. 위·상체 근육·일부 말초신경은 미수록입니다. 여성 표면의 경혈 좌표는 검수 전이므로 표식과 경혈 좌표 확대를 제공하지 않습니다. 경혈 문서와 여성 원본이 있는 장부 비교는 이용할 수 있습니다.
