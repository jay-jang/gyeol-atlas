
# 모델 좌표와 검수 이력

**좌표 상태: 학습용 근사 · 전문가 미검수.** 문헌의 위치 설명을 화면에 대응시킨 편집 좌표이며, WHO가 제공한 좌표가 아닙니다.

## 생성 과정

1. BodyParts3D v3.0 STL의 공통 좌표계를 유지해 피부·뼈·근육을 가져옵니다. 공식 4.3 자료에서 보완한 신경·장기 OBJ에도 같은 공통 좌표 변환을 적용합니다. 각 파일의 버전·이름·FMA와 원본 해시를 확인하며 독립적인 임상 정합을 수행한 것은 아닙니다.
2. 축을 Y-up으로 바꾸고 밀리미터를 미터로 변환합니다. 각 부위를 별도로 중심 이동하지 않습니다.
3. 해부 구조의 경계와 문헌 기준점을 보고 초기 앵커를 수작업으로 설정합니다.
4. 각 앵커를 해당 방향에서 피부에 투영하고 화면 표식을 위해 3 mm 띄웁니다. 이는 표시 오프셋이며 신체 치수가 아닙니다.
5. 좌우 대응점은 초기 앵커를 반사한 후 각쪽 피부에 따로 투영합니다. 모델의 비대칭과 개인차를 완전히 교정하지는 못합니다.

## 검수 이력

2026-09-07: AI가 자료를 조사하고 초안을 작성했습니다. WHO 문서 재현본의 경혈 항목·쪽수를 대조했습니다. 의료 전문가의 임상 위치 검증이나 사람 대상 정확도 평가를 진행하지 않았습니다.

모델 자체도 단일 남성 형상에 기반합니다. 메시 단순화로 작은 표면 특징이 소실될 수 있습니다. [원 모델과 한계](https://lifesciencedb.jp/bp3d/info/index.html)

## 다시 검토해야 할 항목

전문가 검수 시에는 원문 위치, 모델 자세, 좌우, 표면 투영 방향, 해당 메쉬 ID를 함께 확인합니다. 수정 이유·검수자·날짜를 데이터에 남겨야 합니다. 검수가 끝나기 전에는 `illustrative` 상태를 바꾸지 않습니다.

## 409개 명칭의 표시 범위

2026-09-16 확장: 양측·복수 위치를 포함한 834개 표식을 편집했습니다. 협척은 34곳, 사신총은 4곳, 십선·기단은 각각 10곳입니다. 서로 다른 명칭이 같은 부위를 포함할 수도 있습니다.

얇은 손끝·발끝에서 축 방향 투영이 닿지 않을 때는 초기점에서 25mm 이내의 가까운 피부 삼각형을 사용합니다. 이 거리 제한과 피부 위에 있다는 검사는 경혈의 해부학적 위치 정확도를 보장하지 않습니다. 모델의 구부러진 손가락과 개인 비례 때문에 문헌 기준점과 차이가 남습니다.

입·코 안의 GV28·내영향·취천·해천·금진·옥액은 외부 체표 표식을 **부위 참조**로 표시합니다. 이것을 실제 내부 위치로 읽지 않습니다. 새 경혈의 개별 기준점 메쉬 연결은 대부분 미완료이며, 기존 36개 연결은 유지합니다. 표식이 피부에 놓인 것과 모든 해부 구조를 연결한 것은 다른 검증입니다.
